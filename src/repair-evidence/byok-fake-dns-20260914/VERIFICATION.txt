ROOT_CAUSE=The Linux host's Mihomo/Sakurai fake-DNS mode returns 198.18.0.0/15 and fdfe:dcba:9876::/48 proxy addresses. The SSRF guard treated those non-global transport addresses as a private destination, so PUT /v1/account/model-config failed with HTTP 500 before persistence even when base URL, model and key were valid.
FIX=For only the two recognized fake-DNS proxy ranges, verify the hostname independently through the fixed Cloudflare DNS-over-HTTPS endpoint and require every returned A/AAAA address to be globally routable. Continue rejecting loopback, private, link-local, metadata and every other non-global address. Convert DNS transport validation failures into typed HTTP 422 provider-configuration errors instead of generic HTTP 500.
