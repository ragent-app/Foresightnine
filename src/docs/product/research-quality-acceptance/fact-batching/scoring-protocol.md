# 分批事实记录实验：冻结判读与验收

冻结于新实验结果判读前；此文件约束 D1–D4 全批次，非效果事后定标。题目及材料以 `../cases.json` 为准，历史比较以 `../e1-preregistration.md`、`../e1-index.json` 和原始 `../e1-results/` 为准。本实验 A 是 E1 的 B（完整需求反馈、原事实记录策略），本实验 B 在同一冻结实现上增加分批事实指令；不得把本实验 A/B 与历史 E1 A/B 当作相同分组。每题两臂各两次，AB/BA 串行，以题号及重复序号配对；一个观察单位是完整运行，不是单次工具调用或片段。四题共 16 轨。实验侧须在运行前另行冻结代码、实际提示与工具 schema、模型协议及非秘密配置并记录指纹。

每运行最多 4 次模型调用、160000 预算核算 token、单次最多 2048 输出 token、180 秒进程边界、零外部搜索；非用户产品默认预算。保存实际调用次数、returned/settled 状态、reported 和 budget-accounted 用量、耗时、缓存和实际费用（不可得即未知）。分别保留逐轨完整原始回执、状态、工具输入输出、事实、计算、报告及中止原因；凭据与端点不写出。未启动不作失败、也不放入已执行分母；预定数量和未启动原因单列。外呼状态或结算不明时停止批次并标未知，不补发该轨；截断仅在已返回且结算明确时计失败并可按实验驱动规则继续。预算终止不等同供应商或认证故障。

## 判读记录和分母

盲于实验臂独立检查原始结果与冻结题目，在评分表中保留每项的来源位置、事实 ID、计算 ID、工具回执或原文摘录、判读及未判理由。盲态不可实现则记录事实；本地自动核查不称为独立人工复核。未知与错误分开，含未知分子的结果写上下界：已确认有据 / 已执行全部核心项，及（已确认有据 + 未知）/ 已执行全部核心项；不把未知排除后称作总通过率。每题固定两核心项，每实际启动轨分母 2（不按模型生成行数、状态或已回答行数更改）；因结果缺失或状态不明而无法检查时两项记未知。已知截断但保有可检查检查点，则照常判已保存项，未保存项计未有据，不能以截断为理由删轨。既报告预定 16 轨的执行情况，也报告已启动全部分母；不把缺失文件当成零或未经核实的未启动。

正式提交与核心项分开：仅在 `submit_research` 成功工具回执且对应服务端/检查点结果证实提交被接受时计入正式提交；完成和部分提交分别统计，不能凭工具名、正文、模型自述或 `status` 单独判断。无成功回执或被拒绝是未提交；证据不完整而无法判定的为未知。未提交产生的 `partial` 单列被动 partial，不并入正式 partial。按已启动轨为分母报告已接受 completed、已接受 partial、被动 partial、其他确定未提交和提交状态未知，须互斥并交代数量；同时报告正式提交率的确认值和未知上界。对于每个核心项，保存的证据和计算可在未正式提交时计入 E1 兼容的检查点指标，但绝不称为已交付答案。

具体核心项：

| 题 | 核心项 1 | 核心项 2 |
| --- | --- | --- |
| D1 | Alpha 2025/2024 收入 120/100 USD million，原文位置可查，计算 `(120/100-1)*100=20%`，数据与计算绑定。 | 稀释 EPS 两期 3/2 USD 每股，原文位置可查，可复核差额 `3-2=1 USD/股`，且绑定事实；50% 增幅本身不能替代差额。 |
| D2 | Beta 两期收入及 20% 同 D1。 | 明确说明 **2024 年稀释 EPS 缺失**，因此无法计算 EPS 变化，限于已检查的冻结材料；只有未编造或泛称可比期间待核验不足。 |
| D3 | Gamma 两日调整收盘 10/12，收益 20%，证据和计算可检查。 | 基准 100/110，收益 10%、超额 10 **百分点**，标的与基准绑定共同窗口及调整口径。 |
| D4 | Delta 两日 10/12 的调整收盘收益 20%，证据和计算可检查。 | 明确无基准观测，两个 Delta 调用是同一标的的重复，不能充作基准，因而不能计算基准及超额收益。泛称需不同标的不够。 |

D3/D4 原样仅提供相对日合成文本，不是结构化行情或真实共同交易日回执；不能用题目文本虚构工具取得的行情、日期或真实市场能力。保留材料缺口；若新轨有结果而其证据可支持到何种程度仍存争议，标未知并说明，不事后换资料或把未独立核验的语义支持当作已验证。D1/D2 对照 E1 检查可定位合成数值及保存计算；相关事实与计算的相互绑定可由计算输入的 fact ID 验证。保存的差额计算可计入 D1 检查点，即使分项文字只显示 50%；这是对 E1 的兼容口径，单独检查最终交付措辞是否明确差额。支持原始资料语义的独立核验仍是未知，不升级为真实研究质量认证。

D2 和 D4 分别另记：明确缺口披露 / 无具体披露 / 未知；有无编造缺失值另记有 / 无 / 未知。无事实或无回答并未编造，不等于正确披露；记录检查范围，不能将工具内部提示或静默当成用户可见披露。重复需求行、已答行残留未答理由、实际核心项遗漏分别记录，重复行不扩张分母，重复调用不得成为独立来源或基准；发现错误数据或不相关调用列举证据，不自动抵消其他可核查核心项。事实/计算的存在、用户可见分项与最终报告各自记录，避免以内部提示代替输出。输出截断无论发生第几调用均保留，按既有检查点评分；未知发送或结算另列，禁止假定无成本或重新发送。

## 比较和结果报告

每题每重复报告 A、B：正式提交类别、两个核心项、负面披露、重复/缺失、截断及回执状态、调用、两种 token、耗时、费用。按同题同重复报告 B−A（正式提交指示、核心项 0–2 与 token、调用、耗时），未知对不计算数值差，列明缺失；同时按题汇总各臂有据项/4 和正式提交/2，并给整体各臂有据项/16、正式提交/8（仅满批时）。披露 D2/D4 各自每臂分母 2。成功率、缺口和资源指标并列，不以总体均值掩盖每题/重复。输出分项配对值和方向，样本少只作探索，不宣称统计显著或总体优势；时间/用量对比必须披露缓存、不可锁模型版本、实际失败与额外混杂。预先不设置虚构质量阈值；验收结论为证据是否足以支持具体差异，仍需泛化、独立复核及真实资料实验。

历史 E1 重放用于统一判读，不是新实验基线配对。`scoring-replay.py` 只针对已知历史 16 轨进行离线、确定性事实位置、计算 ID 及调用结算核验；负面披露以检查点原文人工语义检查为准，脚本中的短语断言只是回归警报，不是通用自然语言评分器。新结果不可直接套用该脚本自动得分；须按本文件逐轨保存有证据的判读和复核状态，再汇总。任何裁决修改要记录时间、原因和前后值，不能静默改阈值。

## 表达等价与审查记录

按语义及证据判定，不要求固定中英文、字段标签、事实录入顺序、批次或 ID：如 `revenue`、`收入`，`diluted EPS`、`稀释每股收益`；FY2025、2025 财年及其明确对应区间；`USD million`、百万美元、1.2 亿美元，数值单位换算一致且币种、主体、期间和口径可核实即可。EPS 差额 `+1 USD/share`、`增加每股 1 美元`、从 2 增至 3、以事实绑定的差额计算等，按可复算的同一经济含义判定；只报告 50% 且没有可检查差额，不能凭空补齐。引用不必逐字相同或依赖固定偏移，只要来源身份明确、实际引用或对应位置可定位并支持所述主体、数值、期间及口径即可；含糊引用、未经证明的跨主体/期间推断不能算。计算以相应证据绑定及运算正确为准，不要求固定公式名；不同排序应依表达式判断方向。最终记录原始数值、归一化单位、原文位置、计算式和结果及用户可见位置，必要时标语义未知；这些等价规则不能把题外数据或不同市场口径变成冻结证据。

独立判读表对每轨每项留 `case/arm/repeat`、原始回执路径及 SHA-256、核心项编号、`supported/unsupported/unknown`、原文定位及内容、事实与计算 ID/引用、单位期间归一化、复算、可见位置、理由和判读者/复核状态。另记提交回执与检查点路径、负面披露及无编造证据、重复/缺失、截断与结算、用量、预算、异常及未判原因。逐项保留，不只交合计；状态未知时不要猜测。历史重放脚本对英文标签、字段结构做了专用检查，仅适合现存 E1，不能拿其字面匹配限制新实验的等价表达。
