# 外呼前评分冻结：计算契约配对

已启动标记为唯一分母：每臂最多 8 轨，每轨 2 核心项；中止后未启动轨不算失败、不补发。结果缺失、损坏或无法判定记 unknown，报告已确认下界与含未知上界。配对按题和重复号匹配；仅两臂均有确认值才计算差，其他保留 unknown。禁止按结果调整判定或挑选轨迹。

正式提交仅在终态 reason=submitted、对应 submit handler 正常返回且其 early_outcome 与终态 status/reason 相符、handler 保存的 submission 与最终 state_submission 相同、工具调用 ID 对应且回执中的提交内容与终态一致时计 accepted。已知被动终止且没有接受回执与状态为 not_accepted；证据缺失或互相矛盾为 unknown。partial 可以是正式提交，但其模型自由文字仅保存在 partial_notes，不能把它当已验证正文。只要无法确认完成状态就不认定正式提交。

逐项人工语义审计，不盲态、不用模型。读取原始资料和可定位原文，核对主体、指标、期间、公式、单位、计算值、有序引用，明确区分引用本身、已保存计算或有出处负向说明、正式正文呈现、终态用户可见呈现。D1 收入应是 120/100 的 20%，EPS 题按冻结评分要求 3−2=+1 USD/股；仅 50% 增幅不足。D2 收入同样核对；另一项要求明确资料未披露 2024 稀释 EPS、故无法计算同比，并有可定位的检查范围。D3 两项分别为 Gamma 20%、基准 10% 和超额 10 个百分点，要求同窗口和调整口径；仅模型文字无绑定计算不计已保存有据。D4 两项分别为 Delta 20% 和基准资料缺失导致无法计算基准/超额；Delta 重复不充基准。精确资料限制不得扩大为整个市场结论。资料核验、语义不充分、显示或端点未验证均记 unknown 或 unsupported，理由要明确；未观察到不等于来源否定。

为每轨每项的 evidence、formal、visible 给出 supported / unsupported / unknown 和具体原因。supported 必须提供逐层可核对的证据文件、JSON 指针与原文摘录；formal 为 supported 时必须已经确认 accepted 且引用已接受正文；visible 为 supported 时须引用真实 API 和页面或导出的可核验产物，不能仅引用中间存储。证据不足而不能排除时写 unknown；确认没有相关内容才写 unsupported。并记录错误完成、重复矛盾行、越权/版本错误及编造缺失输入，未验证记 unknown。UI/导出在统一终态上由 deliveryaudit 通过实际入口独立核验，并在 judgments 中注明文件哈希；未取得 UI 验证则不得用重组推测已可见。

score.py 不自动做语义判断，也不将结果中已有 answered 标记当作证据；它校验人工判断的结构、引用摘录和哈希、提交回执一致性，并汇总下上界和资源。人工判读不等于独立人工复核，不把合成样本结果推广为总体质量。核算预留、提供商实际报告量、未知报告次数和成本独立记录；任何缺数据或错误记录不作零。正式得分只在接受提交后可高于零。运行前冻结本文件及 score.py；外呼后产生的 judgments 与引用产物均绑定结果 SHA256，不覆盖原始轨迹。
