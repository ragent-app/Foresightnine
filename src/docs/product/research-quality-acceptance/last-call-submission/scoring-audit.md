# 事先冻结的评分与审计

探索性配对实验；四个合成问题，每臂各两次，16 次运行。主结果逐次记录：主动提交是否由处理器接受（completed、partial 分开）、未接受（被拒、未执行、未调用分开）、最终状态与理由；只凭出现工具 block 不计接受。以处理器成功 early_outcome、持久 state.submission、最终 reason=submitted 交叉核验。模型请求 completed 而实际 partial 记自动降级，不将主动 partial 当作被动预算停止。按全部 8 个已启动运行作各臂分母，并单列实际收到干预者；停批时只报告已启动样本，不推断未启动结果。

依据冻结 cases 的 question_parts 和事实及引用标准，逐条检查最终可见报告、部分说明、claims、question_parts、gaps 与原始 facts/calculations，标注支持、反驳、未知及缺口；不得把未提交 facts 自动计为已交付。优先对照上批 fact-batching 的 scoring-protocol.md；引用须与主张、时点、单位匹配，D3/D4 相对日文本不能代替结构化价格或交易日依据。记录已支持但未出现在可见答案的条目、未披露缺口、无依据内容；语义无法确认记未知。报告及部分说明均区别产品交付与未经验证模型原文。结合每次 submit 的模型输入、同轮序号、执行前状态、执行结果、状态持久化与可见产物逐次审计遗漏；同轮早返回造成未执行的调用记未执行，不作已拒绝或已提交。截断仅分析安全结构，不推断参数或提交。无提交时也审计最终可见产物。逐题逐重复报告 A/B 结果和配对差，不做显著性或总体推断。

实际执行时记录提示构造前后哈希、尾部原有内容、是否进入 provider、工具历史及成功处理器回执；‘进入 provider’不证明外部服务收到请求。工具输入仅记录正常进入运行器的合成数据；被截断输出只记录 schema 字段形状、长度和数量，不存原始思维或 wire。审计不使用模型自评作事实验证。固定样本、提示、参数、权限和预算，观察结果不能证明真实金融研究质量或投资绩效。
