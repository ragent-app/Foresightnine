# E2 冻结对照

`e2-replay.json` 记录同一固定 NativeTurnRecorder 工具轨迹：旧版从提交 879de1d 加起点快照重建，当前版采用同一输入与回执。旧版两条均 `completed`：一条收入引用后原样重交，一条记录两期收入、计算增长及普通风险搜索后重交；两条均未答 EPS。新版相同两条均 `partial`，且首次提醒、最多一次的断言通过。样本中的缺证误报完成率旧版 2/2、新版 0/2，统计仅限这两条冻结轨迹，不是总体模型误报率。

同批还检验财务数据完整与缺失的需求求值、基准标的重复与有效基准求值，以及完成度组装；五项测试通过。完整证据的判断通过是函数级覆盖，不代表已经完成完整真实模型对照；齐全误报部分完成率不能从这两个缺证运行计算。各版本的工具、文件指纹及原始 pytest 回执见脚本和 manifest。未运行正式独立集盲评。
