原计划 C 对照还需要固定完整的三路径请求和 M1 行情证据组、核对相同容量下逐组覆盖及省略原因；当前没有真实模型的采用、语义正确率、费用或延迟证据。失效来源触发保守清除 opaque 历史；其余来源的已读、同版本、可定位完整证据组会单独重建，不能定位的合法信息仍可能丢失；用户确认的 note 保留，来源摘要失效时不自动复述旧模型总结。
