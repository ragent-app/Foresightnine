# D · 工具呈现对照

在实现按需工具组前冻结。使用同一 Messages 协议、本地可控传输、账户权限、问题、用户资料、模型参数和完整上下文投影。A 使用现行全部工具定义，B 由精确匹配 endpoint/model/version 的能力配置显式开启动态工具。产品默认继续提供现有工具。A/B 都有保存、提交、读取和计算能力。开发验收模拟用户从阅读资料转向制表，以及同一批次尝试使用尚未展示的工具。记录每次实际发送的工具名、定义字节、绑定哈希和工具回执。恢复已返回批次时不得因激活更改本批可执行工具，未启用的外部来源不得由激活工具解禁。补充关闭动态能力后的恢复。

本轮离线数据只能验证字节、可达性及恢复边界。缓存、延迟、交付率和真实费用需在工程出口通过后分别观测；固定回包耗时不可用作缓存命中或费用数据。正常研究仍可继续使用完整定义。
