# C：三路径离线请求对照

`paired.py` 和 `paired.json` 是可重放的确定性对照。A 从 Git 对象 `3e1ca4d` 读取旧 `research_context_manager.py`，B 读取工作区当前实现；两臂加载同一当前工具注册表和其他依赖，所以这是上下文构造的隔离比较，不是完整旧版本端到端比较。F1、F3、M1、M2 各固定相同问题、来源文本及哈希、来源许可、已读范围、已记录事实、资料截止时点、Messages 工具定义和 256 输出上限，分别走普通、追问和带超时检查点的恢复构造。所有请求均小于同一离线检查容量 120,000 bytes；这只是相同序列化容量，不等于供应商 token 窗口或真实预算。零模型及搜索外呼；模型、实际用量、缓存收益、延迟和费用未评估。
