验收按候选、已读、入模、采用、交付分别记录来源及版本、精确位置、事实 ID、计算输入和输出、需求 ID 与状态；权限撤销后分别重验读取、入模、重开与导出。表格证据应包含列头、期间、单位、脚注和限制，行情应包含两端证券身份、日期及价格调整口径。缺任一输入或权限失效时撤回依赖计算而保留无关成果。修订不应把旧位置套到新来源版本。
