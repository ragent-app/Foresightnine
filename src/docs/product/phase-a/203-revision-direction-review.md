# 修订与实际变化的区别

199 号实验中，模型把消费估计向下修订当作消费增长说法的反证。修订表示新旧估计之间的差异，单凭这一点不能确定所估计指标本身是增长还是下降，也不能单独反驳增长。

服务端在有限模式下识别：结论把向上或向下修订称为反驳，同时所附引文中也有可准确定位的修订表述。命中时标记 `revision_vs_change` 待核查，使运行保留部分完成，并阻止二次模型复查把该条直接判为支持。页面说明需核对原估计、实际变化、期间和其他证据；文本及 JSON 导出保留该警示。用户修改结论后重新计算警示，原版本保留。这个提示只是检索线索，可能遗漏或误报；其他资料可能确实构成反证，系统不会自动宣称结论错误。

离线重放 199 号原有结论时，正确标记了上述反方；原实验评分与原始记录不变。201 号原始响应在 202 号变更后离线重放，保留原文定位、两个 GDP 数值和确定性差额，但另一引文仍有多个候选位置，语义尚未独立核验，原失败评分不变。本轮没有模型调用。

API 的证据、模型复查及研究运行测试通过，覆盖有效引用、未授权与错误定位、否定表述、运行状态和修改后的重新检查；Web 类型检查及文本导出测试通过。以上不证明跨领域语义识别全面，也不能证明阶段 B 的 B02、B04 或 B09 已通过。
