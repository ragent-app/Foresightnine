# 用户表格核对与计算

对于 226 号保留的表格候选事实，工作区提供可选的逐项用户核对：用户对照原始表格确认公司、数值、列、期间及单位，服务端重新检查账户、来源权限、截止时间、唯一原文位置和数值。确认记录包含用户类型、时间及绑定事实与引文位置的哈希，保存为新版本；不表示来源经独立验证，也不自动确认其他事实。已有期间冲突、方向、币种冲突或来源警示仍需先处理。用户修改任何事实字段会失效，客户端不能通过编辑直接伪造确认。

仅当相应候选输入都经用户确认、并满足其他计算条件时，确定性计算接口才接受它们；历史计算的输入状态也检查确认是否仍与事实匹配。JSON 和文本导出保留确认记录，表格对齐及来源核验提示继续显示。此功能是产品正常的可选研究复核，不是阶段 B 要求用户进行人工验收，也不将阶段 B 质量缺口算作通过。

API 测试覆盖未确认拒绝、逐项确认后计算、他人访问拒绝、过期版本、伪造确认、修改后失效和历史计算状态；计算、OpenAPI、Web 类型、客户端与文本导出测试通过。Browser 插件未列出，使用本地 Playwright 和合成表格，完成两次数值确认、版本保存和 25.00% 增长率计算，桌面与移动视图无相关控制台错误；该合成测试不证明真实财报模型质量。临时服务已停止，没有新增模型调用。
