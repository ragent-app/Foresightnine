# 单数反对票的资料片段选择

第 73 号美联储公告测试暴露一处通用语法遗漏：投票定位规则支持 `Voting against ... were` 和冒号形式，却不支持单人反对时使用的 `Voting against ... was`，导致与政策决定配对的片段没有被该规则选择。现补充单数形式；选择仍须满足问题范围、政策行动与投票距离、完整句子、片段预算和原文坐标检查。选择方法标识由 v18 更新为 v19。

使用第 73 号固定 PDF、问题和原模型输入预算离线检查，政策决定的 `1/4 to 1/2 percent` 与 James Bullard 的完整反对票及偏好现在分别进入两个原文片段，序列化提示为 2,053 字节；这只证明片段可见，不证明模型会准确引用或理解。相关研究分析和运行测试 113 项通过，包含单数与复数形式。没有新模型调用；第 73 号冻结的 0/2 结果不变，不能作为阶段 B 质量验收通过。
