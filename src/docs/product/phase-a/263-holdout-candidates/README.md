## 运行前登记

固定当前代码、完整来源及提取哈希、问题、来源权限、模型、实际支持参数、提示和选段；`reference.json` 不进入模型提示。每题最多两次模型调用（一次生成、一次批量复查）、10,000 Token、单次 60 秒、研究总计 120 秒，三题合计最多六次、30,000 Token；不搜索、不自动重试。终态或用量不明时停止后续任务。此前已知累计 276,905 Token，另有未知历史用量及未知美元费用。

冻结的机械检查要求三题全部完成：所有保留主张的引文唯一可定位、无既有警示、有带引用的反方、研究状态完成、预算受控；公司样本还需两个收入值及输入状态匹配的 −5.61% 计算，GDP 题需两期增长率、服务增加和商品下降反方，政策题需目标区间、Kashkari 的反对意见与维持原区间的偏好。任一缺失、不可判定或部分完成均不通过本项机械检查。匹配数字或词语不能证明数值、对象、期间和引文语义对应；输出另需逐条依据来源检查。公司开发样本和两个新候选分别报告，不能把新候选的小样本成绩外推为全部领域表现。

## 冻结运行结果

三项操作均完成，每题各一次模型生成，分别报告 **3,189、2,261、1,739 Token**，合计 **7,189 Token**；已知累计 **284,094 Token**，另有未知历史用量及未知美元费用。三项研究均为部分完成，冻结机械检查 **0/3**。原始结果和评分保留。

- **公司开发样本**：结论出现两个收入数值，但相应期间采用 `FY2024 (year ended July 27, 2024)` 等写法，未生成确定性同比计算；部分引用有数值或上下文警示，反方条目没有可用引用。
- **GDP 新候选**：找到 2.7% 和 3.2%，但未选中原公告中服务增加、商品减少的说明。模型进而声称资料不提供拆分，而原始公告实际上包含这一说明；这暴露了对未完整阅读资料的错误概括。
- **政策新候选**：目标区间和 Kashkari 倾向维持原区间的引用在主要结论中出现，但未形成评分所要求的反方条目，且决议生效日期有引文警示。预登记评分对“反方条目”的角色要求比“识别反对票”本身更严格，不能据其失败否认模型已识别反对者；评分保持原样。

本次预算设定有一个预先未识别的限制：每次模型调用按输入与输出上限预留预算，生成后每题剩余预算不足以再预留完整复查调用，因此三题的批量复查均未启动。实际只有生成调用；不能以此评价复查能力或声称已运行复查。此评估没有独立人工复核，候选资料和参考由同一准备者查看；语义判断以上述具体核对为限，不证明整体引用支持或阶段 B 完成。后续若使用这些新候选修复实现或调整提示，它们即成为开发资料，须为后续独立测试另选材料。
