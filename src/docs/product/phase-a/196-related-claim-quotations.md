# 研究条目之间的候选引文

当一条结论或反方的美元金额未在其引文中找到，但同一资料的另一条研究条目已引用包含相同金额的原文时，系统会提供候选引文，供用户检查和选择。候选必须来自目标条目已经引用、允许展示且非模拟的资料；原文须完整、唯一定位并与来源一致。金额及数量级匹配不证明公司、币种、期间、方向、因果或其他语义一致，候选不会自动加入证据，仍标记为需要语义核查。每项最多展示五条，来源扫描有上限，因此不是穷尽检索。

用户编辑结论时可主动添加候选引文；保存会重新定位、重算缺口并创建用户版本，旧版本不变，来源支持仍未独立核验。文本报告保留这些候选及其状态。对 182 号已保存供应商输出离线重放，即使不依赖提取的数值事实，系统也能从另一条结论的引文中提示同一资料里的 `$9.6 billion`；这不证明该反方的其他经济解释，也不改变原实验评分。

API 测试覆盖候选位置、同源和展示权限、重复原文、不同数量级、保存后重新计算缺口及用户版本；Web 类型检查、289 项测试及生产构建通过。本地浏览器用测试替身完成候选展示、用户添加及保存，并检查移动端宽度。构建仍有原主包体积提示。本次未调用真实模型，阶段 B 的完整质量评估仍在进行。
