# 保留模型输出中的日期与单位观察

日期：2026-11-12。122 号真实资料检查中，模型把两个报告期末日期和一项单位声明放入数值事实列表；原流程将它们全部视为无效数字而丢弃。新流程仅识别符合限定格式、日期有效或单位属于千/百万/十亿声明、且值完整出现在模型所给引文中的项目；仍须在模型实际看到的、允许显示的来源片段内定位引文。符合条件的内容作为带来源的未独立核验模型结论保留，不进入数值事实或确定性计算。无法定位、值不在引文中、超限或格式无效时仍省略并提示。模型标签、主体、期间含义和该单位是否适用于其他表格均未因此获得验证。

使用 122 号已保存模型输出及相同来源离线重放，两项日期和单位声明可定位并显示为三条未核验观察；两个数值事实和一项同比计算保留。没有额外模型调用，不更改原始结果及其未通过的预登记评分。新增合成测试覆盖有效日期和单位、无效日期、未引用的值、不存在的引文、被延长的年份以及不可用于计算。研究分析、运行、证据及复查测试 194 项通过；最后一次边界调整后研究分析测试 96 项通过，Web 类型检查通过。Browser 插件及 browser 技能未列出，使用本机隔离模拟 API 和 Playwright，在 1280×900、390×844 验证两条观察、中文提示和空数值事实；未见控制台错误或横向溢出。
