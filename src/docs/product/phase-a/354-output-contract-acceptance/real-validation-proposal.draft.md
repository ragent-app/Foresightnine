# 供应商无关研究输出：受控真实验证提案（草案，未授权运行）

工程检查完成且用户另行明确放行后，拟冻结一个最多两题的独立批次：原 352 的季度差值，以及一项不同结构的定性证据与反方任务。两题均使用事先指定并核验权限与哈希的本地资料，不搜索、不获取、不使用 FRED；第二题及资料在冻结前明确。固定同一个实际已授权的 provider、模型、生成参数，每调用输入 6000、输出 4000、总时限 120 秒；在外呼前确认新契约开销已计入输入预算且仍有实际资料空间。其他 provider capability 仅用离线 fake transport 验证 payload 和失败语义，不宣称已测试多个真实供应商。
