# 结论与反方的版本内关系

研究版本保存时为结论分配服务端标识，并保留后续版本中未重复使用的已有标识；反方可显式记录其回应的结论。服务端只保留当前版本中指向支持结论的关系，对失效、重复、类型错误或超限关系记录省略数量；历史版本不被改写。证据关联索引和文本导出保留这些标识与关系。

Web 允许在编辑研究时添加或移除关系，并明确标注关系未独立核验；没有标识的旧版本可在保存新版本后获得标识。关系目前由用户标记，不根据文字自动推断，不证明反方真实、相关或已充分覆盖原主张，也不改变原有研究完成状态。自动研究规划、模型提出可审查关系及与证据覆盖审查的联动仍待实现。

遵照用户要求，本次未执行测试、浏览器检查或模型实验；迁移、并发、导出及交互行为尚未验证。
