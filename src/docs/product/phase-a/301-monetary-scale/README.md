# 金额倍率与原文核查

金额引用即使明确写出币种和数值，也未必证明模型填写的“百万”或“十亿”等倍率。现在对有限金额类标签和可识别的中英文倍率，如果事实的引用没有对应倍率，保留待核查提示；自动生成的计算可以保留，但输入状态为不可核验，手动计算及重算需要先核查引用。倍率相同也不能证明其对应同一数值、指标、表格列或期间；未识别的倍率不能视为已核验。

沿用币种检查的复核边界：有效的原表用户确认或满足既有条件的原件 XBRL 一致性记录可以提供额外依据，均不代表原始文件真实性和会计语义已独立验证。旧版本在读取和导出副本时提示，不改写原记录。用户更改事实使原表确认失效后重新计算提示。修复了模型使用 `total_revenue_fy2024` 等下划线标签时金额识别漏判的问题。

[离线重放](replay.json)使用 276 保存的 Cisco 财报原件及原模型输出，无新模型调用；两项收入的引用缺少币种和倍率字样，但与原件 XBRL 标签的币种、倍率、期间和数值一致，计算结果仍为 −5.61%，输入状态 `matched` 仅表示与保存事实及标签一致。原研究仍为部分完成，文件真实性、引文语义和反方并未通过独立核验。

分析、计算、表格确认、版本保存及旧结果导出和重算的相关测试、Web 类型检查通过。集中检查首次有四项模拟引用缺少已声明的倍率，已在相应样本中明确金额单位或倍率，相关测试随后通过；尚未重新运行整个阶段 B 全量回归。
