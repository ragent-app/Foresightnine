调用前固定提交 `a687584`、输入及来源哈希、参考、评分、模型参数和预算，见 `manifest.json`。C24 使用 [Caterpillar 2024 年 SEC 10-K](https://www.sec.gov/Archives/edgar/data/18230/000001823025000008/cat-20241231.htm) 的两期销售及总收入衍生 JSON；P25J 使用 [BEA 2025 年 7 月个人收入公告](https://www.bea.gov/sites/default/files/2025-08/pi0725.pdf) 原始 PDF；F24N 使用 [美联储 2024 年 11 月 7 日声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20241107a1.pdf) 原始 PDF。公司题直接提供摘录数值，不检验系统从完整财报定位数据。PDF 当前哈希不证明历史字节未变化；来源条款和适用范围见[来源矩阵](../03-source-inventory.md)。

模型为 `glm-5.3-flash`；每题最多一次调用、10000 Token、120 秒，供应商超时 60 秒，共最多三次。不搜索、不启用二次复查、不重试未知调用。生成参数与完整机械条件在清单中；开发者知晓题目和参考，测试非盲，也未独立人工核验。机械通过不能证明主张语义、历史可得性、完整文件覆盖或总体质量。

预设机械结果 1/3：

- C24 未通过。模型将 JSON 中不连续、次序不一致的字段用 `and` 或省略号拼成所谓引文；这些引文不在来源中，事实、结论和依赖的增长计算被省略。正确的确定性参考是 2024 相对 2023 约 −3.36%。
- P25J 未通过。模型表述的 0.2% 环比与 2.6% 同比符合参考值，但对 PDF 图表与正文交错处生成了不能定位的整句引文，支持结论被省略。仅保留了可定位的同比数值事实，系统标为部分完成。
- F24N 满足本次有限机械条件，保留了 4.5%–4.75% 区间和 0.25 个百分点降幅。但其中一条同时声称降幅和生效日期的结论只引用了生效日期及目标区间片段，降幅不在该条引用中；机械脚本没有检查这一语义缺口，因此不能认为 B02 或 B04 已通过。

三次分别报告 1367、1219、1385 Token，合计 3971；美元费用未知。所有原始运行、失败与评分保留，不针对同一结果重跑或重算。系统对三题均显示部分完成，不能将单题机械通过当作完整研究质量验收。
