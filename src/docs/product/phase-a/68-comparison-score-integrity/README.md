# 双来源比较评分检查

第 67 次预登记评分只要求同一结论引用两份来源，没有要求每份引文包含对应数值，也没有检查中文金额换算。这里提供可在未来评估前冻结并组合使用的两个狭窄检查：同一结论在每个指定来源中引用其对应的数字；明确的中文美元金额经过十进制换算和声明精度舍入后与预先登记的候选参考值比较。

这些规则不验证数字所属的列、实体、期间、反方或全部语义；未列明币种的裸数字和其他币种不受金额检查。使用者必须在模型调用前固定本文件、测试、来源、参考值和任务评分规则。测试将第 67 次已观察结果用作事后回归，确认两个漏项可被识别；不更改原评分，不是独立质量评估，也不代表阶段 B 验收。

第 70 次评估还发现，旧规则漏识别“并不覆盖完全相同的期间”。新增有限的中英文期间差异措辞检查，并拒绝若干明显否定表达；它不能理解所有自然语言，仍要求调用者另行核查日期和引用。第 70 次原评分保持不变，仅用其记录作为事后回归。
