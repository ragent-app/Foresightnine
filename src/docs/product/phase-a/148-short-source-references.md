# 单来源研究的临时短引用标识

研究输入中每个选段重复携带较长的随机来源 ID，占用有限上下文。对仅有一个可用于模型分析的来源、且其 ID 符合系统生成格式的运行，模型提示使用本次运行的短引用标识；服务端只将它解析到本次已处理的授权来源，保存事实和引文时恢复真实来源 ID。提示选段记录同时保存真实 ID 与模型引用标识，供审计。多个可用来源或其他格式的 ID 保持原样；短标识不是权限边界，猜测不存在的标识不能访问或引用其他来源。

预算分配先按原 ID 及既有规则选段，再利用短标识节省的空间扩展相邻原文，不删减原选段。单位截断、来源权限、时间筛选和字节预算仍按现有规则检查；方法标识由 v33 更新为 v34。结构化事实、普通引文和拆分引文都恢复真实来源 ID。

对 146 号已保存的两题离线重放，先前选中的全部原文范围均得到保留；贸易题保留此前各项数值，压力测试题的原文选段新增 `9.9 percent`，但仍未覆盖具体银行类别风险。该结果只检查输入，不证明模型识别正确或语义支持。测试覆盖引用与事实映射、未知标识拒绝、两个来源的独立身份、历史截止、拆分引文和原始 PDF/运行流程；本次无模型调用。真实输出需进一步受控对照，B02、B04、B09 仍未验收。
