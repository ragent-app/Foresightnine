# 百分比与同值金额的证据边界

原有数值警示只核对主张中的数字是否出现在引用内，因此“收入增长 5%”引用“收入为 500 万美元”时，数字 5 可被误当成已覆盖。现在保留原数值匹配行为，同时对数值已出现但引用没有明确百分比单位的情况标记 `percentage_unit_unverified`；它不判定结论为假。表格行和单独表头可能确实共同表示百分比，因此仍需核对原文和列对齐。基点、百分点、货币金额或年份不自动成为百分比。显式百分比也不证明对象、期间和含义相符。

该提示使研究保持部分完成，阻止模型复查直接将其升级为支持，并在工作区及文本报告中显示；用户保存版本时会重新计算。建议数值上限达到 5 项后仍继续检查后续主张值的单位警示。
