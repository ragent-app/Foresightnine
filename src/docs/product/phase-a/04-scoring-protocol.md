# A4：候选评分及人工基线流程

状态：待人工复核，未冻结。用于把 [任务草稿](04-evaluation-draft.md)变成可重复核验的评估；不是已经建立的人工基线，也不预先宣称某个模型达标。

## 样本与角色

每个冻结任务包含 ID、类别、问题、对象、截止时刻与时区、允许的资料及版本哈希、参考事实和来源定位、计算公式、必要限制、预期故障或不确定结果。为来源故障和注入等题目标记合成条件，不能混入真实证据。初研资料与后续资料分开；对不可合法保存的原文，只保存可授权的最小输入、定位和哈希；无法重放时记录限制或更换来源。

输入层级必须分别记录：直接提供衍生事实只能测试计算及解释；提供原始文件可额外检查文档定位和引用；开放经授权的检索才可检查来源发现与取证。三种方式的结果不能混为同一能力指标。[宏观原始公告候选题包](original-source-candidate-v01/README.md)是第二种，尚未冻结，也不证明联网检索能力。

复核人独立阅读原始材料、核对答案和评分点，记录姓名或代号、实际开始结束时间、是否使用工具以及修订依据。单一复核人可能出错，分歧或高影响样本应由另一人复核；未完成部分标记缺失，不按通过计数。真实人工用相同任务及资料完成研究并记录完成和核验时间；人工答案、参考答案和模型输出分开保存。生成者检查代码和数字不能冒充人工耗时或独立复核。

开发样本可用于调试；与之不同的独立测试集锁定后不用于调整提示词、实现或阈值。仅隔离文件名不等于盲测：记录谁见过题目及答案，若已用于调试则从测试集中剔除或更换。测试题和答案在正式被测运行期间由评估负责人隔离，不传给被测系统。

## 每题记录

对每个适用维度分别记录：`pass`、`fail`、`not_applicable` 或 `unverifiable`，附逐条证据；未完成、未评或资料不可验证不算通过。下表是评分定义而不是通过阈值。

| 维度 | 通过标准 | 不通过示例 |
| --- | --- | --- |
| 事实准确 | 所有要求的关键事实与核验来源、期间及口径一致 | 把季度数当全年、把估计写成事实 |
| 引用支持 | 每个关键事实均可定位到支持该事实的允许来源；相关时间可得 | 有 URL 但内容不支持结论或引用未来资料 |
| 计算 | 输入、公式、单位和舍入正确；不适用时正确拒绝计算 | 百分比误当百分点、零分母计算出数值 |
| 完成与缺口 | 所有要求已完成；确实不可完成时准确说明范围和原因 | 无数据仍声称已完成，遗漏核心要求 |
| 反方与限制 | 要求反方时，给出与主张相关、有来源的证据或诚实说明未知 | 用无关风险代替反证，把资料不足当不存在 |
| 更新识别 | 更新题中正确识别变化、保留未变结论并联系版本 | 旧事实未变却称修订，遗漏有依据的变化 |
| 失败与权限 | 故障、预算和权限条件触发时不编造、不泄露，清楚说明状态 | 将超时当作没有变化，将模拟输出当事实 |

逐题计数：事实准确率 = 通过事实检查题数 / 事实检查适用题数；引用支持率、计算正确率和任务完成率同理。对更新题逐项记录人工预期和系统标记：以真实无变化却报变化为误报，以真实应更新却漏报为漏报；明确统计单位、分母和不可判定项。报告每类题数、逐题结果和范围，缺失或不适用不可随意剔除；样本小不应外推总体表现。

人工完成时间和核验时间分别计时。模型系统记录端到端时间及随后人工核验时间，两者不可混成一次时间；复核者的材料熟悉程度和先后顺序可能影响比较，应记录。记录费用时分清模型、搜索、数据、处理、计算、存储和人工；未知值不算零。

## 正式运行前冻结清单

1. 核实所有参考来源的时间、权利及版本，审定答案和每题适用维度；保留修订记录。
2. 明确开发、验证和独立测试集及泄漏处理，锁定材料与评分版本，计算内容哈希。
3. 完成并记录真实人工基线与分歧处理；依据任务风险、基线及资源限制**预先**设定数值通过阈值、失败条件、样本数、重复次数及预算。
4. 锁定比较对象、提示词、工具权限、模型支持参数、调用/时间/费用上限、终止和重试规则；记录不具可比性的条件。
5. 运行并保留原始输出和审计记录；公布每题评分、未完成题和来源缺口。任何事后修改都作为新版本及新实验登记，不能覆盖旧结果。

现有 30 道候选题及 9 道跨领域、异常和更新候选题未通过此清单，不可将其通过率、评分门槛或测试独立性视为已确认。[分题候选包](human-baseline-candidate-v01/README.md)提供题目、限定材料和分开的作答及核验计时栏，未包含参考答案；它仍需审定，且不代表存在真实人工基线。
