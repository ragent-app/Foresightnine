# 328：分别检查计算输入与结果

原有 `input_status` 检查计算使用的输入快照是否与当前事实一致，不证明保存的结果由公式正确算出。现在每次保存新研究版本时，服务端按保存的公式、两个输入和小数位调用确定性计算器，比较结果、公式版本、表达式、单位、币种和舍入方式，记录 `result_status` 为匹配、不匹配或无法重算；忽略客户端提交的状态。缺字段、旧格式和不支持的公式保留为无法重算，不修改历史版本。

研究运行的完成状态和待核查清单同时考虑输入与结果；工作区展示不匹配或无法重算的结果，可通过已有重算入口处理。重算一致只说明记录与计算器一致，不证明输入、来源、期间、财务语义或投资结论正确，也不认证作者。用户修改过的计算继续标记为用户编辑。

按用户要求，本次未运行测试、浏览器检查或模型实验。精度、旧版本、编辑及所有调用路径仍待集中验证，阶段 B 状态不变。
