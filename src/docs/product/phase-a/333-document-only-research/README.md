# 333：资料入口的默认研究任务

用户可以只提供资料创建研究。以前空问题直接传给研究模型，规划和缺口补充也因缺少问题而不可用。现在未填写问题时使用明确的资料概览任务：梳理材料中的主要可核查发现、数值、局限和待解问题并引用资料，不预设投资决策。用户可以在下次运行输入自己的问题；用户问题优先。系统在运行记录、检查点、输入快照和导出中保留任务来源及默认任务文本，界面说明本次使用的任务。

默认概览不触发初始外部来源搜索；要求自动获取但没有用户问题时记录跳过原因。用户单独启用缺口外部搜索时，授权说明明确查询可能包含默认概览任务和模型或用户写入的片段；结果仍只作待核验线索。来源权限、预算、截止时点、反方选择和失败处理继续适用。

按用户要求未运行测试或模型实验，资料入口的模型质量、授权边界、恢复与输出仍需集中验证；阶段 B 状态不变。
