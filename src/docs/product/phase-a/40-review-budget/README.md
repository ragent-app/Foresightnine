# 有界引文复查预算与单例诊断

阶段 B 研究结果的模型复查按固定输入预算运行。此前在第 39 次 GDP_REV 输出上，较早结论先占用上下文，三条结论中仅前两条进入复查；第三条反方被遗漏。v3 先为尽可能多的结论保留完整引文，再分轮分配周围上下文，保留预算上限、原文坐标与遗漏记录。截断的引文不参与复查。预算不足时依然可能遗漏结论或缺少上下文；这不是语义核验保证。

本次 [预登记](manifest.json)固定已有输入、实现、模型参数、提示哈希、单次调用与无重试，并在调用前固定判定：前两条应为 supports，第三条应为 does_not_support、contradicts 或 uncertain。初次本地配置检查因容器内加密密钥路径不可用而失败，发生在 run-started 文件创建及任何模型调用前；随后仅加载模型设置后执行一次。

[结果](result.json)：三条全部进入预算，但模型对三条均判断 supports，单例判定失败。第三条称进口降幅较此前估计小，部分抵消下行修订；引用只覆盖进口降幅较此前估计小，并未支持所述抵消。该模型复查有误，不是独立验证。三个引文均没有额外上下文，且即使提供更多上下文，也不能假设模型必然正确。

运行报告 610 Token、3.273 秒，美元费用未知。已知累计报告 59238 Token；另有 Walmart H03 潜在用量未知。此案例已被开发时观察，非盲、非独立测试，不能作为阶段 B B02/B04/B09 的质量验收，也不能证明模型语义复查可靠。真实模型输出的语义支持和反方真实性仍需评估；系统中的模型复查不得作为独立证明。
