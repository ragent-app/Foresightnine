# 数值旁的明确币种冲突

生成事实时，若引文中同一数值紧邻明确的 USD、EUR、GBP、US$、€ 或 £ 标识，且该唯一标识与事实币种不同，保留事实并提示复核，不让其自动参与计算。用户编辑事实时重新检查；历史计算输入重新核验时，发现该冲突则标记无法验证并拒绝重算。更正币种后可再次重算，历史版本保留。

这只是有限的文本线索：裸 `$`、`¥`、不支持的币种、混合币种、不同数值、复杂排版及换算语境可能无法判定；数值相同或没有警示不证明口径正确。冲突提示也不自动认定来源或用户一定有错。旧版本不静默重写；新计算时按事实及引文重新核查。

相关分析、计算及运行测试 162 项通过，另有生成、编辑、拒绝重算及更正重算的专项测试通过。Web 类型检查及 282 项测试通过。Browser 插件不可用；使用本地内存 API、模型替身和 Playwright 在 1280×900、390×844 检查警示、更正、保存及重开，无页面错误或移动端横向溢出。未调用真实模型，也不改变过去评估结果。
