# 研究结论与反方的类型调整

日期：2026-11-12。在已记录的宏观修订开发检查中，模型把对修订的抵消因素列为普通结论；原界面只能删除并重新添加反方，不能直接保留引用调整类型。现在编辑研究时可将条目在结论和反方之间切换，文本和引用不变，保存产生新版本。

服务端对变更后的条目标记用户编辑，移除旧模型复查，并重新计算证据提示；原版本保持不变。表格标记恢复、拼接引文或位置歧义造成的不完整状态不会仅因编辑类型而变成可完整定位。页面将保存的运行结果和“未提供反方”提示明确表述为上次模型运行的记录，不把它们误认为对用户新编辑版本的判断。将条目改为反方不证明它构成有效反证。
