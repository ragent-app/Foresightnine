# 请求事实进入结论的提示对照：运行前登记

复用 [256 号 GDP 反方诊断](../256-gdp-counterpoint-recheck/README.md)的 PDF、题目、参考、输入权限、模型、生成参数、系统提示、复查方式、预算与预设机械评分。唯一主动改变的模型输入是研究提示中的证据指导：明确要求把请求的事实写进 `claims`，同时继续要求连续引文和缺证说明；文字做了等长度精简以保持输入预算与选段一致。准备脚本校验来源哈希、来源片段、系统提示、模型和预算与 256 一致，且完整提示哈希不同，否则不运行。

256 与本次之间还修复了年化百分比差值单位及历史结果提示；该确定性后处理差异不进入模型提示，比较模型原始输出时需单独说明，不能把完整产品结果变化全部归因于提示。模型内部版本和输出随机性无法锁定。数据和题目已用于开发，本次单题非盲检查不是独立验收、显著性测试或全领域质量结论。

最多四次模型调用、20,000 Token、单次 60 秒、研究 120 秒；不搜索、不重试，终态或用量不明即停止。美元费用未知，此前已知累计 271,990 Token，另有未知历史用量。机械条件与 256 完全相同，保留每项结果、模型原文、引用语义缺口及复查状态；不因输出好看而事后调整评分。

## 结果

一次生成调用报告 **2,089 Token**；已知累计 **274,079 Token**，另有未知历史用量及未知美元费用。运行完成但研究仍为**部分完成**；模型复查因三条主张存在待核查提示而未送审，实际没有第二次调用。冻结机械评分仍未通过：本次 GDP 数值出现在带可定位原文的结论中，服务增加及引文定位条件通过；商品下降出现在主要结论而非评分要求的反方条目中。

模型引用商品减少、服务增加的原文，指出原命题不成立；反方则描述“总体消费增加”的较弱命题，不能直接证明商品消费也增加。GDP 结论引用的原文包含 1.3% 和 0.3 个百分点修订，但系统仍对因果措辞提示复核；其他两条主张仍有季度引用缺口。模型生成的两期增长率之差为 **−2.10 个百分点**，使用此前修复后的计算器。与 256 的一次非盲比较中，请求事实进入结论这一机械检查由未通过变为通过；单次结果不能证明提示造成改善或能泛化，也不改变 B02、B04、B09 的验收状态。
