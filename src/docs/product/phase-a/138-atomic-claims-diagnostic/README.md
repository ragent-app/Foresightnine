# 单一断言提示词诊断：调用前登记

136 号固定美联储声明任务的一条复合结论列出监测事项，但引文仅覆盖政策调整。以该次已保存结果为基线，使用同一题目、来源及标识、实现、选段、用户提示哈希、输入上限 6000、模型、生成参数、60 秒超时和输出上限；仅替换等字节数的生成系统提示，加入每条结论一个断言并分别引用的要求。语句同步压缩以保持 433 字节，因此整体系统提示变化是单一实验变量，并非只改一个词。

最多一次直接模型调用，不搜索、不二次复查、不重试；输入与输出总预留上限 10000 Token，异常或用量不明即停止。美元费用未知，历史已知累计 145455 Token，另有未知历史用量。调用前固定输入、模型参数、系统及用户提示哈希、运行脚本、来源、基线结果及评分哈希。保留提供方输出、已定位引文和用量。

沿用 136 号的有限机械信号，另逐条记录结论中出现的四类监测事项关键词是否在该条引文中出现；未提及的事项不算覆盖，关键词也不证明语义支持。题目及预期已用于开发，单次非盲对照不能证明因果或泛化，也不用于自动调整产品系统提示或声称阶段 B 通过。

## 结果

一次调用有确定终态，报告 2661 Token；已知累计 148116 Token，另有历史未知用量及未知美元费用。沿用的目标利率、两项购买额、风险和已保留引文定位机械信号均为真；这是有限信号，不证明语义支持。

备选提示输出 7 条普通结论与 1 条反方，基线为 4 条普通结论与 1 条反方。基线一条结论提到四类监测事项，却没有在该条引文中覆盖这些词；备选完全没有报告该条监测事项，因而对应机械检查为空，不能算引文覆盖改善。备选反方据“经济已取得进展”推断可能考虑改变购买速度；所引句子并未直接说明正在考虑改变购买速度，推断仍待核查。备选购买金额的一条引文从 `it would continue` 起始，省略前面的指代主体及时间背景；即使数值匹配，仍须核查上下文。

此次为固定用户提示和来源下的单次非盲对照，系统提示整体变化，模型内部版本与随机性不可锁定；保留原始输出和预登记信号。结果不足以证明断言拆分的泛化收益，产品默认提示保持不变，不能据此宣布 B02、B04 或 B09 通过。准备阶段脚本文件名与 Python 标准库同名，导致本地登记命令在任何模型调用前失败；已更名并重新固定清单，随后才调用模型。
