# 金额事实缺少币种的计算边界

此前模型可以将两个标注为收入、净利润等金额的事实都填成 `currency: null`，只因单位文本相同便进行增长或差额计算；同名单位并不能证明两期币种一致。现在对有限的明确金额类标签，在币种字段缺失时保留事实并提示，暂不用于自动计算；手动创建和重算同样要求先核对并填写币种。百分比、百分点、比率及未识别为金额的标签不按这一规则推断。已声明币种也只是输入，仍不证明原文或换算口径正确。

已有研究版本不被改写：读取和导出时在副本中标记缺失币种，并将引用这些事实的旧计算显示为输入不可核验；用户编辑币种会作为未经独立核验的用户修改保存，可再按现有边界重算。规则只识别部分中英文金额标签，未命中不代表币种已核实，也不构成全市场币种识别。

相关分析、计算及旧版本读取、导出和重算测试通过，Web 类型检查通过。本次没有新模型调用，也不改变阶段 B 的跨领域质量验收状态。
