# 受限引文展开后的跨领域候选验证

固定两项此前未作为模型输入的衍生资料：[AMD 2024 年 SEC 10-K](https://www.sec.gov/Archives/edgar/data/2488/000000248825000012/amd-20241228.htm)的净收入事实及 [BLS 2024 年 3 月 CPI 公告](https://www.bls.gov/news.release/archives/cpi_04102024.htm)的月度/十二个月变动事实。均为整理后的结构化数值，非原始文件；SEC 和 BLS 的公开内容使用依据及例外见来源矩阵，历史副本不变性未证明。此前 BLS 同站直接请求返回 403，本次不对该站直接重试或绕过；数值依据官方可读公告整理。

这是在相关题失败并修改后选择的新资料，同类任务已暴露给开发者，不能视为严格独立盲测或全领域验收。调用前固定实现提交、题目、输入、参考值、评分/运行脚本及哈希。每题最多一次模型调用、10000 Token 和 120 秒，合计两次；不搜索、不复查、不重试外部调用。只读查询可退避查询同一 operation；状态不确定则停止后续任务。美元费用未知。

机械条件：所需数值、期间、单位和引用位置正确，支持性主张有可定位引文；AMD 的确定性增长率为 13.69%，CPI 月度为季调、十二个月为未季调；无被程序标记的结论与计算差异、未识别百分比或省略引文；遵守预算。机械通过不证明全部语义、完整历史或整体质量。结果及失败原样保留，不能针对本集反复调参后重计成绩。

结果：B03 的预期数值、期间、季调口径、引文定位和预算通过机械条件，研究仍为部分完成。P03 的事实及确定性计算正确，但正文同时给出约 13.7% 和 13.70%，后者与两位小数的确定性结果 13.69% 不一致；预登记的百分比扫描发现该问题，P03 未通过机械条件，而当时产品差异检测因同一主张含两个百分比而没有标出。两次分别报告 1202 和 938 Token；美元成本未知。相关输出与原评分保留，不重跑该集。机械分数不证明语义和总体质量。

后续调整仅针对同一主张中数值相同但精度不同的百分比：当分母与单一有效计算可以关联时，分别按所写精度核对。对保留响应进行离线检查后标出 13.70% 与 13.69% 的候选差异；涉及多个不同百分比或无法唯一关联计算的表述仍不自动判定。原测试未重跑、原评分未更改。
