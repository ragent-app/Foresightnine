# 明确省略号的分段引用

218 号银行样本中，模型把表格标题和行以省略号连接；两段之间超过连续引文的长度上限，原实现丢弃了整条结论。现在只在连续原文恢复失败后，尝试保留两个或三个明确的省略号片段：每段须在已分析材料中唯一、按原文顺序、同处一个选中段落且总跨度不超过 5,000 字符。各段保留各自精确原文和位置，不拼造连续引文，结论标记为 `incomplete` 并提示核查；事实及计算不使用此恢复。不存在、重复、倒序或跨选中段落的片段不以此方式恢复。
