# 有警示主张的诊断复查

真实 GDP 样本中的主张存在季度引用缺口或因果措辞警示，旧复查器因此全部跳过，无法提供进一步的模型判断。复查方法 v27 对这两类警示允许进行受预算限制的诊断复查，仍只发送经过权限检查、可唯一定位的原文和原有上下文；其他数值缺口、方向冲突、不完整或歧义引文、PDF 表格列等限制保持原有拒绝规则。

警示主张的结果标记为 `diagnostic_only` 并保留警示原因与模型原始判断。即使模型回答支持，对外有效判断也限制为 `uncertain`；其他否定或不确定判断仅作诊断，不能清除原有警示。研究完成条件继续检查这些警示，不能因复查完成而把它们视为已解决。复查调用仍受用户设置的次数、Token、时间和费用限制；模型判断不等于独立证据。

对 [258 号已保存结果](258-requested-facts-prompt-check/README.md)进行离线计划检查，三条主张均可作为带警示的诊断候选；本次没有调用模型，不能推断模型会给出正确判断。复查与研究运行回归通过，另有批量和隔离两种模式的端到端测试，验证模型误答支持时仍保留季度及因果警示、有效判断为不确定且研究保持部分完成。Web 类型检查通过。该功能不改变阶段 B 的质量验收状态。
