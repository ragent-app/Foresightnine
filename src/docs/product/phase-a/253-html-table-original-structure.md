# 原始 HTML 表格结构检查

用户可从 HTML 来源的表格引文打开原件结构检查。服务端先核对保存的原件哈希和提取文本哈希，再以原来源的提取规则重新解析，要求全文与保存文本一致，并将选中行唯一对应到原件的同一表格。界面显示最多此前 15 行与目标行的单元格、原始 `colspan`，其余行被截断时明确提示。展示权限和账户隔离在服务端检查；解析采用两个有界工作槽，最多等待 5 秒，超时后工作槽仍由后台任务占用至任务退出。

嵌套表格、跨行、歧义行、无法识别的结构、哈希不符及解析超时等情况不展示已确认结构。原文中的管道和伪造的跨列标记不能冒充解析出的单元格。浏览器只以文本渲染单元格，不执行 HTML。该检查未执行 CSS 或重现浏览器排版；它只能追溯结构，不证明期间、单位、实体、事实或主张语义，也不会自动确认数值或清除原有提示。

对既有 Cisco FY2024 申报文件的本地检查，在目标行追溯到年度分组，53,803 和 56,998 分别位于结构列 22 和 28；这不是独立质量验收。来源和结构针对性 API 测试 16 项通过，覆盖跨账户、哈希、重复行、跨行、嵌套表格、伪造标记和工作槽超时；另对跨窗口的跨行情况补充验证。Web 类型检查、上下文组件 3 项测试通过；本地 Playwright 使用模拟数据在桌面及移动宽度完成查看结构交互，未发现页面错误或移动页面横向溢出。Browser 插件未列出，使用 Playwright；未调用模型或网络资料。阶段 B 的 B02、B04、B09 仍需完整质量评估。
