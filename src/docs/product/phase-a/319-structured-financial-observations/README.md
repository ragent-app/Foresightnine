# 结构化金融观察值与计算上下文

阶段 B 增加版本化结构化来源适配边界。首个适配器从已有 SEC company-concept 连接器生成的、已保存的 JSON 行中，使用确定性代码提取数值、单位、期间和原始行位置；记录来源标识、CIK、taxonomy/concept、申报日期及可用的财年、表单和申报编号。仅处理本次研究已纳入、允许模型处理及显示的真实来源；不请求网络、不将模拟或无授权材料转为事实，不把来源记录的申报日期称为精确公开可得时间。其他来源不靠猜测套用该适配器，后续可扩展相同契约。

观察值与模型提取的事实分开标记，保留原文位置和来源快照；它们不是独立核验的真实财务事实。用户编辑后移除服务端结构化提取身份与上下文，避免将用户内容误标为供应商原始记录。显示和文本导出保留结构化元数据。单次提取最多 200 条，超过上限记为未处理；每个 SEC 连接器快照本身最多 100 条。

当计算输入包含此类观察值时，一致性检查要求两个输入都有明确结构化上下文且实体一致；增长率还要求相同指标和较早基期，利润率要求相同期间；差值允许同一指标的可比期间或同期间不同指标。持续期间比较检查重叠与时长，未能建立这些条件时标记不可核验。以上检查不证明指标经济含义、来源真实性、修订可比性或投资效果。

该适配器在已有资料完成来源筛选后提供事实，目前不会提前向首次生成模型提供可直接引用的事实标识；通用金融数据工具调用与其他来源适配仍需继续建设。用户已要求暂停测试和模型实验，本次未运行测试、浏览器检查、联网或模型调用；提取、计算边界、性能和兼容性均尚未验证，阶段 B 尚未完成。
