# 分组财报表格的期间冲突提示

已有提取文本中的财报表格可能同时包含季度和年度列，相同年份重复。原提示规则因此放弃检查。新增有界的分组识别：仅当非空分组均为明确的年度或三、六、九个月结束期间，数值位于唯一年度分组，各日期列能归属唯一分组且年度组内年份不重复时，才提示声明年份与所处年份冲突。未识别、歧义、季度列或结构异常时不作判断。

对仓库中已有 Cisco 2024 年报 HTML 原件进行本地提取检查：在收入行，53,803 声明为 2023 财年、56,998 声明为 2024 财年均得到冲突提示；53,803 声明为 2024 财年不产生冲突。相关计算测试 48 项通过，包含混合表头、重复日期和非标准标题的退回行为。无模型调用、无网络请求；既有样本不是独立验收集。

提取标记可能来自原始文本，提示不证明原始 HTML 列结构、单位、公司、引文含义或数值本身正确；没有提示也不代表正确。本次没有完成 B02、B04 或 B09 的质量验收。
