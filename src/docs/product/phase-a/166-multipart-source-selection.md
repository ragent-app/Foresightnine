# 多要点资料选段

v39 对可分辨为多要点、未明确要求反方或风险的问题，在分配给某个资料的字节预算足够时，允许通用检索选择三个不重叠窗口；预算较小时仍选两个，已有专门检索规则优先。明确要求反方或风险时保留两窗口及既有反方平衡方法，因为无条件改为三个窗口曾使开发用银行压力测试的风险段落落选。这是启发式检索，不保证所有要点都被发现，预算增加也可能改变其他选段。

同时尝试恢复窗口开头被截断的数字前缀：仅在不与上一窗口重叠、未超出资料字符配额且完整数字可辨认时扩展原文范围；剩余情况仍需核验。输入提示、来源字符位置和权限限制仍按实际范围记录。

对四份已见资料做无模型离线诊断：在输入上限 6000 的条件下，原 PCE 题的新选段中出现了 23.7、33.3、9.6 和 5.0，修复了其中一段以截断的 `.7` 开头的问题；美联储决议题出现目标区间、异议者和准备金余额利率。旧贸易与压力测试样本中，先前检查的数值和压力测试风险关键词仍出现在选段。3000 上限的四题选段未发生上述变化。这里的关键词和数字出现仅是覆盖线索，不证明指标口径、文本语义或模型结果正确；原有 161 号评估结果保持失败。

161 号题目已经用于本次诊断和调整，已退出后续独立测试集。合成测试覆盖预算选择、明确风险问题保持两个窗口、数字前缀恢复和上限；研究分析及运行 API 测试通过。本次没有模型调用，阶段 B 的独立质量评估仍未完成。
