# 六题跨类型固定开发评估

在外部调用前固定清单、代码提交、任务、参考、评分程序、输入哈希及预算。两题使用 [Meta 2025 年 SEC 10-K](https://www.sec.gov/Archives/edgar/data/1326801/000162828026025534/meta-12312025x10kars.htm) 的收入与营业利润衍生 JSON；两题使用 [BEA 2025 年第四季度及全年 GDP 第二次估计](https://www.bea.gov/sites/default/files/2026-03/gdp4q25-2nd.pdf) 原始 PDF；两题使用 [美联储 2025 年 12 月声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20251210a1.pdf) 原始 PDF。公司题不检验完整年报定位；两题各自共用一份资料，不能当作六个独立来源。历史副本未改变、精确可得时间及材料使用范围不能单凭当前哈希证明。BEA 使用阅读顺序，美联储使用版式顺序；来源使用依据与限制见来源矩阵。

一次调用一题，固定 `glm-5.3-flash` 及清单中的支持参数，不搜索、不启用二次复查、不重试；最多 6 次调用、每题 10000 Token、总计 60000 Token、每题 120 秒，供应商超时 60 秒。报告用量未知、超过单题预算或运行状态不确定时停止后续调用。金额费用未知，不声称有美元上限。运行使用隔离的内存账户与数据，不修改现有业务账户。

预登记机械条件要求六题均通过：要求事实、期间和单位符合参考，关键事实在同一结论中被提及并有可定位的对应来源，适用时计算输入与结果正确，指定人名与引用对应，不存在被省略或截断的引文、未识别百分比或系统数值/日期警示，并遵守预算。引用、数值和关键词同时出现仍不能自动证明语义支持；检查采用有限别名、有限单位格式和小数舍入，可能漏判或误判，不能外推为全面质量或投资效果。参考和题目由同一开发者准备，已知答案，非盲，不能作为独立人工基线或严格独立测试；不对之前测试重评分。评分器在调用前用临时合成数据检查了正确例、错误百分比和错误来源标识。
