# 财报与政策两类任务的固定开发检查

调用前固定两个任务、资料、参考、评分、代码、模型参数与预算：

1. Microsoft 2023 申报的收入比较使用此前从 [SEC companyfacts](https://data.sec.gov/api/xbrl/companyfacts/CIK0000789019.json) 提取并保存的两条数据，不是完整年报或实时 SEC 接口检查。[SEC 2023 年 10-K](https://www.sec.gov/Archives/edgar/data/789019/000095017023035122/msft-20230630.htm)列示的 2023、2022 财年收入分别为 211,915、198,270 百万美元。两条 XBRL 记录的 `fy` 均为 2023，实际期间应看起止日期。原始响应哈希及提取记录保留在输入中；2026 年获取的快照不证明 2023 年任何精确时点的可见性。本次不访问 SEC，不使用未配置联系信息的程序请求。
2. [美联储 2022 年 11 月声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20221102a1.pdf)使用原始 PDF，核查目标区间及关于未来利率的表述。美联储网站复制条件与例外见阶段 A 来源矩阵。

每题最多一次模型调用、10,000 Token、120 秒，两题最多两次调用、20,000 Token；不搜索、不做模型复查、不重试不确定外部调用。终态或用量不明即停止后续任务。美元费用未知，不按零计。每题只有在固定目标、引文位置、预算、无现有数值与上下文警示且研究状态完成时，才记为本次狭义机械通过。评分器在临时目录用构造数据验证正确例通过、错误增长率失败；这些构造数据未发送模型。

两个题目和参考对准备者已知，Microsoft 来源也已在开发中使用；非盲、未经独立人工复核，且非完整财报阅读或历史时点证明。机械评分不判定所有引文语义、币种、反方或计算口径，不能作为正式独立测试或阶段 B 质量验收。

## 结果

两个操作均有确定终态，各进行了 1 次模型调用；分别报告 1,610 和 1,423 Token，合计 3,033。加此前已知累计 115,239 为 118,272 Token，另有历史未知用量及未知美元费用。预登记机械结果 0/2，两项研究均为部分完成。

- Microsoft：选中片段只覆盖第一条 2022 年收入记录，第二条 2023 年记录未进入输入；系统保留 2022 年数值与可定位引文，增长计算因缺少输入被省略。模型关于“提供的摘录”不含第二条记录应理解为本次片段缺失，不代表已保存的完整衍生来源没有该记录。模型还把片段元数据当成反方引文，未能定位并被丢弃。
- 美联储：选中片段落在准备金与贴现率说明，遗漏所问的联邦基金目标区间及未来政策措辞。部分结论可定位，但模型给百分比事实附加 USD 币种，并在反方中给出未获所附引文覆盖的区间及基点数值；系统保留未核验和缺口提示。事后检查发现查询使用繁体中文，部分既有检索映射仅覆盖简体；基点检查同样未覆盖“基點”写法。这些观察可用于后续修复，不能改写本次评分。

两个任务的分数不构成独立测试或阶段 B 质量通过；原始输入、响应和评分均保留。Microsoft 数据是衍生结构化事实，不代表完整 10-K 阅读能力。
