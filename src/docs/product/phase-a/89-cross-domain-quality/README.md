调用前固定两个任务、资料、参考、评分、代码、模型参数与预算：

1. Microsoft 2023 申报的收入比较使用此前从 [SEC companyfacts](https://data.sec.gov/api/xbrl/companyfacts/CIK0000789019.json) 提取并保存的两条数据，不是完整年报或实时 SEC 接口检查。[SEC 2023 年 10-K](https://www.sec.gov/Archives/edgar/data/789019/000095017023035122/msft-20230630.htm)列示的 2023、2022 财年收入分别为 211,915、198,270 百万美元。两条 XBRL 记录的 `fy` 均为 2023，实际期间应看起止日期。原始响应哈希及提取记录保留在输入中；2026 年获取的快照不证明 2023 年任何精确时点的可见性。本次不访问 SEC，不使用未配置联系信息的程序请求。
2. [美联储 2022 年 11 月声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20221102a1.pdf)使用原始 PDF，核查目标区间及关于未来利率的表述。美联储网站复制条件与例外见阶段 A 来源矩阵。

两个题目和参考对准备者已知，Microsoft 来源也已在开发中使用；非盲、未经独立人工复核，且非完整财报阅读或历史时点证明。机械评分不判定所有引文语义、币种、反方或计算口径，不能作为正式独立测试或阶段 B 质量验收。
