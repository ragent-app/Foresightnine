# 授权发现 SEC 公司申报

首次研究在用户明确授权后，现可从搜索线索获取一份直接 SEC EDGAR HTML 申报，并与其他已支持的官方资料一样保存、分析、导出引用和下载原件。仅接受现有严格校验的 SEC 申报路径，不接受 SEC 任意页面、查询参数或重定向；不把搜索摘要当作事实。用户确认包括材料的使用权，自动获取仍限一份、无隐式重试，不适用于历史截止时间、未知费用下的美元上限或明确空资料选择。

SEC 请求只使用部署方配置的真实联系信息，沿用共享 SEC 速率限制；代码不会生成或输出联系信息。未配置时不向 SEC 发请求，记录缺口并可继续检查后续受支持的 BEA 或美联储候选；超限或其他获取失败不伪造资料。网络等待及 HTML 提取共用调用方时间预算；解析不能立即终止时沿用现有有界解析并发，结果不会触发额外网络请求。原始 UTF-8 HTML、哈希、账户权限和中断恢复标识保留。SEC 官方资料中的第三方内容仍须有权使用。

后端测试覆盖配置存在与缺失、其他来源回退、SEC 全局限速、网络及解析超时、原件、幂等和隔离；Web 295 项测试、类型检查和构建通过。Browser 插件未列出，本地 Playwright 在桌面及移动宽度使用模拟 SEC 连接和模型验证授权、研究与原件下载；没有向 SEC 发真实请求。当前本机和容器均未配置 SEC 联系信息，因此真实 SEC 自动路径尚未验证；不会要求用户为了阶段收尾提供该信息，也不能据模拟结果声称联机可用。Web 构建保留既有大包提示。
