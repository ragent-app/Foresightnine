# 较大 PDF 的受限上传

一份 [美联储 2022 年压力测试报告](https://www.federalreserve.gov/publications/files/2022-dfast-results-20220623.pdf)为 3,312,911 字节，超过此前 3 MB 限制。现在 PDF 二进制上限为 5,000,000 字节，前端选择及原文件下载、API 校验和 JSON 请求体边界相应调整；默认 PDF 请求体硬上限为 6,800,000 字节，部署配置仍可设置更低上限。提取文本仍限 2 MB，PDF 提取仍受两路并发、15 秒超时、CPU、内存和文件大小限制；较大的请求也会占用更多网络和内存。超过限制的文件不会被当作已处理资料。

固定原始 PDF SHA-256 为 `5977cfb80bb216a84568fa067393746e13c4b49df3b05eff9c64d6336228ea87`。测试通过 API 保存该原文件、提取文字并逐字节取回原文件；另验证恰好 5 MB 的合成 PDF 可上传，超限拒绝及请求体上限的默认、上限、较低配置和非法配置回退。Web 类型、客户端测试、OpenAPI 快照和生成契约检查通过。

本地页面以测试账户、真实本地 API 上传此官方报告；超限合成文件在浏览器端拒绝且未发起上传，桌面和手机视口无页面错误。Browser 插件不可用，使用 Playwright；初次检查因测试定位器不够精确以及沙箱浏览器无法读取 `/tmp` 测试文件而失败，调整定位器并以内存文件构造超限样本后通过。临时服务已停止。此文件已用于开发测试，不是独立质量评估；5 MB 也不代表支持全部大型财报。
