# 比较版本与政策因素的资料选择

第 100 项评估中，问题同时要求第二次和第三次估计，第三次公告的摘录却优先命中了文中回顾的第二次估计；政策题则重复选中了目标区间，而没有选出后续政策考虑因素。选择方法 `v27` 在问题明确要求两个版本且资料标题只明确标识其中一个版本时，将标题作为该资料的检索线索；标题未确定或同时包含两个版本时沿用原排序。针对询问政策考虑因素的任务，检索对包含收紧、时滞及经济金融状况的相关段落给予有限权重。标题及词语均是不可信检索线索，不证明公告身份、因果、指标口径或结论支持。

固定原问题、来源及 2055 字节预算离线重放：GDP 两份公告分别选中 2.8% 与 3.1%，但第三次估计的库存抵消等原因仍未进入片段；政策题选中决议区间和三个主要考虑因素。两题提示分别为 2055、2054 字节，原文偏移保留。此检查未调用模型，也不改变第 100 项的 0/2 原结果；新的资料选择仍可能遗漏其他重要内容。
