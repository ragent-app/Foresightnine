# 阶段 B 实施与验证记录

2026-11-12。产品保持通用金融分析 Agent 定位；下述来源是当前连接能力，不是产品的行业或市场边界。

## 已实现

- 登录账户可创建研究主题，以问题或资料开始；保存、编辑、确认研究版本，重新打开历史，并在权限允许时导出完整 JSON。完整导出保留来源标识、时间、内容哈希和许可声明，不附原始文件或来源 URL 的查询参数。若来源不能导出，可另行导出仅含版本、时间和计数的记录摘要；该摘要不包含研究正文、来源内容或引文，不能替代完整研究交付。原 v1 流程与 FM 保留。
- 可添加自带文本、PDF、指定官方网页及 SEC company-concept 数据。PDF 提取使用容器内的 `pdftotext`；扫描图片没有 OCR。SEC 接入需要配置真实的 `FORESIGHTNINE_SEC_USER_AGENT` 或 `SEC_USER_AGENT` 联系信息，并明确 CIK、指标和单位。
- 可用 SEC 当前公司名称或代码索引查找并选择 CIK，保留候选项、来源和获取时间；该索引不确立证券类别、交易所或历史有效性，也不能代表全球身份覆盖。
- 未附资料时可使用已配置搜索服务查找候选链接；候选不自动视为证据，也不会自动发送给模型。无可用服务时返回缺口。FRED 不作为模型输入。
- 有授权资料时，研究运行可请求模型提取主张、反方和事实；程序检查引文是否出现在允许展示的原文中。可按字符位置打开有限长度的原文上下文，并提示引文与该位置不一致；同一引文在已分析片段中多次出现时展示至多五个候选位置，不将其标记为唯一定位；PDF 文本保留页码。计算由确定性代码执行。事实与已有计算的输入不一致、缺失或有歧义时标记旧结果；用户可基于当前有效事实重新计算并保存新草稿版本，旧版本保留。引文存在不证明语义支持，事实的单位、口径和解读仍标为未独立核验。
- 用户可选让模型对可定位的引文和结论进行二次支持性复查；额外调用受次数、Token、时间和账户预算约束，复查结果明确不是独立核验。用户编辑结论后移除原复查结果。失败的模型输出保留提示词哈希和片段位置，不保留输出正文。
- 对相同指标名称、期间、单位和币种下不同来源的数值差异生成待核查候选，并显示关联事实与来源；匹配不证明公司、口径或来源独立性一致，不能自动称为已确认冲突。
- 运行开始前记录父版本、来源哈希和权限、预算、片段选择方法与模型配置等，不保存凭据或资料原文；用户可在运行记录中查看。记录也保留在失败或取消之后。支持取消和幂等重试；模型和搜索次数受限，长文档片段选择会检查时间预算。无可核实单价时，设置金额上限会阻止外部调用。按 UTF-8 字节保守控制提示大小，但供应商实际分词和额外封装可能不同。
- 版本记录创建者；研究界面支持新增、修改或移除结论与反方，也可修正事实的指标、数值、单位、币种和期间，并在保存前提示原引文需要重新核验。用户修改的主张、事实和计算标为用户编辑且未独立核验，原运行记录与来源清单由服务端保留。旧版本没有创建者时显示未知。
- v2 研究接口单独提供 OpenAPI 快照并生成 TypeScript 类型；原 v1 契约保持兼容。账户隔离、来源权限、导出限制与已知失败情况有自动化测试。
