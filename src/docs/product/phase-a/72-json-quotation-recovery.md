# JSON 引文中多加结束括号的受限恢复

2026-11-12。第 70 号非盲评估中，模型引用 Walmart 财年收入时在数值后多写了一个 `}`；原始 JSON 该对象还包含后续字段，因此引文无法定位，相关事实和增长计算被丢弃。

现在只对用户提供、长度不超过 100,000 字符且可解析为对象的 JSON 资料，在原引文不能直接定位时尝试受限恢复：模型引文也须能解析为 JSON 属性片段，并以数字和一个结束括号结尾；移除最后一个括号后，剩余文本必须在完整资料中唯一出现，且已发送给模型的同一片段必须包含其后的逗号与下一字段。保存的引文是精确原文前缀，记录 `trimmed_json_closure`、原文坐标及待核查提示，不保留模型虚构的括号。数值边界、权限和既有事实检查仍适用，页面标注此修正并提供原文上下文。文字或值不匹配、重复、非 JSON 与更长数字不会因此被修复。

离线重放第 70 号已保存输入及模型响应：Walmart 两期收入均得到原文定位，对应确定性增长计算为 6.03%；Coca-Cola 计算为 2.86%。该检查未新调用模型，未改动原始响应、结果和 0/3 冻结成绩。它不能证明引用的单位、期间、实体及结论语义正确，也不能证明原始完整申报文件或跨任务表现。来源为衍生数据，不作为 B02、B04、B09 已通过的依据。

验证：相关研究分析、运行及版本 API 测试 122 项通过，Web 类型检查通过；测试覆盖恢复位置、计算、重复前缀、非 JSON 与数字不完整的拒绝。未进行新的真实模型或人工验收。
