# 反方与结论关系：有界模型建议

研究生成可以提出反方回应哪些结论的零起始索引。系统只保留指向有效、已保留结论的索引，并在保存研究版本时转换为版本内结论标识；被省略结论或无效索引不会静默变成关系。额外反方补充只能引用其实际收到的已有结论范围，不能引用未向模型提供的结论。关系被标为模型建议，不证明反方相关、引文支持或研究完整。

Web 在已保存且没有未保存编辑时展示模型建议；用户可以在编辑时明确保留关系。用户保存时，服务端不信任客户端提交的模型建议，只从上一版本在反方和目标结论内容及引用均未变化时继承；用户修改后过时建议被清除。关系与模型输出原文不同，不会自动确认或改变反方证据状态；文本导出保留标记。

此前运行与历史版本不被改写，缺少关系的旧输出仍可读取。遵照用户要求，本次未运行测试、浏览器检查或模型实验；输出兼容性、索引映射、成本和语义效果均尚未验证。此功能不代表完整研究规划、增量取证或阶段 B 完成。
