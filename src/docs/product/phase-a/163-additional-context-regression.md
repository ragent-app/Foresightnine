# 补充句预算回归修正

对已用于开发的 140 号原始资料进行离线对照，发现 v37 虽保留最初选窗，却在相邻上下文扩展之前插入补充句，挤占了原本可用于扩展的预算。银行压力测试样本的主要窗口由 10175–10646 缩短至 10175–10496，导致原本选中的 9.9% 不再进入模型输入。这是回归；162 号记录中“后续相邻上下文扩展的空间可能因此减少”不足以说明其实际影响。

v38 先完成原选窗和相邻上下文扩展，再仅使用剩余预算补充句子。对同一压力测试资料的本地复核保留 10175–10646 和 11840–12000，12.4% 和 9.9% 同时保留。还排除少于六个英文单词或跨 PDF 分页的候选，避免把目录片段当作补充证据；这仍不证明句子是完整且相关的证据。

新增自动测试将启用补充句与关闭补充句的最终选段比较，要求每个原范围均保留，并检查关键数值与输入字节上限；研究分析和运行相关 API 测试通过。本次未调用模型，140 号是已用于开发的样本，不能作为独立评估；161 号评估结果未修改、未重跑。额外候选在没有剩余预算时不会进入输入，仍不能解决所有多要点材料覆盖问题。
