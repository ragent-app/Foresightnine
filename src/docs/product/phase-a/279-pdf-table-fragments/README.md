# 长 PDF 表格引文的有界恢复

复查 278 号运行后发现，两条单源数值结论的模型引文在忽略 PDF 水平空白后，确实分别对应各自原件中的连续表头和数据行；原先定位失败是因为原件空格展开后超过了单条引文 1,000 字符的上限。278 号记录此前将这两条引文描述为“原文中不存在的连续引文”，该判断有误；原始运行和评分仍保持不变。

现在对符合条件的长 PDF 表格引文，在换行处分成两段独立定位的原文：每段在已分析片段中唯一、长度不超过 1,000 字符，两段顺序一致、间隔仅为空白、处于同一页及同一选段。不存在的数字、重复位置、被其他文字隔开、跨页、跨选段或未授权的页码均不能通过此恢复。恢复后的结论仍标为 `incomplete`：文本位置不证明 PDF 列对齐、期间、单位、来源准确性或陈述语义。

对 278 号保存的原始模型输出[离线重放](replay.json)，此前丢弃的两个单源数值结论各恢复两段原始引文，均保持待核查；跨来源关系结论仍只引用后一份来源，反方语义也未解决。没有新模型调用或历史重评分。分析、运行、证据和复查测试，以及针对跨页、重复、不同数值和片段边界的定向测试通过。该结果不代表阶段 B 完成，复现方式见 [replay.py](replay.py)。
