固定当前实现、两份 PDF 与文本哈希、问题、选段、模型参数和提示。参考答案单独存放，不进入被测模型。每题最多两次模型调用（一次生成、可选一次反方补充）、20,000 Token，总计最多四次、40,000 Token；不搜索、复查、重试或重新下载，单次 60 秒、研究 120 秒。终态或用量不明时停止后续任务。调用前已知累计 322,886 Token，更早用量和美元费用未知。

## 运行结果

两项操作均正常结束，各两次真实模型调用。BEA 报告 **4,606 Token**，FOMC **4,017 Token**，本次新增合计 **8,623 Token**，已知累计 **331,509 Token**；更早用量和美元费用未知。两项研究均为 `partial`，冻结机械检查 **0/2**；全部保留引文可唯一定位，所列关键数值与姓名的机械检查通过，但均存在警示，定位及词语匹配不能证明语义。

- **BEA**：1.6% 和 0.5% 的同期比较由首条引用支持；“下修 0.4 个百分点”由另一条引文支持，但原结论同时写出的初值 2.0% 及期间未由该引文完整覆盖。GDP 与 GDI 的两条反方引用中，1.6% 指的是前一季度 GDI，不能单靠该引文支持将其作为本季度 GDP 的对比；系统对此保留数值警示。
- **FOMC**：目标区间、Bowman 和 Waller、他们偏好的 1/4 个百分点降幅均能在给出的引文中找到；目标区间主张的会议日期没有附上支持日期的引文，存在提示。第一条所谓反方主要是对动机缺失的解释，并作未受完整阅读支持的资料缺失断言；补充反方主要重述已有结论，虽有引文，也未清晰说明对原结论的反对或限制。它被标为补充完成，暴露出“有引文”不等于“是相关反方”的质量缺口。
