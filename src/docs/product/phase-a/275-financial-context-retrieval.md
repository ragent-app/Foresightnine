# 财务表格与变化背景的选段

272 号公司研究的问题同时要求财年收入和变化限制；先前选段集中在合并经营报表，模型因未见管理层讨论而报告资料缺口。现仅在问题明确要求风险、限制、解释或反方，且指明两个年度和一个可识别财务指标时，尝试在同一来源内同时选取财报表头、目标行，以及包含两个年度、该指标和变化词的原始叙述段落。选段受同一输入预算约束，财报核心结构无法保留、段落不满足条件或窗口重叠时回退既有选择逻辑。

对 272 号保存原件和问题进行离线选段，当前选段包含公司对两个财年总收入变化、收购贡献以及产品与服务变化的讨论，也保留目标财务表中的两期收入与表头。叙述中的关键词和两年共现只是检索线索，不证明该段是反方、因果解释或对全部资料的概括；来源、期间、事实和模型引用仍须分别核查。相同数据、预算下的模型表现尚未验证，不能由选中段落推断阶段 B 质量通过。选段方法版本升至 v49，旧版本运行记录保持不变。
