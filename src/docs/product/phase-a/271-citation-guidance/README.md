# 引用指引对照：运行前登记

复用 270 号高预算组的 GDP 生成调用作为对照，固定相同的官方资料快照、问题、来源选段、模型、系统提示和供应商参数。候选提示仅替换同一 `evidence_guidance` 字段，增加：主张须引用期间、没有明确依据时不添加具体期间、反方应引用相关反证、不能把摘录缺口推广到全部来源。候选的资料、来源偏移和问题与对照逐字段相同；提示序列化字节仍在原输入上限内。

最多一次新生成调用，预留不超过 10,000 Token、60 秒，不搜索、不复查、不重试；已有对照来自上一次独立调用。此前已知累计 297,677 Token，其他历史用量及美元费用未知。两次调用并非同时，模型内部版本与随机性不可锁定，因此不能用一次对照证明效果或泛化。题目及资料已用于开发，不是独立验收。

预先检查引用期间、事实与引用的匹配、反方是否相关且有原文，以及来源不足时是否准确披露；逐项保留无法判定的状态。复用输出结构和定位检查，不能用模式匹配冒充语义验证。若调用结果或用量不明则记录并停止，不重试。原始输出独立保存，不能覆盖 270 号结果；只有有依据的改进才考虑进入产品提示，并须报告未验证部分。

## 结果

候选调用完成，供应商报告 2,509 Token；已知累计 300,186 Token，历史未知用量及美元费用仍未知。对照组生成调用为 2,412 Token（不含 270 号另一次复查）。候选与对照均正确引用了消费中服务增长、商品下降的原文，但候选有 **0 条带引用的反方**，对照有 1 条；离线重放的期间警示分别落在候选 4 条、对照 2 条主张上。这些是有限的机械观察，不是完整语义评分。候选还将进口上修与抵消消费下修并列归因，所附文字不足以确认该方向关系。候选没有展示出采用价值，**未修改产品提示**；单次非盲对照不证明提示调整普遍无效。

候选还称“提供的来源中没有反证”，但模型仅看到摘录。原有模式未识别 `in the supplied sources` 这种说法；后续增加该表达的范围警示，保存了[修正前](inspection-before-fix.json)与[修正后](inspection.json)离线检查，修正后标出候选第 4 条主张。检查脚本在模型调用后编写，属于诊断而非预先冻结的评分器；原始模型输出及 270 号结果未更改。未再调用模型，不改变阶段 B 验收状态。
