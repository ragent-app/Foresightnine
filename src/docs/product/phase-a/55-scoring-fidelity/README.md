# 未来研究评估的文本匹配修正

第 54 次对照发现，原评分器不能识别 269.74 亿美元与 26,974 百万美元等值，将原文支持的“下降 0.6%”与带符号参考值 -0.6% 分开，并漏识别“没有委员投反对票”。本目录为**未来、调用前冻结**的评估提供修订版匹配器和评分脚本：

- 美元金额仅对明确的中文美元单位做十进制精确换算，不把其他币种或不合法分组视为等值。
- 参考百分比使用带符号值；仅在可识别、未被否定的下降表述紧邻正幅度时，将该幅度匹配到负的参考变化。方向相反或“下降负数”等含糊写法不匹配。
- `name_checks` 明确指定 `kind: no_dissent` 时，可识别有限的中英文无反对票表达；引用仍须指向预先指定的原文，否定句不算通过。
- 结论存在未覆盖金额、引文主体提示或未核实数值方向时，相关检查保守处理。评分不能证明实体、期间或完整语义正确。

未来评估需在模型调用前将 `score.py`、`matching.py` 和参考数据一并固定，清单分别记录 `scorer_sha256`、`matching_sha256` 与 `references_sha256`。脚本校验这些哈希；任务、来源权限、阈值与预算仍须单独预先登记。此工具只执行有限机械核验，不能把通过解释为独立语义证明或投资有效性。

[事后文本检查](prior-inspection.json)仅说明上述四个先前表达可被新匹配器识别；它没有重新计算第 54 次分数，原先 1/3 对 1/3 结果和采用决策不变。测试覆盖正确与错误方向、否定表述、等值金额、来源提示及冻结后脚本篡改拒绝，共 4 项通过；此次未调用模型。
