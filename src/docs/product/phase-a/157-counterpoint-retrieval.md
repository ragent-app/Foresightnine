# 风险资料选段改进

选段方法 v35 在用户明确要求反方或风险、通用选段得到两个窗口且次要窗口看起来是未检测到数值行的表头时，尝试以一条包含问题词的完整转折句替换该表头。原首选窗口不变；如果句子太长、与首选窗口重叠、主题词不足或表头含有可识别数值行，则不替换。该规则无法理解全部表格或验证相关性，转折句也不一定构成反证；来源未覆盖范围继续显示。预算、权限、实际原文偏移、用户手动选择资料片段和既有专门选段规则不变。

对 151 号已用于开发的银行压力测试资料作本地重放：输入预算、问题和来源不变，原选段为 10197–10623 和 27136–27430，新选段为 10175–10646 和 11840–12000；送入模型的文本同时包含 12.4、9.9 和报告中关于抵押贷款、信用卡及商业地产集中风险的完整句子。贸易资料选段本次仍为 1893–2200 和 2625–2911。本次未调用模型，结果不证明模型会正确使用片段、表格未含其他重要信息或 B02/B04/B09 已通过；此开发样本不能充当独立质量集。

研究分析和运行相关 API 测试通过；覆盖显式要求、主题词不匹配、已有数值行、片段过短和原始字符偏移。该规则仅作有限检索提示，后续仍需更广泛的研究问题与资料验证。
