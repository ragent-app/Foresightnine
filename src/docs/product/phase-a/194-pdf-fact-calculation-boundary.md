# PDF 换行恢复事实的计算边界

PDF 提取时的行末连字符可能是真实连字符，也可能只是断行。对通过 `pdf_line_hyphen_restored` 定位的数值事实，系统继续保存原文和位置供核查，但不将其用于模型自动请求的计算，也不允许直接新建或重算；已保存计算会标为无法核验。方向确认也不能绕过该检查。

用户可通过数值的引文替换功能重新选择原始连续文本；服务端在唯一定位后记录精确引文及用户编辑版本，旧版本保留原恢复标记。这样只表明用户选择了可定位的原文，仍不自动证明财务指标、方向、表格列或语义正确；其他数值和来源校验继续生效。

自动测试覆盖恢复事实保留但不自动计算、未复核时拒绝新建计算、重新选择准确原文后的计算和历史版本保留。Web 提示对应核对要求；本次无真实模型调用，不改变旧评估成绩，阶段 B 尚未完成。
