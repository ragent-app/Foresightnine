# 反方补充结果的证据警示状态

政策任务 285 的补充观点虽可定位引文，但观点包含引文没有明确支持的条件关系。此前系统会将补充步骤显示为“已完成”，即使该观点存在已识别的证据警示，容易与观点已通过核查混淆。

现在补充观点存在可定位引用，但所有补充观点都带已知证据警示、状态不完整或计算差异时，步骤显示“有引用但存在证据警示，需复核”；研究继续保持部分完成。数量截断仍显示部分完成，无引用仍显示没有可用证据。该状态只表示已检测出的警示，既不证明其他观点得到语义支持，也不自动确认反方是否充分。已有研究结果不被改写。

通过模拟供应商的研究运行回归覆盖无警示结果、因果关系警示、额外字段、预算、数量上限和已有反方。此次未调用模型，不改变 285 的原始结果或独立质量验收状态。
