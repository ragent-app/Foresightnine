# 有符号变化的用户确认与计算

对来源中以“下降正数”表述、模型据此提取为负数的事实，研究工作区提供单项操作“我已核对：这是负向变化”。这属于产品中研究者自主复核的功能，不是阶段 B 开发需要等待用户验收。服务端核查事实唯一性、账户与来源权限、研究截止时间、引文唯一完整定位和明确下降线索，再创建用户版本，记录确认时间与事实内容哈希。确认表示用户认可该对象及变化方向，**不将来源或解释标成独立验证**。

确认只对当前事实的指标、值、单位、币种、期间、来源和引文位置有效；编辑事实会清除确认，旧版本仍保留。普通版本保存接口不能注入或伪造确认；过期版本返回冲突，其他账户无法确认。计算与重新计算仅在确认仍匹配且其他已有校验通过时使用该数值，计算结果保留原始输入和用户确认所依据的事实版本。其他诸如币种冲突、引文位置和表格期间警示不由此自动解除。

API 测试覆盖未确认时拒绝计算、用户确认后计算、跨账户拒绝、旧版本冲突、编辑后失效、旧版本保留和普通保存接口的伪造确认。Web 客户端测试、类型检查、生产构建及契约检查通过；本地浏览器使用测试替身完成生成与确认，并检查移动端宽度。浏览器测试不代表真实模型质量或生产部署验收；Vite 保留原有主包体积提示。本次无真实模型调用，阶段 B 尚未完成。
