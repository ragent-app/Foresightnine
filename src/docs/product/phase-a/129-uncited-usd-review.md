# 未覆盖的美元金额提示

126 号真实资料开发样本中，模型反方在只有购买政策概述的引文下写出了两项购买金额，并表示无法从所给摘录确认。此前金额提示依赖匹配到结构化数值事实，缺少事实时可能不提示。

新增独立检查：从结论中识别明确标示美元的中英文金额，将其与已获展示权限、非模拟、可准确定位的引文中的明确美元金额按精确单位换算比较。未匹配金额列为需要复核，不能作为支持结论的证据，也会使自动完成状态保持部分完成；模型支持复核重新计算该提示并跳过此类结论。用户编辑后重新计算，界面和文本导出保留提示。最多展示五项；数值相同也不能证明对象、期间和语义正确。裸 `$` 不被当作明确美元，四舍五入、跨句币种上下文、计算和其他币种需要人工或后续机制核对，因而可能产生保守提示。

对 126 号已保存输出离线重放，使用与保存记录 SHA-256 一致的原始资料 `fed-source.txt`，无需调用模型：第 3 条结论提示 `800 亿美元` 和 `400 亿美元`。这只证明针对已知开发样本的提示行为，不证明模型幻觉、语义支持、总体效果或阶段 B 质量验收；旧输出和原评分不变。本次没有新增模型调用和 Token 用量。
