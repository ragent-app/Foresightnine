# 单次研究的输入预算

研究请求和 Web 研究预算面板新增可选的单次模型输入 Token 上限。留空时使用部署配置；指定值只能低于或等于部署的研究输入上限（默认 3000，服务端可配置至多 12000），并且每次调用的输入加输出预留仍受该研究总 Token 预算约束。请求上限超过部署限制、不是有效整数或供应商不支持该控制时明确拒绝，不更改共享提供商配置。该选项不自动提高部署上限或保证资料覆盖及研究质量。

运行输入记录保存请求值和实际提供商限制，重放相同幂等请求不重新调用；不带新字段的旧请求保持原有请求哈希。支持性复查使用同一个单次输入上限，其调用仍受总预算和次数限制。不同研究可以各自控制预算，不影响其他请求。

相关 API、提供商、OpenAPI 及契约检查通过；Web 类型检查、285 项测试和生产构建通过。Browser 插件未提供，在本地内存 API、模拟模型与测试账户下使用 Playwright 检查预算面板填写 2500、运行并在输入记录显示实际 2500，桌面及 390 像素宽度无横向溢出和页面错误；未进行生产环境或真实模型调用。构建保留主包大于 500 kB 的既有提示。阶段 B 的研究质量及独立测试条件仍未完成。
