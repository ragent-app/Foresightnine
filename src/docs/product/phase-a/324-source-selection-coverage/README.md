# 324：首次研究的资料选取范围

研究运行在每份已分析资料的来源摘要中记录首次模型输入选中的提取文本范围。后端合并重叠片段，统计不重复的 Unicode 字符数及提取文本总字符数；范围不合法或无法确定时标记未知，不推定为零或完整。工作区展示资料级选取范围，旧版本没有记录时明确显示未知。JSON 和文本报告保留记录。

该范围只描述首次提示中选取的提取文本；PDF 或 HTML 的提取可能遗漏原件内容，也不能证明模型理解、检索充分或结论有证据支持。反方、补充取证与复核可能使用不同片段，不与首次输入合并；完整覆盖不等于研究完整，部分覆盖也不自动判定结论错误。用户编辑保留原运行记录，数字只反映当时的输入。

本改动尚未测试、浏览器检查或执行模型实验，不改变阶段 B 验收状态。用户要求暂停测试与模型实验，后续按授权集中验证。
