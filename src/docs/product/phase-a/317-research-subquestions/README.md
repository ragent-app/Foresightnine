# 研究子问题与缺口线索

首次研究的结构化输出可包含最多十条模型建议的子问题，以及每条关联的结论索引。系统先执行既有引用定位和结论筛选，再将有效索引映射到保留结论；无效或已删除的引用不形成关系并留下提示。保存研究版本时索引转换为版本内结论标识；后续用户编辑结论文本或引文后，相关旧链接不再继承。历史版本和未提供此字段的旧模型输出仍保留原样。

工作区展示模型建议的子问题、关联结论或未关联状态；有链接不证明问题得到回答、引用支持或证据充分。未关联的子问题进入通用待核查列表。用户启用有界证据缺口补充时，最多三条未关联子问题与已有证据警示可作为不可信的本地取证线索；补充仍只处理本次已授权资料。两次模型输出中只有文字完全一致的子问题才合并关联，不自动将相似问题当作同一问题；引用的结论索引按实际保留结果重新映射。

这些子问题在首次模型生成时提出，是可检查的研究覆盖建议，不是在生成前执行的自主计划；当前仍未实现独立规划器、动态外部发现或覆盖充分性的语义证明。按照用户要求，本次未运行测试、浏览器检查或模型实验；模型输出兼容、预算影响、恢复与实际效果尚未验证，阶段 B 尚未完成。
