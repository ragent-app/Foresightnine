# 降少金额的有符号候选事实

182 和 183 号真实研究都把“商品支出减少正数金额”提取为负的金额变化，而原文没有显式负号，旧规则会丢弃该事实。现在仅在引文明确包含下降词、美元符号、相同数值和相同数量级时，保留模型提取的负数为待核对事实，并记录 `direction_context_unverified`。美元符号不能单独确定币种，负号也不能证明对象、期间或该数值是变化而非水平；否定、金额或数量级不符时不作这种推断。

这类候选事实不能直接用于自动计算或重新计算；用户编辑后服务端仍重新检查并保留方向提示，不能通过删除提示字段绕过。实际用户如需计算，必须先解决方向及来源口径。[后续实现](189-direction-confirmation.md)为此增加了版本化的单项用户确认；确认不等于独立核验。

使用 183 号保存的供应商输出离线重放，原被丢弃的 `-36.7` 十亿美元商品支出变化现被保留并标为方向待核对，未进入计算。相关分析、研究运行及计算测试通过，覆盖下降词次序、否定、数量级和数值不符，以及编辑后不能绕过计算限制。离线重放未调用模型，不改变原评分；阶段 B 尚未完成。
