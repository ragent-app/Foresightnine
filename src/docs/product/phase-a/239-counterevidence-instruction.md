# 反方证据提示

真实研究回归曾出现把资料不足、解释上的提醒或对同一事实的确认当作反方的问题。研究系统指令现要求反方提供有引用的相反证据；没有时记录缺口，不把缺口当作证明。原有来源和问题是不可信数据、只使用给定来源、不能自行计算、证据与推断分开等约束保留。

新旧系统指令均为 433 UTF-8 字节，使基于该长度预留的输入预算不变；真实 PDF 的既有摘录回归及研究分析测试通过。提示修改不保证模型遵循，也不能代替对相关性、因果关系和语义支持的独立核查；本次没有调用模型。页码输出结构与系统提示均已在 238 号调用之后发生改变，因此不能将下一次整体结果直接归因于其中任一项；进行质量比较时须分别固定其他条件并预先登记，避免把多个变量同时改变的回归当作单因素实验。
