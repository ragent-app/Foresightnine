# 阶段 B 真实模型试运行预登记

本次仅是开发样本的真实模型连通与行为试验，不是盲测、跨领域评估或阶段 B 质量验收。固定问题为 “What was 2023 annual real GDP growth, and how does it differ from the quarterly annualized rate?”；唯一资料是此前保存的 BEA 2023 年第四季度初值公告 PDF，SHA-256 `3cc68c16d15ce51e8a5c821c407e32b9f2185edbcadbaadfb1a3fed01ed9b31d`，公开时刻采用 2024-01-25 13:30 UTC，研究截止 2024-01-26 UTC。历史版本未独立证明。BEA 的使用说明和例外限制见来源矩阵。

固定调用已配置的 GLM Coding 模型，保持现有供应商生成设置；一次研究最多两次模型调用（首次生成和可选二次复查），最多 20000 Token、120 秒、不搜索、不重试外部调用。实际单价未知，因此不设置美元上限，也不能声称费用为零。预期每次的配置上限和实际消耗以运行记录为准；供应商返回不确定时保留费用不确定性。本实验不比较模型，不调参，不使用 FRED。只运行一次；失败照实记录，不据结果修改此次预登记。

预先检查点：请求提交及终态；生成与复查调用次数；是否报告 2023 全年 2.5%、第四季度折年率 3.3% 并区分口径；引用能否在资料中定位。数值和关键词检查仅是机械冒烟，不等价于完整逐项语义核验；模型复查不属于独立核验。保存原始研究输出、运行元数据和检查结果，不保存密钥或访问令牌。
