# 原因表述的引文核查提示

231 号 BEA 研究在反方中提到疫情影响，但引用的历史数值表没有这一原因。现在对有限中英文因果词进行提示：当结论或反方出现原因表述，而其可展示、非模拟、唯一定位的引文中没有相应因果词时，标记 `causal_attribution_unverified`，研究保持部分完成，模型复查不能直接清除该已知缺口。用户编辑结论后按新引文重新检查；旧版本保留。页面和文本导出显示这一提示。

这是有限词汇线索，不判断因果关系是否成立，可能遗漏其他表达或产生误报；引文中出现因果词也不代表证明了相同对象、原因或传导关系。对已经引用的原文进行检查，不把未引用的周边文本当作依据，不把模拟、不可展示、位置含糊或伪造的引用用于消除提示。

231 号已保存输出的无模型离线检查将原有疫情解释标记为待核查；原结果、评分与历史记录不变，不据此宣称独立质量评估通过。证据、复查、研究版本及文本导出测试通过。Browser 插件未列出，使用本地 Playwright 与合成资料验证提示显示、编辑结论后重新检查和旧版本保留，桌面与移动视图无相关控制台错误；临时服务已清理。未新增模型调用。
