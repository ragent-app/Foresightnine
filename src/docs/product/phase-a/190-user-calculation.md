# 从已保存事实创建计算

研究工作区新增基于已有数值的计算入口，支持差值、增长率和利润率。用户选择第一个和第二个事实；差值为前者减后者，增长率使用本期和基期，利润率使用分子和分母。结果由现有确定性计算器生成，保留公式、输入快照、单位、舍入和精度提示，并作为新研究版本保存；不调用模型，不把输入或计算结果视为独立核验。

新建与重算共用服务端事实检查：事实必须属于当前账户和研究版本且唯一，方向推断必须经用户单项确认；歧义来源位置、期间列冲突、币种冲突和带币种的百分比等保持拒绝。计算器继续检查两个输入不同、单位币种一致、分母为正，以及增长率和利润率的期间规则；不可计算时不创建版本。账户越权及过期父版本分别拒绝，历史结果保留。用户资料中的数值与来源本身仍需核对，计算一致不能证明投资结论。

API 测试覆盖有效计算、缺失或重复事实、零分母、不兼容单位、账户隔离、版本冲突以及方向确认前后；Web 类型检查、测试、生产构建和生成契约检查通过。本地浏览器使用测试替身完成研究、确认下降方向、选择两项事实并保存差值，移动端无横向溢出；该测试不代表真实模型质量或生产部署验证。Vite 仍提示原有主包体积较大。本次没有真实模型调用，阶段 B 的整体质量评估仍在进行。
