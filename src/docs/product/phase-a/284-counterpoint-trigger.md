# 反方补充触发条件与容量边界

已有反方如果仅有引文但存在已识别的来源范围、数值、期间、因果或其他证据警示，不能阻止可选的反方补充；现在使用与研究完成状态一致的警示集合，并考虑另行计算的金额和计算差异。原反方和警示继续保留，新结果仍须经过原文定位和同样的检查。没有警示仅表示未发现已知问题，不证明反方相关或正确。

反方已达 20 条时不再发起补充调用；若剩余容量不足以保存所有新反方，保留可容纳的结果、明确标为部分完成并记录遗漏，不覆盖已有反方。工作区相应显示可用性及容量状态。

将 272 号政策样本用当前证据提示离线检查，其已有反方带有未引用的百分比和动机归因警示，因此不再阻止用户已启用的补充步骤；此次未调用模型。API 测试覆盖有警示与无警示、独立计算差异、容量耗尽及结果截断；Web 类型、客户端和本地模拟页面交互测试通过。Browser 插件未提供，页面检查使用 Playwright；该功能的真实跨领域质量仍待验证，不能据此认定 B04 或阶段 B 完成。
