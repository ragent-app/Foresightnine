# 338 来源使用范围核验

核验时间：2026-11-14 09:16 UTC。沿用项目 [来源矩阵](../03-source-inventory.md) 的限定用途，本轮仅将冻结清单中的 BEA 和美联储自行发布的宏观公告提取文本用于隔离研究、模型输入及经服务端许可检查的结果导出，不包括生产发布、图片、标志或其他第三方材料。

- [BEA FAQ](https://www.bea.gov/help/faq/147) 称网站信息除另有说明外可使用及复制，并建议注明 BEA。2026-11-14 再次读取，页面显示最后修改于 2018-04-24。
- [美联储声明](https://www.federalreserve.gov/disclaimer.htm) 称其网站信息除另有说明外可复制和分发，要求注明来源；非美联储图像或其他材料须向权利人另行取得许可，标志亦有单独限制。2026-11-14 再次读取，页面显示更新于 2024-08-02。
- 五份来源的主机均为 `www.bea.gov` 或 `www.federalreserve.gov`；逐项复核清单中原 PDF 与 `pdftotext -layout` 提取文本的 SHA-256 均一致。两个新资料的提取文本中检索 copyright、third-party、licensed、permission、photo、reprinted 和 source 标签，未见例外声明；该文本检索不证明 PDF 图片或未标注第三方内容不存在。实验只发送提取文本，不使用图片或标志。
- FRED 不在清单和输入中；清单逐项设置的导出许可仅针对以上核验范围。文本未发现例外并不自动证明全部第三方权利、历史版本不变或其他产品场景获准；如出现第三方素材则不纳入。获取时间与哈希见 [预登记](preregistration.json)。
