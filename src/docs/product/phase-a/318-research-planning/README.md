# 有界研究规划

研究运行新增默认关闭的 `plan_research` 选项。用户启用后，在既有来源发现及授权获取之后、资料分析之前，系统可用一次独立模型调用提出最多六个研究子问题；问题、范围及模型输出均是不可信数据。计划只能引导已授权资料的选段，不提供新的来源或工具权限，也不在此步骤调用搜索、读取私人资料正文或执行计算。来源发现依然由用户原问题和既有搜索授权控制。

规划调用、后续生成、反方补充、缺口补充和复查共用总调用次数、Token、时间与费用约束。规划仅在至少有一个允许的来源、可用模型、足够预留两次调用预算和剩余时间时启动；请求货币费用上限但报价未知时不调用。调用前预留，结束后结算，记录模型报告的用量、提示与系统提示哈希、失败和计划；不明费用保持未知。规划失败时允许原问题继续研究，并明确标记规划未完成。程序中断时运行收据和已有检查点按既有语义保留，不能保证第三方未计费。

计划作为不可信提示进入来源选择及原始研究模型输入；用户问题本身不被计划替代。原始研究后的子问题列表保留计划项：只有问题文本完全一致时才关联模型提出的结论索引；无链接表示覆盖未知，有链接也不证明问题已回答。启用证据缺口补充时，未关联计划子问题可作为已授权资料内的补充线索。反方补充和引文线索重放使用相同计划，以保持来源选段一致。

工作区显示计划为模型建议并提示额外调用与可能遗漏；JSON 和文本导出通过运行记录保留计划及成本信息。当前规划并不保证覆盖用户需求，不按计划自行扩大资料或执行外部发现，也不构成多个独立 Agent 或语义验证。计划与研究质量、调用时延及费用需要后续统一评估。

按用户要求，本次未运行测试、浏览器检查或模型实验；仅按当前接口生成了 API 模式快照和 TypeScript 类型。兼容性、成本控制、恢复及模型效果均尚未验证，不能视为阶段 B 完成。
