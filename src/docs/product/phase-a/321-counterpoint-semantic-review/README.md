# 引文支持与反方相关性分开复查

对用户请求的模型复查，反方除了检查自身引文是否支持其陈述，还可根据明确的用户关联或模型建议关联，将相关原结论作为未可信上下文提供给复查模型，单独返回“相关、不相关、不确定”。原结论上下文不是反方证据，模型判断也不是独立核验。未有关联、关联无权发送、上下文过长或预算不足时，相关性保持未评估或不确定，不能把模型的“相关”提升为有效判断。支持结论仍使用原有引文复查语义。

合并和逐条复查均保留此边界；针对性证据警示仍不会由模型复查自动清除。用户要求反方且请求复查时，反方相关性未获模型支持会使结果保持部分完成；它不要求用户手动验收，也不代表模型说相关即为事实。工作区、待核查列表与现有文本导出分别呈现引文支持和相关性结果。复查方法版本为 v31，历史结果不改写。

按用户要求，未运行测试、浏览器检查或模型实验；提示兼容性、上下文权限、预算、恢复与语义质量尚未验证，不代表阶段 B 完成。
