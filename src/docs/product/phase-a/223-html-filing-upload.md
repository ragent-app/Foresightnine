# 用户提供的 HTML 财报导入

研究工作区支持上传最多 5 MB 的 UTF-8 HTML 或 PDF。HTML 按用户声明的权限保存原始文件、原文件 SHA-256 与独立的提取文本哈希；提取器跳过脚本、样式和 inline XBRL 的 `ix:header` 元数据，保留可见文本、表格分隔符与跨度标记。提取标记由程序生成，并不保证表格列、样式或实际可见性完整；研究仍须对照原始文件核查。无法处理的编码、无正文、未闭合的 XBRL 头部、超过尺寸上限或存储权限未授予时拒绝；并发提取受限。HTML 不执行，不抓取其中资源。

原始 HTML 不包含在普通来源元数据或研究导出中。只有所属账户且来源同时允许显示与导出时才可下载，服务端以附件、`application/octet-stream` 和 `nosniff` 返回；用户仍须自行判断文件是否安全。时间、归属与使用权均为用户声明，不因上传而被验证。原文件持久化沿用项目现有存储与备份语义，不代表生产环境备份已验证。

验证使用已有 Cisco FY2024 原始 SEC HTML（约 3.55 MB，之前已经用于开发，不能视作独立评估）：通过完整 HTTP 上传并重新读取研究资料，可找到 53,803 和 56,998；这不证明列对齐、财务计算或主张语义正确。API 检查覆盖表格提取、XBRL/脚本排除、原件哈希与字节、权限及账户隔离、错误输入，且通过 v2 OpenAPI 对照；Web 类型检查、客户端请求测试及既有 291 项 Web 测试通过。新增导入控件尚未单独做浏览器交互验证，仍须在阶段结束时完成整体回归。没有新增模型调用。
