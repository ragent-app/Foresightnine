# 多片段检索的配对探索：调用前登记

复用 161 号已退休为开发样本的 BEA 公告和问题；该样本不再是独立测试。固定当前代码、来源及哈希、模型、生成参数、系统提示和每次 6000 输入及 4000 输出 Token 上限。唯一主动变量是通用检索使用两个或三个窗口：对照在相同代码内将三窗口请求改为两个，窗口宽度由三等分反推二等分，最多有一字符舍入差异；候选使用当前实现。两个条件的选段和提示哈希分别登记。其他依赖窗口数量的处理属于该变量的后果。

先对照后候选，各直接调用一次模型，最多两次、每次预留 10000 Token、总计 20000 Token，60 秒超时；不搜索、不执行支持复查、不重试。首次不确定或用量未知即停止。美元价格和供应商内部版本未知；此前已知累计 178711 Token，另有历史未知用量。

调用前固定资料、参考、脚本及实现哈希；沿用 161 号 PCE 有限机械评分，分别检查要求的四个数字及商品和服务是否出现在可定位主张及引文。评分不检查数字所属指标、正负方向、所有推论的语义或研究整体质量；仍需记录明显问题。该非盲、单样本、每条件一次的开发探索不证明因果或泛化，不能作为 B02、B04 或 B09 验收。

## 结果

两次调用均确定完成；两窗口和三窗口条件分别报告 3037、2931 Token，合计 5968，已知累计 184679 Token，另有历史未知用量及未知美元费用。对照未同时覆盖四个指定数字与商品、服务关键词；三窗口条件覆盖这些有限信号。两项保留的引文均可定位。

对照中商品支出数字所在句子被截断，模型指出缺口；其反方同时讨论价格指数及实际支出，但仅引用了名义支出的表格行，不能由该引文单独支持全部内容。三窗口条件的主张引用了名义消费增长、服务增加和商品减少的对应原文及储蓄率；但其另一条比较名义支出、价格指数和实际支出的主张，没有在该条自身引文中包含名义 0.1% 的依据。此外，三窗口条件有一条模型生成的事实被剔除、一条引文不匹配后被剔除、一个计算因缺少可用输入被省略，最终没有保留反方。引用可以定位和关键词命中不意味着所有主张均获支持。

该探索只表明已知样本上该次运行的有限覆盖信号发生变化，不能证明整体研究完成、语义质量提高或可推广。保留两次原始输出与预登记评分，不重算或覆盖 161 号首次评估结果；阶段 B 仍未通过独立质量验收。
