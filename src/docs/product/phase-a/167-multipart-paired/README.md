# 多片段检索的配对探索：调用前登记

复用 161 号已退休为开发样本的 BEA 公告和问题；该样本不再是独立测试。固定当前代码、来源及哈希、模型、生成参数、系统提示和每次 6000 输入及 4000 输出 Token 上限。唯一主动变量是通用检索使用两个或三个窗口：对照在相同代码内将三窗口请求改为两个，窗口宽度由三等分反推二等分，最多有一字符舍入差异；候选使用当前实现。两个条件的选段和提示哈希分别登记。其他依赖窗口数量的处理属于该变量的后果。
