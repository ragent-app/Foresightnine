# 三类原始资料的固定任务检查：调用前登记

一次性冻结三个此前未用于本项目模型调试的原始 PDF：美联储 [2025 年压力测试报告](https://www.federalreserve.gov/publications/files/2025-dfast-results-20250627.pdf)、BEA [2021 年 5 月个人收入与支出资料](https://www.bea.gov/sites/default/files/2021-06/pi0521_fax.pdf)、美联储 [2017 年 3 月决议](https://www.federalreserve.gov/monetarypolicy/files/monetary20170315a1.pdf)。分别检查公司资本实际值与情景、消费总额与商品/服务反向变化、政策区间及反对票。资料使用条件见来源矩阵。参考答案单独保存，不输入被测系统；快照和代码、题目、参考、评分、提示与来源哈希均在调用前固定。

固定当前实现、同一模型和参数，每题最多 1 次生成、不搜索、不请求模型复查、不自动重试；单次上限 10,000 Token、60 秒、任务上限 120 秒，三题合计最多 3 次、30,000 Token。真实货币成本未知，不当作零；用量或终态不明时停止后续任务。无数据泄露或未来知识保证，来源为后来获取的副本，不能证明历史逐字节内容。

在调用前确定狭义机械条件：三题均需包含各自的预期要素及可定位原文，所有保留主张有唯一完整引用、无已有数值或上下文警示、预算受控，若研究为部分完成则明确缺口。三题全部满足才算本项机械检查通过；逐词和数值共现不能证明数值对应关系、表格列、引用语义或完整性，还需另外检查实际输出。计分程序、任何失败及所有原始响应均保留，不因后续修复改分。

这些资料未用于本项目开发，但任务形式类似先前的开发样本，准备者看过参考，来源和模型训练数据可能公开，不是独立盲测。只有三题，不能替代完整多类型独立测试集或全部 B 阶段验收；不把用户要求跳过人工验收解释为已经取得人工基线。

## 结果

三题各执行一次，报告 2,956、1,595 和 1,739 Token，共 6,290；累计已知报告 236,673 Token，另有历史未知用量与未知美元费用。三个操作均完成，但研究均标为部分完成；按预登记检查为 0/3，原始输出和评分保留。

- 公司题找到并引用了三项资本比率和列标题，但一处假设说明在原文中重复，另一条预测主张未引用对应季度；不能认定引文全部唯一且完整。
- 消费题的 `reading` 提取在英语单词间丢失大量空格；模型输出的引文与该提取文本不一致，主张未被保留。离线提取同一 PDF 的 `layout` 版本显示空格正常，但这不是本次运行的模型输入，不改变成绩。
- 政策题找到了目标区间、反对者及其偏好；所附主张还存在数值复用及其他事实候选提示，故未满足预登记的无主张警示条件。另有部分模型利率事实附加 USD 币种，系统保留单位核查提示；该事实层提示并不是评分器中该项失败的直接判据。

数值和词语共现不能证明表格、时期与结论的全部语义；本组结果不足以认定 B02、B04 或 B09 通过，也不代表所有问题类型的表现。

评分器事后核查：其“无已知主张警示”检查未包括 `rate_unit_warnings` 和 `publication_date_warnings`，比预登记文字中的“无已有数值或上下文警示”更窄，也未覆盖事实层币种提示。本次三题均已因其他条件失败，不修改原评分或事后放宽标准；该评分器不能用于声称全面无警示。
