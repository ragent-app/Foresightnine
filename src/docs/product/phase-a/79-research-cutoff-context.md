# 截止时间进入研究上下文

此前用户指定的研究截止时间已用于按资料声明的公开和修订时间过滤来源，也记录在运行输入快照中，但没有进入模型提示，打开研究时页面也未显示。现在非空截止时间以带时区的 ISO 时间传入模型，提示其只使用截至该时点的信息；页面显示保存的时间，并说明来源时间为声明值且模型训练可能包含之后的信息。没有截止时间的提示内容保持不变；新增提示占用原有输入预算，片段选择方法标识更新为 v21。

时间过滤仍以来源声明为依据，不能保证声明真实、原文历史版本未变化或模型没有未来信息；提示也不能替代前向观察。超出截止时间或公开时间未知的来源继续不进入模型。本次无真实模型调用，不改变历史评估成绩。

相关 API 分析与运行测试 117 项通过，Web 类型检查通过。本地测试账户和内存 API 的桌面、手机浏览器检查验证截止时间提交及保存后显示；首次检查脚本错误地把等价 ISO 时间的 `.000Z` 与无毫秒表示当作不同字符串，改为比较时间值后通过。未因此修改产品数据或时间处理。
