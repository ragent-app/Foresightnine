在调用前固定问题、资料、预期结果、评分、代码、片段与提示哈希、模型和参数。每题通过研究 API 使用一次生成及最多三次逐条复查，输入上限 6000、输出上限 4000，每题最多 20000 Token，合计最多八次调用及 40000 Token；每次超时 60 秒、每任务 120 秒，不搜索、不自动重试不确定调用。状态或用量不明时停止后续题目。模型内部版本及美元费用未知；此前已知累计 209215 Token，另有历史未知用量。

评分仅检查指定事实出现在同一主张及其准确定位的引文中：PCE 的名义总额、商品、服务、储蓄率和实际 PCE 的小于号与方向；政策目标区间及准备金利率和生效日期。所有主张必须有唯一定位的引文；任一项不满足即该题有限机械检查失败。数字、关键词和位置共现不能证明全部语义、单位、期间或因果正确，模型的复查结果也不能独立证明支持。保留所有原始供应商输出、检查点、遗漏、评分及未完成状态，运行后不改分、不重跑。
