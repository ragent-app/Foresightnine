# 新宏观原始资料检查：调用前登记

固定两份此前未在项目资料中发现、未用于产品调试的官方原始 PDF：BEA [2023 年 3 月个人收入和支出](https://www.bea.gov/sites/default/files/2023-04/pi0323.pdf)及美联储 [2023 年 2 月 1 日决议与实施说明](https://www.federalreserve.gov/monetarypolicy/files/monetary20230201a1.pdf)。2026-11-12 14:39 UTC 前后各取一次；保存 PDF 与哈希，并按原件标记发布日期。BEA 与美联储资料通常可使用和复制，第三方例外需另核，依据见[来源矩阵](../03-source-inventory.md)；不使用 FRED。现时副本不证明历史字节从未改变，任务不设历史截止时间。

在调用前固定问题、资料、预期结果、评分、代码、片段与提示哈希、模型和参数。每题通过研究 API 使用一次生成及最多三次逐条复查，输入上限 6000、输出上限 4000，每题最多 20000 Token，合计最多八次调用及 40000 Token；每次超时 60 秒、每任务 120 秒，不搜索、不自动重试不确定调用。状态或用量不明时停止后续题目。模型内部版本及美元费用未知；此前已知累计 209215 Token，另有历史未知用量。

评分仅检查指定事实出现在同一主张及其准确定位的引文中：PCE 的名义总额、商品、服务、储蓄率和实际 PCE 的小于号与方向；政策目标区间及准备金利率和生效日期。所有主张必须有唯一定位的引文；任一项不满足即该题有限机械检查失败。数字、关键词和位置共现不能证明全部语义、单位、期间或因果正确，模型的复查结果也不能独立证明支持。保留所有原始供应商输出、检查点、遗漏、评分及未完成状态，运行后不改分、不重跑。

这些题和参考由开发者在运行前查看，非盲、未经独立人工审定；虽然资料未用于此前调试，也不能称为完整独立测试集。两个宏观题不能替代 Microsoft 首研及其他领域的 B09 验证，不凭其成绩宣布 B 阶段完成。

## 结果

两次研究操作均有确定终态，PCE 使用三次模型调用共 3935 Token，决议使用四次共 3411 Token，合计 7346；已知累计 216561 Token，另有历史未知用量和未知美元费用。两题各自满足预登记的有限数值和位置检查，但研究均如实标为部分完成，不能把机械通过当作研究质量验收。

PCE 题的总额、商品、服务、储蓄率及实际支出小于号均能在相关主张与定位引文中找到。五条主张中三条未进入复查：其中第一条的“小于 0.1%”引文已存在，却因另一条不同指标恰好也是 0.1% 而被提示存在未引用事实；这是需要进一步处理的保守误报。反方涉及多个口径与修订表，但附带引文不足以支持其全部陈述，复查未覆盖。

决议题的目标区间、准备金利率和日期均有对应定位引文。三条进入复查，其中模型对“准备金利率帮助将有效利率维持在区间内”的额外机制解释给出 `does_not_support`；该机制并非所引两段文字直接证明。反方混合目标上限、准备金和贴现率，其引文只覆盖后者，未进入复查。模型复查本身不是独立证明。

以上结果说明新资料上的主要定位和目标数字能够进入成果，但反方与复合主张仍有证据缺口，且存在同值不同指标引起的误报；B02、B04、B09 不能认定全面通过。原评分和供应商输出保持不变。
