# 保留摘录预算的 PDF 页码提示

在既有检索算法完成选段后，仅使用剩余提示词预算标注所选 PDF 摘录的首页和末页；先去除同一来源重复的标题及覆盖元数据，保留各来源首次出现的标题、覆盖范围和所有原文。预算不足则回退原提示，不挤占或缩短摘录。模型可在引文或事实中给出可选整数页码，系统仅在实际展示过页码且对应来源的已选文字内定位；页码无效、页内没有引文或非 PDF 页码不能成为引文，同页多处匹配仍有歧义。没有页码时沿用原有定位。

这是模型对页码的选择，并非独立核验，不能证明表格列关系或主张的语义支持。系统保留上述限制并在运行记录中标记 v46；原始文件和历史版本不变。

不调用模型的离线比较中，235 号三份 PDF 的选取范围与旧版完全一致；在修改提示语前，BEA 及政策声明得到部分页码提示，银行报告预算不足因而没有页码提示。此结果只是预算与选择范围检查，不证明模型会使用页码或研究质量合格。研究分析、真实原文与任务运行回归通过；需进行正式独立质量评估，不能以此宣称阶段 B 完成。

后续 [238 号单题回归](238-pdf-page-single-recheck/README.md)中，真实模型没有使用页码字段，研究仍为部分完成；不能把该功能等同于解决表格歧义。
