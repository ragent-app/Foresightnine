# 经营现金流的公司资料开发检查

调用前登记：使用此前已在项目开发中使用的 [NVIDIA FY2023 SEC 申报](https://www.sec.gov/Archives/edgar/data/1045810/000104581023000017/nvda-20230129.htm)完整 HTML 本地文本提取，提出新的 2023、2022 年经营活动现金流、日期、单位与同比问题。表格分隔符及跨列标记由提取器生成；需回看原申报核对列对齐。来源已用于开发，本题和参考对准备者可见，非盲，也不测试联网发现或历史字节不变性；不作为独立测试或完整阶段 B 验收。

固定原始提取文本、资料标识、题目、实现、模型与参数、提示哈希、预选片段、参考和评分脚本，见 manifest。只提供一份来源，不搜索；此事实核验任务不强制反方。最多调用模型一次、10,000 Token、120 秒，不进行模型复查或不确定调用重试；终态或用量不明即停止，美元费用未知。已知累计 131,420 Token，另有历史未知用量。

预先要求两期数值、期间及单位、财务表格表头与行引文、确定性同比结果、引用位置、预算及系统警示全部满足才记为狭义机械通过；原资料只选中一部分时研究状态仍可为 partial。评分不证明所有结论的语义、币种口径、来源授权或阶段质量；必须保留逐项缺口。构造评分测试在调用前确认正确例通过、增长方向错误及引用位置错误失败。原历史实验不改写。
