# 风险资料选段：配对探索预登记

使用此前开发用的 2023 年美联储压力测试原文、问题和来源权限。固定当前分析代码、模型及生成参数、系统提示、输入预算、调用顺序和评分方法；唯一主动变化是启用或关闭 v35 的反方候选选段，其影响是模型输入片段发生变化。先运行关闭条件，再运行启用条件；每项一次调用，不搜索、不重试、不做二次复查。每次最多 3000 输入及 4000 输出 Token，整体预留上限 20000 Token、单次超时 60 秒；未知状态或用量立即停止。此前已知累计 171980 Token，另有历史未知用量，美元费用未知。

调用前冻结脚本、代码提交、原始来源及题目哈希、提示哈希与选段。比较两项：是否保留实际 12.4% 与情景最低 9.9% 的可定位引文；是否有引用原文中抵押贷款、信用卡或商业地产风险的反方。原始输出和全部引用将保留，定位与关键词不证明语义正确，须同时检查可能的无依据推论。此前观察过这个样本并据此开发选段，单次配对也无法消除顺序及供应商内部变化；本探索不是独立质量验收，也不能证明 B02、B04 或 B09 通过。

## 结果

两次调用均确定完成，关闭和启用条件分别报告 1225、1313 Token，总计 2538；已知累计 174518 Token，另有历史未知用量及未知美元费用。两项均有可定位引文包含 12.4 和 9.9。关闭条件的反方引用仅包含预测期间，未引用具体集中风险；启用条件引用了报告关于抵押贷款、信用卡和商业地产集中度较高的银行资本比率降幅较大的完整句子。两项各有三条已保存引文，均可在原始资料中精确定位。

启用条件进一步解释为“行业韧性不均”，这是对资本比率降幅的解释，不能由该句单独证明所有银行的整体韧性；关闭条件的反方引用只有期间，不足以单独支撑其对模型假设的完整解释。来源覆盖仍是部分。两次输出是一次非盲开发样本上的配对探索，不估计普遍质量，不代替独立测试或阶段 B 验收。
