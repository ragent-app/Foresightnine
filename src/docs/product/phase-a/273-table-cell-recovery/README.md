# 表格单元格引用恢复与原件核对

272 号公司任务中，模型把同一行的名称与后一个年度数值拼成一段并不存在的连续原文，因此旧流程丢弃 FY2023 事实。现在对于模型提供的“行名 + 数值”两格，如果在已分析片段中能找到完整原始表格行、行名与首格完全相同、数值在该行唯一，就恢复**原始整行**作为待核查引用；不把拼接内容当作原文，也不自动证明列、单位或主张。重复数值、不同名称、缺失数值、不完整行和多行歧义继续拒绝或保留歧义。

对有保存 HTML 原件的真实表格，严格原件哈希与 Inline XBRL 检查也可处理位于表格行内的精确子串引文；此前它只处理恢复后的整行。带下划线的模型标签可正确识别财年后缀。只有实体、年度、数值、列、币种、倍率和已支持的指标等条件满足时才生成来源一致性记录；文件真实性、会计语义与模型解释仍须独立核验。

[离线重放](replay.json)直接使用 272 号保存的原件、固定输入选段和模型原始输出，没有重新调用模型：FY2024 和 FY2023 两项事实分别对应原件内标签，同比增长计算为 **−5.61%**，输入状态为 `matched`，含义仅为与保存事实及原件标签一致。输出依然没有反方，存在资料、表格上下文和未独立核验等限制；272 号原始结果与评分保持不变，此单题重放不是独立质量验收。具体复现方式见 [replay.py](replay.py)。

验证包括 API 分析、原件追溯、XBRL 生命周期和计算测试，以及 Web 类型检查。合成案例覆盖不相邻单元格、重复值、错误行名、缺失数字和片段截断；原始 HTML 单元格、期间或币种不匹配继续不能作为已核验输入。
