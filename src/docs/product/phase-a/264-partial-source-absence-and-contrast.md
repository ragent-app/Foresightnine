# 部分资料的缺失断言与同向问题检索

[263 号冻结运行](263-holdout-candidates/README.md)的 GDP 题询问商品和服务是否都增加，但问题没有使用“反方”等显式词语；旧检索未启用对照句查找，遗漏了原文中服务增加、商品减少的段落。选择方法 v47 对询问多个组成项是否都沿同一方向变化的问题，也使用原有的双主题、相反方向检索线索。它仍只选择原文窗口，不判定反证是否成立。

同次运行中，模型从局部摘录推断“资料未提供消费拆分”，实际上全文有相关说明。现在若模型对某份来源作全文件缺失断言，而记录的选段不能覆盖该来源全文，系统标记 `source_scope_absence_unverified`，在界面及文本导出中提示，并阻止复查模型将其升级为支持或研究被标为完成。该规则只覆盖有限的中英文表达，可能漏报；没有警示不证明缺失结论成立。明确限定为“所给摘录缺失”的表述不自动转成全文断言。历史记录保持原样，不自动改写。

离线重放 263 GDP 的原始材料与问题，新选择范围包含 2.7%、3.2%、2.9% 和服务增加、商品减少的句子；旧输出在旧选段下的全文缺失断言可被新警示识别。未调用模型，不能据此证明新研究结果正确。该 GDP 候选已用于调整检索，现为开发样本，不能再用于后续独立验收；原先冻结成绩不变。研究分析、证据、复查及运行回归通过，Web 类型和文本导出测试通过。B02、B04、B09 仍未完成质量验收。
