# 结构化年度数据摘录修正

2026-11-12。第 89 项跨领域评估中，微软收入样本的输入预算只保留了 2022 年记录，未提供 2023 年记录；原评估结果仍为 0/2，本次没有重跑模型，也不改变该结果。

对符合限定格式的 JSON 结构化材料，问题恰含两个不同年份时，摘录器尝试保留原文中的发行人、指标和单位，以及按 `end` 年份匹配的两条记录的期间和数值。期间跨度 330–400 天只是筛选条件，不证明其为标准财年或保证指标口径正确；`fy` 不作为期间归属的唯一依据。三个摘录均保留原始字符位置并关联同一来源，覆盖不完整仍按部分资料标记。

此路径要求根对象明确提供 `issuer`、`concept` 和 `unit`，并要求相关记录唯一且单位和指标不冲突。重复 JSON 键、相同年份的多条候选、缺失字段、预算不足等情况退回普通摘录；它不适用于所有 SEC 数据结构，也不能替代来源、期间和指标口径核验。

对第 89 项保存的微软输入进行离线重放，在相同 2055 字节提示预算内，提示实际为 1936 字节，保留原文字符区间 51–200、646–777 和 887–1018，分别包含来源身份和两期记录。该检查使用假提供方，不证明真实模型能够正确完成研究。

验证：相关研究、来源、证据和计算测试共 190 项通过；随后针对结构化摘录补充重复键、季度记录和取消检查，专项测试通过。选择方法版本为 `v25`。
