# 金额来源候选

当结论使用明确的中文美元金额、已引用某来源，且同一来源存在未编辑、原文位置全局唯一、数值与显示精度匹配的美元百万事实时，系统检查所附引文是否完整覆盖该事实片段。如果没有，展示待核查金额和候选原文，并使自动研究保持部分完成；未覆盖的金额结论不会进入模型支持复查。工作区编辑结论时可添加候选引文，保存时仍由服务端重新定位、检查来源权限和研究截止时间。添加引用不代表公司、期间、会计口径或结论语义已验证。

规则仅覆盖上述中文美元表达及有限单位，无法覆盖所有币种、英语金额、没有已提取事实的数字或全部语义错误；金额按显示精度匹配，可能涉及舍入。同值多事实、原文有多处匹配、截断引文、不可展示来源及用户修改事实不会自动生成该候选。已有历史结果不自动改写；新版本编辑时重新检查。直接引用其他有效原文但没有覆盖候选事实片段时可能提示，需要按上下文判断。

对第 37 次 META_M 保存响应离线检查，识别出收入和营业利润两项候选，未更改原评分或调用模型。相关 API 58 项、Web 类型检查通过；本地模型替身及 Playwright 验证了候选展示、一次添加、保存和仍未独立核验的状态，覆盖桌面与手机视口。Browser 插件不可用；该检查不证明真实模型语义质量。
