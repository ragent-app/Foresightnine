# 编辑数值后的来源核查提示

在核查研究版本时发现，用户编辑已保存数值后，旧引文和位置可以继续保留；例如把 100 改成 200，而引文仍为 `Revenue 100`。用户编辑标记本身不能清楚说明这个来源不一致。

现在保存新增或修改的有来源数值时，在可展示且符合研究截止时间的资料中检查引文是否可定位、是否有歧义或截断、保存的位置是否一致，以及数值是否出现在引文中。未关联来源的引文、未提供引文、资料不可用和检查额度耗尽也分别提示。检查结果由服务端重算，页面在保存后显示待核查原因；精确数值匹配仍不能证明指标、单位、期间或结论正确。用户可以保留自己的数值和计算，计算结果继续标明输入未独立核验；历史版本不被改写。

本次每个保存请求的引文定位检查合计最多 200 次，失败的定位也计入，超出部分显示未检查；不改变原有资料权限和截止时间。相关研究版本、运行、证据和计算测试 112 项通过；末次补充的来源缺失及失败定位限额用例单独重跑通过，Web 类型检查通过。本地内存 API 与测试账户的桌面、手机浏览器检查覆盖旧引文不匹配、修改后清除提示及历史版本保留；未调用真实模型。
