# 主张与引用的方向冲突提示

此前，主张“收入增加 5%”引用“收入下降 5%”时，相同数字和百分比单位可能通过数值检查。现在对有限的英文“指标＋增加或减少＋百分比/百分点”表达，在主张和已定位引用的指标短语、数值和单位均一致，而方向相反时，提示核查。若双方明确季度或年份且不重合，不据此提示；含否定语句、位置歧义和不可展示来源也不作为该提示依据。

该规则不自动改写结论，不把警示判成事实错误；同名指标、期间、统计口径及不同来源可能解释差异，仍需核对。它不覆盖所有语言、语序、金额、时态或表达，未命中不代表语义支持。带此警示的研究保持部分完成，模型复查不能直接将其升级为支持；用户编辑后重新计算提示。

合成的收入、消费、GDP 和出口用例覆盖相反方向、相同方向、不同季度、不同单位、否定和歧义位置；模拟 API 测试覆盖部分完成及修改后的未独立核验状态。证据与复查测试和 Web 类型检查通过。未进行新模型调用或将此结果当作真实研究质量验收。
