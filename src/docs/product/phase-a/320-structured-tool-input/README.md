# 结构化金融观察值作为计算工具输入

研究运行从已授权、时间合规的结构化来源中生成候选观察值，在首次模型分析的输入预算内，按来源轮流放入最多八项，记录事实标识、来源、值、单位、币种、期间、实体和指标。候选占用有上限的输入空间，不获取额外来源；无法纳入的记录仍保留在已授权资料中，不默认为不存在。候选仅作为未经独立核验的工具数据，模型可引用其标识请求确定性计算，但仍需从实际提供的资料片段引用原文；提供结构化值不等于允许模型引用未看到的原文。

计算由既有确定性引擎执行，检查输入一致性和结构化实体、指标及期间约束，保留输入和结果；模型不得覆盖服务端分配的结构化事实标识。运行记录保留发送给模型的事实标识，补充取证单独记录其输入标识，避免将不同调用看到的数据合并成一次输入。后续补充碰到同一来源行时复用已有观察值及其计算引用，不重复制造独立证据；不一致的标识仍重映射或拒绝。

当前适配器只处理明确支持的 SEC company-concept 来源，范围不限定产品的市场或行业；其他提供方必须经过数据权利、结构与口径验证后再接入。模型输入选择、来源语义和计算结果仍不构成独立真实性核验，也不能自动说明来源覆盖完整或研究结论正确。
