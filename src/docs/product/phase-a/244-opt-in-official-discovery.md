# 授权后从问题获取官方网页

此前只有问题的研究可以搜索来源，但搜索结果始终只是线索，需要再单独获取资料。现在用户可在研究运行中明确授权：当没有选定资料时，从搜索结果中尝试获取最多一份 BEA 或美联储官方网页，保存并供模型分析。选项默认关闭，只对当前研究工作区保留；搜索片段本身不作为证据。来源按用户授权记录为可保存、展示、模型处理及导出研究引用；网页中第三方内容的使用权由使用者确认。完整导出包含研究引用及来源元数据，不包含整份网页正文。此前以不允许导出权限创建的来源不会自动升级。此为首批连接能力，不代表产品或后续来源的市场范围。

获取只接受 HTTPS 官方主机，无重定向，不携带查询参数；复用现有安全传输、响应大小和格式限制。搜索最多一次、网页最多一次且不隐式重试，网页超时不超过运行剩余时间或 15 秒；设置美元费用上限时因外部价格未知不执行。历史截止时间不自动获取当前网页，因为无法证明其修订历史；明确选择空资料时也不自动获取。网页公开和修订时间未经核实，不从搜索结果冒充来源时间。来源、权限、获取时间、哈希、调用次数及状态保留在研究版本中。

运行接收前记录一个仅所属账户可访问的预定资料标识。若网页已保存但后续处理崩溃，用户可通过运行输入记录恢复它，不必重新获取；同一幂等请求不会再次触发搜索或获取。获取失败保留未核验线索与缺口，不用搜索摘要或模拟数据替代资料。修复搜索结果未提供发布者或日期时被错误拒绝的问题；历史研究仍排除时间未知的线索。

验证：后端覆盖明确授权、未授权默认、官方主机筛选、时间/费用/空选择边界、失败无重试、跨账户隔离、幂等及获取后崩溃恢复；接口快照和生成契约通过，Web 295 项测试、类型检查与构建通过。Browser 插件未列出，使用本地 Playwright 和模拟搜索、网页及模型验证授权默认关闭、桌面和移动界面、成功获取与中断后恢复；没有真实联网搜索或模型调用，不能据此声称生产来源覆盖或研究质量已验收。构建保留既有大包提示。
