# 带百分号的连字符区间

第 104 项政策任务中，模型以 `5.25%-5.50%` 表示区间，旧解析器不接受该格式而省略事实。现在仅在两个端点均显式带 `%` 时，将中间连字符识别为区间分隔符；支持负值与混合分数，仍要求下限小于上限且两个值分别能从原引文核对。不带百分号的连字符仍不作区间猜测。百分比附带未经核实币种时，端点保留并标记，不能自动参与计算。

对第 104 项已保存响应的离线重放保留了 5.25 和 5.50 两端，均标为币种上下文待核查，原提示哈希一致；没有外部调用或改变历史分数。相关分析、运行及计算测试 168 项通过；初次新增测试误期望去掉 `5.50` 的末尾零，已改为检查保留输入精度后通过。数字与引用匹配不证明指标或币种语义正确。
