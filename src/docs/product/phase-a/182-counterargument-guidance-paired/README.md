# 反方指引配对探索：调用前登记

复用 179 号已知 BEA 公告、问题、来源选段、模型及参数。基线与候选的来源、问题、系统提示和输出结构固定，唯一主动变量是在研究提示的证据指引中增加一段：若材料含与结论相反的实质观察，引用并解释对照；不得将重复结论或无依据缺口冒充反证，无相反材料时说明缺口。候选指引使提示更长；除此之外来源选段和字段逐项相同。先基线后候选，各一次，不搜索、不重试；输入上限 6000、输出上限 4000，每次预留 10000 Token，合计最多 20000，每次超时 60 秒，状态或用量不明即停止。此前已知累计 203705 Token，另有历史未知用量、未知美元费用和供应商内部版本。

该公告给出整体消费增加而商品支出下降及服务支出上升。预定的有限检查：反方文字应指出商品下降，且其某条准确定位的引文包含 goods、9.6 和下降词；只检验反方是否引用了一个特定相反观察，不证明方向、全部因果或经济推断的充分性。分别记录所有反方和其他遗漏；完整输出、提示、哈希及预定评分保留。若候选符合且基线不符合，仅作为开发线索，不自动认定总体质量提升。此题已用于开发，作者已知答案，非盲、非独立测试，不能作为阶段 B 验收。
