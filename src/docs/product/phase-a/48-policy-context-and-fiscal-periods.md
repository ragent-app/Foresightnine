# 投票上下文与财年结束日期

对明确询问货币政策投票的任务，片段选择可分别保留目标利率行动陈述和附近的反对票记录；两段仍是原文中的独立范围，不拼接成一段，也不因邻近就断言投票对应某一行动。若识别不到合适的行动和投票，或预算不够，回退到原有选择方法。对第 45 次会议纪要离线检查，所选片段同时包含委员会提高目标区间的表述和无反对票的表述；具体指代仍须核对完整纪要。

增长计算现可比较双方均为英文 `Year Ended Month Day, Year` 的明确财年结束日期，拒绝本期不晚于基期的可识别情况。它不把此格式与普通日期、财年标签混为同类，不验证财年长度、两公司会计口径或来源是否正确；非法或不支持的日期仍标记未自动检查。第 47 次离线重放对应的两个日期现属于可比较格式，历史计算结果与版本不被静默改写。

新方法标识为 `ranked_nonoverlapping_windows_v15`。离线检查第 45 次三题的目标收入、GDP 估计和投票文字仍可见，并检查第 37 次四道 PDF 题及第 28、29 次修订资料的既有目标段仍可见；这些都是曾见过的开发样本，并非模型重跑、独立质量验证或语义证明。相关分析、运行、计算和复查 API 测试 121 项通过，本次无模型调用；第 45、46 次原始评分不变。
