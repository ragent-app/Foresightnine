# 预留跨领域任务：运行前登记

本组固定三道此前未参与本项目模型调试的新任务：NVIDIA FY2023 与 FY2022 收入及增长、BEA 2022 年第三季度 GDP 修订、2023 年 5 月美联储会议反对票。来源分别是 [SEC 10-K 网页](https://www.sec.gov/Archives/edgar/data/1045810/000104581023000017/nvda-20230129.htm)、[BEA 原始公告](https://www.bea.gov/sites/default/files/2022-12/gdp3q22_3rd.pdf)和[美联储会议纪要](https://www.federalreserve.gov/monetarypolicy/files/fomcminutes20230503.pdf)。来源使用范围见既有来源矩阵。保留当前下载文件及哈希，不能证明过去任一时点的字节内容。

公司材料为 SEC 原始 HTML 的本地完整正文提取，压缩后的 HTML 副本随包保存；单元格分隔符和合并标记由提取器生成，必须回看原网页核实列与上下文。原 PDF 大于上传限制且本地字体解码异常，因此此项不是公司原始 PDF 阅读测试；也不测试联网发现。另两项输入为原始 PDF 和固定读取顺序。三个题目和参考结果由同一开发者准备，开发者已知答案，不是盲测或独立人工复核；用户要求跳过人工验收，不以此虚构人工基线。材料不同于已用于调参的样本，但不能排除模型训练知识、题型相似及实现选择带来的泄漏。

[清单](manifest.json)在调用前冻结实现、源文件与输入、参考项、评分脚本、模型参数和预算。每题最多一次真实调用，最多 10000 Token、120 秒；总计最多三次、30000 Token；不搜索、不进行模型二次复查、不重试不确定调用。美元成本未知。若运行终态或用量未知、超限，停止后续调用；只读轮询同一操作不重复提交。

[机械评分](score.py)预先要求全部三题在限定事实、引用定位、确定性计算或指定投票、来源及预算方面通过；反方有引用，或缺少反方时明确说明。计算所得百分比仅在候选计算输入被引用覆盖时允许作为机械检查项；仍不能据此认定语义支持。任何结果、失败、未运行项均保留；不以该组结果修改规则再重计为同一次测试。机械评分无法判断所有结论是否有真正支持、反方是否充分、时间或模型知识是否无泄漏，因此即使三题通过，也不单独代表 B02、B04、B09 或整个阶段 B 验收通过。
