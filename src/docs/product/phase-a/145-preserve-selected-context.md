# 利用重复标题预算扩展原文上下文

140 号贸易公告选段从 `in January, revised` 开始，紧前方的前期数值未进入模型输入。直接将片段前移以及把通用两片段改成三片段的离线尝试，均会挤掉其他问题所需内容，因此没有采用。

新实现先沿用 v32 的选段和原有预算分配，不删除已选内容。对同一来源的多个片段，只在第一个片段传递重复的来源标题，保留每段的来源 ID、覆盖状态及现有规则要求的声明时间；再将节省的字节用于有界的相邻原文：片段以时间/关系短语开始且紧前方是带单位的数字时，尝试包含该数字；片段以数字结束时，尝试向后补足上下文。若新引入的数字会被截断在单位之前，则撤回该数字的扩展。扩展不跨相邻已选片段或页面分隔符，不超过来源字符配额与序列化字节上限；坐标仍指向原文。来源选择方法由 v32 更新为 v33。

对 144 号原始输入、3000 输入上限离线重放：两题原先选中的所有字符范围均被新范围完整覆盖。贸易题新增 1 月 `67.6`，同时保留此前 `68.9`、`263.0`、`331.9` 与 `1.6 billion`；压力测试题保留此前 `12.4 percent`，但仍未取得 `9.9 percent`。这只验证这两题的选段内容和预算，不证明更广泛任务、模型输出或引用语义。重复标题减少后，模型仍依同一来源 ID 关联片段；其实际效果需进一步受控检查。相关选段、原始 PDF 与运行测试通过，本次无模型调用。
