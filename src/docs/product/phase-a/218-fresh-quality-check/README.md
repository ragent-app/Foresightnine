# 新原始资料的跨类型检查：调用前登记

固定三份此前未在本项目模型实验中使用的原始资料：美联储 [2021 年压力测试报告](https://www.federalreserve.gov/publications/files/2021-dfast-results-20210624.pdf)、BEA [2022 年 5 月个人收入与支出公告](https://www.bea.gov/sites/default/files/2022-06/pi0522.pdf)、美联储 [2018 年 12 月决议](https://www.federalreserve.gov/monetarypolicy/files/monetary20181219a1.pdf)。任务分别核查公司资本比率、当期美元消费总额与实际商品/服务变化、政策区间与主席。资料与模型使用条件见来源矩阵；均使用原始 PDF 的 `layout` 提取。此公司报告是监管情景数据，不等于公司完整财报研究。

在调用前固定资料、题目、分离参考、评分程序、代码、模型、参数、片段与提示哈希。每题最多一次生成、10,000 Token、60 秒、任务 120 秒；三题最多三次、30,000 Token，不搜索、不自动重试、不请求模型复查。公司和政策事实题不强制生成反方，消费比较题要求有引用的反方。遇到用量或终态不明则停止剩余任务；美元费用未知，不计作零。

预设机械检查要求每题的相关名称、数值、方向词和限定词同时出现在主张与可定位引文中，所有主张引文唯一完整、没有已知主张或事实警示与省略内容、请求的反方有引文、调用预算受控，部分结果明确披露。三题均满足才算本项机械条件通过。词语与数字共现不能证明每个数字的列、期间、方向及语义，须另查原始输出；模型复查也不是独立核验。失败保持原评分。

来源文件按哈希检查未与现有本地 PDF 重复，但准备者看过资料与参考，题型与此前开发样本相似，模型训练数据和供应商版本不可锁定，因此不是盲测。三题不足以代表多领域或替代完整财报样本、独立质量基线与阶段 B 全部验收；用户要求跳过人工验收，不将人工基线记为已完成。

## 执行结果

三次调用均结束，供应商报告总用量 6,453 Token，美元费用未知。三个结果均为部分完成，预登记的机械条件均未通过，详见 `score.json`；分数没有事后调整。银行样本保留三个数值事实，但模型拼接引文未能定位，主要结论被省略，另一处表头引文有多个位置；不能将三个数值事实当成已经验证的完整研究。消费样本的主张引文可定位且包含预期方向，但负向事实标记待核验，相关计算被排除。政策样本的主要主张引文可定位，但数字事实格式不符合契约而被省略，另有重复百分比提示。以上提示中既有保守防护也有输出格式问题，不能仅凭机械失败断定原始结论全部错误；也不能把词句匹配当成语义验收通过。

本次结果暴露格式处理的一个具体缺陷：单数值末尾重复的单位已从局部变量移除，却未写回模型事实；带 `percent (range)` 单位的显式范围也无法进入既有范围拆分。后续修复和回归另行记录，不修改本次结果或以同一批材料重新计作独立测试。
