# 编辑表格事实时保留币种复核提示

日期：2026-11-12。生成时对于从表格行中间截取的引文，可以根据来源原行提示币种不明确；但编辑事实后，旧流程只检查引文本身是否以竖线开头，可能丢失这一提示。

生成和编辑现在共用表格行识别逻辑：仅在可定位的单行引文与原文完全匹配时识别行首竖线。编辑流程在服务端重新定位后计算提示，不信任客户端提交的提示字段；事实保存并重新打开后仍可见。若引文中出现明确币种线索，提示可以移除，但这不表示金额、期间或列对齐已被核实。引文歧义或来源不可用仍保留原有来源核对警示。

验证：API 研究分析、研究版本及计算相关测试共 151 项通过；新增版本保存、篡改提示、重新打开及更换为明确币种引文的测试。本次未调用外部模型，不改变既有评估结果。
