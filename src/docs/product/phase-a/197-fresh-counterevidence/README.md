## 结果

运行有确定终态，研究标为部分完成；生成和两次逐条复查共报告 3670 Token，已知累计 222839 Token，另有历史未知用量及未知美元费用。预设检查中总额和引文定位满足，但服务金额与直接反方均不满足，故本次有限检查失败。逐条复查覆盖了两项保留主张，但其中一项被判为 `does_not_support`；模型复查不构成独立核验。

系统选中了总额和实际支出变化，却遗漏了原公告第 2 页同时包含服务增加 49.1 十亿美元和商品减少 10.0 十亿美元的名义支出段落。模型因而明确表示无法量化名义分项，反方引用的是实际商品和服务变化，不能直接证明或反驳名义口径。未选中内容不能视为模型已读或证据缺失；系统如实披露了未分析范围。
