# PDF 上传容量与来源准备

一份官方 BEA 公告为 1,507,251 字节，略超既有 1.5 MB 上限，导致第 98 项评估在创建研究运行前停止。前端文件选择、API Base64 模型及原件下载上限现统一为 3,000,000 字节；PDF 专用 HTTP 请求体默认及硬上限为 4,100,000 字节，以容纳 Base64 与元数据。一般请求和文本来源的限制不变；已配置更低 `FORESIGHTNINE_MAX_PDF_BODY_BYTES` 的部署仍会按该配置拒绝较大请求。

PDF 提取仍有并发、时间、地址空间和文本输出限制；容量增加会提高单次上传与存储开销，并不保证大文件均可解析。使用合成 PDF 测试 1.5 MB 以上上传和原件往返，以及超 3 MB 拒绝；另用该官方 PDF 验证上传和原件一致。PDF 与安全测试 26 项、Web 类型检查和 282 项测试通过。Browser 插件不可用，使用本地测试账户、内存 API 和 Playwright 验证官方 PDF 在 1280×900 与 390×844 下上传、保存读取方式和重开；没有页面错误。上述不涉及模型调用。
