# 失败运行的来源追溯

模型输出结构无效或调用受预算、提供商故障中断时，研究版本会保留本次已选中的授权来源摘要、内容哈希和已有的片段坐标，同时保持部分完成与实际错误。来源被选中并不代表模型调用已开始、调用成功或来源支持了结论；调用次数、提示哈希和错误分别以运行记录为准。未授权、模拟及历史时间条件不满足的来源依然不会进入选中来源；排除原因保留在限制中。旧版本不被改写，原始模型输出不因错误而写入研究版本。

相关来源、运行和分析 API 测试 95 项通过；另行验证零调用预算下记录来源选择而不虚报调用，运行测试 27 项通过。本次未调用真实模型，也不改变第 45 次 BEA 结构校验失败及其原始评分。
