# 搜索候选与待添加资料的隔离

从搜索候选选取新来源时，如果资料表单已有正文、标题、链接、时间、文件或其他待添加信息，页面会保留它们，并提示先添加或主动清空；不会把旧正文与新链接合成一份资料。表单提供清空按钮。两种入口（创建前搜索和研究运行后的候选）使用相同规则；可选中新来源后重置保存、模型处理和导出授权，以及模拟资料标记，避免把上一来源的声明带入新来源。搜索候选依然只是未核验线索，支持抓取的来源范围没有扩大。

Web 类型检查和 275 项测试通过。本地测试身份、搜索替身及 Playwright 检查两种入口、待添加正文与时间保留、新来源授权重置，并查看桌面和手机视口；Browser 插件不可用。没有调用真实搜索或模型，也不能由此证明来源使用权或内容真实性。
