# 直接添加 SEC 财报链接

研究资料链接支持 SEC EDGAR 的直接 HTML 申报路径，与已有 BEA 和美联储网页获取并列。SEC 路径严格限定 HTTPS、官方主机、CIK、18 位申报编号和 HTML 文件名；不接受查询参数、其他路径或重定向。服务端使用部署方配置的真实 SEC 联系信息和现有全局一秒请求间隔，受每账户请求预算、15 秒超时及 5 MB 响应上限约束。不生成或猜测联系信息；未配置时明确返回不可用，用户也可自行上传已保存的 HTML 文件。

获取成功后保存 UTF-8 原文、原文哈希、提取文本和声明的来源时间、权限；原文件仅在允许展示和导出时由所属账户作为附件下载。提取器、XBRL 与表格限制沿用 HTML 上传路径；提交或用户声明时间不代表 SEC 精确公开时间，来源和语义仍需核验。请求失败、限流、非 HTML 与过大文档不会用模拟资料替代。

针对性测试使用模拟 SEC 响应和既有 Cisco 原始申报文件，覆盖 URL 限制、联系信息、原件哈希、表格提取、重定向、超时、429、格式、权限、跨账户与契约；Web 类型检查和客户端测试通过。Browser 插件未列出，使用 Playwright 在本地模拟 SEC 服务验证网页粘贴链接、创建研究及原文下载，桌面与移动视图均完成，下载响应哈希一致且无相关控制台错误。没有向 SEC 发出新请求，也没有调用模型；因此不声称生产 SEC 接入、真实网络稳定性或财报研究质量已经验收。
