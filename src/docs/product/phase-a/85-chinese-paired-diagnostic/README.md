# 中文统计资料片段选择配对诊断

资料来源：[香港特别行政区政府统计处网站](https://www.censtatd.gov.hk/)，知识产权属香港特别行政区政府。本测试使用[第 83 号检查](../83-chinese-official-data/README.md)已说明来源和修改的文字节录；根据统计处[知识产权告示](https://www.censtatd.gov.hk/en/page_31.html)，复制和修改的统计资料应注明来源、政府权利人及修改。本目录保留上述声明；原 PDF 未随测试分发。

调用前固定第 83 号问题、来源文本及 ID、模型与生成参数、系统提示、评分、预算和运行脚本。准备脚本重建旧提示并验证其哈希与原调用一致；新旧提示除来源片段外相同，片段数量从一段变为两段属于本次选择变化。来源、题目和答案已经被开发者看过，比较非盲；供应商内部模型版本和随机性不能锁定。

最多一次外部模型调用、10,000 Token、120 秒，不搜索、不复查、不重试；终态或用量不明即停止。美元费用未知。沿用第 83 号固定机械检查；它不验证全部语义、单位或反方充分性，单次结果也不能证明因果、泛化或阶段 B 通过。第 83 号原始输出及成绩保持不变。

## 结果

一次调用有确定终态，报告 1,992 Token；此前已知累计 113,247，加本次为 115,239 Token，另有历史未知用量和未知美元费用。预登记的狭窄机械检查通过：五个目标数值及临时估计均出现在结论与可定位引文中。但研究状态仍为部分完成，不能把该机械结果当成研究质量或阶段验收通过。

结果仍有明显缺口：两项下降百分比以负数形式输出，原文使用“下跌”加正数；现有方向解析未识别该中文表述，因而删除两项数值事实。模型还以已四舍五入的 29 和 317 计算 9.15%，与公告中的 9.3% 存在口径和舍入问题；自动差异提示却把总销售同比降幅 7.3% 与这个占比计算比较，属于不相关的候选，不能视为确认错误。所附引文写“亿元”，模型声明港元，币种仍需结合原报告上下文核对。反方提出临时数值可能修订，不能当作已核实的实际修订。

上述计算差异和事实缺失未被本次预登记评分覆盖，因此机械通过存在明显盲点。两次仅改变资料片段选择，但样本非盲、各调用一次且供应商内部版本不可锁定；原第 83 号失败结果不变，也不能据此断言因果或泛化。
