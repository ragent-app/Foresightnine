# 贸易与压力测试的输入预算配对：调用前登记

复用 140 号两个任务、来源及字节、ID、问题、模型、生成参数、系统提示、代码、来源权限与同一评分器，直接比较原有 3000 与 6000 输入上限。唯一主动变化为输入上限，选段和提示长度随之变化；固定 140 号原始结果、评分及来源哈希，不重新运行旧条件。

新条件每题最多一次直接模型调用、输入及输出预留共 10000 Token、60 秒；合计最多两次及 20000 Token。不搜索、不做二次复查、不重试；终态或用量未知即停止。美元费用未知，历史已知累计 151882 Token，另有未知历史用量。保存选段、提示哈希、响应、用量和原评分器的机械信号。

两题及参考已用于开发，模型内部版本和随机性不可锁定，单次非盲配对不是独立验收。评分器未完整判断单位、主体、计算、方向及语义，即使机械信号改善也不能认定每条结论成立。此诊断不是完整 API/账单链路；预算上限是否改变默认值，须综合安全预留、成本和更多未用于开发的任务，不由这两题自动决定。

## 结果

两次调用均有确定终态，分别报告 3150 和 2408 Token，共 5558；已知累计 157440 Token，另有历史未知用量及未知美元费用。较 140 号的 3000 条件，6000 条件的贸易题四项数字、商品和服务项目及反方关键词机械信号均出现，所有保留引文可定位；压力测试题的实际与最低比率、情景及个体最低水平信号出现，但保留引文存在歧义，具体风险反方信号仍未满足。

贸易题给出了 1 月修订逆差和完整的服务顺差句；反方进一步说进出口增长本身并非所述驱动，但它只引用了商品与服务差额分解，没有同时引用进出口数字，且该推论不能仅由分解句确立。压力测试题给出 12.4%、9.9% 和 10.5% 并区分实际与预测；关键引文存在多个匹配位置，反方主要是预测性质和资料更正，引用只覆盖更正内容，未覆盖所有论断，也未说明抵押贷款、信用卡或商业地产集中风险。

以上为原预登记信号的结果和人工可检查的逐条观察，不修改旧评分；引文定位或关键词满足不证明语义支持。一次非盲配对不能证明总体效果，也不足以调整默认输入上限或宣布 B02、B04、B09 通过。
