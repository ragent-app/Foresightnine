# PDF 重复引文的同页候选提示

231 号银行报告的重复表头出现在不同公司页面，而同一结论的公司名称和数值行已唯一定位。现在，对已分析 PDF 中未截断的重复引文，如果恰有一个候选位置与同一结论、同一来源中的另一条唯一引文位于同一页且相距不超过 5,000 字符，记录该候选的序号并在原文上下文中提示。所有候选位置仍保留，提示不证明公司归属、列对齐、引文位置或语义支持；不存在唯一候选、多页都有锚点、结果截断、其他来源及非 PDF 情况不提示。

同时修正原有状态：含模糊定位引文的结论应标为 `incomplete`，不能因引文文字存在而显示为完整的未独立核验结论。模型复查和自动研究完成状态继续排除含糊定位；无模型调用，无历史版本或 231 号结果改写。

无模型离线回放 231 号已见资料，两个重复表头均提示第 2 个候选，结论保持不完整。研究分析、证据复查、Web 类型及来源上下文组件测试通过。Browser 插件未列出；本地 Playwright 使用保存的原报告与模型输出桩，验证桌面和移动界面显示候选提示及不完整状态，无相关控制台错误。临时服务已清理。上述材料不是独立测试，不能据此认定阶段 B 质量验收通过。
