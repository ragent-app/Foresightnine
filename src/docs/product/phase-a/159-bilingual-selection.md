# 中文问题选段改进

v36 为通用选段增加银行、资本、比率、压力测试及相关术语的中英文检索提示；对明确要求风险或反方的问题，反方候选句同时支持简繁中文和英文，并按概念分组匹配，避免将同一概念的双语词重复计数。提示只用于检索，不改变原文、不建立引用支持关系，也不宣称覆盖所有中文表述。

在此前开发用的压力测试资料上，本地固定中文问题和输入预算、不开启模型：修改前选中范围 11008–11342 和 52993–53316，输入中均未出现 12.4 和 9.9；修改后范围为 24326–24716 和 30765–31107，输入中出现 12.4 和 9.9。但本次中文选段仍未包含已知的具体集中风险句，也没有同时提供对个别银行的完整说明；数字出现不等于其口径已完整或语义已验证。该样本和中文问题均已知，不能作为独立评估或 B 阶段通过证据。

测试覆盖中文问题检索英文资料、简繁中文和英文候选句、双语同义词不重复计数、原文偏移及现有防替换条件。没有新的模型调用；此前已知用量维持 174518 Token，另有未知历史用量及美元费用。
