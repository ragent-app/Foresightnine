# 政策反方中的动机归因提示

272 号政策样本将“通胀补偿偏低”推断为反对加息者的关切，但所附引文只报告前者，并未说明该投票者的动机。现在对“某人反对、投票或决定背后的原因、关切”等明确动机归因，如果其已定位引文没有相应动机表述，增加既有的因果归因待核查标记；引用中另有与该动机无关的因果词也不能清除这一提示。带此提示的模型复查只能作为诊断，不能把 `supports` 直接用于解除警示。

[离线重放](replay.json)对 272 号保存输出的第 5 条主张给出提示，没有调用模型、没有改写原实验结果。相关测试覆盖未引用动机、无关因果、直接动机表述、局部词截断，以及模型复查的诊断限制。该方法是有限词法提示：匹配的因果或动机词也不证明人物、原因、期间或关系正确；没有提示不代表不存在推断错误。

276 号收购金额使用 `$1.4 billion`，单独的 `$` 不唯一表示美元，因此保留相应的币种证据警示；不能仅因数值与“14 亿美元”可换算就假设币种。此项修正不能代替反方的语义核验或阶段 B 验收。
