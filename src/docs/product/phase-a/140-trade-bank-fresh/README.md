# 新贸易与银行压力测试资料：调用前登记

准备两份此前未在阶段 A/B 记录中检出的官方资料，作为不同任务的开发质量检查：

- [BEA 2024 年 2 月商品与服务贸易公告](https://www.bea.gov/news/2024/us-international-trade-goods-and-services-february-2024)：从网页 article 提取文本，保留网页和提取脚本。参考：总逆差 689 亿美元、1 月修订值 676 亿美元，出口 2630 亿、进口 3319 亿；商品逆差下降 3 亿、服务顺差下降 16 亿。网页资料按 [BEA 使用说明](https://www.bea.gov/help/faq/147)核对，须保留出处；快照不证明历史字节未变。
- [美联储 2023 年压力测试报告](https://www.federalreserve.gov/publications/files/2023-dfast-results-20230628.pdf)：使用官方完整 PDF 的 reading-order 提取。参考：不利情景下 23 家银行合计 CET1 比率从 2022 年四季度实际 12.4% 降至预测最低 9.9%，个体和合计均高于规定最低值；抵押贷款、信用卡及商业地产集中银行的降幅较大。依 [美联储网站声明](https://www.federalreserve.gov/disclaimer.htm)记录来源，网站标识等不作为模型输入。报告可能包含后续更正，当前副本不证明历史版本未变。

固定上述资料及提取文本、题目、来源 ID、提示和代码哈希、评分程序、模型参数、输入上限 3000。每题最多一次直接模型调用、输入加输出预留 7000 Token 且不超过任务 10000 Token 上限、60 秒；合计不超过两次及 20000 Token，不搜索、不二次复查、不重试。未知终态或用量即停止。美元费用未知，历史已知累计 148116 Token，另有未知历史用量。来源时间未给精确时点，输入不假设具体发布时间；不设历史截止时间。

预登记机械信号检查目标数字、可定位引文、相关术语和反方；它们不可靠判断数字角色、方向、单位、口径、假设或每条语义是否成立。单项通过不等于研究质量通过，另保留原始结果与缺口。这些材料和答案对准备者可见，未经独立人工审定，单次模型输出非盲，直接调用也未覆盖 API/计费流程；不作为 B09 正式独立验收，不据结果调整事先登记的分数。

## 结果

两次调用均有确定终态，分别报告 2076、1690 Token，共 3766；已知累计 151882 Token，另有历史未知用量和未知美元费用。所有保留主张的引文均可定位，但预登记信号中贸易题缺少四项数值覆盖，压力测试题缺少实际与最低比率的共同覆盖及具体反方证据；两题不能算完成。

- 贸易题：模型列出 689 亿逆差、2630 亿出口和 3319 亿进口，也提到商品逆差下降、服务顺差下降；所选片段遗漏 1 月修订逆差，模型说明无法从摘录确认。关于服务顺差下降的引文在 1.6 后截断，缺少 billion 和该句后续内容；反方解释该下降抵消商品逆差改善属于推断，不能仅凭数值同时出现认定完全支持。表格数值和单位仍需结合原表核对。
- 压力测试题：模型区分实际与预测，并引用个体及合计资本比率高于最低水平的表述；但所选片段在 12.4 后截断，遗漏 9.9% 的压力情景最低值。模型将摘录缺口及“实际表现可能偏离模型”作为反方，未取到题目要求的具体风险材料。

原始公告在所选范围之外包含缺失信息；这些结果暴露通用选段与片段边界问题，而不证明原始资料缺失。引用可定位不等同于引文完整或支持全部主张。本次是已预登记的非盲开发检查、直接模型调用而非完整 API 验收，不能称为独立质量通过；评分器对数值角色和推断没有完整语义判定。
