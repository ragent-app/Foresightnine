# 表格引文恢复与验证记录

日期：2026-11-12。此项是阶段 B 的证据定位改进，不改变既有实验评分。

模型有时省略从 HTML 提取表格时出现的跨列标记或空单元格，导致原文逐字定位失败。现在仅在模型已收到的来源片段内，对完整单行表格按顺序比较所有非空单元格；仅忽略限定格式的跨行、跨列标记及空单元格，不跨行、不跳过有内容的单元格。匹配后返回原文中的完整行及其位置，而不是把模型输出当成原文。多处匹配保留歧义；截断行不恢复。

恢复后的引文和结论标记为未完成，页面提示检查列对齐及证据是否支持结论；通过此方式定位的数值事实暂不进入自动计算。这一处理不证明表格列、币种、期间或结论语义正确，也不取代对原始文件的检查。对用户资料中形似标记的文本同样只显示原文并保留待核查状态。

使用 112 号现金流开发检查中已保存的模型输出离线重放，数值行和日期行可恢复为原始完整行，均保持未完成状态。本次没有调用模型，也没有修改原实验结果或分数。已覆盖错值、缺失非空单元格、片段截断、无标记、多处匹配和取消等情况。

验证：研究分析、运行和证据相关 API 测试共 164 项通过；Web TypeScript 类型检查通过。浏览器使用隔离的模拟 API，未访问外部模型。人工基线、独立测试集和正式质量阈值仍待后续评估，不能由本次修复替代。
