# 可读研究报告导出

研究工作区新增纯文本报告导出：先向现有服务端完整导出接口请求当前已保存版本，通过账户隔离与全部关联来源的导出权限检查后，才在浏览器生成 `research-report.txt`。若有来源不允许导出，仍拒绝完整报告；不自动替换成内容摘要，用户可另选原有不含研究内容的记录摘要。存在未保存修改时需先保存。

报告按问题、范围、截止时间、版本及复核状态、结论与反方、事实及引文位置、计算输入与公式、来源追溯、运行记录和局限组织；保留未知值和相关数值警示。模型解释和声明权限未独立核验、计算输入精度未知等提示明确列出。动态文本中的控制字符不会成为伪造的报告标题。报告是完整结构化记录的可读视图，不替代原有 JSON；既有保存与导出权限不变。

Web 类型检查和 284 项测试通过，生产构建通过（仍有主包超过 500 kB 的既有提示）。Browser 插件不可用；使用内存 API、测试账户和 Playwright，在 1280×900 与 390×844 验证真实文本下载、引文及局限内容、无权限时拒绝下载；无页面错误或手机横向溢出。该测试未调用模型，也不验证研究结论语义。
