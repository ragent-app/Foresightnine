# 分行财务表头的上下文复核

日期：2026-11-12。真实申报材料的提取表格可能将 `Year Ended`、年度日期和金额单位放在不同的行，而模型引文也可能只覆盖数据行的一部分。原有表头上下文检查只识别单行年度表头及以竖线开始的整行引文，因而可能漏掉这种缺口。

现在对已精确定位的数字表格行或行内片段，检查附近连续表格行中的年度表头；年度可以出现在后续最多四行内，单位可以出现在表头前或其后有限范围内。缺少所需表头或单位引用时，指出原文上下文范围供核查。存在非表格叙述分隔时不跨越；存在年份的引文不因此被判定为已核实。该提示不证明列与日期对齐、单位或主张语义正确；上下文不是自动附加的证据。

以 112 号开发检查保存的 NVIDIA 提取文本离线验证，经营现金流片段能提示包含表头、两个日期和单位的上下文；没有模型调用，也没有改变原实验记录和评分。新增分行表头、行内引文、完整引用及叙述分隔测试。研究证据、分析、模型复查和运行测试共 187 项通过。
