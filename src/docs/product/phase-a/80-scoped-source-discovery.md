# 资料发现中的研究范围

此前研究运行会使用已保存范围，但资料搜索只发送问题。现在创建前的“查找资料”和已保存研究的自动来源搜索分别提供可选开关，将部分研究范围纳入查询。开关默认关闭，页面显示实际将发送给搜索服务的内容；切换账户或主题时已保存研究的开关重置。未选择时仍只发送问题。查询最多 70 个 Unicode 字符；选择范围时保留问题前 45 字符并用剩余位置携带范围。外部搜索结果仍只是待核验线索，不自动成为证据。

运行请求的 `include_scope_in_search` 默认为 false，省略和显式 false 保持旧幂等键兼容；选择 true 时记录在运行输入预算中。搜索仍受用户选择、调用预算、费用上限、超时和历史日期规则限制，不会因为选择范围而自动搜索已有资料的研究。范围仍可能包含敏感内容，应由使用者决定是否选择发送；查询预览仅表示发往搜索服务的内容，不代表服务一定被调用。

相关 API 运行和契约测试 44 项通过；Web 281 项测试、类型和生成契约检查通过。本地测试账户与搜索替身的浏览器检查覆盖默认关闭、查询预览、显式选择及运行请求，检查了桌面和手机视口，未进行真实搜索或模型调用。
