# 省略号拼接引文中的位置歧义

模型有时把表头和多个数据行以省略号拼接成一段并不存在的引文。此前只要其中一个原文片段有多个可能位置，就会丢弃整个主张或反方，连同其他能够定位的原文也会丢失。

现在仅在所有片段都能与原文匹配、未截断候选、且至少存在一组按顺序位于同一已分析摘录的候选时，保留单独的引文片段。重复位置全部标为歧义，不选择所谓正确位置，也不把它们拼成新引文；整条主张仍为不完整，不能作为模型支持复查的已核实输入。超出候选上限、顺序不可能、含虚构片段或重建表格行位置歧义时仍丢弃；用 `and` 拼接的引文仍要求位置唯一。

对 238 号已保存原始模型输出离线重放后，先前被全部丢弃的一条反方保留为不完整，包含一个位置歧义的表头和两条可定位数据行。这不证明模型的表述是真正的反方、数据列已对齐或语义受到支持，也不改变 238 号原有失败结果。相关分析和复查测试通过；没有新增模型调用。
