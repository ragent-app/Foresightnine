# 纯资料缺口与反方的区分

模型有时把“提供的资料不包含某项信息”放入反方字段。系统此前只将直接声称没有反方的简短语句归为局限；现在对少量中英文、明确只描述所提供资料缺口的句式，也保留原句作为未独立核验的局限，而不计作反方。若没有其他反方，要求反方的研究保持部分完成。句子包含数字、转折、因果、并列或多句时不作这种判定，避免丢掉混合表述中的实质论点；这种保守规则无法识别所有缺口，也不验证保留下来的反方是否成立。

单元和研究运行测试验证纯缺口、混合陈述和缺少反方的处理。对仓库已保存的模型结果进行离线扫描，未发现符合该窄规则的反方；因此目前没有证据表明这项规则改善了已有真实样本的质量。本次不调用模型，也不改变历史结果或评分，不作为 B04 验收通过的依据。
