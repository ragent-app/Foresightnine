# 研究输入预算配置

真实原始资料检查多次因片段过短遗漏所需上下文。研究运行此前沿用提供方固定输入上限，部署方不能在不改代码的情况下扩大可用输入。现提供可选的服务端 `FORESIGHTNINE_RESEARCH_MAX_INPUT_TOKENS`，范围 1–12000；未设置时保留提供方原上限（当前默认 3000），不自动改变模型、提示词、数据或预算。

仅 OpenAI-compatible 的研究调用使用请求级提供方副本；原提供方及旧 Challenge、情景和其他调用策略不变。研究预留仍为输入上限加输出上限，超出用户本次 Token 预算时在调用前停止；原有时间、调用次数和美元预算限制保持。输入上限较高并不等于每次都使用全部上限，也不证明提供方支持相同长度或费用较低。该设置不暴露凭据，配置错误会拒绝运行。

自动测试检查配置边界、副本隔离、预算不足时不调用、足额时的预留，以及合成资料在更大输入预算下能保留全文。本次没有真实模型调用，也没有将默认值调高。是否提升真实资料任务质量需要预先固定题目、资料、模型、参数、预算和评分后作配对比较；不能仅凭更多文本断言质量提高，B02、B04、B09 仍未验收。
