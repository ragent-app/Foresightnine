# 修订与政策资料选择的配对复核

调用前登记：复用 [第 100 项](../100-fresh-macro-after-upload-fix/README.md)的完整任务、原始资料、来源标识、参考值、系统提示、模型参数和预算；主要变化为资料选择方法从 v26 到 v28，新的片段和提示哈希记录于 manifest。另有中文分数边界修复（见 [101](../101-chinese-fraction-boundaries.md)），可能影响生成后的数值警示；因此即使提示的差异来自选段，也不能把全部评分变化单独归因于选段。模型供应商版本不能锁定。

每题最多一次模型调用、10,000 Token、120 秒；最多两次、20,000 Token，不搜索、不执行模型复查，不重试不确定调用；终态或用量不明即停止后续任务。美元费用未知；此前已知累计 124,908 Token，另有历史未知用量。

评分器和通过条件沿用第 100 项并在调用前固定，构造测试确认错误位置失败；该评分仍存在语义及方向盲点，机械通过不代表实际引文支持。由于资料已用于开发及选择规则调整，本次是非盲配对诊断，不是独立测试或阶段 B 正式质量验收。原始 0/2 结果与输出不覆盖。

## 结果

两项操作各调用一次并有确定终态，分别报告 1,353 和 1,171 Token，共 2,524；已知累计 127,432 Token，另有历史未知用量和未知美元费用。预登记机械结果仍为 0/2，研究均为部分完成。

GDP 题本次在有定位的引文中给出两期年化数值、出口与消费上修，以及库存下修的抵消作用；但模型把后者归入支持性结论，预登记评分要求该项归入反方，因此该项机械检查失败。其反方写“无来源提供反方观点”并引用版本标签，不能据此证明不存在反证。

政策题正确引用维持区间以及累计收紧、时滞、经济金融发展的完整句子；评分器未覆盖“收紧”同义表达，且对引文跨行空白的匹配不完整，因此对应机械检查为失败。模型将区间数值输出为 `5.25%-5.50%`，现有数值解析未接受该格式，事实被省略；模型另给百分比附加 USD 币种，仍须核查。反方引用的片段不完整，不能证明其推论。

上述是对保留的实际输出所做的补充检查，不重算预登记成绩。两题仍有语义和反方缺口；本次非盲样本不能证明泛化或阶段 B 验收通过。
