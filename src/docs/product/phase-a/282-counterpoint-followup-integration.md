# 反方补充接入研究运行

研究运行新增可选 `counterpoint_followup`，默认关闭。启用后，如果首次研究有结论但没有可用的带引用反方，系统可在相同问题、允许来源和已选摘录上发起一次补充调用；旧结论作为不可信文本提供。补充调用保留原摘录、截止条件和提示哈希，不增加检索范围。结果重新经过既有定位、权限和警示流程，仅有有效原文位置的候选反方会进入研究；模型输出仍非独立核验。

调用须同时满足次数、Token 和时间预算；不满足时明确记录预算状态。额外调用前先保存首次生成检查点，取消、失败或结果不明时保留该版本；未知用量不能记为零。之后若启用引文复查，其调用次数及 Token 与生成、反方补充共同计入上限，并继续使用既有受限复查规则。保存终态前检查版本，用户并发编辑不会被覆盖。重复提交同一幂等键不重复请求。检查点可查看，但运行中断后不能自动接着向供应商重发，重新运行可能产生额外费用。

Web 工作区提供明确的可选开关和付费提示；未自行修改 Token 上限时，开启后默认使用 20,000，总预算、输入上限和时间仍可由用户调整。没有反方、预算不足、输入超限、失败及已完成等状态分别显示。反方和复查同时启用时，批量复查的调用上限包含三次；逐条复查仍受用户所设总次数限制。

验证：API 使用模拟供应商覆盖两次生成和第三次复查的累计用量、无预算、无效引用、供应商失败、幂等重放、取消及并发编辑；原有研究分析、运行和复查测试通过。Web 类型检查与客户端测试通过。Browser 插件未提供，使用本地 Playwright 和模拟 API，在桌面及移动视口验证开关、20,000 默认预算、请求参数、补充结果和无横向溢出；未接触真实用户资料。281 号探索使用了不同提示；本次接入的具体提示和完整链路**尚无真实模型质量验证**，不能因此宣称 B04 或阶段 B 已通过。
