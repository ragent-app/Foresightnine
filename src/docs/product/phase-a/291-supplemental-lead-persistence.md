# 候选引文的版本保存

补充响应中提取的候选引文原先只存在于生成结果：用户保存备注或确认版本时，服务端重算候选列表，但无法从主张列表中重新找到额外响应的引文，导致候选消失。

保存新版本时现在从上一版本的已保存候选中读取最多 50 条补充引文位置，重新执行来源可展示权限、精确原文、唯一位置和数值关联检查，再生成候选。它不复制额外响应中的主张文本，不把候选附加到引用，也不会清除已有缺口；用户删除相关数值或来源不满足检查时，候选不会被继续建议。普通研究条目的候选仍按原规则生成。

API 测试覆盖生成、保存新版本后保留候选，以及编辑结论移除相关数值后不再建议；证据模块回归通过。此修正涉及候选的持久性，不证明引文语义或阶段 B 质量验收通过。
