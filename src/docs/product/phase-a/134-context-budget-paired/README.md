# 输入预算配对诊断：调用前登记

在 128 号已经使用过的美联储声明任务上，对照提供方输入上限 3000 和 6000；固定题目、资料字节和来源 ID、选段算法、系统指令、模型、生成参数、权限和超时。输入上限是唯一主动变量；它会改变进入模型的选段和提示长度。固定运行顺序为 3000、6000。各项最多一次直接模型调用，不搜索、不二次复查、不重试；每次输入上限加输出上限最多 10000 Token，全部最多两次及 20000 Token。未知终态、未知用量或预算超限则停止。美元费用未知；此前已知累计 139881 Token，另有历史未知用量。

固定来源和提示哈希、脚本及评分器；保存实际模型响应、已定位引文、选段、时间及报告用量。预登记机械信号只检查关键数值、因素和反方中的关键词与引文位置；它不判断主体对应、推理和所有引文语义是否正确。分别显示各信号，不将其合成为正式验收或模型质量分数，也不据本次单题自动改变默认上限。此题已用于开发且参考公开，单次结果有随机性，非盲、非独立测试；此诊断不是完整 API 或账单链路测试。

## 结果

两次调用均有确定终态，分别报告 1174 和 2259 Token，合计 3433；已知累计 143314 Token，另有历史未知用量和未知美元费用。3000 条件提示为 2055 字节，选段为 6154–6442 和 7486–7781；6000 条件提示为 5055 字节，选段为 4919–6669 和 7037–8787。两者各为一次调用，保留原响应、选段、位置和预登记机械信号。

3000 条件未引入购买金额或利率目标段，模型承认无法从摘录确认这些数据；6000 条件引用了两项购买额和持续条件，风险引用也出现。两组信号都未满足目标区间检查。6000 的模型文本在说明摘录不含利率目标的同时，仍写出 0 至 0-1/4 的目标区间，且引文不含该数字，不能把它当作有依据的事实。其关于监测事项的复合结论只引用调整政策的句子；反方的“没有把通胀视为主要风险”与“未把金融环境收紧列为当前风险”也属于超出引用原句的推论，不能仅由可定位引文认定支持。

本次评分器对目标区间的正则未覆盖 `0-1/4` 这一数值写法；但引文缺少目标区间是独立的实质问题，不能将机械失败简单归因于此。更多输入带来部分额外内容，也带来未经引用支持的陈述；单题结果不足以证明因果或泛化，因此维持默认预算。直接调用诊断未经过完整 API 的数值提示和状态判断，不代表这些提示不存在；没有独立语义复核，也不构成阶段 B 质量通过。
