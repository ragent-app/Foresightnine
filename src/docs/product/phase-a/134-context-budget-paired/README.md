# 输入预算配对诊断：调用前登记

在 128 号已经使用过的美联储声明任务上，对照提供方输入上限 3000 和 6000；固定题目、资料字节和来源 ID、选段算法、系统指令、模型、生成参数、权限和超时。输入上限是唯一主动变量；它会改变进入模型的选段和提示长度。固定运行顺序为 3000、6000。各项最多一次直接模型调用，不搜索、不二次复查、不重试；每次输入上限加输出上限最多 10000 Token，全部最多两次及 20000 Token。未知终态、未知用量或预算超限则停止。美元费用未知；此前已知累计 139881 Token，另有历史未知用量。

固定来源和提示哈希、脚本及评分器；保存实际模型响应、已定位引文、选段、时间及报告用量。预登记机械信号只检查关键数值、因素和反方中的关键词与引文位置；它不判断主体对应、推理和所有引文语义是否正确。分别显示各信号，不将其合成为正式验收或模型质量分数，也不据本次单题自动改变默认上限。此题已用于开发且参考公开，单次结果有随机性，非盲、非独立测试；此诊断不是完整 API 或账单链路测试。
