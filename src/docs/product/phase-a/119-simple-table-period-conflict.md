# 简单表格的年度列冲突检查

日期：2026-11-12。对明确的矩形竖线表格，系统增加有限的年度列检查：只处理以 `Year`、`Years Ended` 或 `Fiscal Year` 等明确表头开头、每列为不同四位年度、列数一致、数值在行内唯一、金额格式可识别，且表头和数据行之间没有叙述或异常表格行的情况。事实期间也必须是单一年份或 `FY` 年份。表头和数据之间最多检查十行，不处理跨行跨列、重复值、含歧义的期间或复杂格式。

当事实声明的年份与数值所在列不同，保留事实、展示声明年份和疑似列年份，但不将该事实用于模型请求的自动计算；研究保持部分完成。用户编辑事实时服务端重新从来源检查，旧的冲突标志不能通过客户端删除。已有计算引用冲突事实时标为无法核对，重算被拒；改正期间后可重新计算。即使没有冲突，表格对齐及单位仍须核查；该规则不是会计语义校验，也不会自动确认事实正确。历史版本不会自动回填，新运行或编辑保存后才检查。

验证：研究计算、分析、运行及版本测试 204 项通过；新增测试覆盖倒置年度、重复值、合并单元格、叙述分隔、无效位置、存档、导出、编辑后重算等。Web 284 项测试和类型检查通过。Browser 插件及其 browser 技能未列出，按前端测试流程用本机隔离模拟 API 和 Playwright 检查 `http://127.0.0.1:15174/`；1280×900、390×844 均显示年度冲突和部分完成，不显示被排除的计算，无横向溢出或控制台错误。测试是合成表格，没有调用模型；未改变既有真实资料评估结果。
