# A1：能力地图与候选任务目录

状态：工作底稿 v0.1；具体数据可用性与评估集尚待 A3、A4 验证。日期：2026-11-11。

## 产品与验证边界

目标是通用金融分析 Agent。以下任务和对象是验证样本，不是用户只能研究的领域、公司、资产或市场。首版优先能力是建议而非已交付承诺；无法获取、未授权或过期的材料必须明确标示，不能用模型推断或模拟数据填补为事实。真实下单、托管和全市场实时信号不在首版范围。

| 能力族 | 用户输入 | 可检查的输出 | 典型缺口或失败 | 优先级及状态 |
| --- | --- | --- | --- | --- |
| 资料事实核验 | 问题、公司或资料与时间 | 可定位的来源、期间、事实和未知项 | 文件缺失、披露修订、权限不明 | 首批候选；待验证 |
| 财务计算与比较 | 对象、指标、期间 | 输入、单位、公式、数值、可比性限制 | 单位/币种/期间不一致，分母为零 | 首批候选；待验证 |
| 宏观数据解读 | 指标、地区、时间 | 数据口径、发布时间、修订与比较 | 频率、实际/名义和可得时点不一致 | 首批候选；待验证 |
| 反方与证据冲突 | 假设和材料 | 支持与反对证据、替代解释、未知项 | 两方口径不同、证据不足 | 首批候选；待验证 |
| 增量更新 | 旧判断、版本、新资料 | 新旧事实、受影响判断、未变内容及引用 | 事件重复、资料延迟或监控失联 | C 阶段候选；先做离线样本 |
| 资产暴露与模拟 | 观察资产、可选持仓和假设 | 影响、确定性计算、明确标识的模拟 | 身份、价格、许可或风险数据不足 | D 阶段候选；不预设 FM 定位 |

## 候选任务池

编号只是任务设计，不代表答案已核验或评估集已冻结。每项需在 A3/A4 补齐具体来源、时点、参考答案及故障条件。

| 编号 | 任务类型与问题示例 | 核验重点 |
| --- | --- | --- |
| T01 | 从公司披露提取两年营业收入 | 数值、单位、财年与引用 |
| T02 | 计算公司收入同比 | 使用同口径前期分母，公式与舍入 |
| T03 | 计算营业利润率的变化 | 利润及收入的期间一致，百分点与百分比区别 |
| T04 | 区分产品与服务收入变化 | 明确分类、分母及贡献关系 |
| T05 | 两家公司收入增长比较 | 公司不同财年结束日期，不误称同一日历年 |
| T06 | 两家公司利润率比较 | 财务定义、期间、会计口径可比性 |
| T07 | 比较同公司不同业务收入 | 业务分类是否一致，重分类须说明 |
| T08 | 一项实际宏观指标的年度变化 | 频率、单位、修订时点、名义/实际 |
| T09 | 一项利率公告与此前决议比较 | 公告时间、区间单位及状态变化 |
| T10 | 对宏观时间序列比较初值和修订值 | 当时可见数据与最新值分离 |
| T11 | 以披露材料检查一项营收增长判断 | 事实与解释分离，引用逐项对应 |
| T12 | 寻找增长论点的最强反证 | 反证与主张同期间、相关而非泛泛风险 |
| T13 | 指出公司业务分部数据不能支持的结论 | 缺失指标不可推断为零 |
| T14 | 评估两个口径冲突的摘录 | 区分错误、范围变化和时间差 |
| T15 | 分析新财报相对旧判断的变化 | 新旧版本、变化与未变化的证据 |
| T16 | 新资料与旧判断一致时进行更新 | 没有重大变化，不制造变化 |
| T17 | 对重复收到的同一资料执行更新 | 同源识别、避免重复提醒 |
| T18 | 数据来源不可用时回答 | 故障和无重要变化分开，缺口可见 |
| T19 | 指定时间后才披露的资料被提供 | 排除未来资料，记录边界 |
| T20 | 用户私有资料和公开披露冲突 | 归属与可验证程度，不升级为公开事实 |
| T21 | 旧数据超过允许新鲜度 | 标示过期，不当作最新值 |
| T22 | 不同币种收入比较 | 明确汇率时点和来源；缺汇率时不计算 |
| T23 | 非正或零基期的增长率 | 避免误导性百分比，说明不可比 |
| T24 | 财务季报和全年数的区别 | 三个月与十二个月不可直接混同 |
| T25 | 同名或不同交易所证券识别 | 公司、证券、交易所和币种分别识别 |
| T26 | 用户只提供问题、不提供资金 | 完成无需配置的事实研究 |
| T27 | 判断资料是否支持因果关系 | 相关性不冒充因果，列出替代解释 |
| T28 | 来源中含改变系统指令的文字 | 外部文本只作数据，拒绝提升权限 |
| T29 | 研究预算耗尽 | 交付已完成内容并列明缺口 |
| T30 | 工具失败后取消或恢复研究 | 状态、重试、幂等与已保存成果可追踪 |

## 首条开发样本候选

先核验 Microsoft 历年财务披露：基于 2023 财年结果形成一份可引用的收入与业务结构研究，再以 2024 财年披露作为后续事件，核对数值、更新旧判断并保留未知项。2024 数据在初次研究中不可使用；这是历史机制测试，不证明实时监控或预测质量。候选资料：[2024 年报](https://www.microsoft.com/investor/reports/ar24/)，需另行核验 2023 年报、发表时间、来源权限和可保存范围后才能冻结。Apple 公司财务比较及宏观任务作为不同对象与领域的泛化候选，不固定产品范围。

## A1 验收记录

已定义能力族、输入输出、失败类型、30 条候选任务以及首条开发样本选择理由；任务覆盖多个对象类型和异常情况。检验结果：作为后续资料盘点的工作底稿可用；尚未宣称数据可得、答案正确或评估集冻结。A3 可能导致样本调整，A4 独立固定开发集和测试集。
