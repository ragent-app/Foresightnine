# 重复百分比的证据提示

179 号真实研究中，一项结论把相同的 `0.1 percent` 用于名义支出和价格指数，但引文仅覆盖后者；模型仍给出支持判断。为避免仅凭相同数值掩盖这种缺口，系统现在识别同一主张内重复出现的相同百分比，展示需要分别核对指标及引文的提示，将研究标为部分完成，并暂不将该主张送入自动支持性复查。编辑后重新计算提示；带有同一数值但不同格式（例如 `%` 与 `percent`）也会提示。百分比点、基点及公式中的比例缩放因子不按普通百分比处理。

这是保守的范围提示，不判断数字是否指向不同指标，也不表示引文一定不足；同一事实在一句话中被重复时也可能触发，代价是减少自动复查覆盖。不同数字或单次出现的相同指标仍可能有语义问题，不能依赖这一规则证明支持关系。

使用 179 号保存的原始结果离线重放后，原来被模型误判为支持的结论获得重复百分比提示并从复查候选中排除；这不是新模型调用，不改变原实验成绩。证据与复查、研究运行自动测试及 Web 类型检查和测试通过。本次修复不证明研究质量已全面达标，阶段 B 继续进行。
