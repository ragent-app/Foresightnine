# 复查批次隔离：配对诊断预登记

复用 174 号已见资料和仅保留必要上下文的四条主张。目标主张同时声称名义消费增长、价格下降与实际消费增长，而引文没有名义消费增长的依据。固定目标主张的文字、引文、空的可选上下文、系统提示、模型与参数；对照保留四条批次，候选只保留目标一条并将其批次编号由 1 改为 0。两份实际提示、其来源与哈希在调用前固定；唯一主动变量是与目标同时送审的其他主张及相应编号，构造批次的合成材料只存在对照提示，不进入产品证据。

先批量后单条，各最多一次调用，输入上限 6000、输出上限 4000、每次预留 10000 Token、超时 60 秒，合计最多两次及 20000 Token；不搜索、不重试，异常或用量不明即停止。此前已知累计 196157 Token，另有历史未知用量；美元费用和供应商内部版本未知。

预先检查结构和编号，并记录目标 verdict；因关键事实未由引文支持，`supports` 是失败，`uncertain` 或 `does_not_support` 符合该项检查。其他主张的判断也保留，但本次不评估它们的完整语义。单条与批量有不同上下文长度及编号，供应商内部状态和随机性不可锁定；单次已知样本不能证明因果、泛化或 B 阶段验收通过。

## 结果

两次调用均确定完成；批量和单条分别报告 658、431 Token，合计 1089，已知累计 197246 Token，另有历史未知用量及未知美元费用。两项结构与索引均有效。目标主张在批量条件下被判为 `supports`，未通过预设检查；在单条条件下被判为 `does_not_support`，符合该项检查。

结果提示同批其他材料可能影响判断，但也可能受提示长度、编号、调用顺序和模型波动影响，单次不能确定原因或证明逐条复查总体更可靠。逐条复查会增加模型调用、时间和费用，并需要受预算约束及处理部分完成和中断恢复；本次未修改默认复查方式，不将结果视为阶段 B 验收。
