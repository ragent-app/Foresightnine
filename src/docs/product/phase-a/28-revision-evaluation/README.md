# 两份官方公告的修订对照

调用前固定提交 `2bf3c20`、模型参数、两份 PDF 及文本哈希、问题、评分程序和预算，见 `manifest.json`。本次使用 [BEA 2024 年 10 月公告](https://www.bea.gov/sites/default/files/2024-11/pi1024.pdf)及[11 月公告](https://www.bea.gov/sites/default/files/2024-12/pi1124.pdf)的原始 PDF，分别提供给研究任务；两者对 2024 年 9 月当前价个人收入较前月的美元变动给出 74.4 和 88.2 十亿美元，后一公告将前者列为修订前数值。两份文件当前哈希不能证明历史字节未被修改；实际公开时间和一般使用依据见来源元数据及[来源矩阵](../03-source-inventory.md)。题目与参考值对开发者可见，非盲测或独立人工评估。

调用上限为一次、10000 Token、120 秒；`glm-5.3-flash`，供应商输入策略 3000、超时 60 秒，不搜索、不复查、不重试。预设条件要求两个数值各自作为带原始位置、期间和单位的事实保留，并有一条引用两份来源、包含两个数值及修订关系的结论；机械检查不证明引用语义支持。

本次失败：模型获得的两个短片段是后续发布时间和联系方式，没有目标修订表；没有保存两个目标事实，也没有满足预设引用条件。研究标为部分完成，反方引用包含歧义位置，且引用内容不能支持完整结论。调用报告 1017 Token，美元费用未知。保留原始响应、评分及记录，不重算或重跑。

后续开发中为有限上下文改进 PDF 片段处理：仅在模型输入中压缩原始 PDF 水平空白并提示检查表格列；保存的来源、原文坐标和引文仍使用未经修改的提取文本，位置核查允许空白差异。选择器补充中文月份及财务词映射，短片段时回退为较大的连续片段，并缩短提示词中的固定说明。方法升级为 `ranked_nonoverlapping_windows_v10`，输入和提示词同时变化，本次不能归因于其中某一变化。离线诊断显示两个修订表片段均包含目标数值、指标和月份；旧 P24/P25 的月度和年度目标段落也可见。表格压缩后列对齐变弱，模型是否正确识别列、引用和修订语义尚未验证。诊断不是新的模型调用或测试集重评分，原成绩不变。
