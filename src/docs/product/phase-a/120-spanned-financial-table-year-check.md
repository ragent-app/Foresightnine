# 跨列财务表格的年度冲突检查

日期：2026-11-12。119 号检查只覆盖无合并单元格的矩形表格，无法覆盖已保存的 NVIDIA 申报 HTML 提取文本：其中日期表头和数值行通过提取器生成的 `[colspan=…]` 标记维持列宽。

对精确定位的单行事实，新增有限的跨列检查：计算有界 colspan 的逻辑列位置，只在明确的 `Year Ended` 标题、可解析且年份不重复的完整日期列、相同总列宽、连续结构和行内数值唯一时，比较事实声明年份与疑似数值列年份。只支持简单正负数字；任何 rowspan、异常列宽、叙述分隔、无法识别的单元格或复杂期间均回退普通复核。冲突沿用现有提示、计算排除、编辑复核和导出机制。跨度标记可能是提取器标注或用户提供的文本，并不证明原始 HTML 表格或模型解释正确；没有警告也不表示已核实。

对 112 号开发检查保存的完整 NVIDIA 提取文本及模型响应进行离线对照：原始两项年份未出现冲突，保留两项计算；仅交换模型响应中两项事实的期间后，两项均提示列年份不同且两项计算被排除。交换输入是合成故障验证，不是另一次模型运行，不改变原始实验结果或评分，也不能证明模型质量和会计口径。

新增合成测试覆盖有效跨度、倒置年份、重复值、错误列宽、rowspan、无效日期、叙述分隔和无关引文；研究计算、分析、运行及来源提取测试 199 项通过。未调用外部模型。
