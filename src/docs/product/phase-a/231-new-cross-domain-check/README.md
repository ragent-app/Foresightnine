# 新来源跨类型研究检查：调用前登记

固定此前未在本地资料快照中发现相同 PDF 哈希的三份一手材料：美联储 [2020 年 12 月压力测试](https://www.federalreserve.gov/publications/files/2020-dec-stress-test-results-20201218.pdf)、BEA [2020 年个人收入与支出历史比较](https://www.bea.gov/sites/default/files/2021-03/pi0221_hist.pdf)、美联储 [2016 年 12 月政策声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20161214a1.pdf)。分别要求公司实际与压力情景资本比率、名义与实际消费变化及储蓄率、政策利率与主席。压力报告是监管情景数据，不等同于完整公司财报。

原始 PDF、问题、分离参考、检查代码、模型、生成参数、提示及选中片段哈希在调用前固定；每题最多一次生成和 10,000 Token，合计最多三次、30,000 Token，不搜索、不重试、不请求模型复查；单次 60 秒、任务 120 秒，终态或用量不明即停止。美元费用未知，不按零计。FRED 不参与。已知此前报告累计 250,059 Token，另有历史未知用量。

预先规定三题全部满足固定机械检查才算此检查通过：规定值与必要标签同时出现于主张和可定位引用，BEA 下降值要求显式负号；所有主张有完整、唯一定位的引用，无已知数值和来源警示或被省略内容；要求反方时需有引文；预算受控且部分结果明确披露。具体模式在 `score.py`，不在运行后更改。数字和词语共现不证明对象、期间、列对齐或语义支持，还须另行检查原始输出和资料。

这些材料与题目由同一准备者查看参考和登记，题型与开发经验相似，模型训练资料和供应商内部版本不可锁定，因而不是盲测。三题不能代表全市场、独立正式测试集或阶段 B 全部验收；用户已明确跳过人工验收，不要求用户参与，也不把缺失的独立质量证据记为通过。

## 结果

三次调用均完成，分别报告 2,523、2,761 和 1,729 Token，共 **7,013 Token**；已知累计 257,072 Token，另有历史未知用量与未知美元费用。三项研究均为部分完成，按调用前固定规则 **0/3** 通过。

- 银行报告：主张与数值行出现三个参考值，但表头引文有多个可能位置，且部分季度和反方数值未由其引用覆盖。不能仅按数值共现确认列对齐。
- BEA：各项目标值与相关段落出现，但两条简短表头引文有歧义，另有上下文和反方数值提示；反方还提到疫情影响，而所引段落本身未证明该因果解释。不能将位置匹配当成完整语义支持。
- 政策声明：利率区间可定位，但答案没有给出主席，且存在未覆盖的百分比和被省略计算；原 PDF 的投票段落实际包含 Janet L. Yellen，所选模型片段截掉了她的名字。模型称所供摘录未包含姓名，不能推断原文不包含姓名，也不能作为有依据的反方。

所有输出与固定评分保留，不能把这轮非盲小样本作为全部领域或阶段 B 验收依据；后续修改不得覆盖本次结果。
