# 增长计算的期间顺序

增长公式将第一个输入视为本期、第二个视为基期。对于可直接识别且同类型的年份、FY 年份、`YYYY-Qn` 季度、`YYYY-MM` 月份和 ISO 日期，计算器拒绝本期不晚于基期的输入；保留事实并显示省略计算的原因。计算结果记录是否进行了这项格式限定的比较；这不是对原始资料、财务口径或期间归属的独立验证。

不同类型、无法识别或无效的期间文本不自动比较，结果保留“未检查”状态，页面提示核对；旧计算缺少该记录时也显示提示，历史数据不改写。已编辑或输入已变化的计算同样提示，重新计算会生成新版本。公式没有改变，原历史公式版本保留。

验证：相关计算、分析、运行和版本 API 测试 101 项通过，Web 类型检查通过。Browser 插件不可用；本地 Playwright 使用测试身份和替身验证历史结果提示、重新计算后的状态以及桌面与手机视口。这没有调用真实模型，也不改变先前模型评估结果。测试不覆盖所有财务期间表达或跨会计日历比较。
