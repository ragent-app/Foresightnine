# 完整研究与复查诊断：调用前登记

复用 161 号已作为开发样本的 BEA 原始 PDF 和问题。固定当前代码、数据和提示哈希、供应商模型参数；通过真实研究 API 的内存隔离运行，使用每次输入上限 6000、输出上限 4000、总预算 20000 Token、最多生成和复查各一次、120 秒任务与 60 秒调用超时。不搜索、不重试不确定调用，保留供应商原始输出、用量、复查范围、遗漏及研究版本。模型供应商内部版本和美元费用未知；此前已知累计 184679 Token，另有历史未知用量。

沿用 161 号有限机械评分，另记录复查覆盖、每项 verdict 和任何遗漏；核对复合主张的所有事实是否由其各自引文支持。模型自评不构成独立证明。该单次非盲诊断同时改变了相对于 161 的输入预算和后续代码，相对于 167 又改用完整 API 和复查，不能将结果差异归因于单一因素；本次不作为独立测试或 B 阶段质量验收。

## 结果

操作有确定终态，生成与复查共调用两次、报告 4362 Token；已知累计 189041 Token，另有历史未知用量及未知美元费用。研究结果仍为部分完成。四个指定数值及商品、服务关键词均出现在可定位主张和引文中，但这不证明语义支持或整体完成。

复查向模型提交原结论索引 1–5，索引 0 因数值提示未送审；供应商却返回索引 0–4，其中 0 不在提交范围，故程序拒绝整批结果并标记复查失败。可能是模型按顺序重新编号，但无法从该响应确定，不能事后改写索引或声称任何判断通过。第一条主张的原引文含 `(0.1 percent)`，现有数字解析没有识别这个括号内附单位的正数，产生了未引用数值提示；这是需修复的误报，不改变本次结果。

另一条主张同时讨论名义支出、价格及实际支出，却只引用价格和实际支出原文，名义 0.1% 未在该条引文中得到支持；反方引用压缩的多列表格，其月份列对齐未独立核验。来源选段不完整，部分事实和计算被省略。结果保留原始响应和评分，不能证明 B02、B04 或 B09 已通过。
