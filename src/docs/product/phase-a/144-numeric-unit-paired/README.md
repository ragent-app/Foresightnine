# 数字单位边界：配对复核预登记

复用 140 号贸易公告和银行压力测试任务的原文及哈希、来源 ID、问题、模型、生成参数、系统提示、输入上限 3000、权限、超时及原机械评分。唯一主动变化是 v31 到 v32 的通用选段边界处理；由此可能改变选段、提示长度和模型输出。固定 140 号原始结果及评分，不重跑旧条件。

每题最多一次直接模型调用、输入与输出预留共 7000 Token、60 秒；合计最多两次及 20000 Token，不搜索、不复查、不重试；终态或用量不明时停止。历史已知累计 157440 Token，另有历史未知用量；美元费用未知。保存提示哈希、原始输出、选段、计量和不变的机械信号。

两题及参考已用于开发，对照非盲、每种条件仅一次，无法锁定服务内部模型版本，不能据此证明因果或泛化。机械信号不完整判断数字角色、单位、引文语义和反方充分性，不能作为 B02、B04、B09 的正式验收。直接调用未覆盖 API 和账单链路。

## 结果

两次调用均有确定终态，分别报告 1767 和 1165 Token，共 2932；已知累计 160372 Token，另有历史未知用量及未知美元费用。沿用 140 号的机械信号，两题结果与旧条件相同：贸易题仍缺少四项数字覆盖，压力测试题仍缺少最低比率及具体反方证据；全部保留引文均可定位。

贸易题关于服务顺差的引文这次保留了 `1.6 billion`，但 1 月修订逆差仍未进入选段，模型如实列为缺口。压力测试题的首条引文这次保留了 `12.4 percent`，但缺失 9.9% 最低值；该结论还写了 2022:Q4 和 2023:Q1–2025:Q1，而所附首条引文并未覆盖这些期间，不能单凭数字及位置匹配认定整条结论受到支持。模型反方主要是资料缺口，未给出原报告中的具体风险。

边界处理在这两项已知样本中保留了单位，但没有解决资料选择和语义支持问题；单次非盲配对不证明因果或泛化，不能作为阶段 B 验收通过。旧结果和评分不变。
