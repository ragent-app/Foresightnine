# 模型复查的引文边界探索

针对上一候选题中收入引文附近出现财年周数，但引文本身没有覆盖周数的情况，固定同一衍生来源、同一引文上下文、三条预先列出的主张及供应商配置，比较原复查提示和带精确引文边界的新复查提示。唯一主要实验因素是复查提示方法；两种方法各最多调用一次，不重试，第一项结果不确定或格式无效则停止。模型、参数、预期和哈希见 `manifest.json`，费用未知。实际输出与评分不得覆盖。

三条主张分别为：仅在引文周围出现的 53/52 周、引文明示且上下文给出单位的 2024 收入、把 2023 收入错记为 2024 收入。预先要求第一条不得判断引文本身支持，第二条应支持，第三条应拒绝或判矛盾；所有项满足才称本次检查通过。这是开发者已知的小规模提示词探索，模型复查不构成独立核验，无法证明任意引文的语义支持或阶段 B 的整体质量。

结果：原方法将周数主张判为支持，因此未通过这项预登记检查；新方法将该主张判为不支持，对正确收入判支持、错误年份收入判矛盾，满足三项检查。两次分别报告 528 和 732 Token；美元费用未知。此配对只涉及一个已知衍生来源、三条构造主张，不能证明新方法在其他资料或实际研究中可靠。源文上下文仍仅用于解释引文，复查结论明确是模型判断。
