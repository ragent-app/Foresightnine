# 数值单位重复的处理

218 号检查中，模型以 `2 percent` 表示数值且单位也写作 `percent`，已有代码移除重复单位后没有把值写回事实列表，导致事实被错误省略；另一个显式百分比区间的单位是 `percent (range)`，未被识别。现在仅在单位与数值后缀一致时保存剥离结果，并对明确、有效的 `percent (range)` 区间复用既有的精确端点解析。原文定位、期间和单位检查、币种限制及计算防护保持有效；解析不证明来源支持结论。

API `tests/test_research_analysis.py` 全部 133 项通过，覆盖单事实、区间、倒置区间和不匹配单位。218 号实验及评分不重跑、不修改，尚需全阶段回归和独立资料质量评估。
