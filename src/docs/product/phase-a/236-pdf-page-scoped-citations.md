# PDF 模型引文页码定位

此前 PDF 中同一表头在不同页面重复出现时，仅凭引文文本无法确定模型所指位置。现在在输入预算内将选中的 PDF 文字按提取页分段，向模型提供页码；模型可对引文或数值事实返回可选页码。定位只在该来源实际提供给模型、且属于所选页的文字范围中进行。未见页面、非 PDF 页码或页码内不存在的文本不能形成引文；同页出现多次仍标为歧义。未提供页码时保留原有定位规则。超碎片页面和跨页聚焦输入保留未分段路径，避免丢失用户选定上下文。

页码是模型选择，不能证明选择的表头对应目标行，也不能证明引文语义支持结论；结果和导出仍注明需要独立核查。文本内容、页码按原始 PDF 提取文本计算，非 PDF 不增加页码。提示词、引文模式和检索版本变更为 v46，会影响模型输入；历史运行与证据不改写。

已运行研究分析及任务运行测试，覆盖不同页同一引文、同页重复、无效页面和非 PDF 拒绝；未进行新增模型调用。本改动尚未以独立资料验证研究质量，不代表阶段 B 的 B02、B04 或 B09 已通过。
