# 模型输入预算的配对诊断

调用前登记：复用 [第 104 项](../104-revision-paired-recheck/README.md)的两个问题、资料、来源标识、参考、系统提示、模型、生成参数、模型调用及总 Token 上限。主要实验变量为每次调用的提供商输入上限从 3,000 提高到 6,000 Token；模型输出上限仍为 4,000 Token，因此每题的最坏调用预留从 7,000 变为 10,000，正好受原有单题总预算约束。选段和实际提示哈希作为该变量的结果记录于 manifest；提示字节上限仍保守地按输入 Token 上限扣除系统提示和帧预留。

每题最多一次调用、10,000 Token、120 秒，两题总计不超过两次、20,000 Token；不搜索、不复查、不重试不确定调用，终态或用量未知即停止后续任务。美元费用未知；此前已知累计 127,432 Token，另有历史未知用量。模型供应商版本不可锁定，单次结果不能证明因果或稳定性。

后处理较第 104 项另有带百分号区间识别、单纯反方缺口分类、期间粒度提示等修复；提示生成本身主要由输入预算改变，但整体评分差异不能全部归因于输入预算。评分器保持原版及已知盲点，不改变旧成绩；资料已用于开发，非盲配对诊断不构成独立测试或阶段 B 质量验收。使用的政策声明为去除官方标志的提取文本，BEA 原始 PDF 使用条件见第 98 项。
