# 三类任务固定评估

准备三项：两个此前已用于模型开发的 SEC 衍生公司数据快照构成跨公司财年比较；一份 BEA 2022 年三季度第二次估计原始 PDF；一份美联储 2021 年 12 月声明原始 PDF。两份 PDF 此前未见于本项目记录，但 BEA 与已测试的同季度 GDP 资料相关；题目与参考值对准备者已知，非盲、未经独立人工复核。公司输入是衍生事实而非完整申报原文。不可称为严格独立测试，也不足以说明总体质量或 B 阶段验收。

BEA 资料为 2022-11-30 08:30 EST 发布，第二次与初次季度折年估计分别为 2.9% 和 2.6%；美联储声明为 2021-12-15 14:00 EST 发布，国债与机构抵押贷款支持证券月度购买速度分别减少 20 与 10 十亿美元，次年一月分别购买至少 40 与 20 十亿美元。来源分别为 [BEA 公告](https://www.bea.gov/news/2022/gross-domestic-product-second-estimate-and-corporate-profits-preliminary-third-quarter)和[美联储声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20211215a1.pdf)，版权说明见既有来源矩阵。当前副本哈希及声明发布时间不能证明历史字节不变。一次尝试取得另一份 2019 年 BEA PDF 返回 HTTPError，未重试，也未发送给模型；改用不同的 2022 年公告。

在调用前固定输入、原文与提取文本哈希、参考、评分、实现与供应商参数。每题最多两次模型调用、10,000 Token、120 秒，合计最多六次和 30,000 Token；无搜索、外部调用重试，终态或用量不明则停止后续任务，美元费用未知。每题必须达到预设的数字、引用位置、模型复查覆盖和预算检查，三题全通过才称狭义机械检查通过；对金额角色、因果、引文语义和反方充分性仍须逐项检查，不能以机械分数代替。模型复查不是独立证明。
