# 暂定计算的状态与版本边界

研究运行的完成状态现在直接检查计算输入状态：只要计算输入不能与当前事实核对，运行保持部分完成，并明确提示结果暂定；不再依赖局限说明中的固定文字来触发这一状态。已保存与导出的计算保留 `unverifiable` 状态。原件结构提示与用户确认分别保存；编辑数值、期间或其他事实内容会清除旧结构提示和确认，不会覆盖旧版本。

对已有的原始 HTML 结构可识别的年度表格，用户确认恢复的表格行时会重新检查数值列的完整结束日期；若与声明期间冲突，拒绝确认。即使存在历史确认，已记录的结构冲突也会阻止重新计算。无法解析原件时，仍沿用原有明确标识的用户核对流程；结构匹配本身不证明指标、币种、单位或语义正确。

针对性 API 与计算测试 50 项通过。端到端测试用模拟来源与模型输出覆盖生成、部分完成、导出、编辑、伪造检查结果、旧版本保留及冲突确认；测试还移除诊断文字，确认状态由计算输入而非文案决定。本次无模型或网络调用，不能视为阶段 B 独立质量验收。
