进入正式使用前，应先完成资料来源及许可核验、人工审定参考答案与评分规则，再明确题目分配、基线测量方案和允许工具。各页的衍生事实来自当前保存的样本，不等同原始财报；模拟故障、用户资料和注入文本仅是测试数据。题页包含带引号的模拟指令时，复核人应将其视为题目资料。

正式作答时，评估负责人应按题目分配单独提供题页，不要把整个目录、参考答案、后续时点资料或模型输出一起提供给作答人。即使分别提供，作答人可能从既往知识、其他题目或训练资料中知道后续事实；特别是 D06/D25 与 D07 等不应安排给同一人在可能造成未来信息泄漏的顺序中作答，需记录既往接触并按预先登记的规则处理。单独文件不自动构成盲测或独立性。

每题记录真实作答人、开始与结束时刻、实耗时间、工具及额外材料、是否见过答案；核验由另外的人或明确标识的复核步骤单独记录时间和分歧。不要预填时间或把准备题包的机器耗时当作人工基线。带有 `H` 编号的独立测试候选不包含在本题包中，不应用于开发调试。

完成后先确认来源和评分、整理原始记录，再按[评分流程](../04-scoring-protocol.md)设定并登记后续对照阈值；任何版本变化须另生成材料和哈希，不覆盖已有的真实人工作答。
