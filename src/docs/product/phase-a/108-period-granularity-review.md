# 增长计算的期间粒度核查

增长计算使用的期间标签若能识别为不同的年、季度或月份粒度，现在保留算术结果并标记需核查存量或流量及期间可比性；自动研究因此保持部分完成。此类结果不会被用于自动建议或校正其他结论。用户仍可查看和重新计算：不同标签可能对应两个时点的资产负债表余额，不能仅凭标签判为无效；相反，不同长度的收入等流量直接比较可能产生误导。

仅识别已有明确日期格式；裸日期、自由文本、不同会计日历、相同粒度但不同定义和滚动期间仍可能无法判断。相同标签粒度不代表财务口径已核验；无法识别时不做猜测，原有期间顺序及输入精度提示继续保留。旧历史版本不静默重写，新计算记录该检查状态。

相关计算、分析和运行测试共 178 项通过，另有自动运行保持部分完成的专项测试通过；Web 类型检查和 284 项测试通过。Browser 插件不可用，使用本地内存 API、模型替身和 Playwright 在 1280×900 与 390×844 验证数值、核查提示和部分完成状态，未发现页面错误或手机横向溢出。未调用真实模型。
