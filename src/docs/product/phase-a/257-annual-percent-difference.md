# 年化百分比差值的单位修正

[256 号真实样本](256-gdp-counterpoint-recheck/README.md)中，模型将两期实际 GDP 年化增长率的单位写为 `annual percent`。确定性计算器先前未识别这种写法为百分比水平，因此把两者之差错误标成 `annual percent`；1.3% 减 3.4% 的正确单位是 **百分点**，结果为 −2.10 个百分点。数值正确并不能弥补单位错误。

现在识别 `annual percent`、`annualized percentage` 和 `annualised percent` 等明确的年化百分比写法，差值使用版本 2 的百分点单位；百分比关联币种仍拒绝计算。对历史保存的同类错误差值，在研究读取和导出时附加重算提示，不修改历史版本原文；这些计算不能用于自动支持主张，用户可以在新版本中重新计算。界面也提示相关旧结果的单位问题。

针对性计算及版本测试 53 项通过，覆盖实际样本数值、百分比和百分点区分、币种拒绝、历史版本读取与导出提示、原始记录不变以及新版本重算；Web 类型检查和报告测试通过。本次修复不改变 256 号原始结果或评分，不证明 GDP 结论、反方或阶段 B 质量已通过。
