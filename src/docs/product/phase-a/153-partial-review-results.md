# 模型复查返回部分结果时保留已覆盖项

151 号贸易任务向模型提交两条结论复查，模型只返回其中一条；旧流程因未完整覆盖而丢弃整批复查结果。现保留格式有效、索引唯一且属于本次提交范围的已返回判断，并逐项记录模型遗漏；未返回的结论不产生判断。只要有遗漏，复查和研究仍为部分完成，界面明确指出模型没有返回对应判断。空结果、重复索引、未提交索引、无效 verdict 或额外字段仍拒绝整批；旧判断不会被当作本次新结果保留。

这些判断始终标为未经独立验证，保留部分结果不代表模型判断正确，也不解决方向推理错误。生成检查点、调用次数、用量及既有输入预算遗漏仍保留。严格要求完整覆盖的内部函数仍可用于需要完整结果的调用；复查方法标识更新为 v18。

离线重放 151 号保存的复查响应：提交索引 0、1，模型仅返回 0；新处理保留 0 的模型判断，明确记录 1 为模型遗漏。151 号历史结果和评分不变。本次无新增模型调用；相关 API、校验和前端类型检查通过，不作为阶段 B 的语义或反方验收。
