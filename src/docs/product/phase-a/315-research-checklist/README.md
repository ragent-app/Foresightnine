# 研究待核查项

研究版本保存时，从已记录的来源、结论、引文警示、反方关系、计算输入和运行状态派生有界的 `run.research_gaps`。它只保存缺口类别及版本内索引，不复制原文或创建新的模型判断；保存修改或检查点时重新计算，历史版本不改写。Web 在没有未保存修改时显示该列表，文本和 JSON 导出通过运行记录保留。

该列表是通用的状态导航，不从具体公司、行业或样本措辞推断结论，不保证穷尽问题，也不能证明引用语义、反方相关性或数据真实。模型建议的关系仅表示有可供核查的关联，不视为已证明。最后一次运行部分完成仍是历史状态，编辑后不会伪称运行重新成功。自动规划、针对缺口补充取证及语义审核仍需继续实现。

按照用户要求，本次未运行测试、浏览器检查或模型实验；兼容性与实际效果尚未验证。
