# 反方补充响应中的候选引文

政策样本的补充响应在非请求的 `answer` 字段中提供了可能相关的通胀原文。过去为了保护结果边界整个字段被丢弃。现允许从该字段的直接子项中读取最多 20 个符合主张格式的条目，仅提取经过同一来源、同一选段、权限和原文定位检查的引用线索。条目本身不作为研究结论，也不解除任何数值或语义警示；匹配已有研究缺失数值的引用仍仅是候选，必须核对对象、期间、单位与含义。来源重复位置、超长引用、无效引用及未经授权内容继续遵循既有排除逻辑。

候选与来源于其他研究条目的候选在界面中区分。已有来源展示、版本和导出权限仍适用；未经用户操作不会把候选添加到结论的引用中。额外字段中的文字不会作为新主张或原始自由文本保存。模拟供应商测试覆盖有效、编造的线索和原有缺口，其他反方预算及警示回归与 Web 类型检查通过。尚未据此宣称真实材料语义支持或阶段 B 验收通过。
