# 原件内嵌 XBRL 的来源一致性检查

对保存的 HTML 财报，系统在既有原件哈希、提取全文和表格行追溯的基础上，读取目标单元格中的内嵌 XBRL 数值标签，并从同一原件解析其期间、实体标识和币种单位。仅对严格支持的年度、无维度、明确 USD 与计量倍率、可识别的收入/净利润/营业利润概念及对应行名称，且数值、列日期、模型标签和单位一致的事实，保存 `xbrl_source_consistency`。不支持、存在歧义或校验失败时退回原有未核验流程；这些条件不是产品的长期市场或任务边界。

使用两项此类事实计算时，还核对原件哈希、实体、相同指标（增长或差值）、年度期间不重叠及长度近似；满足条件的计算输入可标记为 `matched`，表示与保存的事实和来源标签一致。**这不认证文件真伪、不证明申报内容准确、不代表独立核验，也不自动证明结论引文的语义支持。** 引文缺少币种、表格上下文和其他既有警示仍保留。用户编辑事实会清除该服务端生成的一致性记录；导出受既有来源权限控制，旧版本不被改写。

对 [263 号 Cisco 已保存原件与模型输出](263-holdout-candidates/README.md)离线重放，两期总收入分别对应相同实体、USD、百万倍率和各自的年度 XBRL 标签；计算为 **−5.61%**，输入状态由 265 号的 `unverifiable` 变为 `matched`，事实仍标记为模型提取、未独立核验。未重新调用模型，263 和 266 的原始结果与评分不变；公司任务的完整引用、反方和真实质量验收仍未通过。

研究运行、分析、计算、证据、复查和 XBRL 回归通过，覆盖来源哈希、命名空间、重复或带维度的上下文、币种、倍率、实体冲突、重叠期间、编辑伪造、重算和导出。Web 类型与文本导出测试通过；本地 Playwright 使用模拟数据检查桌面及移动端的标签信息与计算展示，无页面错误或移动页面横向溢出。Browser 插件未列出，使用 Playwright。真实申报材料离线重放不替代多任务独立质量评估。
