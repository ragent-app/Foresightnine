## 真实复验条件与记录

- 使用普通 API 研究入口、独立内存实例和原问题「纳斯达克近一个月走势及未来可能的走势的分析报告」。研究截止为原主题发起时段 2026 年 11 月 18 日 14:41:12（上海时间）。没有预先提供资料。
- 使用既有授权的搜索与 Messages 端点，模型为 `glm-5.3-flash`。单次生成上限 4096 tokens，单次请求技术超时 120 秒，任务调用数、总 tokens、费用及时间预算留空。提交一次，提交前冻结的 87 份 API Python 文件哈希与结束时一致。
- 运行约 45 秒。一次模型请求返回、一次搜索完成，供应商报告 3000 tokens。工具先找到 8 条待核验线索，再调用历史行情工具并得知没有可用的授权来源。未取得原文或行情观测，引用和计算记录均为 0。
- 异步任务已结束，研究结果为 `partial`，原因是 `provider_timeout`。研究版本保留候选链接、历史行情缺口和模型调用超时的说明。结算无待处理的预留，隔离 API 已退出。

## 启用历史行情的条件

独立历史行情配置只对明确声明的标的生效。需核实订阅和数据提供者条款涵盖所需的标的范围、保存期限、模型处理和用户展示，按许可单独开启导出。当前旧行情快照配置没有记录这些研究用途的批准，复验未启用实时历史行情连接器。

真实指数走势和未来情景尚未通过验收，此次部署环境没有切换。
