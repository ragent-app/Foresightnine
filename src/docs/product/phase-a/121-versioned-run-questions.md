# 同一研究主题中的运行问题

日期：2026-11-12。原流程允许仅上传资料创建研究，但创建之后只能使用创建时的问题；资料主题若没有初始问题，不能在同一主题补充具体研究问题。现在最新版本的下一次运行可填写可选问题；留空时沿用主题初始问题，保持旧客户端行为。主题、资料、原问题和研究截止时刻不因新问题被修改。

新问题仅作用于对应运行，用于资料选择、分析和经用户授权的来源搜索，并保存在生成结果或复查前草稿的运行记录中。历史版本及导出可查看各自问题；问题进入幂等请求摘要，因此同一幂等键不能用于不同问题。运行输入快照记录实际问题的哈希，不在预算明文中复制问题。若运行在产生研究版本之前取消或失败，该快照只保留问题哈希，不可由哈希恢复问题。问题不改变既有研究范围、截止时刻、资料权限或外部调用预算；用新问题运行会产生新的模型调用。

更新 v2 OpenAPI 和生成类型；同时刷新快照中先前未同步的 PDF 字节上限。研究运行、版本与 OpenAPI 测试 69 项通过，覆盖资料主题两次不同问题、历史版本与导出、搜索内容、输入快照、空白问题和幂等重放/冲突；Web 测试 284 项、类型检查及契约生成检查通过。Browser 插件及其 browser 技能未列出，按前端测试流程用本机隔离模拟 API 和 Playwright，在 1280×900 与 390×844 验证资料主题连续提问、保存结果及历史版本切换；无页面或控制台错误、无横向溢出。本次未调用外部模型，不作为真实研究质量验收。
