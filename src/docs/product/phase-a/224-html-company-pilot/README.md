# HTML 财报端到端开发样本：调用前登记

使用已在 60、64 号研究中反复观察的 Cisco FY2024 SEC 原始 HTML，经新增用户 HTML 上传接口进入研究工作区。问题要求 FY2024 和 FY2023 总收入、期间、单位、同比计算，以及有来源的收入变化限制。原始文件沿用仓库现有快照，不重新请求 SEC。题目、参考值、提取文本与原文件哈希、输入片段、提示哈希、实现版本和运行代码在调用前固定。此题并非独立测试，且财报数值与参考已为开发过程所知，不能用于推断泛化能力或单独通过阶段 B。

最多一次生成、10,000 Token、60 秒单次超时、120 秒研究预算；不搜索、不复查、不重试。模型标识、生成参数、输入及输出上限、资料权限与总预算在清单和运行器固定；供应商内部版本和美元费用未知。实际用量未知或运行状态不明时不重复调用。

结果按预先约定逐项检查：上传文件哈希与提取文本哈希一致；保留的目标事实分别为 53,803、56,998 百万美元且引用能唯一定位原文；同比由确定性公式算出 -5.61%；有针对收入变化且引用可定位的限制或反方；所有主张引文完整并明确其语义是否真正受引文支持、期间和表格列是否可核实。任一缺失、含糊或未验证均分别记录，不因位置匹配就判定语义通过。原始输出和失败均保留，事后不改写上述条件。

## 结果

实际一次调用，供应商报告 2,707 Token；此前已知 247,352，加本次为 250,059 Token，另有历史未知用量与未知美元费用。操作终态为完成，研究状态为部分完成。上传与提取哈希符合登记值，但其他预设条件未通过：模型输出了两个预期收入值及计算请求，其引文把表头和不连续表格行拼接；第一项事实的引文无法定位，另一项仅能恢复带表格标记的行、列对齐未核实。系统因此未保留数值事实、未执行同比计算，也未保留没有有效引文的主张和反方。模型还明确指出截取材料没有管理层对收入下降原因的说明。

该结果表明新增 HTML 端到端路径可调用模型，但不能提供本题可复核的完整研究。拒绝缺乏依据的事实是防护行为，并不等于任务通过；也不能仅因模型输出参考数字就推定其引文和期间正确。全部原始输出、运行状态与用量保留在本目录，不重跑或修改本次结果。用户要求跳过人工验收，没有把缺少独立复核或此前已用于开发的样本称为独立测试通过。
