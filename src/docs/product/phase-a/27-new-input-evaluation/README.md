# 两项新资料模型检查

运行前固定实现提交 `d75246f`、输入与参考哈希、脚本、评分规则和预算，见 `manifest.json`。每题最多一次调用、10000 Token、120 秒，最多两次调用；模型为 `glm-5.3-flash`，请求超时 60 秒，不搜索、不做二次复查、不重试不确定调用。生成参数与供应商输入上限记录在清单中。模型内部版本、美元费用未知。

B24 使用从 [Booking Holdings 2024 年 SEC 10-K](https://www.sec.gov/Archives/edgar/data/1075531/000107553125000010/bkng-20241231.htm)整理的两期总收入数字，是衍生 JSON 而非原始申报；P24 使用 [BEA 2024 年 12 月 PCE 公告原始 PDF](https://www.bea.gov/sites/default/files/2025-01/pi1224.pdf)。各来源用途和例外见[来源矩阵](../03-source-inventory.md)；现时文件哈希不证明历史版本未变。两种输入分别评估，不能把直接提供答案的财报题看成完整原文阅读或来源发现。

预设机械检查结果为 1/2：B24 保留两期事实、可定位引用和 11.11% 的确定性计算，满足本次机械条件；其反方主要是资料局限而非实质反证，部分短引文只含数字、不独立包含单位或实体，因此机械通过不证明逐项语义支持或 B04 通过。P24 选中片段因 PDF 图表列与正文交错，月度 0.3% 被截断，同比 2.6% 虽保留但引用缺失比较口径；按预设规则失败，系统标为部分完成。模型的反方引文混入图表中的 2.0，不能凭位置匹配认为它支持整条解释。原始结果和评分保留，不重复调用或修改分数。

B24、P24 分别报告 1148、950 Token，合计 2098；美元费用未知。输入未在此前运行中使用，但开发者已看到参考答案，非盲测或独立人工评估，也不能证明历史时点可得性及整体质量。

随后修改片段选择，仅作离线诊断：`ranked_nonoverlapping_windows_v8` 在提问同时要求环比和同比、原文存在相应英语短语和临近百分比时，允许两段使用不同长度，以覆盖 PDF 提取的空白和被图表挤开的数字。`post-fix-selection-diagnostic.json` 使用原来源 ID、标题和供应商输入预算，显示 P24 和此前 P25 的两种比较片段均入选；旧成绩不变，也没有新的模型调用。该方法仍是有限检索启发式，所选百分比可能属于其他上下文，未覆盖的文本仍明确标记，不能作为语义证明。

之后的 `ranked_nonoverlapping_windows_v9` 为比较候选加入问题指标词与局部上下文排序，避免直接采用前面更不相关的指标；不满足关键词或预算条件时回退通用排序。[离线记录](post-fix-v9-selection-diagnostic.json)显示固定预算下 P24 和 P25 的目标段落仍被选中，但关键词匹配不能保证实体、期间或语义正确，模型未再次调用。
