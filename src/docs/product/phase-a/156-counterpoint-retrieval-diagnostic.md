# 风险资料选段诊断

151 号银行压力测试的原始报告包含一段具体风险：集中于抵押贷款、信用卡和商业地产的银行，压力测试后资本比率降幅一般更大。当前选段未包含这段文字，因此模型无法基于该段直接引用它；这不是模型一定会正确使用该段的证明。

运行 `PYTHONPATH=apps/api uv run --project apps/api python docs/product/phase-a/156-counterpoint-retrieval-diagnostic.py`，在当前代码和 151 号原始资料上复现选段范围、风险句范围及覆盖状态。仅使用已保存资料和本地确定性代码，不调用模型或网络；样本、问题和预期材料均已知，不能作为独立质量评估。

试验性地对包含转折词的第二段提高排名，曾使风险句进入选段，但有限输入预算中的主要段落同时缩短，导致关键的 9.9% 数值不再进入模型输入。该试验未部署、未调用模型，不改变原来的评分。后续选段设计需要同时检查主要问题和风险材料的覆盖，并明确预算不足时的缺口；不能用风险词命中代替反方的相关性或语义支持验证。
