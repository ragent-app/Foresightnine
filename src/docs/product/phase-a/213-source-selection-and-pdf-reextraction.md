# 每次研究选择来源与 PDF 重新提取

研究工作区现在允许勾选本次要使用的已关联资料。未显式选择时沿用原来的全部来源；明确选择空列表时不将已有来源送入模型。服务端限制选择范围并核对账户归属，记录本次选择、来源哈希、权限和预算，幂等重放仍返回原运行；历史版本、已有引文和未选资料均保留。选择仅影响下次运行，不改变来源本身的授权。新旧提取结果可同时保留，但用户应避免把同一原文件当成独立来源。

对保存了原始文件的 PDF，用户可以在工作区选择另一种文字顺序，服务端基于同一原文件创建新的来源，并继承原有保存、展示、模型输入和导出权限、声明时间与模拟标记。新来源记录原来源标识、原 PDF 哈希和所选顺序；原文件与历史版本不变。工作区成功添加后将原提取排除在下一次运行之外，选择新提取。该操作不会自动修改用户已确认的结论或声称重新提取准确。

本记录最初实现仅能在已收到来源标识后安全重试；后续对提取响应丢失的幂等恢复已在 [216 号记录](216-reextraction-idempotency.md)中补充。新来源和旧来源均是同一原始资料的不同文本表达，不是独立证据。

验证使用模型替身，没有调用真实模型：API 测试覆盖默认与空选择、选中资料进入模型及运行快照、跨账户与不属于主题的来源拒绝、重复标识拒绝、幂等重放、原文与权限继承及 PDF 哈希异常。临时 PostgreSQL 跨进程重启检查保留了两种提取、来源关系、所选输入和幂等结果。Web 类型检查、291 项测试、生产构建及生成契约检查通过；构建仍提示主包超过 500 kB。

本地页面使用真实本地 API、保存的官方 PDF 和模型替身检查桌面及手机流程，验证自动选择新提取、下次运行只发送新来源、旧来源保留，以及模拟添加冲突后重试不重复创建。Browser 插件不可用，使用 Playwright；首次界面检查误用精确文本定位失败，调整定位后通过；故障注入产生的 409 控制台消息属于预期。临时服务与数据库已清理。以上验证不证明生成研究的语义质量，也不改变既有真实模型实验结果。
