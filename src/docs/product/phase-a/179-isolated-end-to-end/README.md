# 逐条复查的完整研究诊断：调用前登记

以 161 号已用于开发的 BEA 2022 年 7 月原始公告和既定消费支出问题，从研究 API 开始进行一次实际模型运行，检查生成结果、引用位置、反方、逐条复查覆盖、运行预算和保存的检查点。原始 PDF、问题、提示与脚本在调用前按哈希固定，来源与使用说明见 161 号；不用 FRED。模型输出、结果及每次提供商响应分开保留。该题和参考答案均已见，非盲、非独立测试，不是正式阶段验收。

使用 `glm-5.3-flash` 和清单中的固定生成参数，输入上限 6000、输出上限 4000，最多五次调用（首次生成及最多四次逐条复查）、总预算 20000 Token、任务 120 秒、单次 60 秒；不搜索、不重试未知调用。预算不足时允许部分完成并记录遗漏和原因。美元费用、历史部分用量和供应商内部版本未知；此前已知累计 199741 Token。

沿用 161 号的有限机械评分，不把数值出现或模型复查等同语义支持。另记录复查逐项判断、遗漏和反方，核对是否覆盖各条主张的所有实质部分；若未完成或无结果，按实际状态记录。相对 168 号批量复查记录，代码和生成输出均可能变化，不能将结果差异归因于批次模式，也不在运行后改变评分或重跑。

## 结果

操作确定完成，研究标为部分完成。首次生成 2866 Token，两次逐条复查分别为 414 和 684 Token，共 3964；已知累计 203705 Token，另有历史未知用量及未知美元费用。四项指定数字及商品和服务关键词出现在主张与引用中，所有保留引文均可定位，但只能说明有限机械信号满足。

四条主张中只有两条进入复查：首条遗漏了名义支出百分比的对应引文，反方有待核对的数值依据，系统因证据缺口没有送审。其余两条获得模型 `supports`。其中一条同时讨论名义支出变化、价格下降及实际支出增长；所附引文包含价格变化和实际增长，也解释“现价”等于“名义”，但没有引用名义支出变化本身。该条的 `supports` 因此是语义误判，表明相同百分比出现在不同指标的引文中仍可能掩盖证据缺口。反方也主要澄清名义与实际口径，未充分展开与原结论对立的经济证据。

研究虽如实标为部分完成，单条模型复查仍不能独立证明支持关系；该结果不能支持 B02、B04 或 B09 通过。运行前固定的评分和模型输出保留原状，后续修复不得追改本次结果。
