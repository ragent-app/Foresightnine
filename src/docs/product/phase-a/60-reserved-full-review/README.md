# 新资料首次研究与模型复查：调用前登记

本次固定此前未用于本项目模型调试的三份材料和任务：Cisco FY2024/FY2023 收入及同比、BEA 2023 年第一季度 GDP 第三次与第二次估计、美联储 2019 年 7 月声明中的两名反对票委员及其政策偏好。来源为 [SEC 10-K](https://www.sec.gov/Archives/edgar/data/858877/000085887724000017/csco-20240727.htm)、[BEA 公告](https://www.bea.gov/sites/default/files/2023-06/gdp1q23_3rd.pdf)和[美联储声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20190731a1.pdf)。SEC 官方索引记载申报日期为 2024-09-05；由于接收时间与首次公开时点并不等同，公司资料的精确公开时间留空，不把当前副本哈希当作历史时点证明。相关来源使用依据和限制见[来源矩阵](../03-source-inventory.md)。

公司任务使用 SEC HTML 的完整本地正文提取，表格分隔符和合并标记由提取器生成；保留压缩原 HTML 与提取输入，不把它算作原始 PDF 阅读或联网发现测试。直接获取 SEC 文件时使用了示例联系地址，不能视为满足生产程序化访问的真实联系方式要求；不再进行 SEC 请求。BEA 和美联储任务使用原始 PDF。最初考察的 2021 年 BEA 文件在本机提取时存在严重粘连，调用前改选可提取的 2023 年文件；没有对前者调用模型。

[清单](manifest.json)在调用前固定实现、三份材料、来源 ID、问题、参考、评分程序、模型和参数。每题允许一次研究生成和最多一次模型复查，单题最多两次调用、10000 Token、120 秒；三题合计最多六次和 30000 Token。无搜索、无外部调用重试；运行状态或用量不明、超限时停止剩余任务。美元费用未知。复查会受实际首次用量和预算限制，无法进行或未覆盖也如实记录。

预登记的狭窄机械阈值为三题全部满足[评分脚本](score.py)，包括预期事实与定位、适用计算或投票人、引用完整、两次调用、模型复查覆盖全部结论并认为支持及预算。脚本使用调用前固定的[等值匹配规则](matching.py)，并将已知引文、单位及上下文提示视为缺口。通过只表明这些机械条件满足，模型复查本身不构成独立证明；脚本不能完整判断每条结论的语义、反方充分性、来源历史可得性或总体任务质量。任何失败与不确定项均保留，不事后修改评分规则再计为同一次测试。

这三份资料与任务没有用于此前本项目的模型调试，但制定者知道题目和参考，非盲，且没有独立人工复核；用户要求跳过人工验收，不等待人工。三题规模有限，模型训练资料和供应商模型版本不可锁定，即使三题通过也不能单独证明阶段 B 所有验收条件。
