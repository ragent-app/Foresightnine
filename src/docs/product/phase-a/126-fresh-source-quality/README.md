# 新来源的宏观与政策固定检查

调用前登记：固定两项此前未在项目阶段 A/B 开发记录中检出的来源和任务，准备者已阅读题目、资料和参考，因此本检查非盲，不是独立人工验收，也不能单独证明阶段 B 整体质量。

- [BEA 2023 年四季度第三次估计原始 PDF](https://www.bea.gov/sites/default/files/2024-03/gdp4q23-3rd.pdf)，要求对比第三次与第二次实际 GDP 年化增速，并指出上修及抵消因素。参考为 3.4%、3.2%，消费及非住宅固定投资上修，部分被私人存货投资下修抵消；[公告原文](https://www.bea.gov/news/2024/gross-domestic-product-fourth-quarter-and-year-2023-third-estimate-gdp-industry-and)可检查这些表述。
- [美联储 2021 年 7 月 28 日声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20210728a.htm)的 HTML 提取文本，要求目标利率区间、每月国债及机构抵押贷款支持证券购买额，以及声明中的风险或尚未恢复领域。参考为 0–0.25%、至少每月 800 亿及 400 亿美元，并关注病毒或未完全恢复的部门。只保存文字提取，不保存网站标识图像。

[BEA 使用说明](https://www.bea.gov/help/faq/147)称除另有说明外其网站资料属于公共领域；[美联储网站声明](https://www.federalreserve.gov/disclaimer.htm)对资料使用及标识等有相关规定。分别标注来源；不使用 FRED、私人资料或 SEC 程序接口。快照为当前获取，不证明历史字节从未修订。
