# 新来源的宏观与政策固定检查

调用前登记：固定两项此前未在项目阶段 A/B 开发记录中检出的来源和任务，准备者已阅读题目、资料和参考，因此本检查非盲，不是独立人工验收，也不能单独证明阶段 B 整体质量。

- [BEA 2023 年四季度第三次估计原始 PDF](https://www.bea.gov/sites/default/files/2024-03/gdp4q23-3rd.pdf)，要求对比第三次与第二次实际 GDP 年化增速，并指出上修及抵消因素。参考为 3.4%、3.2%，消费及非住宅固定投资上修，部分被私人存货投资下修抵消；[公告原文](https://www.bea.gov/news/2024/gross-domestic-product-fourth-quarter-and-year-2023-third-estimate-gdp-industry-and)可检查这些表述。
- [美联储 2021 年 7 月 28 日声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20210728a.htm)的 HTML 提取文本，要求目标利率区间、每月国债及机构抵押贷款支持证券购买额，以及声明中的风险或尚未恢复领域。参考为 0–0.25%、至少每月 800 亿及 400 亿美元，并关注病毒或未完全恢复的部门。只保存文字提取，不保存网站标识图像。

[BEA 使用说明](https://www.bea.gov/help/faq/147)称除另有说明外其网站资料属于公共领域；[美联储网站声明](https://www.federalreserve.gov/disclaimer.htm)对资料使用及标识等有相关规定。分别标注来源；不使用 FRED、私人资料或 SEC 程序接口。快照为当前获取，不证明历史字节从未修订。

调用前冻结题目、文件和提取文本哈希、来源及声明时间、选段、提示词、模型与参数、评分器和代码提交。每题最多一次模型调用、10000 Token、120 秒，最多两次调用和 20000 Token；不搜索、不二次复查、不重试外部调用；终态或用量不明则停止下一题。美元费用未知；此前已知累计 134408 Token，另有历史未知用量。模型内部版本无法锁定。

预登记机械检查要求关键数值、单位及因素在模型文字和可定位引文中出现，风险或抵消因素出现在反方，所有保留结论引用可定位，并满足调用预算及提示/来源哈希。研究标为部分完成会单独记录，不自动当成通过正式验收。评分不能可靠判断所有主体、数值角色、方向或推论；构造测试明确显示把两次 GDP 数值角色颠倒仍可能机械通过，因此每项机械通过也不是语义通过，不外推总体能力或更改历史评分。输入、原始响应、运行状态和评分全部保留。

## 结果

两次操作均有确定终态，各调用模型一次，分别报告 1309、1356 Token，合计 2665；已知累计 137073 Token，另有历史未知用量及未知美元费用。两项研究均为 partial，预登记机械检查均未通过；预算、来源和提示哈希检查均通过。原始结果和评分不改写。

GDP 题给出并引用 3.4% 和 3.2%，但截取的原始 PDF 范围在第二次估计的数值后结束，未包含紧邻其后的上修及抵消因素。模型据所见片段报告缺失，不能据此认为完整公告没有这些内容。政策题选中了利率区间及资产购买段的结尾，却遗漏中间的具体购买数额和风险段；模型在声称无法确认的同时写入未由引用支持的 800 亿与 400 亿美元，不能将其当作已核验事实。两项所谓反方主要是摘录缺口而非实质反证。

本次暴露资料选择和未经引用的数字问题；候选资料与题目此后若用于修复，就不再是未用于调试的材料。机械规则本身存在已登记的方向和语义盲点，不能从分数外推整体质量，也不能用于宣布阶段 B 已通过。
