# 日期引用缺口的来源线索

292 号政策研究的目标区间结论包含会议日期，但其引用只覆盖决定本身。现对带有日期缺口的结论，在其已引用的同一来源、实际发送给模型的摘录范围内，有界查找包含相同完整日期的原文行，提供可定位的候选引文。来源须允许模型使用及展示，原有引用和候选位置须可唯一定位；不搜索未分析的内容，不自动把候选附加到结论，也不清除日期警示。

日期相同不证明日期含义相同：发布时间、会议日期、财务期间及修订日期可能不同。工作区将来源摘录线索与额外模型响应线索区分，并提示核查含义。保存版本时仅在来源哈希不变、仍有使用及展示权限、符合时间条件且候选仍相关时重新生成线索。

对 292 政策结果[离线重放](replay.json)，找到包含 2025-07-30 的发布行；该行可以帮助查找，不能单独证明主张中的会议日期。原始日期警示和引用保持不变，历史运行和评分不变；没有新模型调用。模拟 API 覆盖生成和保存后的保留，单元测试覆盖权限、未分析范围及歧义位置，Web 类型检查通过。该能力不证明引用语义或阶段 B 质量验收通过。
