# 财报与原始宏观材料候选检查

在模型调用前固定当前实现提交、两项输入和来源哈希、参考值、评分、运行脚本与预算。每题最多一次模型调用和 10000 Token、120 秒；总共最多两次，供应商请求超时 60 秒，不做外部调用重试或额外检索。模型参数使用当前 GLM Coding 配置（`glm-5.3-flash`，`max_tokens=4000`、`thinking=enabled`、`reasoning_effort=low`、`do_sample=false`、JSON 输出）；模型服务内部版本和美元费用未知。如运行状态不明则停止后续任务。

- C24：根据 [Costco 2024 年 SEC 10-K](https://www.sec.gov/Archives/edgar/data/909832/000090983224000049/cost-20240901.htm) 整理的 2023/2024 总收入和财年周数，要求收入增长计算及 52/53 周可比性说明。输入是衍生事实，不是完整申报文件。SEC 公共申报复用及第三方例外的依据见来源矩阵。
- G24：本地保存的 [BEA 2024 年四季度及全年 GDP 初值 PDF](https://www.bea.gov/sites/default/files/2025-01/gdp4q24-adv.pdf)，要求区分全年增速与季度环比年化增速。原始 PDF 和提取文本分别锁定哈希；当前副本不能证明其历史字节不变。资料用于模型输入的条件与例外见来源矩阵。

参考值、机械规则和预算见 `manifest.json`、`references.json` 与 `score.py`。每题分别报告，不把衍生资料和原始文档的结果混为同一能力。所有所需事实、定位、口径、计算或财年周数比较、引文和预算检查均通过才称该题机械通过；缺失或不确定按失败。此检查不能验证全部自然语言语义及资料历史不变性，也不评估自主寻找来源。

题目及参考值对开发者可见，且任务类型与先前实验相关；新来源此前未作为模型输入，但它们不是盲测、没有独立人工复核或真实人工计时。该检查不取代 A4 的正式独立测试和总体质量门槛。保留原始输出和评分，不根据此集结果重新调参后重算。

预登记结果：C24 的两项收入、5.02% 确定性计算及有引用的 52/53 周说明均满足对应机械项，但公式中的“× 100%”被评分扫描和产品差异检测当成待检查百分比，因此原机械成绩为失败。该 100% 在此处是公式系数，不是模型宣称的增长率；此外，首条主张里的周数并未直接引用周数来源，后续反方才引用该来源，不能仅凭定位断言逐项语义支持。G24 两项增速、期间、单位和引文定位满足机械规则；原始资料仅有两个片段送入模型，整体仍标为部分完成，且不能据此证明全文已检查或语义已独立核验。两次调用分别报告 1232 和 1313 Token，美元费用未知。

后续修正只识别数字除法表达式后直接乘以 100% 的明确公式系数；普通陈述的 100% 和等号后的数值仍参与差异检查。对 C24 已保存输出的离线检查不再产生该条误报，见 `C24-post-fix-check.json`。原始结果与评分保持不变，不视为 C24 通过，也不代表已进行独立模型复测。
