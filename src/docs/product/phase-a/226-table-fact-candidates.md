# HTML 表格引用候选与计算保护

224 号试验中，模型输出的收入事实引文省略了程序生成的表格标记，或以省略号连接了表头与数值行。系统现在可在有限条件下恢复唯一定位的原始完整表格行，保留为待核查事实；带省略号的引用必须每个片段唯一、顺序正确且处于同一个已分析片段。主张中满足同样条件的表格片段作为独立引文保存，主张状态仍为不完整。模型给出的值必须出现在原始行的实际内容中，生成的跨列标记中的数字不能当作事实。

恢复不验证公司、币种、表头归属、期间或列对齐。此类事实被明确标记 `table_markup_expanded` 和 `table_alignment_unverified`，不能用于自动计算；手工计算接口及已保存计算的输入状态也排除它们。仅修改其他事实字段不能移除恢复标记；用户替换引用后仍按既有来源检查处理。原文和用户版本不被覆盖。

使用 224 号原模型输出和材料进行无模型离线回放：两个收入候选事实及一条主张和一条反方被保留，主张仍为不完整，自动计算仍未产生；未改变 224 原始结果或评分。该材料此前已用于开发，不是独立测试，不能据此宣称语义或阶段 B 质量验收通过。

研究分析、确定性计算及相关研究运行测试通过；新增检查覆盖原始行定位、歧义、倒序、伪造片段、跨列标记数字、拒绝计算与编辑后保护。完整工程回归仍须在后续阶段出口重新运行。
