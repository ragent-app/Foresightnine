# 325：跨检查点的结论身份

一次研究可能在生成、补充或复查期间保存多个检查点。先前模型生成的内存结果不携带上一个检查点由服务端分配的结论 ID，因而即使结论完全没有改变，也可能在下一版本获得新 ID，影响按结论追溯子问题、反方与证据。

现在仅对服务端生成的版本，在新旧版本中按结论文本、角色和引文进行精确匹配；同一内容在两侧均唯一且旧 ID 未被占用时，沿用该 ID。重复或不明确的条目、修改过的文字或引文仍创建新 ID，不推断语义等价，也不改变用户编辑版本已有的标识处理。原有链接仍需按当前版本重新规范化，ID 沿用不证明结论正确或证据支持。

历史版本不回写。该变更尚未经过测试或模型实验，用户要求暂停测试，阶段 B 的完成和质量状态不变。
