# 其他研究条目中的相同数值

205 号实验中，一条结论已引用公司表头与数字，另一条同来源结论需要同一组百分比，但只引用了重复出现的假设说明。现在除了原有美元金额，系统也可在同一已引用来源的其他研究条目中查找与未覆盖百分比数值相同、可唯一定位的原文，作为用户可选择的候选引文。目标原引文存在多个已验证的匹配位置时，也可按来源查找候选；候选自身仍须唯一定位，未授权、模拟、截断及含糊的候选不会使用。

数值匹配不确认单位、公司、期间、表格列对齐或语义支持。系统不会自动附加候选，也不因候选出现而清除缺口或改变研究状态；页面明确提示核对，用户自行选择后保存新版本，仍标为未经独立核验。候选与历史版本可随文本及结构化记录导出。

对 205 号保存结果离线检查，包含公司表头和三项数值的原文被列为候选，另一个相同数值的汇总表候选也被标为待核查；该检查没有调用模型或改变原实验成绩。API 验证覆盖多数字合并、目标位置歧义、原文不匹配、重复候选和授权限制，以及用户替换引文后的版本与状态；Web 类型及文本导出测试通过。首次自动测试发现句末小数后紧跟句号时未匹配，修正后相关证据与复查测试及新增 API 场景通过。
