# 结构化资料的父级口径边界

年度 JSON 摘录原先扫描所有叶对象，可能将嵌套分组中的记录与根节点的币种、指标或发行人配对，即使中间分组声明了不同口径。现在该专门摘录路径只接受根对象 `records` 数组中的扁平记录，并核对原文叶对象与解析后数组逐项一致；不满足时回退通用摘录，不把回退视为口径已核验。选择方法版本为 `v26`。

覆盖了父分组币种不同、额外嵌套分组以及记录内嵌套维度等情况。已保存的微软样本仍保留相同的三个片段（51–200、646–777、887–1018）。相关研究分析和运行测试 126 项通过；未重新调用模型，旧评估结果不变。结构符合条件仍不证明发行人、会计口径或数据准确，通用摘录和模型仍需复核。
