# 百分比结论的完成状态

此前已有 `uncited_percentages` 提示，但研究运行状态没有使用该提示，即使引文缺少结论中的百分比、模型复查又错误给出 supports，也可能将研究标为完成。现在发现此类百分比时保留研究、事实和计算，并标为部分完成，同时明确提示该值也可能来自计算，需要核查计算及来源。候选事实不是语义证明，模型复查也不能覆盖这个缺口。

该检查只覆盖受支持的百分比写法，数字匹配不证明单位、期间、对象或含义一致。当前尚无可靠的主张到计算的明确关联，因此即使百分比确实由已有计算得出，也会保守地显示部分完成；原始计算仍可查看。这是限制而非表示计算错误。已有历史版本不被改写，用户编辑后的候选提示按现有逻辑重新计算。
