# 来源内 XBRL 核对：币种、分类和表格行扩展

2026-11-13。在原有保存原件、表格位置和年度标签一致性检查的基础上，支持以三字母币种代码匹配其他币种，以及 IFRS 全集分类命名空间；同一表格行的原样名称也可用于更多项目。既有明确项目的名称与分类对应检查仍然有效，不能借通用行匹配绕过。IFRS 命名空间格式参考 [IFRS Foundation 数字分类指南](https://www.ifrs.org/content/dam/ifrs/standards/taxonomy/general-resources/ifrs-taxonomy-regulators-guide.pdf)。

这是一种来源内一致性检查：它记录原件同一单元格的行名、数值、标签、年度、实体和币种，并不验证标签与行名的会计语义、文件真实性或来源独立性；生成的事实仍为未独立核验。三字母币种仅检查格式及与原件标签是否一致，不验证代码是否属于当前 ISO 货币清单。当前实体标识仍要求 SEC CIK；其他标识、发行人扩展分类、非年度期间、复杂维度、不同数字格式等可能无法核对，不能从此次扩展推断完整全球覆盖。

通过合成资料检查 IFRS/EUR 和其他项目，覆盖伪造分类命名空间、币种和倍率不一致，以及已知项目分类不匹配；既有 API 和计算回归另行运行。没有调用 LLM，也没有新增真实 IFRS 原件或跨领域独立质量评估。历史实验结果和阶段 B 的 B02、B04、B09 验收状态不变。
