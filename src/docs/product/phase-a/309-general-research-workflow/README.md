# 阶段 B：通用研究流程调整

现有研究路径有问题：选段和告警中积累了大量针对特定材料的启发式，真实资料上的未覆盖问题仍可能以不同措辞出现。已知样本可以用于定位缺陷，但针对单一题目增加匹配规则不能证明能力泛化，也不作为后续的主要开发方式。

本轮先调整模型输入契约：要求把证据不同的对象、期间、指标、比较和因果解释拆成分别可核查的主张；每项主张的全部实质内容都要有对应引用。要求反方明确指出其限制或反驳的解释，使用自身证据，并把未知和材料缺口放在限制中，而不是当作已证实的反方。补充反方时明确原结论可能不完整，不能把局部视图的缺漏说成完整研究的缺漏。

此调整沿用现有输出结构、授权来源、调用与预算控制及提示哈希记录，不修改已有模型结果。提示加长会占用输入预算，可能影响来源选段；具体效果和兼容性尚不清楚，不能当作已验证的质量提升。用户已要求暂停测试和模型调用，因此此轮没有执行测试或 LLM 实验。

后续实现应围绕可复用的证据和研究步骤，而不是扩展例句匹配：来源分段及覆盖、可核查的主张与证据关联、计算和事实的确定性校验、反方与冲突的语义审查、缺口与失败恢复。应保留可解释的现有保护，不能未经验证地把历史规则全部删掉；阶段收尾时再在固定的跨任务材料上集中检验这些机制，控制模型、输入、参数和预算，并如实记录不足。人工验收按用户要求跳过。
