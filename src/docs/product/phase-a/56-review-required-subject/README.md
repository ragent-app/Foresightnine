# 复查所需的原文主体上下文

可选模型复查现从已授权、可展示且非模拟的原文重新计算引文主体提示。若已识别引文省略句首指标，复查输入必须包含从该指标到完整引文的连续原文；如不能在调用预算内完整纳入，该结论记为未复查，不能用不含主体的片段获得模型“支持”判断。其余结论仍优先保留完整引文，再按剩余预算扩充上下文。原文坐标及所需上下文起点记录在复查片段中；外部文本仍是不可信数据，模型结果仍非独立核验。

[离线检查](inspection.txt)沿用第 50 次 BEA 已保存输出、同一系统提示和 1770 字节预算：旧方法复查了 3 条但错误推论的片段没有个人储蓄率主体；新方法复查 2 条并带上该主体，另外 2 条因预算省略。覆盖下降是该预算下的明确取舍，复查状态保持部分完成。这只验证输入和边界，不证明模型会正确判断或覆盖未识别的主体；未调用模型或改变历史评分。

复查、证据及运行 API 测试 57 项通过，覆盖精确引文、预算不足时省略、拒绝模拟资料及忽略调用方伪造的上下文提示；Web 类型检查通过。
