针对当前 master 实现进行工程回归，未调用真实模型。API 收集 772 项，常规运行通过 762 项，10 项因未配置临时 PostgreSQL、备份或 Redis 而跳过；随后分别运行这些服务集成检查：

- 临时 PostgreSQL 中的 8 项进程中断或重启检查通过，包括新增的来源引文修正、用户方向确认及计算跨进程持久化；确认所绑定的事实被修改后重新计算仍会拒绝。
- 独立临时数据库的备份与恢复演练通过，恢复后版本、账户隔离、研究运行幂等、方向确认和计算结果保留。仅演练临时实例，不能代表生产备份或第三方费用恢复。
