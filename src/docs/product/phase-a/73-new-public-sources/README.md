# 两份新公告的受控开发检查

调用前固定两份此前未在项目记录中检索到的官方 PDF：BEA《2023 年 2 月个人收入和支出》与美联储 2022 年 3 月 16 日声明。来源和参考分别为 [BEA 公告](https://www.bea.gov/news/2023/personal-income-and-outlays-february-2023) 与 [美联储声明](https://www.federalreserve.gov/newsevents/pressreleases/monetary20220316a.htm)。当前副本和哈希不能证明历史字节完全一致；资料使用依据参考阶段 A 来源矩阵。准备者已查看题目和参考，测试非盲、未经过独立人工复核，也不代表公司研究能力或阶段 B 正式验收。

调用前冻结材料、抽取文本、问题、实现、模型参数、脚本、机械评分与预算，见清单。每题至多两次模型调用（生成和可选的模型复查）、10,000 Token、120 秒；两题合计不超过四次、20,000 Token。关闭搜索与外部调用重试；终态或用量不明即停止后续调用。美元费用未知，不视为零。

评分程序只检查有限的数字和姓名、来源原文定位、复查覆盖、预算及既有警示；两题均满足才称该机械检查通过。数字和原文同时出现不证明其语义关系；模型复查也不是独立证据。结果、错误及未完成项均原样保存，不依据本次结果事后改写规则或历史成绩。

## 结果

两项操作均有确定终态且各进行了两次模型调用；分别报告 1,817 和 2,210 Token，合计 4,027。加此前已知累计 106,665 为 110,692 Token；历史另有未知用量，美元费用未知。冻结机械结果 0/2，研究均为部分完成。

- PCE 的两条结论分别将 0.3% 环比和 5.0% 同比正确对应到两条原文，模型复查认为支持，但这不是独立验证。反方错误地表示核心 PCE 的 0.3% 不适用于总指数，而该公告中两者同为 0.3%；其引文也未完整涵盖数值事实，系统因此未将该反方送入复查并提示缺口。
- FOMC 的反对者和偏好得到原文定位，但提供给模型的片段遗漏多数派决定的目标区间；模型在反方中错误推断该区间，复查认为矛盾。事后离线检查发现先前投票片段规则只匹配复数 `were`，不匹配该公告的单数 `was`。该观察可用于后续修复，不能修改本次冻结结果或将两题作为独立测试。

任务、响应、评分和缺口均保留；两项结果不能证明引文语义普遍可靠，也不能认定 B02、B04 或 B09 通过。
