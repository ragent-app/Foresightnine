# 反方相关性提示对照：运行前登记

292 政策样本的反方补充以“先前结论与原文一致”开头，主要重复已有信息。此次复用该样本的已保存首次生成、同一问题、来源、选段、系统提示、模型参数和预算，只替换补充提示中的 `counterpoint_request`：要求有来源的相关挑战或限制，不把同意原观点或缺失事实当作反方，材料不足时留空。其他字段逐项相同；生成阶段不重新调用模型。题目与材料已用于开发，不是盲测或独立验收；调用时间、模型内部版本及随机性可能变化。

最多一次真实补充调用、10,000 Token、60 秒，不搜索、不复查、不重试。调用前已知累计 334,000 Token，其他历史用量及美元费用未知；终态或用量不明时停止。检查预先固定：输出是否可解析、反方及有效引用数量、既有警示、是否实质挑战或限定已有结论、引用是否支持论述、是否推断反对者动机或将摘录缺口扩大为全文缺口。无可核查反方时应诚实留空而非编造。仅在候选给出有引用的相关挑战或限制、没有明显新增事实错误且不削弱来源边界时，才考虑引入产品；一次非盲对照不能证明泛化。原输出、预算及对照不覆盖。

## 结果

候选补充调用完成，供应商报告 **1,796 Token**，本次新增后已知累计 **335,796 Token**；更早用量和美元费用仍未知。对照保留一条有定位引用的补充反方，但该条明确以同意原结论开头并触发相关性警示；候选将 `counterarguments` 留空，未给出带引用的实质挑战或限制。候选还声称所给来源没有反方或限定证据，而材料明确记录两位委员倾向降息；部分摘录也不足以作全文缺失断言。这些额外文字按模型报告处理，不能当作已核实事实。

候选未满足预先登记的采用条件，**不修改产品提示**。留空避免了把重复结论冒充反方，但未解决寻找相关反方的问题。只进行了一次非盲对照，不能证明该提示普遍无效；原始输出、[离线检查](inspection.json)与对照均保留，阶段 B 质量验收状态不变。

补充限制：对照提示包含“先前结论可能被截断”，候选替换整个字段时遗漏了这一提示，而本次先前结论确实被截断。因此虽然程序只变更了一个字段，变化同时影响了相关性要求与截断披露，不能将结果差异归因于相关性措辞；也不满足“不削弱来源边界”的采用条件。后续若再对照，应保留截断提示。
