# 百分比严格上限与精确值

183 号 PCE 研究正确引用“less than 0.1 percent”，却因同一来源中服务支出恰好为精确的 0.1% 而收到未引用事实提示。现在，对主张中只作为严格上限出现一次的十进制百分比，不再把另一个数值相等的精确事实自动推荐为相同事实。若同一数字也以精确值出现、存在分数或其他歧义，保留原有保守提示。

同时检查英语 `less than`、`below`、`under`、`<` 及对应中文严格上限：如果主张含此类上限，而附带引文中没有相同阈值的严格上限，则提示核对限定词、将研究标为部分完成并不对该主张自动生成支持性复查。附近出现 `not`、`no`、`不` 等否定时不将其识别为严格上限；这只是保守处理，不是完整否定解析。上限并非精确数值；相同阈值也不能证明两者属于同一指标。其他界限、否定、单位、对象和方向仍需核对，本规则不提供完整语义判断。

以 183 号已保存结果离线重放，原有无关服务数据的 `uncited_fact_values` 提示消失，该条可进入复查；这只是候选状态，并非证明它已获得复查或语义通过。原研究结果和事先评分不变，本次没有新的模型调用。自动测试覆盖上限引文缺失、同值精确事实、混合精确与上限、等价限定词及模型复查入口。
