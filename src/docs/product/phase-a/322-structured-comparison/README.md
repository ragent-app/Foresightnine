# 结构化观察值比较视图

研究工作区对具有明确结构化实体和指标标识的已保存观察值提供比较表：按记录的同一指标、期间、单位和币种分组，对象与期间分页；同一单元格中不同申报或修订不合并，分别保留申报日期、编号和来源上下文。没有记录显示“未记录”，不能视为零或不存在。用户有未保存的数值编辑时隐藏此已保存版本视图。

该视图使用已有来源权限与原文上下文接口，不发起新的数据或模型调用，不计算增长率或推定不同实体的口径可比。只有支持的结构化适配器可产生对应上下文；目前不是所有市场或资料都有结构化覆盖。导出继续使用权限检查后的完整研究记录，未新增独立表格导出接口。

遵照用户要求，本次未执行测试、浏览器检查或模型实验；显示、分页、权限及跨任务效果尚未验证，不代表阶段 B 完成。
