# 单来源短引用标识：配对复核预登记

对照 146 号贸易公告和压力测试的固定资料、来源 ID、问题、模型、生成参数、系统提示、权限、输入上限 3000、60 秒超时与原机械评分。唯一主动变化为 v33 到 v34 的单来源短模型引用标识及其节省空间后的相邻原文扩展；实际模型提示中的 ID 和片段随之变化，服务端保存时恢复真实 ID。固定 146 号结果与评分哈希，不重跑旧条件。

每题最多一次直接模型调用，输入与输出预留 7000 Token、60 秒；合计最多两次及 20000 Token。不搜索、不做二次复查、不重试，终态或用量不明即停止。已知历史累计 163901 Token，另有历史未知用量；美元费用未知。保留输出、引用定位、模型短标识与真实来源映射、片段及用量。

题目与参考已用于开发，每种条件仅一次且非盲，供应商内部模型版本及随机性无法锁定；机械信号不足以证明语义支持或因果泛化，直接调用也不验证完整 API 及账单流程。不得据此声称 B02、B04、B09 已通过。

## 结果

两次调用均有确定终态，分别报告 1966 和 1456 Token，共 3422；已知累计 167323 Token，另有历史未知用量及未知美元费用。两题所有保留引文可定位并使用真实来源 ID；模型短标识到真实 ID 的映射保存在各次片段记录中。原评分器下，压力测试题的实际与最低比率、情景及个体最低水平信号均出现，具体风险反方信号仍未出现；贸易题的四项数值与商品/服务信号出现，但反方关键词信号未满足。146 号基线结果和评分保持不变。

压力测试题这次引用了实际 12.4% 和情景最低 9.9%，但还写出 2025:Q1，所附首条引文在 projection 处截断，没有覆盖该日期；反方提到约 2.5 个百分点及更严重情景，需分别核对计算与假设。贸易题反方比较逆差和出口两个百分比，却只引用出口百分比，并进一步推断整体贸易活动扩大，不能单凭该引文证明。1 月数值短引文也仍需检查此前的指标主体。

短标识与额外上下文没有导致本次引文来源归属丢失，但模型仍会省略依据或作未经充分支持的推论；单次非盲对照和机械信号不能证明因果、泛化或阶段 B 验收通过。
