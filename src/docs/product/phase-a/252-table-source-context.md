# HTML 表格的相邻提取文本

原有引文上下文只显示前后各 300 字符，较宽财报表格的日期、年度分组和单位可能被截断。HTML 来源的单行表格引文现在可展开查看此前最多 15 行及目标行，最多约 10,000 字符；可附带一行短的相邻说明。超过限制时提示前面还有未显示内容。结果保留原始提取文本的精确字符位置，不重组列，也不把内容作为额外引文自动保存。

接口继续执行账户所有权及展示权限检查，按需返回；前端使用文本渲染并明确说明提取文本、表头含义与列对齐尚未核验。它不能识别任意 HTML 表格的真实边界或保证上方文本属于同一张表；查看原始文件仍有必要。PDF 上下文不受本次修改影响。

针对性测试：来源 API 测试 13 项、Web 类型检查及上下文组件 3 项通过，覆盖账户隔离、精确位置、截断、跨段落处理及不执行 HTML 文本。对既有 Cisco 年报原件的本地提取检查中，53,803 对应的展开文本包含年度表头和单位说明，并与保存文本的对应范围完全一致。无网络请求及模型调用；该旧样本不是独立验收，也不证明财报引用或结论语义正确。阶段 B 的 B02、B04、B09 仍未通过完整质量验收。
