# 中英文分项方向复核

在既有贸易差额方向提示基础上，增加有限的中英文表达，并增加营业利润方向检查：当同一准确定位引文明确表明收入和营业费用均下降，而结论说两项变化都会提高营业利润时，提示按收入减相关成本费用的关系检查方向。其他因素不变时，收入下降的贡献方向是降低营业利润，费用下降的贡献方向相反。

提示仅适用于规则识别的句式、同一引文内的两项变化和允许展示的非模拟来源；它不是对企业会计口径、币种、期间、因果或所有结论的验证。否定句和正确区分方向的结论不应触发；表达、语言或分散引文不同仍可能漏报。贸易及营业利润提示在界面分别说明，历史版本的旧提示继续可读；模型复查会跳过存在提示的结论，方法标识更新为 v19。

自动测试覆盖中英文和繁简中文示例、常见语序、否定句、正确方向、权限和原文定位；相关 API 测试及前端类型检查通过。本次没有模型调用，不证明对其他任务的泛化或阶段 B 质量验收通过。
