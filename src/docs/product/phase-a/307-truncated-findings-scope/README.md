# 反方补充对原结论范围的提示

306 号对照的补充模型只看到前两条初始结论，却声称初始结论遗漏反对者的偏好；完整初始结果第三条已经包含该信息。候选提示未被采纳。

现在若补充调用只接收到部分初始结论，其保留的反方带有范围标记；对于有限中英文措辞中声称原结论遗漏信息的条目，系统给出待核查提示，不将该条视为已满足反方要求，也不允许常规引文复查消除此范围问题。网页和文本导出展示提示，保存研究版本时重新计算提示。用户编辑后仍应核对完整研究。

离线重放读取 306 号已保存候选并按该实验的已知截断情况附上标记，命中提示；没有新模型调用，也没有修改历史实验结果。API 针对性测试覆盖提示的重新计算、复核排除、补充调用、部分完成状态和版本保存；Web 类型检查通过。

这只是有限词法提示：其他表达可能漏检，也可能出现误报。没有命中不意味着反方正确，不能代替对完整原结论和引用的语义核查；该修复不代表阶段 B 的真实资料质量或跨任务验收已通过。
