# PDF 读取方式的配对检查：调用前登记

使用 209 号已观察过的 BEA 2021 年 5 月原始 PDF 和同一道问题，比较 `reading` 与 `layout` 两种提取。两份来源由同一文件创建，题目、标题、授权、代码、模型、系统提示、生成参数和预算相同；两次运行都通过新增的来源选择功能仅选择对应提取。两种提取不仅空格不同，也可能改变段落或表格顺序，因此变化因素是**整个读取方式**，不是单独控制空格。模型供应商内部状态和随机性不能锁定，单次配对不能证明因果或泛化。

调用前固定 PDF、输入、参考、评分程序、提示哈希与代码。每种方式最多一次模型生成、10,000 Token、60 秒，任务上限 120 秒；总计最多两次、20,000 Token，不搜索、不复查、不重试不确定请求。用量或终态不明时停止后续调用；美元费用未知。分开保留输出与得分。

预设机械检查要求生成主张和可定位引文中均包含总额 2.9、商品及服务和增减词，全部保留主张有唯一完整引用，输入快照仅含所选来源且调用受预算约束。关键词和数字共现不证明方向归属、单位或语义支持，需要另行检查；任何失败保留、不事后改分。此题已用于开发，本次不是独立测试，不证明阶段 B 全部通过。

## 结果

两次各调用一次，`reading` 报告 1,928 Token，`layout` 报告 2,298 Token；本次合计 4,226，已知累计 240,899 Token，另有历史未知用量及未知美元费用。两次快照都只包含所选来源，运行均为部分完成，预设机械条件均未通过。

`reading` 输出中关于商品和服务变化的引文不能定位，系统未保留对应主张，并提示文本可能缺少空格。`layout` 保留了可定位的服务增加、商品减少等引文，但总额 **29 亿美元**（2.9 billion）的原文没有进入选段，回答未给出所问总额，因此也未通过。另一条反方把价格指数与“消费量”作对比，而题目涉及当期美元支出；该措辞仍需核查，不能将可定位引文等同语义通过。

两次为已见单题的非盲配对，提取方式也改变选段数量及内容，供应商输出存在变化，不能外推其他文档或认定因果。原始响应和评分保留。
