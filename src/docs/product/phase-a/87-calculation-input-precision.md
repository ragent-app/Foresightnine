# 计算输入的来源精度

第 85 号中文统计资料检查中，模型用公告中显示的 29 和 317 计算比例，得到 9.15%；公告另给出 9.3%。两者可能涉及原始数值舍入或统计口径，不能仅凭显示值判断原因。计算器的输出舍入位数不表示输入的来源精度已经得到核实。

现在新计算结果记录 `input_precision_status: not_established`，与已有的输入未验证、输出舍入方式和位数分开。研究页面在计算区域说明已记录输入的来源精度及先前舍入尚未确认；完整 JSON 导出对新旧版本均附加相同说明，历史计算本身不被修改。该字段不表示输入一定经过舍入，也不推断误差区间或自动判定来源比例正确。

相关计算、研究运行、版本与契约测试 91 项通过，Web 类型及生成契约检查通过；本地测试账户和内存 API 的桌面、手机浏览器检查覆盖说明显示与完整导出。未新调用模型，原评估结果及成绩保持不变。
