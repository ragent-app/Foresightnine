# 历史研究的搜索日期提示

搜索服务提供的通常只是日期，服务端兼容旧契约时把它表示为当日 UTC 零点；这一转换不代表来源在零点公开。此前页面直接展示这个时间戳，容易误认为精确公开时间，创建前的搜索结果也没有结合用户的研究截止时间提示。

现在两处来源候选均只显示搜索服务日期，明确标记未经独立核实。历史研究中，日期早于截止日 UTC 时仍提示核查公开与修订历史；日期未知、无效或在截止日当天及之后时，不声称截止前可用。候选不会因此自动填入资料的公开时间，也不会自动成为证据；服务端原有历史搜索过滤和资料时间检查保持不变。搜索结果返回后若修改问题、范围、截止时间或范围搜索选择，旧候选会被清除；搜索期间禁用这些输入，避免将旧结果显示在新条件下。

Web 282 项测试通过，类型检查通过。首次类型检查发现可选属性与项目严格类型设置不兼容，修正后通过。本地内存服务、测试账户和搜索替身的桌面及手机浏览器检查覆盖更早、同日、未知日期、旧候选清除及不自动填写来源时间；没有真实搜索或模型调用。搜索日期和来源声明均不能证明历史版本或历史时点的真实可得性。
