# 复查覆盖和失败原因

可选模型复查的运行记录现在保存未纳入复查的原运行结论编号及原因，区分证据不满足输入条件、完整引文与必要主体上下文超过输入预算、调用次数、Token 或时间预算不足；调用失败的已选编号另行记录。生成检查点保留已选择及未纳入的编号，便于中断后判断当时的进度。编号仅解释原运行输入，不应映射到之后编辑或删除过结论的版本。

页面逐条提示没有已保存模型复查结论的项目；原始 Agent 版本可展示对应的预算或引文原因。结论编辑后旧的复查结果失效，页面不再把原编号原因套用到用户版本。历史版本不改写；“本次运行复查完成”仍不等于来源已独立验证。

复查和研究运行 API 测试 46 项与 Web 类型检查通过，覆盖部分复查、未覆盖原因、预算不足、模型复查失败以及生成检查点。Browser 插件不可用，使用本地模型替身与 Playwright 检查桌面、手机、部分覆盖、编辑和保存后的状态，无页面异常；没有真实模型调用。
