# 官方自动获取路径真实资料检查：调用前登记

使用此前已用于开发的 [BEA 2023 年 GDP 初值网页](https://www.bea.gov/news/2024/gross-domestic-product-fourth-quarter-and-year-2023-advance-estimate)，问题要求区分全年增长和第四季度折年增长。BEA 声明网站资料除另有说明外可使用，具体内容仍须核对；当前网页副本不能证明历史版本未改变。样本已被开发者和系统使用，不是独立测试、盲测或完整阶段 B 验收。

预先固定网页快照、原件与提取文本哈希、问题、系统提示、模型及生成参数。搜索由固定的测试候选替代，不调用外部搜索；实际运行最多一次官方网页请求，结果必须与固定快照和提取哈希一致，否则不调用模型。最多一次模型生成、10,000 Token，任务 120 秒、单次模型 60 秒、网页 15 秒；不请求复查、不重试，状态或用量不明即停止。模型美元费用未知，先前已知用量 268,091 Token，另有历史未知用量。因数据、题目及实现均不同于 238 号检查，不把结果差异当作单因素比较。

评分脚本在调用前固定：检查全文与可定位引文中是否各出现 2.5、3.3、2023 和第四季度，所有主张有完整定位的引文，无列出的已知警示或遗漏，并在预算内完成。该机械共现规则不能证明不同数值分别对应正确期间，也不能证明语义支持；结果须保留逐条原文及输出供检查。用户要求跳过人工验收，本次不要求用户参与，也不将其视为独立质量验收。
