# 批量与逐条复查：四项材料核验预登记

使用 161 号已作为开发资料的美联储 2022 年 6 月公告，人工构造四条此前未用于该复查配对的主张：两条有引用支持，两条混淆供需原因或决策机构与操作利率，不能由各自引文支持。原 PDF、文本哈希、引用定位、主张和判断规则在调用前固定；模型仅收到每项主张与其引用及受限上下文。资料和参考由开发者选择且已知，非盲、非独立测试，不等于 B 阶段验收。条款与来源信息沿用 161 号记录，不使用 FRED。

同一模型、系统提示、源码、材料和四项主张下先发送一批，再逐条发送；主动变量为批次隔离，与之耦合的上下文分配、局部编号、请求长度及调用顺序亦变化。批量须四项完整且编号有效，逐条须各项完整且编号有效。对于支持项，只有 `supports` 计作符合；对于不支持项，`uncertain`、`does_not_support` 或 `contradicts` 计作符合，`supports` 为误判。只报告各项与总数，不据小样本推断准确率或启用新默认。单条错误类型和实际模型输出原样保留。

最多五次调用，单次输入上限 6000、输出上限 4000，总预留不超过 50000 Token，每次 60 秒，不搜索、不重试；失败、用量未知或超额即停止。供应商实际内部模型版本及美元费用未知。此前报告累计 197246 Token，另有历史未知用量。预登记脚本和提示哈希写入 `manifest.json` 后提交，再执行一次，结果文件仅追加保存。

## 结果

五次调用均有确定结果，批量报告 920 Token，四次逐条分别报告 358、385、412 和 420 Token，合计 2495；已知累计 199741 Token，另有历史未知用量和未知美元费用。两种方式均在四个预设判断上符合有限检查：对两项有支持的主张给出 `supports`，对两项不支持的主张未给出 `supports`。其中最后一项批量为 `uncertain`、逐条为 `does_not_support`；两者都只符合预设的宽松拒绝条件，不能视为相同判断。

该测试用已见资料和人工构造的少量主张，未测试模型生成研究、资料发现或未提供引文的缺口；批量与逐条请求也存在长度、上下文及顺序差异。这不是独立评估，不证明逐条更可靠、泛化准确率或 B02/B04/B09 已通过，不改变产品默认模式。
