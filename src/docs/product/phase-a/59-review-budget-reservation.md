# 已报告用量与复查预算

此前，即使首次研究调用已返回有效 Token 用量，复查预算仍按首次调用上限加第二次调用上限计算。对于输入上限 3000、输出上限 4000 的提供方，默认 10000 Token 即使实际首次用量远低于 3000，也会被判定不足。

现在首次用量为非负整数时，使用提供方报告值，加上第二次调用的完整输入与输出上限，判断是否允许复查；用量缺失、负数或格式无效时视为未知，仍按首次调用上限保守预留。第二次调用仍先完整预留额度，合计超限、时间耗尽及费用未知的现有处理不变。实际用量和美元费用以提供方报告与可用计费信息为准，未知不记为零，无法保证提供方没有误报。

运行与复查 API 测试 53 项通过，覆盖已知用量、未知或无效用量、恰好达到额度、超额、失败与计费结算。Web 类型检查通过；Browser 插件不可用，使用本地模型替身和 Playwright 验证默认 10000 Token、提供方单次上限 7000、首次报告 1795 时完成两次调用，覆盖桌面和手机。此次未调用真实模型，历史评估成绩不变。
