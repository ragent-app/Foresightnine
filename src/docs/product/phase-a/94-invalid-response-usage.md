# 无效模型响应的用量记录

2026-11-12 的第 93 项模型调用返回无效结构化结果，运行此前统一把该类调用的用量记为未知，即使供应商返回的响应外层可能带有用量。现在仅在已收到大小受限的成功 HTTP 响应、且外层用量为非负整数时，把供应商报告的 Token 数附在安全错误上并用于研究运行记录和预算结算；无效内容仍被丢弃，不记录原始输出或异常原因链。来源无用量、类型无效、超大响应、超时或传输失败时，仍按未知用量结算已预留预算。复查调用同样处理。

用量由供应商报告，不等于已独立核对账单；美元成本仍为未知。此修改不能追溯恢复第 93 项已丢弃的响应或未知用量，不改变该次实验结论，也不进行重试。相关供应商和研究运行测试共 95 项通过。
