# 政策任务反方补充：运行前登记

用 272 号已保存的 FOMC 政策任务首次输出和同一原件，验证已有反方带证据警示时的补充步骤。首次生成离线重放，不重新调用供应商；保留其已引用但存在阈值和动机警示的原反方，再允许最多一次真实补充调用。固定当前提交、资料与选段、先前输出、模型及支持参数、系统和补充提示哈希。复查关闭、不搜索、不重新下载、不自动重试；最多两次逻辑调用，其中一次实际供应商调用，逻辑预算 20,000 Token、单次超时 60 秒、总计 120 秒。终态或用量不明即停止。

首次生成按其原报告用量注入运行账本以测试预算，该用量已包含在先前已知累计 **321,313 Token** 中，不重复累加；美元费用及更早历史用量未知。比较调用前检查点与最终结果，分别核查旧反方是否保留、补充引用是否可定位、论点与投票证据的关系、数字与动机是否受支持；机械评分不证明语义。任务与原件已用于开发，单次非盲回归不能说明质量泛化，也不是阶段 B 验收。

## 运行结果与离线修正

首次生成离线重放的账本用量为 1,862 Token；真实补充调用报告 **1,573 Token**，运行账本总计 3,435。重放部分已在历史累计中计算，本轮新增后已知累计 **322,886 Token**；更早未知用量及美元费用仍未知。原运行保留了带警示的旧反方和调用前检查点，但补充状态为失败，冻结机械评分未通过，研究仍为 `partial`。

失败原因是模型除请求的 `counterarguments` 和 `limitations` 外，还返回了一个 `answer` 字段；旧流程因整体格式不符拒绝了补充。后续仅提取并严格校验两个请求字段，丢弃其他字段并记录数量，不把额外答案并入研究。对已保存输出[离线重放](replay.json)后，丢弃一个额外字段，可定位一条政策反方；其中“政策取决于通胀”的条件关系未被所附引文明确说明，因此增加条件关系的既有因果核查提示。引文定位和提示都不证明反方含义正确，旧反方的数值和动机警示也仍存在。

API 模拟测试覆盖额外字段丢弃、无效引用、预算和结果数量边界；条件关系与模型复查提示测试、Web 类型检查通过。离线重放没有新模型调用，原始运行和评分不变。本次仅重放首次输出、真实调用补充步骤，不能作为独立质量验收或阶段 B 完成的依据。
