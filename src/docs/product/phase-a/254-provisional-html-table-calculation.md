# 基于原件表格列的暂定计算

研究生成时，若模型引文需要恢复表格标记，且保存的 HTML 原件、提取全文、唯一目标行和原始单元格可以对应，系统可检查数值单元格与明确的年度结束日期是否位于同列。支持年度日期与标签同行，或年度标签单独跨列并与季度列并存的两类严格结构；日期、数值或列不唯一、结构不受支持、来源无展示权限、超时及原件校验失败时不作判断。每次研究最多检查两个不同表格行，复用同一行的检查结果；检查等待受任务取消及时间预算控制。

结构和日期匹配时，可以按模型请求生成确定性计算候选，`input_status` 仍为 `unverifiable`，并提示该结果为暂定。列结构不证明指标、公司、货币、单位或含义正确；这类计算不会因为数值匹配而自动成为结论证据。日期冲突或未能确认结构时，恢复的表格数值仍不用于自动计算。用户修改事实后，旧结构检查结果被清除。文本导出包含检查提示。

离线重放 [224 号历史 Cisco 研究](224-html-company-pilot/README.md) 保存的模型输出及原件：两个数值与各自的年度日期在原 HTML 中结构对齐，确定性增长计算为 **−5.61%**；其输入状态仍为 `unverifiable`，币种与指标含义仍需核验。原研究结果和评分未修改，本次没有网络或模型调用；此已用于开发的样本不能作为独立验收，也不能证明主张和反方得到支持。

研究分析、计算与表格结构针对性测试通过，覆盖同列匹配、日期冲突、重复值、来源不可展示、缺原件、取消与超时；研究运行回归通过。Web 类型检查、文本导出与来源上下文组件测试通过。阶段 B 的 B02、B04、B09 仍需真实质量证据和完整验收。
