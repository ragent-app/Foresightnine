# 丢弃非契约注释后的离线重放

仅对模型结论中不超过 100 字符的 `status` 字符串，以及计算计划中不超过 1000 字符的 `note` 字符串，丢弃其内容并继续执行严格的结构、引文和数值校验；其他未知字段、非字符串或超限内容仍导致结构校验失败。丢弃会留下限制说明，并令研究保持部分完成，不把注释当作事实、权限或判断依据。原始模型输出不会写入研究版本。

[离线重放](result.json)使用第 45 次 BEA 模型原始响应、原先固定的代码与资料片段，仅在验证前丢弃两个 `status` 和一个 `note`；提示哈希保持一致，无新模型调用或原成绩修改。重放保留了 3.2% 事实，但同时保留了错误的“第二次估计为 3.3%”模型结论：模型把另一段的修订描述归于 GDP，原文实际第二次估计为 2.9%。该错误再次说明字段清理和引文定位不能证明语义，不能把这次重放视为通过；在实际运行中未被引文覆盖的百分比和丢弃注释都会保持部分完成。
