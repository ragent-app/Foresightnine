# PDF 页码定位原型结果

曾尝试将模型看到的 PDF 摘录按页拆分并在引文中附页码，以区分跨页重复表头。页码只用于定位，不能证明表格列对齐或语义支持。

真实 PDF 回归发现，在固定输入预算下，额外的结构与提示占用了上下文，导致已有研究中重要数值、对比文字或公司名称未被选入；原型的首轮检查发现 6 项失败，缩短提示和重复元数据后仍有 3 项失败。因此该实现已整体撤回，恢复原有 v45 检索与引文行为；未因样本失败而修改原有真实资料测试预期。撤回后 `test_research_original_document.py` 的 16 项测试通过。本记录不表示阶段 B 的真实研究质量已通过，也未新增模型调用。

后续若重试页码提示，应先固定原有摘录，只有剩余输入预算足够时才增加页码信息，并验证不会改变基线摘录；还需独立检查模型所选页码和表格列关系，不能把模型选择当成语义验证。
