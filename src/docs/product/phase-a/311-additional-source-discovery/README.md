# 已选资料与授权官方发现并用

阶段 B 的研究工具需要能够结合已有资料和更多资料。原运行路径只在没有已选资料时搜索，导致用户已有一份材料时，勾选的官方资料授权不会带来其他来源。

现在，仅在用户显式开启既有官方资料自动获取授权、允许搜索且满足既有预算与时点条件时，已有资料的运行也可进行一次来源发现，并在支持的官方来源中最多获取一份，连同已有资料分析。跳过已附来源的相同 URL；研究资料总数达到上限时停止自动获取并给出状态。搜索结果仍是待核验线索，只有经过受限官方获取、许可设置和后续处理才可能成为资料。历史截止、显式空来源选择、成本上限、速率、时限、幂等和运行前计划来源 ID 的既有边界保留。Web 授权文案明确新增资料可以与已有资料并用。

这是运行开始前的一次有界来源发现，并非根据研究过程中识别的证据缺口迭代检索；通用研究规划与有界增量取证仍需建设。用户要求暂停测试和模型实验，此次未运行测试、浏览器检查或外部调用；权限、恢复、兼容性和效果尚未验证，不代表阶段 B 已完成。
