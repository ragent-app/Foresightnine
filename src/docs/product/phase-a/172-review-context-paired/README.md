# 复查可选上下文配对诊断：调用前登记

复用 171 号的五条已见主张、原文引文、人工构造的跳过项、连续批次编号、模型、生成参数、系统提示和输入预算。唯一主动变量是每条引文前后的可选上下文：对照保留现有片段，候选清空这些上下文但保留原引文；此样本没有机械规则要求必须保留的主体上下文。完整提示分别保存并在调用前固定哈希，两个条件只差这两个上下文字段。

先对照后候选，各调用一次，不搜索、不重试；每次输入上限 6000、输出上限 4000、最多预留 10000 Token 和 60 秒，合计最多 20000 Token。失败、状态或用量未知即停止。已知历史累计 192047 Token，另有历史未知用量；供应商内部版本和美元费用未知。

记录结构及索引有效性、逐条判断和遗漏；原索引 3 的主张含名义消费 0.1% 增长，但所附引文未包含该事实，故 `supports` 是预先定义的失败。其余主张也保留实际判断，不能假定正确。样本与期望已知且每条件只跑一次，结果不证明泛化或因果，更不能把无上下文方法普遍用于需要主体或指代的引文；不改写历史结果，也不作为 B 阶段独立验收。

两次调用均确定完成；保留上下文和仅引文条件分别报告 1500、1079 Token，合计 2579，已知累计 194626 Token，另有历史未知用量及未知美元费用。两项输出的五个索引均有效且完整。原索引 3 在保留上下文时被判为 `supports`，未通过预设检查；仅引文条件将其判为 `uncertain`，符合该项检查。其余四项在两个条件中均被模型判为支持，但尚不能据此确认它们正确。
