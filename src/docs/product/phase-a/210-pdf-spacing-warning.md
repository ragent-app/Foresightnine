# PDF 提取空格异常提示

209 号检查发现同一份 BEA PDF 的 `reading` 提取将大量英文单词粘连，而 `layout` 提取保留空格。系统现在对 PDF 提取文本做有界采样：当英文长词比例异常时，上传响应、已关联资料及授权导出显示待核查提示；研究运行记录也说明可能缺少词间空格，并保持部分完成。页面建议查看原 PDF，必要时用另一读取方式重新添加。原始文件、用户选择的读取方式和已存文字不被自动替换。

此检测只是一种可能有误报和漏报的提示，不评估中文间距、表格顺序或来源是否支持结论；没有提示不表示提取准确。采样最多读取 100,000 个字符；对短文本不作判断，非 PDF 文本不套用该规则。

相关 PDF 上传、来源、分析、原始文档及研究运行测试通过；实际保存的 209 号 PDF 在 `reading` 下触发提示、`layout` 下不触发，中文及非 PDF 对照不触发。Web 类型和导出测试通过。本地页面使用临时测试账户、真实本地 API 和保存的 PDF，在桌面 1280×900 及手机 390×844 检查上传与资料提示，无页面错误。当前环境未提供 Browser 插件，使用 Playwright；首次启动因未设置依赖路径失败，配置工作区依赖后通过，临时服务已停止。未调用模型，209 原有评分保持不变。
