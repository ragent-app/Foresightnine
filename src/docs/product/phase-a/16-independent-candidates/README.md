# 未用于此前模型调试的公司与宏观候选集

冻结两项：H04 使用可口可乐 2024 SEC 公开申报中的衍生收入数值，M01 使用 BEA 2024 年 GDP 初值的原始 PDF。前者不是原始 10-K 阅读测试，后者不是联网发现测试。来源分别为 [SEC 10-K](https://www.sec.gov/Archives/edgar/data/21344/000002134425000011/ko-20241231.htm) 和 [BEA 公告](https://www.bea.gov/sites/default/files/2025-01/gdp4q24-adv.pdf)；SEC 和 BEA 来源使用依据、例外及当前副本的历史时点限制见来源矩阵。两个源此前未用于真实模型调试，但题目与参考值是已公开候选，开发者已看到数据，不是盲测或独立人工复核；两题不足以推断总体质量。

`manifest.json` 在调用前固定实现提交、输入、参考文件、评分脚本和运行脚本的 SHA-256。两题分别最多一次模型调用、10000 Token、120 秒，合计最多两次；不搜索、不执行模型二次复查、不重试外部调用。只重试对同一 operation 的只读状态查询，发生 429/503 时继续观察原 operation，不新建研究运行；无法确认结果时停止后续任务并记不确定。引用内容及用量按实际记录，美元单价未知，不按零计算。

预定义每题检查：预期事实的值、期间、单位和原文位置；每个支持性结论至少有可定位引文；H04 的确定性增长计算；无被当前程序检出的正文与计算差异；模型调用和 Token 预算。两题均通过这些机械项才称机械检查通过。机械检查不判定引文是否真正支持结论，不证明历史可得性，也不是完整阶段验收。原始输出、评分与失败留存；不得基于该集反复调参后重新计为同一测试。

结果记录：H04 的两项数值、来源位置和 2.86% 确定性计算达到预登记机械条件；研究仍为部分完成，反方没有引文。M01 的原始 PDF 研究只选中一段未包含全年数值的文本，模型未返回要求的 2.8% 与 2.9%，因此机械条件未通过，研究状态为部分完成。两次分别报告 881 和 1070 Token，美元费用未知。完整结果和评分保留在本目录；语义支持及历史可得性仍不可由机械分数证明。M01 的失败已用于后续排查片段选择，故不再作为独立测试样本，也未重跑本集。
