# 中文问题与中文资料的片段选择

通用片段排序此前主要从英文单词、年份和有限的中英映射生成关键词。中文问题遇到中文来源时，相关原文可能没有这些英文词，导致靠前的无关片段被选中。现在额外从问题和可选范围中提取有限数量的中文短词组，直接匹配原文；每种长度最多八项，问题处理范围和候选数量均受限，其他关键词和原文偏移规则不变。此匹配只是检索线索，不能识别所有公司、语言、长词或同义表达，也不验证事实或语义支持。片段方法标识更新为 v22。

验证过程中，一项保留的 BEA 原始 PDF 测试发现前一轮新增截止时间提示增加字节占用，使英文问题的全年 GDP 段落落选。现压缩该提示，保留截止时间和不使用后续事件的要求，并仍在既有总输入预算内分配来源；不能因此保证其他预算或任务不会遗漏。初次相关测试为 129 通过、1 失败，修改后研究分析、运行和原始文档测试 130 项通过，覆盖中英文原始 PDF、中文合成资料、准确原文坐标及输入预算。中文样本为确定性测试替身；没有新模型调用或修改历史评估成绩。
