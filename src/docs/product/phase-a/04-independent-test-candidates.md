# A4：独立测试集候选（未封存）

状态：草稿，2026-11-11。用于扩展零售、饮料及宏观领域，不传给待评估系统作调试或优化。此文件包含答案，**不是保密测试集，也未独立审定**；需由人工审核、补足评分及时间边界，再由测试负责人选择未用于开发的题目和材料、冻结版本与哈希。当前同一作者准备题目与参考答案，是潜在偏差。公开候选题如果被模型或开发流程用于调参，应剔除或重新出题。

来源 R1：[Walmart FY2024 10-K 利润表](https://www.sec.gov/Archives/edgar/data/104169/000010416924000056/wmt-20240131.htm)，FY2024 截至 2024-01-31，总收入 648,125、FY2023 为 611,289，FY2024 营业利润 27,012，净销售 642,637、会员及其他收入 5,488，单位百万美元。

来源 R2：[Coca-Cola FY2024 10-K](https://investors.coca-colacompany.com/filings-reports/annual-filings-10-k/content/0000021344-25-000011/ko-20241231.htm)，2024 和 2023 年净营业收入分别 47,061、45,754 百万美元；以 2024-12-31 为财年末。

来源 R3：[BEA 2023 年四季度 GDP 第二次估计](https://bea.gov/index.php/news/2024/gross-domestic-product-fourth-quarter-and-year-2023-second-estimate)，2024-02-28 发布；该季度实际 GDP 折年环比 3.2%，此前初值 3.3%。

| ID | 题目与可用材料 | 参考答案和评分重点 |
| --- | --- | --- |
| H01 | R1：Walmart FY2024 和 FY2023 总收入以及同比 | 648,125、611,289 百万美元；`(648125/611289−1)×100 = 6.03%`。区分总收入和净销售，引用年度列。 |
| H02 | R1：FY2024 营业利润率，题目指定总收入为分母 | `27012/648125×100 = 4.17%`；同时说明公司按净销售额展示的口径为 `27012/642637×100 ≈ 4.20%`。 |

| H07 | 模拟监控超时与已有 Walmart 历史资料 | 本次是否有变化未知；旧资料仍是历史证据，不能把超时写成无变化。 |

| H09 | 模拟指标从 100 降至 95，原假设要求至少 100 | 受影响假设需复核，不相关的旧注释保持不变；数值仅为合成测试。 |
