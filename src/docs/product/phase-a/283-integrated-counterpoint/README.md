# 接入后的反方补充：运行前登记

在完整研究 API 中重放 276 号已保存的首次模型响应和同一原件，再允许一次真实反方补充调用；首次生成不重新请求供应商。固定当前提交、来源与选段、先前响应、模型与参数、系统及补充提示哈希。复查关闭、不搜索、不重新下载、不自动重试；最多两次逻辑调用，其中最多一次实际供应商调用，逻辑预算 20,000 Token、单次超时 60 秒、总计 120 秒。若终态或用量不明，保留结果并停止。此前已知累计 318,822 Token，其他历史用量及美元费用未知。

首次响应按其原始报告的 Token 注入运行账本以测试预算，因此运行总量包含已在历史累计中计算过的重放用量；本轮新增用量只统计真实补充调用。比较调用前检查点与最终版本，检查预算、引用定位、相关性、未知与反方质量；沿用既有公司题机械评分，不能把机械通过当成语义验证。该题与材料已用于开发，提示和代码已发生变化，此单次回归不是独立验收、无法推断总体表现。
