# 公司财务研究真实模型试验预登记

本试验是已知答案的开发样本，不是独立盲测、完整 10-K 阅读、SEC 联网接入验收或阶段 B 质量验收。使用 Microsoft FY2023 10-K 的两条 SEC API 衍生收入记录作为唯一材料；原 API 响应未保存，衍生快照 SHA-256 `a46d6f7767d87a6bf3b0d2b546ed1b9dd352de1d92c9139fdde266fc01c21c60`，来源、提取时间、提交号和限制记录在快照及来源矩阵。仅向模型提供两条 2023 申报中截至 2022-06-30、2023-06-30 的收入，不能看到 2024 记录；材料经过 JSON 紧凑序列化而非原始 10-K。无历史截止参数，不能据此验证时间点防泄漏。

固定问题："Using the supplied SEC-derived records, report Microsoft revenue for fiscal 2022 and 2023 in USD, calculate the percentage growth, and identify what cannot be concluded from revenue alone." 真实 GLM Coding 服务，保持已有生成设置；最多两次模型调用（生成与可选支持复查）、20000 Token、120 秒，禁用搜索与重试，金额单价未知，不将费用按零计算。记录模型和复查输出、材料哈希、用量、终态与限制，不记录密钥；调用失败或预算不足不重试。

预先记录检查点：材料是否覆盖 198270000000 和 211915000000 美元及正确财年；基于两值的增长率应为 6.88%（四舍五入到两位小数）；引文须在已提供的衍生快照中定位，计算需由程序执行并保留输入。负面或不确定信息缺少资料时应直接说明。每项单独记录，计算或引用的出现不等于语义正确；缺失或错误不能算通过。该题已为开发者所知，不能以此作为独立测试集。
