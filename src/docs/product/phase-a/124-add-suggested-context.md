# 将候选原文上下文加入引用

日期：2026-11-12。真实财报检查中，系统能指出结论引文缺少表头或单位，但用户此前需要另行搜索、复制原文才能补充引用。现在编辑最新版本结论时，可直接打开系统标记的候选原文上下文，检查后将其中选定的连续片段添加为引文。其他上下文警示也可使用同一操作；最多十条引用且自动避免重复。

候选片段由账户授权的来源上下文接口读取，添加时仍由服务端重新定位并检查来源、展示权限与研究截止时间。更改后结论标记为用户编辑，旧模型复查不再适用；原版本保留。上下文提示消失只表示对应的定位条件得到满足，不证明来源支持结论，也不自动确认表格列、单位或结论语义。权限不足、位置无效或超过限制时不会提供添加操作。

验证：研究版本及证据 API 测试 41 项、Web 测试 284 项及类型检查通过。Browser 插件及 browser 技能未列出，按前端测试流程使用本机隔离模拟 API 和 Playwright，在 1280×900、390×844 验证表头警示、查看候选、添加并保存、服务端重新定位、重新打开和用户编辑状态；无控制台错误或横向溢出。测试采用合成资料和模型替身，未调用外部模型，不代表真实资料质量验收。
