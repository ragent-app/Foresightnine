沿用 66 号双公告任务，固定原 PDF、问题、提取方式、模型、供应商参数、预算和机械评分。被比较的实现变更同时包含完整月度行选择及固定提示压缩；每次运行的来源 ID 不同，供应商内部版本和随机性也无法锁定，因此单次结果不能归因于某一改动。此前离线重放显示两行和表头均进入原预算；不等于模型能正确读取列。

调用前固定材料、运行程序、参考与评分。一次调用、最多 10,000 Token、120 秒、无搜索与复查、不重试，费用未知。任务及答案已用于开发，非盲、非独立测试；机械通过不证明引文语义支持或阶段 B 验收。
