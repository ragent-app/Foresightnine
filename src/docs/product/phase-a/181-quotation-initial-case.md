# 摘录首字母大小写恢复

179 号生成结果将原文句中小写开头的 `personal consumption ...` 摘录写成大写开头，导致整条引文被丢弃，尽管其余文字和数字与原文一致。来源定位现在在精确及空白匹配均失败后，仅允许摘录首个 ASCII 字母的大小写不同，仍须在实际分析片段中逐字匹配其余内容，并返回原始大小写与位置；多个位置继续标为歧义。对该恢复标记 `initial_case_normalized` 并在研究限制中提示，不能把字面匹配视为语义支持。其他字母大小写变化、数值改动或跨片段拼接不会因此被接受。

使用 179 号保存的供应商响应离线重放，原被遗漏的名义支出原文现在可定位，原文的小写开头被保留；同一主张中的另一段引文仍保留。离线重放没有新的模型调用，不改变该实验原有评分，也不证明反方质量或整个研究完成。分析、PDF 导入和复查相关自动测试覆盖唯一匹配、歧义与其他字符大小写变化的拒绝。
