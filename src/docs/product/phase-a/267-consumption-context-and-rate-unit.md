# 消费对照上下文与年化率差值

[266 号回归](266-cross-domain-recheck/README.md)暴露两个问题。第一，商品与服务也可能出现在进出口或其他指标中；仅按两个词和相反方向选择段落，不能保证其对应用户询问的消费。检索现在对“是否都同向变化”的问题要求明确提及所问的已识别组成项，并在问题涉及消费时要求消费语境；同时尝试让结果标题与对照句分别保留在不重叠窗口。来源定位和输入预算约束不变，识别不到时不能推断没有反证。

针对 263/266 已使用的 BEA 材料，离线检查现在验证**同一摘录中的完整消费句**，并分别确认 2.7%、3.2%、2.9% 仍在输入；而不是像 264 号那样只检查跨段落的词语。两个来源 ID/元数据条件下的相关回归测试通过。该材料已用于开发，没有新增模型调用，不证明模型会正确回答。

第二，模型输出 `percent annual rate` 时，旧计算器未将其识别为百分比水平。现在该写法及明确的类似年化率写法被识别，两期 2.7% 与 3.2% 之差为 **−0.50 个百分点**；旧的错误单位结果沿用既有历史提示与重算机制，不改写历史研究。研究分析和计算回归及 Web 类型检查通过。B02、B04、B09 的质量验收仍未通过。
