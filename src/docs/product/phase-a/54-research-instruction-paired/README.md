# 研究指令配对诊断：调用前登记

针对已观察到的引文缺少主体、跨指标推论和无依据反方，比较当前研究系统指令与另一种更明确要求引文主体、期间、数值及有依据反方的表述。此包只在隔离实验中替换系统指令，尚未修改产品默认指令。

固定同一个实现、三道已使用过的 NVIDIA、BEA 和美联储任务、资料、来源标识、提示片段、输出结构、模型及生成参数。两条系统指令均为 433 字节，以保持输入字节预算和片段选择一致；[准备脚本](prepare.py)预先计算三题完全相同的用户提示哈希，运行器在每次外部调用前再次核对。基线和备选指令、来源哈希、调用参数及相同评分规则分别保存在两个清单中。BEA 的 -0.6% 与 NVIDIA 的毛利率数值已根据原始材料加入本次允许的附加数值范围；这是本次调用前固定的新规则，不改变历史评分。

先运行基线再运行备选，每组每题最多一次外部调用，不搜索、不二次复查、不重试，单题 10000 Token 与 120 秒，合计最多六次和 60000 Token。基线发生未知终态、未知用量或超限时不运行备选。美元价格未知。记录所有原始响应、错误、用量与既定机械评分。

**预定决策**：只有备选三题全部满足本次机械规则且通过题数高于基线，才将该指令用于产品；否则保留当前指令。该规则用于避免事后挑选结果，不代表能够自动证明每条结论的语义或阶段 B 验收。题目已用于开发，每种条件只有一次调用，非盲且供应商模型版本、服务状态和随机性不可锁定；结果不得当作独立测试或可靠因果结论。

按预登记规则，基线和备选均为 **1/3**；备选未满足“三题均通过且优于基线”的条件，产品默认指令保持不变。全部六次调用均有确定终态和用量，所有研究版本均为部分完成。原始响应、运行记录及两份评分分别保存在 `baseline` 和 `variant` 目录。

- NVIDIA：基线满足机械条件；备选把 26,974、26,914 百万美元分别写成 269.74、269.14 亿美元，换算数值本身等值，但本次评分的主张数值匹配没有覆盖这种写法，不能单凭该评分认定换算错误。其结论引文仅覆盖收入行，未完整覆盖含列头与单位的事实片段，因此系统提示金额依据待核查。
- BEA：两组都保留 3.2% 和 2.9% 的目标事实。基线反方写“下降 0.6%”符合原文方向，但评分只预先允许带负号的 -0.6%，该项是评分局限；备选反方提到两项数值却只引用了不含这些数值的资料片段，系统仍提示引文缺口。
- 美联储：备选满足机械条件；基线输出的“没有委员投反对票”未匹配评分中有限的文字别名，且另有模型事实或引文被省略，不能仅凭别名失败解释整题结果。两组均无法据此证明所有引文和推论的语义充分。

基线三次报告 1795、1682、1325 Token，共 4802；备选报告 1582、1187、1174，共 3943；本次合计 8745，已知累计报告 77133 Token。另有 Walmart H03 潜在用量及美元费用未知。单次、非盲配对与机械分数不能证明因果或总体质量，阶段 B 的 B02、B04、B09 不因此视为通过。
