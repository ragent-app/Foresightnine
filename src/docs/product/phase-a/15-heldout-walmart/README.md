# Walmart 候选保留集：运行前冻结

本包在本次模型运行前固定输入、参考检查和调用预算。题目来自已有公开候选 H01—H03，开发者已看到题目和答案；模型此前未针对本包运行，但模型训练知识不可控，因此这是已知答案的未调参保留样本，不是盲测或独立人工复核。三题共用一个公司和报表，相关性高，不可外推整体性能。用户要求跳过人工验收，本包不假称存在人工基线。

使用 SEC 公开 2024 10-K 利润表中的衍生数值，核对来源为 [SEC 原始申报](https://www.sec.gov/Archives/edgar/data/104169/000010416924000056/wmt-20240131.htm)；[SEC 权限说明](https://www.sec.gov/about/webmaster-frequently-asked-questions)允许访问与复用 EDGAR 公开申报内容。快照不等于原始文件，未证明过去任一时刻的可得性；不启用历史截止时间。三题输入分别固定在 `H01-input.json`—`H03-input.json`，参考结果单独保存在 `references.json`，模型不可访问参考文件。`manifest.json` 记录来源与哈希。运行前先验证全部哈希；每题一次外部调用，最多合计 3 次、30000 Token、每题 120 秒；不搜索、不复查、不重试。实际美元单价未知，费用不按零计算。

每题自动检查所需数值、单位、来源位置及预先列明的计算；未达到的检查为失败。自然语言主张是否真正得到支持、其他遗漏或误导、准确历史可得性仍为不可自动判定，不得将自动指标标为全面通过。所有结果、错误和用量均保留；测试完成后不针对本包修补后再以同一版本重新计分。

结果：H01、H02 的冻结数值和确定性计算均通过机械检查，研究状态均为部分完成；H03 的运行脚本抛出 `KeyError`，未保存可判定的运行终态或第三次供应商响应，因此该题按未完成处理。脚本没有保留触发错误的 HTTP 状态或操作 ID，不能确定它是在外部请求前还是请求期间发生；第三次供应商调用与费用均为未知，未重试。评分规则和参考结果在调用前固定，评分脚本在运行启动后、结果人工查看前写成，脚本 SHA-256 为 `c7b27924ea2d868afa78efcf826ad01cde62e3a76ba87f527811fefdbbacf1ee`；这一时间顺序降低了预注册的严格性。详见 `score.json` 与逐题原始记录；自然语言语义未独立核验。

后验发现：H02 模型正文把净销售额口径利润率写成 4.21%，而确定性计算结果为 4.20%。原机械评分只核对计算对象，漏掉正文中的矛盾，不能把 H02 的 `mechanical_pass` 当作整份答案数值正确；[独立记录](post-run-findings.json)保留该缺陷及处理，原评分未改写、未重新调用模型。后续修复仅能识别满足特定数字锚点、百分比和计算唯一性的候选差异，不是完整语义核验。
