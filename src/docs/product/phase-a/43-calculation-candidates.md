# 百分比的计算候选

对于结论中未被原文直接覆盖的百分比，系统可提示可能相关的已保存计算：计算必须是可按保存输入和舍入规则重算的增长率或利润率，输入事实须唯一、未被用户编辑且保留原始位置，两项输入原文位置须均被该结论所附的同来源引文覆盖；计算值按结论所示精度匹配。修改事实、计算或引文后，候选重新生成；旧版本不改写。页面显示公式类型、输入事实和计算编号，便于查阅完整公式与来源。

这只是有来源的数值候选，不自动建立对象、期间或语义关系，也不证明事实正确；原有未覆盖百分比提示和部分完成状态保留。系统最多展示五个候选，且只处理特定公式及百分比写法，因此不能认为没有显示候选就没有可用计算。用户可核对计算输入和原文，仍需自行判断结论。

相关 API 运行、证据和计算测试 58 项、Web 类型检查和 275 项测试通过。Browser 插件不可用，使用本地 API 测试替身和 Playwright 检查桌面、手机展示、修改时隐藏以及保存后候选更新，无页面异常；未调用真实模型。
