# 阶段 B 独立资料受控验收

状态：任务与资料 v2 已在真实调用前冻结；唯一真实批次已完成，按预登记标准 1/3 满足，三个研究状态均为 partial，阶段 B 未通过。逐题结果见 evaluation.json。

`preregistration.json` 固定三题、来源文本和完整 PDF 的哈希、任务预算和运行记录约束；`criteria.json` 是模型不可见的预先判定标准。首次资料候选中的 2022 年 3 月美联储声明曾在 73 号开发检查使用，已在任何模型调用前排除；原 v1 文件保留以供审计。新候选按日期、标题、URL、正文关键句及仓库 PDF 哈希搜索未发现历史使用，但准备者非盲、来源均属宏观，不能据此推断全市场泛化或排除训练数据重叠。当前副本不能证明历史字节未变化。

BEA 和美联储资料按既有 [来源矩阵](../03-source-inventory.md) 的政府自著公告复制和分发说明用于本地评估和授权导出，不扩展到第三方资料。PDF 保留原件；文本以 `pdftotext -layout` 完整提取。BEA 表格存在原始 PDF 的跨列排版，检查数值时需核对原件，提取文本完整不保证列对齐。

最多三题、每题三次模型调用和 20,000 tokens、180 秒；总计最多九次和 60,000 tokens。关闭搜索、自动获取与模型调用重试；接纳、终态或结算不明时停批，不补跑。各题限额叠加为批次硬上限，即便实际用量不明也按上限保守计入。实际模型、支持的参数、代码哈希在工程稳定后单独写入 `code-freeze.json`，从未锁定的模型别名不能保证外部结果可重现。费用未知，不当作零。

`runner.py` 只允许连接回环地址，登录本地隔离持久 API；接纳前持久化幂等键，接纳后持久化 operation ID 和轮询状态。进程中断可用 `reconcile` 只读查询同一运行，不发起新的模型调用。研究成果仅在逐来源允许导出时通过服务端授权导出后保存；凭据、取消令牌和恢复令牌不写记录。已知字段递归脱敏不等于能检测自由文本中的所有秘密，本批次不得将凭据输入模型。隔离数据库和账号由执行环境临时创建，结束销毁；不得指向生产。

浏览器文件是工作区契约检查：`browser-context.cjs` 使用模拟 API；`real-api-browser.cjs` 使用真实本地 API、内存存储与合成 provider。这些结果不构成模型研究质量证据。`runner-tests.log` 为本地模拟脱敏、对账及授权导出检查；不能证明进程崩溃、持久数据库和真实 provider 的全路径。测试历史保留失败和修复前记录，不将定向通过当作未重跑集合的全量通过。
