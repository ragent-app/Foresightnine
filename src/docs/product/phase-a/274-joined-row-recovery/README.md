# 相邻表格行的引用恢复

272 号公司样本中，模型把产品和服务两行写成一条连续引文，原文不存在这样的连续文本，旧流程丢弃了整项分项陈述。现仅在两个片段分别唯一对应同一已分析片段内、顺序相同且紧邻的完整原始表格行时，恢复两条分别定位的原文；保留 `incomplete` 状态，不能把恢复定位视为列对齐、语义或反方已核实。两行之间存在其他内容、数字不符、倒序、重复匹配或跨摘录时不作此恢复，引用数量和扫描范围仍受限。

使用 272 号已保存模型输出和原始资料[离线重放](replay.json)，产品与服务分别恢复到两条原始行；原件中两期产品收入下降、服务收入上升，但模型未给出单独的反方条目。恢复仅保留可审查的来源线索，不自动生成反方，也不证明整份研究完成。重放未调用模型，原实验结果与评分未修改，脚本见 [replay.py](replay.py)。

分析与来源追溯测试覆盖相邻、数字错误、倒序、重复、跨摘录及被其他行隔开等情况；恢复后的引用继续标为待核查。研究运行与模型复查测试另行执行。此工作不改变 B02、B04、B09 的验收状态。
