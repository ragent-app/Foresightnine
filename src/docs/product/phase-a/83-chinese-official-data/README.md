# 中文官方统计资料的固定开发检查

资料来源为[香港特别行政区政府统计处《2024 年 11 月零售业销货额按月统计调查报告》](https://www.censtatd.gov.hk/tc/wbr.html?ecode=B10800032024MM11)，资料知识产权属香港特别行政区政府。按[统计处知识产权告示](https://www.censtatd.gov.hk/en/page_31.html)核对，其列明的统计报告可在注明来源和政府权利人的条件下复制、改编和分发，修改须注明；许可不涵盖地图、图形、标志等及第三方内容。本测试仅保存按顺序提取的文字和统计表，省略图形及部分页面，在输入和相关输出中注明来源、权利人和修改；原 PDF 不随本测试包分发。具体产品用途与第三方条款仍须单独核查。

调用前固定 PDF 的来源及哈希、修改后的文本、问题、参考、实现、模型参数、提示哈希、评分脚本和预算。问题覆盖总销货及网上销售的金额、同比变化、占比和临时估计限制。资料和参考对准备者已知，非盲、未经独立人工核验；文本节录不代表完整 PDF 阅读或其他中文资料表现，也不能证明历史字节不变。

最多一次外部模型调用、10,000 Token 和 120 秒，不搜索、不做模型复查、不重试；终态或用量不明确即停止。美元费用未知。预定机械规则检查指定数值与原文位置、临时估计、现有警示和预算；数值同现不证明对应的指标、期间及语义全部正确。该开发检查不能作为阶段 B 正式质量验收。

## 结果

一次调用有确定终态，报告 1,059 Token；加此前已知累计 112,188 为 113,247 Token，另有历史未知用量与未知美元费用。预登记机械检查未通过，研究为部分完成：有限输入预算下只选中了节录开头的标题、版权说明和目录，目标数值均未进入模型输入；模型没有形成有效结论，并给出未能定位的反方引文。模型所说“节录未包含主要数字”不能推广到整个节录，实际是本次选中片段未包含；系统记录了未分析的范围。

事后检查发现中文查询词的数量上限被问题开头的来源名称占满，关键指标词未得到均衡代表。这一观察可用于后续修复，但原始输入、输出和评分不变；本例为单次非盲开发检查，不证明中文研究或阶段 B 质量通过。
