两项 API 操作均有确定终态，各调用模型两次；贸易题报告 2777 Token，压力测试题报告 1880 Token，合计 4657。已知累计 171980 Token，另有历史未知用量及未知美元费用。两题最终研究均为部分完成；两题均保存了生成阶段的部分完成检查点和后续结果版本。API 状态完成只表示操作终止，不表示研究质量完成。

- 贸易题：原机械信号全部满足且保留引文可定位，但一条普通结论和反方错误声称“商品逆差下降”和“服务顺差下降”都会缩小总逆差；服务顺差下降会朝扩大总逆差的方向作用。此处是实质方向错误，不能用关键词或可定位引文掩盖。部分反方金额/百分比未被该条引文覆盖，系统给出提示。二次复查原计划检查两条，模型只返回一条，严格覆盖校验拒绝整个复查结果；另有结论因数值提示或输入预算未送审，状态如实记为失败及遗漏。
- 压力测试题：报告并引用实际 12.4%、情景最低 9.9% 及个体和合计高于最低水平的描述；两条普通结论获得模型 `supports`，但模型判断并非独立证明。反方因复查输入预算未覆盖，且主要讨论预测假设与资料范围，未引用题目要求的具体集中风险，因此该任务仍部分完成。

引文定位与机械信号并未识别贸易题的方向错误；现有模型复查也因输出覆盖不完整而失败，不能认定 B02、B04 或 B09 已通过。保留原响应、用量、选段、复查遗漏和版本记录；不改变既定评分或重试。
