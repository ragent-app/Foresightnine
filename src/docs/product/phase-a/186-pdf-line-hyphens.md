# PDF 换行连字符定位

185 号报告的模型引文把原始 PDF 提取文本中的 `esti-` 换行 `mates` 写成 `estimates`，导致附加引文无法定位。来源为 PDF 且常规定位失败时，系统现在可在本次实际送给模型的片段内，临时忽略英文字母之间的行末连字符；定位成功后仍保存完整连续的原始片段、字符位置和页码，包括原始连字符与换行。省略号仍只允许在同一分析片段内按顺序展开，跨度限 1000 字符；重复位置标为歧义。非 PDF、其他字词变化或超出片段的内容不能借此匹配。

原文中的连字符也可能有实际含义，因此该恢复带 `pdf_line_hyphen_restored` 标记和限制提示，主张保持不完整、需要核对；它不验证段落或表格对主张的语义支持。对 185 号保存的模型输出离线重放后，先前未定位的附加引文可定位并保留原始 `esti-` 换行，主张仍标为不完整。离线重放没有调用模型，不改变 185 号原始结果或评分。

相关分析、PDF 导入及复查测试通过；补充用例检查普通引用、带省略号的连续原文、重复位置、不同内容及非 PDF 输入。此修复不代表阶段 B 的完整质量已达标。
