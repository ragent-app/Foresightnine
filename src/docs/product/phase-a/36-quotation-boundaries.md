# 引文边界与数值定位

引文精确出现不一定代表引用了完整单词或数字。系统现检查有限的 ASCII 单词及数字边界，包括小数、分数、负号和会计括号；不把汉字连续排列误当作截断。被截断的模型数值事实不会进入事实或计算，引文仍可供查看，但结论标为不完整、不会送入支持性复查。用户新增此类引文时也标为不完整；编辑其他文字不移除警示，替换成完整原文后重新定位。规则只是边界检查，不验证语义，其他文字体系和记法仍可能漏检或误报。

同一引文有多个可能位置时，保留模型数值和候选位置供核查，但不将该事实自动用于计算；已有计算也不能直接依据这类事实重算。独立计算工具仍可接收用户显式提供的输入，并继续标明输入未由计算器验证。

相关分析、运行、版本和原始资料 API 测试 93 项通过，新增边界用例另行通过；Web 类型及 275 项测试通过。本地 Playwright 使用测试身份与替身检查截断引文提示、替换后保存，以及多个候选位置提示；桌面和手机视口均检查，Browser 插件不可用。首次候选位置检查使用了旧界面文案而超时，按当前文案重跑通过。第 31 次美联储保存响应的离线重放识别出截断的 `adjustm`；无新模型调用，历史成绩不变。
