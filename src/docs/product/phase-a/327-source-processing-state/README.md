# 327：结构化记录已选资料的处理情况

研究分析对每份本次已选资料使用共享的资格判定，分别记录可用、模拟资料、来源未授权、缺少模型或展示权限、截止时点可用性未确认、超过来源数量上限。对可用资料记录首次输入是否选入完整提取文本、部分、未选入或范围未知；记录基于选取的原文区间，不证明模型调用成功、理解或资料本身完整。未选择用于本次研究的资料不在此列表中。

这些状态写入运行版本和检查点，工作区显示原因，导出随运行记录保留。首次选择未覆盖或资料被排除时，运行保持部分完成并产生待核查项；原有其他证据限制和保护保留，避免依赖新增的展示文案决定处理状态。补充分析可能使用不同片段，不将其与首次输入的范围合并来宣称任一次调用已完整阅读。

该机制不证明跨来源研究已经充分，也不改变历史版本。按用户要求，未运行测试、浏览器检查或模型实验；兼容性及多任务表现尚未验证，阶段 B 状态不变。
