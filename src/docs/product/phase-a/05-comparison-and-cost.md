## 已执行的有限试跑

[固定计算脚本](baseline/fixed_workflow.py)使用分别保存的 [FY2023 衍生事实](baseline/msft-fy2023.json) 和 [FY2024 衍生事实](baseline/msft-fy2024.json)：先构造初始结果，再读取后续年份，计算收入同比和营业利润率；[单次运行记录](baseline/fixed-workflow-run-2026-11-11.json)含输入哈希、输出、耗时和调用数量。2023 增长 6.88%、2024 增长 15.67%，对应营业利润率 41.77% 和 44.64%。来源取自公司披露，提取事实仍待独立人工审核；两个 JSON 不是原始文档快照。

本次模型调用 0、网络调用 0、重试 0，因而本次没有模型或数据提供方按调用收费；本机计算、人工和存储成本尚未测量，不能称总成本为零。记录耗时仅为本地算术和文件读取，不含资料获取、研究、核验或人力。本试跑没有反方分析、引用支持核验、自动采集、真实监控或可恢复执行，**不能当作完整固定工具研究流程，更不能作为系统间质量或成本比较**。仅构造初始结果后才读取更新数据是代码级隔离，不能消除模型预训练中的未来知识。

随后按 accession、年度起止日及单位将四个收入事实与 SEC 结构化结果[逐项交叉核对](baseline/sec-revenue-crosscheck-2026-11-11.json)，四项相符；这不验证营业利润、引用权利或替代人工复核。

### 两步固定研究回放

在算术试跑之后，另以 [固定流程](baseline/fixed_research_replay.py)分别运行[首次研究](baseline/fixed-research-initial-2026-11-11.json)和[后续更新](baseline/fixed-research-update-2026-11-11.json)。初次只读取 2023 资料，列出收入及利润率计算，并以 More Personal Computing 收入下降作为“并非所有分部增长”的反证；更新在独立调用中读取已保存的首次结果及 2024 材料，记录新增数字、沿用的历史反证和未能判断的 2024 分部情况。相同年度的收入或利润冲突时停止，不能静默覆盖。两次结果保存材料、脚本与前一版本哈希；[阶段检查](baseline/fixed-research-validation-2026-11-11.json)核对计算、版本衔接及冲突拒绝。

每一步模型、网络调用均为 0；首次与更新分别记录了本机文件读取和固定计算耗时，不包括原始资料获取、核验、人工编辑及基础设施费用。这是为一项已知任务手工编写的固定规则与预设反证，不自动理解任意问题，也不读取或核验原文、完成独立人工评判或代表持续监控；未达到完整通用固定工具研究流程，更不能据此宣称质量达标或与 Agent 作正式比较。源事实、许可和历史可得时间仍待复核。

### 原始公告固定工具探索

在已检查过原文后，编写[固定 PDF 提取流程 v0.1](baseline/fixed_original_macro.py)，对 D19—D23 分别读取[原始公告候选题包](original-source-candidate-v01/README.md)中允许的文件，检查文件哈希和截止时间，用 `pdftotext -layout` 提取并记录页码、数值、公式、调用和耗时；不访问网络、不调用模型。前四个成功结果分别为 D19、D20、D22、D23。D21 首次运行因相同句式匹配到两个位置而拒绝输出，退出码 1；后来仅收紧 GDP 年度上下文、并更换输出文件名以保留版本，使用 [v0.2](baseline/fixed_original_macro_v02.py)再运行 D21，产生候选结果。[运行台账](baseline/original-macro-pilot-results/run-ledger-2026-11-11.json)记录了五个结果的哈希、首次失败和版本变化。

结果中的数字与候选参考项一致，但规则是在查看同一批材料后写成的，D21 又针对本题调整；这是**样本内探索，不是独立评估、成功率、系统比较或通过率**。逐题耗时包括文件读取及 PDF 提取，不包含资料搜集、人工评分或模型推理；计算、存储和人力成本未知。来源历史副本一致性、许可与真人独立核验依旧未完成。正式对照须先冻结数据、规则及阈值，并使用未用于规则开发的独立测试材料。

进一步检查发现 v0.2 只把 PDF 与题目内部写入的哈希比较，没有将题目自身与先前清单绑定：在临时副本中改变 D19 问题后，旧程序仍会运行。[对照探针](baseline/candidate-integrity-probe-2026-11-11.json)记录这一行为；[清单校验器](baseline/verify_source_candidate.py)要求由运行方提供独立保存的预期清单哈希，并检查清单、题目和资料的一致性。临时副本中修改题目、同时修改题目与清单、修改 PDF 的三种情况均被拒绝。此校验不提供操作系统隔离，也不证明权利、历史真实性或评估质量。

已另行创建 [提取流程 v0.3](baseline/fixed_original_macro_v03.py)，把校验通过的 PDF 字节直接交给本地提取器，并以 D19 做一次[探索运行](baseline/original-macro-pilot-results/D19-v03-ledger-2026-11-11.json)；旧版本与旧记录保留。v0.3 改变了校验及传输方式，不能拿其耗时与旧运行直接比较。校验器源码哈希在运行后记录，不是可信执行环境的证明；正式实验仍须外部可信地保存清单哈希、冻结全部工具版本并隔离进程。

在评估集及独立测试集完成复核后，先冻结问题、输入快照与引用、检索与工具权限、时点、提示词版本、输出格式、重试规则、评价口径和费用/调用/时长上限；在此基础上进行独立重复。不同模型对生成参数支持不同，只记录和设置实际支持的参数。逐次记录模型标识与版本可锁定程度、提供方、提示词哈希、参数、工具输入输出、尝试与重试、时间、费用与终止原因。未经同条件匹配的结果不做直接效果归因。

输入应分层登记：现有衍生事实题只评价从给定事实计算和解释的能力；[原始公告候选题](original-source-candidate-v01/README.md)可额外评价文档定位和引用，但不评价自主发现来源。若未来允许搜索，须独立指定来源、时间、许可、工具和预算，并记录三组能否接受相同约束；不能拿不同层级的结果直接比较。按每题单独提供允许的文件和工具，实际运行时用进程和文件权限实现隔离，目录结构本身不是安全边界。

先以已核验的人工作答与耗时制定正式门槛，并在首次正式运行前写入不可变实验登记；对开发集调试、独立测试集盲评和任何阈值变更分别记录。涵盖事实、引用支持、计算、任务完成、反方、更新误报漏报、用户核验时间、延迟和每个有效成果的总成本。生成式系统不可锁定模型权重、在线检索或训练时间时，应在结论中写明限制，不宣称完全可复现或消除未来信息。

## 成本口径与可用性

分别计量首次研究、增量更新和持续观察：模型输入输出、工具调用、搜索、数据许可、文档处理、存储、计算和人工核验。分别记录供应商实际账单/报价、计价单位、样本次数与数据时点；缺失值保持未知。单次有效成果成本 = 该类任务实际总成本 ÷ 通过预定质量标准的成果数；有效成果数为零时结果不可计算。

本次运行环境发现 `opencode` 可执行文件；进程环境未见所检查的若干模型密钥变量，不能据此推断其他凭据或可用账户。未读取用户环境文件、未调用付费模型。FRED 本机单次试取超时，两个微软页面和 Apple 页面可读，详细来源证据见 [A3](03-source-inventory.md)。[SEC 说明 EDGAR 数据库可免费访问](https://www.sec.gov/submit-filings/about-edgar)，因此以该公开接口直接取得样本的来源访问费用初估为 0 美元；不包括网络、计算、保存、模型、人工或可能的第三方许可，也不构成总任务成本。实际提供方价格、许可、月费分摊、人力费率和总体单位成本均未核定。正式实验应在运行前设置具体预算和中止条件；当前没有足够依据确定有偿预算或默认供应商。

已保存的 4 份官方宏观 PDF 按获取清单计共 4,293,706 字节；这是当前素材大小，不含备份、副本、索引或未来增长。两个固定研究回放输出均未发起新网络或模型调用。首次来源获取、持续观察所需的重复频率、人工核验时间及存储单价未测量，因此不能由此算出每次研究或每月观察总成本；仍须按实际部署与用量测量。
