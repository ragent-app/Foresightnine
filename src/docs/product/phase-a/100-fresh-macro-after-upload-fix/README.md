调用前登记：延续 [第 98 项](../98-fresh-macro-evaluation/README.md)的任务、资料、参考、评分、模型参数和预算，唯一主要实现变化是 PDF 容量限制；新来源标识、提示与脚本哈希固定于本目录 manifest。第 98 项在创建操作之前确定性地因来源准备失败，没有模型请求；本次是修复后的新登记，不重试任何结果不明的外部调用。预先单独验证了两份 PDF 的解析及超限文件的上传和原件往返。

## 结果

两个操作均有确定终态、各调用模型一次；分别报告 1,669 和 1,683 Token，合计 3,352。已知累计为 124,908 Token，另有历史未知用量与未知美元费用。两个研究均为部分完成，预登记机械结果 0/2。

GDP 题成功引用第二次估计的 2.8%，但第三份公告选中的是前次估计和资料完整性说明，未选中 3.1% 及分项修订，无法比较或给出被抵消因素。政策题正确引用维持 5¼%—5½%，但选段没有包含收紧、时滞和经济金融状况等后续政策因素；模型还将利率区间误称为百分点，系统给出警示。政策题的数字匹配提示另把区间分数中的数字 2 与独立的 2% 通胀目标关联，这是提示候选的误报，不能作为语义支持证据。

两题均保留原始输入、响应和评分。本次是已知参考的非盲小样本，不能作为正式质量验收或泛化结论，也不会事后改分。
