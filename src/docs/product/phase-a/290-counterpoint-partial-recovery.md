# 反方补充中的部分结果恢复

补充响应中如果同时包含合法条目和格式错误的条目，旧流程会拒绝整批响应，导致已完成研究无法保留其中可复核的反方。现在仅在反方列表本身符合类型和 20 条上限时逐条验证：保留结构合法的条目，计数并省略结构无效的条目；列表类型无效或超出上限时仍拒绝整批。保留条目继续经过原有选段、来源权限、引用定位和警示检查，不因为结构合法就被视为有证据支持。被省略内容不会作为研究结果保存。

如果保留了带引文的反方但同时省略了无效条目，运行和补充状态都明确为部分完成，展示省略提示与数量；没有可定位引文时仍报告无证据。测试覆盖混合响应、无效列表、数量上限、预算和既有警示，Web 类型检查通过。测试使用模拟响应，不表示真实语义质量通过，也未新增模型调用。
