# 关系从句的缺失主语

第 109 项 GDP 研究将原文中“进口是 GDP 减项”的叙述错误归给库存；模型引文从 `which are ...` 开始，省略了前面的 Imports。旧的上下文提示看到引文里含有 GDP，就跳过了缺失主语检查。现在对特定英文关系从句开头（如 `which are`、`that was`），在引文前紧邻逗号且同句上下文可定位、可显示时，提示核查被省略的先行词，即使引文内部还包含其他指标。提示不自动判断结论真假；若进行模型复查，该必要上下文会随原引文提供，预算不足时仍按原规则省略复查。

对第 109 项已保存结果的离线检查，候选上下文定位到原文 `Imports,`，不改写旧输出或预登记成绩，也没有新增模型调用。规则只覆盖有限英文形式，复杂指代、歧义位置、跨页或未授权资料仍可能漏检，原文匹配与模型复查均不能独立证明语义。
