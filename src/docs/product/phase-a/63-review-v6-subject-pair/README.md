# v6 复查提示的主体上下文诊断

沿用 57 号诊断的同两条已观察结论、同一份资料和同一模型参数，使用 v6 的上下文/引文分字段格式。两次提示仅第二条的上下文不同，先无主体，再含主体；第二条判定为不支持、矛盾或不确定算作该单例通过。固定清单后每条件最多一次调用、60 秒、10,000 Token，总上限 20,000 Token；未知终态、用量或异常停止，不重试，费用未知。

本项是模型已见问题上的非盲开发诊断；不是独立测试，也不证明引用语义准确率或阶段 B 验收。新提示格式与旧 57 号对照不同，结果不能单独证明整体提升或模型行为的因果关系。

结果：无主体条件对两条均判 supports，错误结论未被发现；包含主体条件第一条为 supports、错误结论为 does_not_support，满足本单例预登记规则。分别报告 543 和 688 Token，共 1,231；此前已知累计 89,804，加本次为 91,035，另有先前未知用量，费用未知。

这只验证已知单例的一次行为，缺少主体时仍会误判；v6 不能当作可靠的独立语义核验，也不能据此判定 B02、B04、B09 通过。
