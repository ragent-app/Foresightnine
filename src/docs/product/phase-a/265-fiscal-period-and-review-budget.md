# 财年日期格式与复查预算默认值

[263 号公司样本](263-holdout-candidates/README.md)的模型事实使用 `FY2024 (year ended July 27, 2024)` 等格式；旧解析器只识别独立的 `fiscal year ended ...`，因此未能追溯原始年度列。现将两种明确格式统一解析，并核验日期有效性；当 FY 标签年份和结束日期年份不一致时不自动判断，因为不同发行人可能使用不同财年命名。该解析也用于年度列冲突提示和可识别期间顺序。

对 263 的保存原件与模型输出离线重放，两期事实能对应原始年度列，生成 **−5.61%** 的暂定计算；`input_status` 仍为 `unverifiable`，指标、币种、单位及引用语义并未因此获得确认。没有重新调用模型，263 冻结结果和 0/3 评分保持不变。

263 的每题 10,000 Token 预算虽然允许两次调用，但按输入和输出上限预留后没有足够空间启动复查。Web 在用户主动启用模型复查、且尚未手动修改 Token 上限时，将可见默认总上限从 10,000 调为 20,000；关闭时恢复 10,000，手动设置的数值不被覆盖。界面说明复查需额外付费且仍受剩余预算约束；这一默认值不保证所有提供方或逐条复查都能完成。API 的显式预算与默认值不变。

财务计算及原件结构针对性测试、Web 类型检查通过；本地 Playwright 在模拟后端上验证勾选、取消及手动预算保留，桌面和移动宽度未发现页面错误或横向溢出。Browser 插件未列出，使用 Playwright。此改动不构成阶段 B 真实质量验收。
