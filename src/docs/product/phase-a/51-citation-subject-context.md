# 引文主体上下文提示

当已授权显示的来源有精确、无歧义的引文定位时，系统在有限范围内检查引文前的句子上下文。如果引文未写明指标、但附近可识别出唯一的 GDP、GDI、个人储蓄率或个人消费支出物价指数主体，就提示可能遗漏了该指标，并将自动研究标为部分完成。该提示不判断结论真假，不自动修改正文，也不把附近指标作为引文内容；页面可以继续打开原文上下文。用户编辑引文或事实后重新计算提示，历史版本不变。

对第 50 次已保存 BEA 离线重放结果追加检查时，错误推论引用的片段被提示附近指标为“个人储蓄率”，与前一条 GDP 结论不同。此检查不证明所有误引都可发现：仅覆盖列出的指标名称、有限字符范围与句子边界；缩写、多指标、跨句、权限不足或歧义位置可能漏检，格式异常也可能产生误报。应结合完整原文判断。
