沿用[首次登记](../44-reserved-cross-domain/README.md)固定的三份来源、任务、参考、评分、模型、参数和预算。首次运行在公司资料上传阶段本地失败，没有创建研究运行或调用模型，后两题未运行。此版本仅在实现中修复研究文本来源的有界请求大小，原结果保留；清单记录修复后的提交以及上次清单哈希。

公司资料是 SEC 10-K 完整 HTML 正文提取，表格分隔符由提取器生成，并非原始 PDF；另两份是 BEA 和美联储原始 PDF。预留材料和任务此前没有进入真实模型运行，但答案对开发者可见，非盲且没有独立人工复核，不代表总体质量或历史字节身份。

每题最多一次外部调用，最多 10000 Token 和 120 秒；合计最多三次、30000 Token。无搜索、模型二次复查或不确定调用重试。超限、调用终态或用量不明时停止余下任务。正式质量要求、机械检查及局限与首次登记一致；原评分程序保持相同，不因结果修改规则后重计本次测试。

运行与预登记评分结果：三次外部调用均有已确认终态，[机械检查](score.json)为 **0/3**，三个研究版本均为部分完成。

- NVIDIA：仅选中汽车业务段落，未覆盖总收入表，因此无法给出要求的收入和增长率；模型报告了范围不足。模型另提及汽车业务 60%，不属于本题预期数值，评分据预设规则记录为需检查。
- BEA：模型输出的两条结论含未允许的 `status` 字段、一项计算含未允许的 `note` 字段，结构校验失败，已保留原始输出及失败状态；所选另一段实际讨论其他指标的下修，但模型将其误用于 GDP 修订，不能因为放宽结构校验就视为结果正确。
- 美联储：选中会议标题和另一项纪要批准投票，未选中本次货币政策行动的投票段；模型明确表示不能据所见摘录确认，未达到本题要求。
