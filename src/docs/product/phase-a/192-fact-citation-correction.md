# 数值来源引文的修正

研究工作区现在允许为已有数值替换来源引文：可在已关联且允许展示的资料中查找原文，选择连续片段并保存。服务端重新检查账户权限、研究截止时间、原文匹配与位置；当客户端未指定位置时，只有唯一、完整的引文才自动写入原文坐标及定位方式。找不到、重复、截断、越权或时间不可用的资料不能变成已定位证据。修改事实会清除旧的负向变化确认，用户可在新版本重新核对。

带有来源数值缺失、引文未定位或歧义等 `source_value_warnings` 的事实不能用于新建计算或重算；相应已保存计算会显示为无法核验。如果输入值本身与计算快照不同，仍优先显示输入已改变。正确替换引文后可按既有方向、单位及期间规则继续计算；来源匹配仍不代表数值含义已独立核验。历史版本不变。

API 测试覆盖来源值不符时拒绝、替换引文后自动定位与计算、重复引文拒绝以及旧版本保留；相关研究运行与计算测试通过。Web 类型检查、测试和生产构建通过；本地浏览器用测试替身完成数值修改、引文替换、方向确认和新建计算，并检查移动端宽度。生产构建仍有原主包体积提示。本次没有真实模型调用，阶段 B 整体质量评估尚未完成。
