# 新资料三题开发检查

调用前固定清单、资料、评分器与实现提交。使用 PayPal 2025 年 [SEC 10-K](https://www.sec.gov/Archives/edgar/data/1633917/000163391726000024/pypl-20251231.htm) 的两期净收入衍生 JSON、[BEA 2025 年 8 月公告](https://www.bea.gov/sites/default/files/2025-09/pi0825.pdf)和[美联储 2025 年 1 月声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20250129a1.pdf)原始 PDF。公司题不检验完整年报定位；BEA 采用阅读顺序，美联储采用版式顺序。文件哈希不证明历史字节未变，来源使用依据见来源矩阵。

使用清单内固定的模型、参数和预算，每题最多调用一次，不搜索、不复查、不重试不确定调用。机械检查三题全部通过才算本次有限检查通过；引用语义支持及美联储维持利率的判断还须单独检查。开发者已知题目和参考，本次是非盲开发检查，不能证明独立测试或完整阶段质量，也不能归因于某一提示变化。单次 Token 上限不等于美元预算，费用未知。
