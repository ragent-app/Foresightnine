# 330：面向研究计划的通用选段

研究计划生成后，原问题较长时可能占满通用检索的词项上限，子问题虽然进入提示，却没有参与资料选段。现在对原问题和最多六个规划子问题分别提取有限的词项，轮流分配同一检索词预算；候选片段优先兼顾尚未涉及的子问题词项和原有相关度。没有研究计划时保留原通用检索路径；计划启用时，受支持的结构化观察值路径仍优先，其他拆分选段优先使用通用检索，已有领域选段保留为后备。

选段仍受每份来源的字符、输入字节和时间预算控制，所有位置对应原始提取文本。研究计划、词项与命中均是不可信的检索线索；词项命中不证明子问题被回答、资料覆盖充分或引文支持结论。没有命中时沿用已有后备选段。系统仍记录未覆盖的资料范围和未关联子问题。选段方法标识更新为 v51，旧版本保持原有记录。

按用户要求未运行测试、浏览器检查或模型实验。跨语言检索、表格上下文、输入预算、原始偏移及计划质量尚待集中验证；这不是质量通过或投资效果证据，也不改变阶段 B 状态。
