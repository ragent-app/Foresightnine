## 结果

三项操作均完成，每题一次生成，分别报告 **3,021、2,773、1,627 Token**，合计 **7,421 Token**；已知累计 **291,515 Token**，另有未知历史用量与未知美元费用。三项研究均为部分完成，预先登记机械检查仍为 **0/3**。与 263 相同，每题预算未能覆盖第二次调用的保守预留，因此复查均未启动。

- 公司研究生成了 **−5.61%** 的暂定计算，输入仍标为不可核验；模型把两期收入换算为 538.03 和 569.98 亿美元，评分器要求主张中出现未经换算的百万美元数值，故两项机械数字检查未通过，不能据此判断换算本身错误。其他引用、反方和完成状态也未通过。
- GDP 研究正确给出 2.7% 与 3.2%，但仍声称消费资料没有商品、服务拆分。复核选段发现模型看到的是**进出口**的商品与服务对照，并未看到原文中**消费**的对应句；评分器的 `services` 关键词检查因此产生误导性通过，不能视为消费方向通过。生成的两期百分比差值数值为 −0.50，但单位被错误保留为 `percent annual rate`，应为百分点。
- 政策研究识别了目标区间和 Kashkari 的反对意见，但该意见仍在主要结论而非预设要求的反方条目，且通胀措辞有引用警示；冻结规则下未通过。

进一步检查发现，[264 号离线选段检查](../264-partial-source-absence-and-contrast.md)只验证了“服务增加”和“商品减少”两个词组同时出现，没有验证它们属于消费而非进出口；该检查声称消费句已入选的结论有误。以上问题是开发回归发现，模型、资料和评分均不足以证明独立质量或阶段 B 完成。
