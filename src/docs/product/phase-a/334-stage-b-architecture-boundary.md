# 阶段 B：研究 Agent 架构与推进基线

本文件将[宏观方案](../fusion-finance-ai-macro-plan-2026-11-11.md)和[阶段 B 规格](06-phase-b-spec.md)落实为整体工程边界，记录当前建设状态及剩余工作。具体历史和验收证据见[当前验收记录](208-stage-b-current-audit.md)。它不是阶段完成声明。

## 产品与系统边界

产品是通用金融研究 Agent 工作台，不以某个行业、公司、来源或评估样本限定能力。阶段 B 的目标是从问题或授权资料出发，完成首次研究、来源和证据核查、计算、反方、部分交付与版本保存。持续更新属于阶段 C，持仓和资产影响属于阶段 D。

```text
用户问题、研究范围、资料权限与预算
                  ↓
研究协调：规划 → 来源发现和获取 → 分析与计算 → 缺口、反方及审查 → 交付
                  ↓
共享工具：来源策略 / 文档与结构化数据 / 确定性计算 / 模型与搜索适配器
                  ↓
研究状态：主题、资料、事实、主张、证据关系、运行快照与版本
                  ↓
工作区：查看阶段成果、核对来源、编辑与确认、重开和权限内导出
```

模型负责规划和解释；代码负责权限、预算、计算、状态和可追溯记录。外部材料与工具结果是不可信数据，不能授予权限或改变系统指令。来源线索不等于证据；引文定位、模型意见与独立核验是不同状态。流程概览只描述保存时的执行状态，缺少历史记录时标为未知。

## 当前落地的主要边界

| 边界 | 已接入的能力 | 仍需完成 |
| --- | --- | --- |
| 任务协调 | 可选规划先于来源发现；首次生成、搜索、预算、取消及模型调用经过共享运行上下文 | 补充、复查等步骤仍部分由 API 入口编排，需继续收敛生命周期与阶段契约；默认任务应仅执行必要步骤 |
| 来源与工具 | 首次和缺口搜索共用受控发现处理并记录超时、限流等失败类别；来源资格、时点、权限和选段摘要由共享策略处理；官方资料自动获取需单独授权 | 扩展工具和来源时逐项确认许可、故障及数据口径；当前官方自动获取和 SEC 结构化数据不代表全球覆盖 |
| 研究与审查 | 成果组装、证据处理和交付评估具有共享边界；版本待办区分未复查、不确定、反对及可能矛盾等模型意见 | 通用词法检索已优先于历史主题特例，结构化资料处理与旧规则保留为补充或回退；既有分析与证据模块仍包含大量历史启发式，应以任务、资料结构、证据关系和明确状态逐步替代，不为个别样本继续堆规则，也不未经验证删除保护 |
| 状态与恢复 | 用户编辑、检查点及最终交付沿同一研究版本链保存；已尝试规划及首次分析后可保存阶段快照；工作区可查看已保存阶段及高层流程状态 | 当前不支持从检查点自动续跑；需维持幂等与并发保护，明确外部调用状态和费用未知，验证中断与恢复边界 |
| 工作区与交付 | 研究问题、结论、来源和反方可按已记录关系查看；提供版本、编辑、复核、导出及缺口 | 需要端到端核对各界面、来源权限和旧版本兼容；关联与模型复查不能作为证据充分的证明 |

运行上下文分别记录模型和搜索调用，已知模型用量按报告值计入预算，未知用量按对应预留上限保守计入；实际用量和费用未知时不补造。自动官方获取保留独立授权和限制。FRED 条款尚待核清，当前不能将其视为已获授权的 Agent 或模型输入。

## 接下来的整体工作

1. **完成协调与工具闭环**：把剩余阶段围绕统一任务、权限、预算、阶段产物及错误状态整合；保持现有 API 与历史版本兼容，不以拆分文件数量作为目标。
2. **形成通用证据链**：在问题、资料范围、事实、计算、主张、反方和未知之间保留可追溯关系。对全文未读、实体或期间不明、矛盾和缺失明确表达；不因数值共现或模型打分确认语义支持。
3. **贯通工作区与失败交付**：用户可以查看已保存成果、来源和待办，编辑后形成新版本并在许可内导出。失败、预算耗尽与取消保留可用成果；不能确定是否重复收费时明确提示。
4. **按阶段集中验证**：在用户解除当前测试暂停后，对 B01–B10、多个研究类型及故障、隔离、恢复场景进行相应验证，固定实验数据与预算。人工验收按用户要求跳过；缺失的独立质量证据不能因此视为通过。

## 状态与约束

当前工作在原工作树及 `master`。近期架构和选段顺序变更按用户要求尚未测试或进行模型实验；选段方法记录为 `general_lexical_with_legacy_fallback_v52`，后续对照时需固定数据、任务、提示词、权限、模型参数及预算；历史测试只证明当时的范围，不证明当前实现或研究质量。现有真实研究仍有引文语义、反方和财务口径缺口，阶段 B 尚未完成。

保持用户数据、原始资料、历史版本、已有功能和 FM 计算边界。未获明确授权前不迁移生产数据或发布服务；模型、供应商、市场范围和 FM 产品定位保持可替换或待评估状态。
