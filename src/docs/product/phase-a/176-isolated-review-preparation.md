# 逐条复查的输入准备

新增内部逐条复查准备与响应校验：每个提示只包含一个可复查主张及其授权原文，批次内编号为 0；服务端保留到原研究主张的索引和原文片段映射。支持观点与反方交替排序，未授权、无定位、缺证或超过单次输入预算的项目保留原索引及遗漏原因。必要主体上下文继续与实际引文分开，模型结果不能视为独立证明。

这只是内部准备能力，尚未接入研究 API、界面或模型调用，也不会改变当前批量复查。调用方接入时仍需逐次执行预算预留和结算、调用及时间限制、失败停止、用户取消、幂等、中断后的部分结果保存，并明确每个未完成项目的状态；不能将准备好的提示全部无界发送。单次探索中逐条判断较好不证明普遍更准确。

测试覆盖单条隔离、原索引映射、反方排序、来源权限、必要上下文、输入预算、空或越界及重复响应；现有研究运行和复查相关 API 测试通过。本次未调用模型，不更改 175 号实验结果，阶段 B 尚未完成。
