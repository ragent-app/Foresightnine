# 通用资料选段基础

阶段 B 现有选段代码含大量特定问题和措辞分支。新增通用的有界文档分段与词项覆盖索引：基于研究问题中的通用词项及中文短词匹配原文，按词项覆盖、区分度和多样性选择互不重叠的候选段落；保留原始字符偏移、总长度、取消与处理数量上限。没有词项匹配时回退原有选段；现有表格、结构化数据等专门保护暂时保留。该方法不做跨语言翻译或语义判断，匹配和未匹配都不能证明资料是否相关或支持结论；来源覆盖不完整仍照原路径披露。

为保持审计，选段方法更新到 v50，历史记录不变。此变更不声称代替语义检索、针对缺口的多轮研究或表格理解。根据用户要求，本次未运行测试、模型实验或性能检查；效果、性能和兼容性尚未验证。
