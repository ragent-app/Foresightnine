# 326：按任务选择反方要求

研究工作区已允许用户关闭“完成研究需要反方”，但模型分析提示此前没有接收这个选择。现在初次研究与后续取证在用户未要求反方、也未启用反方补充时，明确告知模型反方可以为空；问题或资料存在相关冲突与限制时仍应保留，不能编造反方。默认反方要求及用户明确选择的反方补充保持原有路径。

初次分析、反方补充的来源重建及线索检查使用同一设置，以保持选段和提示哈希一致；证据缺口补充沿用该设置。用户的选择和提示哈希继续记录在运行记录中。关闭反方要求只改变该任务的完成条件与提示，不声称相关冲突不存在，也不改变引用、计算、未知和来源校验。

提示词变化可能改变模型行为及选段预算。按用户要求，本次不调用模型、不运行测试或模型实验，效果和兼容性尚未验证；之后如获授权开展质量对照，需固定任务集、来源、参数和预算，单独记录本次变量。阶段 B 尚未完成。
