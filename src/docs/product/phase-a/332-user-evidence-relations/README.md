# 332：用户记录结论与数值的关系

在现有按相同原文位置自动提示关联之外，用户可为已保存结论添加已保存数值，明确标为支持或反对。关联写入研究版本、证据关系记录及完整导出；不自动把用户判断当作来源事实、语义核验或计算证明。用户可移除关联，单条结论最多保留 20 项。

服务端只接受本版本及上一版本中唯一、关键内容未变化的数值标识；结论文字、角色或引文变化，或数值、期间、单位、来源与位置变化时，旧关联不自动沿用，并记录被省略数量。模型生成不能伪造用户关联；只有相同结论及未变化的数值才允许继承先前用户关联。添加关联前需先保存结论与数值，以获得稳定标识；历史版本不改写。

该功能尚未测试或执行浏览器检查。关系是否合理、来源是否充分仍需核对；用户要求暂停测试及模型实验，阶段 B 状态不变。
