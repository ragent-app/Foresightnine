# 歧义引文的上下文修订

当一段结论引文在资料中有多个匹配位置时，用户在编辑最新版本的结论时可以展开候选位置、核对原文，并选择将当前显示的连续上下文替换为待保存引文。选择只修改本地草稿；保存时服务端重新检查资料权限和引文位置，仍可能出现歧义，也不证明语义支持。上下文与原引文不一致或合并后超过 1000 个 Unicode 字符时不提供该按钮。旧版本与已保存内容不会被自动改写。

修复了长引文选项及长来源标识使移动端研究工作区横向溢出的问题。Web 类型检查及 282 项现有测试通过。Browser 插件不可用，使用 Playwright、本地内存测试 API 和模型替身，在 1280×900 与 390×844 检查候选选择、保存后定位和刷新重开；控制台无页面错误，移动端无横向溢出。截图位于本机临时目录 `/tmp/foresight-ambiguous-desktop.png` 和 `/tmp/foresight-ambiguous-mobile.png`，不是生产数据或真实模型质量验证。
