# 同值数字的指标归属提示

292 号 GDP/GDI 样本中，一条反方把引文中属于上一季度 GDI 的 1.6% 同时用作 GDP 数值。此前若模型未提取相关数字事实，单凭相同数值和季度出现在引文中，未必能提示这个归属问题。

现在对有限的 GDP/GDI 英文表述，如果结论明确把一个百分比归给某指标，而唯一定位的引用及紧邻句首把相同数字用于另一指标的两季度比较，且其他引用中没有同指标、同数值的明确表述，系统提示核查指标归属。提示不会断言结论错误；不同原文可能另行支持该数字，且相同数字仍不能证明期间、单位或语义。此类警示阻止研究直接标为完成，模型复查不能清除警示；编辑引用后重新计算，原结论与历史版本保留。

对 292 原始 BEA 输出[离线重放](replay.json)命中该反方，没有新增模型调用，也没有修改原评分。证据模块、模型复查及模拟 API 测试和 Web 类型检查通过；模拟测试还覆盖添加另一条明确 GDP 引用后不再出现该提示，但结论仍非独立核验。该规则只覆盖有限的指标和措辞，不证明其他事实无误或阶段 B 已通过。
