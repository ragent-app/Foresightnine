运行前固定实现提交、数据哈希、输入选段与提示哈希、模型支持的参数以及脚本，采用 263 的原有机械评分，另检查是否启动复查、各条主张及其原文。评分器对商品和服务的词语匹配不能确认它们属于消费而非进出口，不能单独证明语义支持；复查模型判断也不是独立证据。单次比较有模型和供应商波动，不能归因推广，且这些资料早已用于开发，不是独立验收。若其中一项未完成、调用终态或用量不明，保留事实并停止，不重跑补齐成绩。
