# 复查预算对照：运行前登记

使用 263、266 号已用于开发的同一 GDP 问题与 BEA 原件，在同一当前实现、模型、提取快照、生成及复查提示、参数、工具权限和无搜索条件下运行两次。唯一有意改变的变量是每项研究的总 Token 预算：分别为 10,000 与 20,000；每次最多一次生成和一次批量复查，合计最多四次调用、30,000 Token。单次调用超时 60 秒、每项 120 秒，不自动重试；状态或用量不明即停止。记录每次实际调用、耗时、用量及未知美元费用，不将未知费用记为零。此前已知累计 291,515 Token，另有未知历史用量及未知美元费用。

运行前固定实现提交、数据哈希、输入选段与提示哈希、模型支持的参数以及脚本，采用 263 的原有机械评分，另检查是否启动复查、各条主张及其原文。评分器对商品和服务的词语匹配不能确认它们属于消费而非进出口，不能单独证明语义支持；复查模型判断也不是独立证据。单次比较有模型和供应商波动，不能归因推广，且这些资料早已用于开发，不是独立验收。若其中一项未完成、调用终态或用量不明，保留事实并停止，不重跑补齐成绩。

## 结果与后续修正

两项操作终态均为完成，但研究状态均为 **partial**，原先登记的机械评分均未通过。10,000 Token 条件生成一次、用量 2,479，复查因预算预留不足未启动；20,000 Token 条件生成和批量复查各一次，共用量 3,683，其中复查 1,271。两次合计 6,162，已知累计 297,677 Token；美元成本和更早历史用量仍未知。模型服务的随机性和版本无法锁定；仅两次运行不能证明预算造成了内容质量差异。

两次都引用了消费支出中服务增加、商品减少的原句，而不是进出口对照；高预算样本额外产出带引用的反方条目，模型复查也完成，但对多项带既有警示的主张仅能给出诊断结果。该条目同时声称“来源中不存在反对证据”，模型只看到了原件片段，不能支持对完整来源的这一断言。复查后仅有的相关提示来自另一条因果警示，未覆盖这个来源范围问题；两个结果及模型原始输出保持原样。

后续代码在保留原有引用和语义限制的基础上，增加对“来源中不存在反对证据”等表达的范围警示；使用本次已保存输出离线重放，识别到第 4 条主张，未再次调用模型。该检查依旧是有限模式匹配，未覆盖的表达不能被视为安全；它不证明原文确有反证、不确认反方质量，也不改变 B02、B04、B09 尚未通过的状态。
