# 诊断复查的明确警示

[260 号真实检查](260-guarded-review-live/README.md)中，复查模型对三条带季度或因果警示的主张均回答支持，系统仍强制保留不确定状态。复查方法 v28 在提交给模型的相应主张中加入服务端重新计算的警示说明：季度未在引文中匹配时要求检查期间；缺少因果词时要求检查原因与关系，并明确“没有词语”本身不证明结论错误。

警示说明计入复查输入预算，源材料、引文权限和定位约束不变。模型即使仍回答支持，有效判断依旧为不确定，原有警示不被清除。复查方法版本已更新，历史 v27 结果保留。本次复查与运行测试 46 项通过；暂未调用模型验证该提示是否改变判断，不能视为阶段 B 质量验收。
