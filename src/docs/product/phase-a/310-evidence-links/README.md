# 研究版本中的证据关联基础

阶段 B 系统性改进需要将结论、资料、事实和计算关联起来。此变更在服务端创建研究版本时，从实际保存的结论引文和计算输入生成 `run.evidence_links`，使用当前版本内的索引指向结论、引文和计算，并关联已记录的来源标识。事实只有在来源及原文位置完全一致且事实 ID 唯一时才列为同一段落的候选；计算仅按显式输入事实 ID 建立引用。无位置、事实 ID 缺失或重复时不推断关系；条目数受限且超限时标记截断。

这是从现有记录构建的版本内索引，不保存新的资料正文，不改变原结论，也不声称来源真实、证据支持主张、计算输入正确或反方有效。保存用户编辑和检查点时重新生成，避免客户端传入或旧版本携带的索引覆盖当前内容。历史版本不被改写；后续如需长期稳定标识、任务级关系或针对缺口的研究循环，仍需继续实现。

遵照用户要求，本次不运行测试或模型实验；功能、兼容性和性能尚未验证。它不代表阶段 B 完成。

Web 在已保存、未编辑的版本中展示同原文位置的候选事实及使用这些事实的计算编号；它们不是对结论是否成立的确认。用户存在未保存编辑时不显示该索引，历史版本若没有索引则不展示；截断时有提示。此界面改动尚未运行测试或浏览器验证。
