# 新资料的双来源修订检查

调用前锁定实现提交 `3ad2421`、问题、两份新 PDF、提取文本、参考值、评分程序和预算，见 `manifest.json`。资料来自 BEA 的 [2023 年 9 月公告](https://www.bea.gov/sites/default/files/2023-10/pi0923.pdf)和[10 月公告](https://www.bea.gov/sites/default/files/2023-11/pi1023.pdf)。两份资料此前未作为这项任务的输入，但任务与先前修订表开发样本同类，开发者可见参考值；本次不是盲测、独立人工复核或跨领域质量验收。PDF 当前哈希不证明历史字节一致。

固定条件为一次 `glm-5.3-flash` 调用、最多 10000 Token 和 120 秒、供应商超时 60 秒；不搜索、不进行二次复查或重试，美元费用未知。预登记机械条件要求保留两份来源的 94.0 与 105.1 十亿美元事实、期间、单位和可定位引文，并有一条带两份来源引文的修订关系结论。满足这些条件也不能证明语义或引用充分性。

原结果失败：94.0 的事实从第一份表中提取并定位；第二份只选中百分比表，没有 105.1 的金额事实，也没有满足预登记的跨来源修订结论。模型还把 9 月、10 月所述报告分别说成相应月份发布，而这两份公告实际于 10 月 27 日、11 月 30 日发布；这是机械评分没有覆盖的额外错误。系统标为部分完成，但部分结论将摘录中缺少金额说成公告未提供，仍需核查。此次报告 1813 Token，未重跑模型或修改评分。

`post-fix-v11-diagnostic.json` 是运行后一次尚未提交的候选检索修改在开发中的离线观察；它使既有样本目标片段丢失，随后已撤销。该文件不代表当前实现，也不是重新评分或模型调用。当前代码仍为 `ranked_nonoverlapping_windows_v10`；原问题尚未解决。

其后提交的 `ranked_nonoverlapping_windows_v11` 改为先压缩 PDF 水平空白再对片段排序，并将选中范围映射回原始文本；针对金额和前月问题增加有限的表格标题候选。保存的原始资料、偏移和引文仍以原提取文本为准。[离线诊断](post-fix-normalized-selection.json)显示本次及前次两份双来源材料的目标数字已进入所选片段，P24/P25 的目标月度和年度段落也在固定预算内被选中。该修复没有修改原模型成绩或再次调用模型，列对齐、发布日期表述和语义理解仍需实际验证。

后续新增的有限发布日期差异检查，对已保存响应离线识别了两条把报告月份写作发布日期的表述；见 [候选提示记录](publication-date-warning-diagnostic.json)。该检查只比较部分明确的中英文日期写法与单一所引来源的声明发布时间，日期可能指其他文件，来源声明本身也可能有误；它不自动判错，也不能发现所有日期错误。旧评分保持失败，没有新的模型调用。
