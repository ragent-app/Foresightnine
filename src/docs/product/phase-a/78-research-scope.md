# 研究范围进入研究运行

阶段 B 规格允许用户指定研究对象、期间和期望成果。此前主题契约和存储已有 `scope`，但研究运行只使用 `question`，会静默忽略通过 API 保存的范围；Web 也没有范围入口。

现在 Web 创建研究时提供可选范围，并在打开主题时展示。运行时将范围作为用户问题的一部分传入模型和资料片段选择，受既有不可信用户输入、来源权限、预算与截止时间约束；未填写范围时，提示内容维持原样。运行输入快照记录非空范围的 SHA-256，不在快照额外复制其明文；主题本身继续保存明文，供所有者打开和导出。来源搜索仍使用问题文本；范围仅在研究运行中使用。片段选择方法标识更新为 v20，不能保证所选片段覆盖所有范围要求或模型会遵循范围。

相关 API 分析及运行测试 115 项通过；Web 280 项测试和类型检查通过。本地内存服务及测试账户的浏览器检查覆盖桌面与手机视口的范围输入、创建请求和保存后显示；未调用真实模型。本次未改变以往模型实验的输入或成绩，也不能据此认定阶段 B 的语义质量通过。

后续增加了可选的范围搜索开关，见 [资料发现中的研究范围](80-scoped-source-discovery.md)；默认搜索仍只发送问题。
