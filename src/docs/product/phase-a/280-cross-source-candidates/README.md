# 跨来源比较的待核查证据候选

278 号研究把 94.0 和 105.1 写进同一修订关系，但只引用了后一份公告；两项数值的独立事实及位置已保存在研究中。现在对于有比较或修订表述的结论，如果其两个数值来自同一跨来源差异候选，且当前有效引文至少覆盖其中一项，可从另一份已授权、时间符合要求的来源提出唯一定位的另一项事实作为候选，并标出未引用的数值。只采用未由用户改写、原文位置与数值一致的事实；重复值、来源权限不足、不同期间或缺少有效引文时不建议。

候选**不会自动加入引用，也不代表结论已获支持**。数值与标签相同仍可能对应不同主体、单位、统计口径或修订关系；保留已有的来源、原文和 `requires_semantic_review` 标记，并利用研究工作区已有的候选证据展示。用户修改事实或来源不再符合条件时，候选随研究版本重算，历史版本不变。
