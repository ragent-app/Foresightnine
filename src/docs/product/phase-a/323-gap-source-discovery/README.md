# 323：证据缺口的可选来源发现

本次在已有缺口补充流程中增加一次可选的来源发现，以研究问题和已记录的未回答子问题或待核查结论组成有限长度的查询，不针对特定公司、行业或措辞。只有用户单独勾选授权，才会向搜索服务发送该查询；其中可能包含模型或用户写入的私人研究内容。取消搜索或缺口补充、切换账户或主题时，界面清除该授权。

搜索最多额外调用一次，总搜索预算上限为两次；沿用服务端次数、时间和取消约束。设置费用上限但无法事先确认搜索费用时不发起调用。结果最多作为未核验来源线索保存，去除 URL 查询参数，不自动获取、分析或传给模型；用户需要自行选择资料并授权其后续处理。依据声明发布日期过滤历史时点只是初步过滤，不证明发布日期可靠。

搜索前保存运行检查点并标记状态未确定，搜索返回后保存线索、计数和状态；中断或外部服务费用未知时不能保证没有发生调用或计费，也不自动重放。记录查询哈希而非明文，但哈希不能保证对低熵内容保密。无缺口、不支持、预算不足、部分、失败等状态分别呈现，未完成的请求保留为研究缺口。

本改动及生成的接口类型尚未执行测试、浏览器检查或真实模型和搜索调用；不表明该能力或阶段 B 已通过验收。用户当前要求暂停测试和模型实验，解除后再按阶段集中验证。成本、实际数据来源授权以及跨任务质量仍需另行核实。
