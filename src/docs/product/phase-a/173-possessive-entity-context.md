# 引文前的所属实体

对复查上下文的合成检查发现：原文 `River's revenue increased 5 percent` 若只引用 `revenue increased 5 percent`，原规则因引文含指标词而不提示被截掉的实体，可能把子公司的收入错误归给母公司。

现在对有限的英文大写实体所有格及常见财务指标，在原文可定位且允许展示时提示引文前的所属实体；若另一条有效引文已完整覆盖该实体，则不重复提示。复查输入将该部分作为必要上下文，仍与实际引文分开，不能把主体上下文直接当作被引用的事实。研究页面以“引文前的所属实体”提示核查；存在提示的研究仍标为部分完成。规则并不覆盖所有实体名称、语言、所有格和指代，也不判断引用是否支持结论。

相关证据、复查和研究运行测试以及 Web 类型检查、285 项测试通过。Browser 插件未提供；使用 Playwright 和本地内存 API、模拟模型，在桌面及 390 像素宽度验证提示、原文位置和无横向溢出，未调用真实模型。复查方法标识更新至 v23，历史结果不改写；本次不改变 171、172 号评估结果，也不能证明阶段 B 的语义核验完成。
