# 修订对照的来源预算与原文片段

在两个来源、明确要求修订原因且来源声明的发布时间依次较早和较晚时，为后一个来源分配较多输入预算；日期只是未经核实的检索线索，反序、缺失或其他任务仍按原规则分配。对有限的 GDP 和收入修订表述，如果同一资料中找到带指标、数值与版本标识的原文片段，以及同一句中方向相反且互相抵消的修订原因，优先保留两段独立原文；预算不足、表述不匹配或歧义时回退原排序。两段使用同一来源标识，首次片段携带标题与声明时间，均标为部分覆盖。方法版本 `v28`。

对第 100 项 GDP 固定输入的离线重放，在 2055 字节预算中使用 2041 字节，保留第二次估计 2.8%、第三次估计 3.1%，以及出口和消费上修被库存下修部分抵消的原文，三个片段分别为 371–535、386–536、843–1003（后两段属于第二份资料）。政策题仍在 2054 字节内保留目标区间和主要考虑因素。首段与第二段均是部分摘录；匹配词语或标题不证明来源、数据口径、因果关系或结论语义正确。

合成测试覆盖双来源预算、原文偏移、冲突方向、句子边界和预算不足；相关研究分析与运行测试共 132 项通过。此次未调用模型，既有评估分数不变；模式以英文少量常见表述为限，其他语言、跨句原因或来源顺序不同仍可能遗漏，须继续验证泛化及模型质量。
