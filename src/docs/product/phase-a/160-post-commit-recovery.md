# 结果提交后的进程中断验证

在一次性 PostgreSQL 容器中增加故障测试：研究结果、终态与响应已在数据库事务中提交，工作线程尚未更新本地缓存时，立即终止整个进程。新进程读取同一账户和操作，确认状态为完成、研究版本及原文引用仍存在、模型用量已结算；以相同幂等键重放请求，确认返回原操作、未创建额外版本，且测试供应商仅被调用一次。

新的提交后中断测试通过；与已有的受理事务中断、供应商调用前、生成中、复查中及结果事务提交前场景一起运行，六项 PostgreSQL 中断测试全部通过。首次尝试因临时数据库尚未执行项目迁移而失败；加载两项现有迁移后重跑通过。测试使用供应商替身和单节点临时数据库，不证明真实供应商不会重复计费、生产数据库高可用或全部故障边界均已覆盖。临时容器已停止；没有真实模型调用。
