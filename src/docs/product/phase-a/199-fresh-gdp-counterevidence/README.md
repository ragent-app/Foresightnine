# 新资料上的事实与反方检查：预登记

目的：在 v40 检索修正后，用此前未使用的 BEA 2024 年一季度 GDP 第二次估计 PDF 检查真实研究及反方引用。题目询问真实 GDP 年化增长率，并核查商品和服务消费是否都上升。参考答案与题目分存，参考答案不输入模型。来源为美国经济分析局 2024 年 5 月 30 日发布的[官方文件](https://www.bea.gov/sites/default/files/2024-05/gdp1q24-2nd-fax.pdf)，快照和哈希固定；公开数据使用仍按来源矩阵约束。

沿用上一实验的模型与支持的生成参数，固定来源、问题、提示、版本和预算：最多 4 次模型调用、总计 20,000 Token、单次 60 秒、运行 120 秒、不搜索、不重试；实际费用未知则如实记录。生成后启用独立模型审查，记录全部输出与调用。机械条件要求有准确可定位的 GDP 数值、服务增加及商品下降反方引用，且每项主张有完整定位；还需检查引用是否真正支持主张以及期间和口径。关键词与定位通过不等于语义通过。

该单项任务不能代表全领域质量，也非独立盲测。人工验收按用户要求跳过，不把缺失的人工基线、正式独立测试集或质量阈值说成已经完成。

## 结果

按预登记条件执行，实际调用 2 次、报告 2,670 Token，累计已知报告用量 225,509 Token，另有历史未知用量；美元费用未知。运行完成但研究状态为部分完成，机械条件未通过：回答没有给出 1.3% GDP 数值，也没有识别服务增加、商品减少。原文相关段落在字符 2658 附近，未进入所选模型输入。

更严重的是，模型将消费数据向下修订描述为对“两者均增长”的反证；向下修订本身不意味着下降，也不能反驳两项均增长。独立审查输出包含这一语义限制，但其 verdict 和备注不一致，程序将审查标为失败，未将其当作通过。所有原始输出、来源及定位保留，既有评分不因后续修复而改变。此结果不支持宣称 B02、B04 或 B09 通过。
