# 跨领域候选测试预登记

两题分别使用 [Pfizer 2024 年 SEC 10-K](https://www.sec.gov/Archives/edgar/data/78003/000007800325000054/pfe-20241231.htm)的衍生收入事实、[BLS 2024 年 1 月 CPI 公告](https://www.bls.gov/news.release/archives/cpi_02132024.htm)的衍生通胀事实。BLS 直接程序化请求返回 403，未重试或绕过；事实依据官方可读公告整理，输入不是原始公告。SEC [允许复用公开申报内容](https://www.sec.gov/about/webmaster-frequently-asked-questions)；[BLS 版权说明](https://www.bls.gov/opub/copyright-information.htm)将其发布材料列入公共领域，已知版权照片和插图除外，并要求标明来源。这些说明不证明完整历史版本、全部第三方材料或任意商业用途。

题目、资料数值与参考值对开发者可见，模型此前未使用这两份输入；样本为非盲的独立候选，不代表独立人工核验或总体质量。调用前固定当前代码提交、输入、参考项、评分和运行脚本哈希。每题最多一次模型调用、10000 Token、120 秒，合计两次；不搜索、不复查、不重试外部调用。只对同一 operation 重试只读状态查询，不确定时停止后续题目。美元成本未知。

每题预先要求全部参考数值、期间、单位、来源位置和可定位支持性引文；P01 必须有 6.84% 确定性计算，B01 必须分别保留月度季调及 12 个月未季调口径；预先定义不明百分比扫描和程序检测的计算差异为待核查。所有机械项通过才称机械通过，不能据此声明任意自然语言语义或全领域质量已验证。不针对该集的结果调参再重算同一测试。

结果：P01 的 2023/2024 收入、6.84% 确定性计算、来源定位及预算通过机械条件；研究因缺乏引文充分的反方仍为部分完成。B01 的模型原始输出包括 0.3% 与 3.1% 两条有可定位原文的事实，但另一条引文并非提供文本的连续原文，旧实现拒绝了整份输出，故 B01 的原预登记机械结果为失败。两次分别报告 968 和 1048 Token；美元费用未知。模型输出及原评分已保留，未重新调用或重算原成绩。

后续产品修正后，对同一已保存 B01 原始响应做离线重放：两条有依据的数值和两项可定位主张得以保留，带虚构引文且无其他有效引文的主张被移除并提示缺口。该重放不是新一轮独立测试或原评分通过，见 `B01-post-fix-replay.json`。
