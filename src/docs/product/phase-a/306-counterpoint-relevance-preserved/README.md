# 保留截断提示的反方相关性对照：运行前登记

305 号替换整个反方请求时遗漏了已截断结论的提示，无法隔离相关性措辞的影响。此次仍以 292 政策样本的已保存首次生成和补充调用为对照，保留原提示全文及截断提示，仅在 `counterpoint_request` 末尾追加一句：同意原结论或信息缺口本身不是反方。问题、资料、选段、输出结构、系统提示、模型和支持参数均固定；提示及输入哈希见 manifest。此题已用于开发，不是独立盲测；供应商内部版本和调用随机性无法锁定。

仅一次真实补充调用，最多 10,000 Token、60 秒；不搜索、不重新生成初始研究、不复查、不重试。调用前已知累计 335,796 Token，其他历史用量及美元费用未知。终态或用量不明即停止并保留结果。预先检查解析与引用、是否提出相关有据的反方或限制、是否编造动机或将摘录缺口扩大为全文缺口；不能以有引用或警示减少证明语义。仅当候选给出有引用的相关反方或限制、无明显新增事实错误且保留原有来源边界时才考虑引入产品。原始结果和评分不覆盖，一次非盲对照不能证明泛化。

## 结果

候选调用完成，供应商报告 **1,706 Token**，新增后已知累计 **337,502 Token**；更早用量及美元费用未知。对照有一条以同意原结论开头的有引用反方；候选也给出一条可定位引文，明确记录两位反对者偏好降息。但候选声称“原结论遗漏了反对者偏好”，而完整初始研究的第三条结论已包含这一点。补充提示只纳入前两条并注明可能截断；模型仍把该截断视图误当完整结论。候选还对完整来源是否包含动机作概括，而模型只读了部分摘录。

因此候选没有满足预先登记的无明显错误条件，**不引入产品提示**。引用与反对票事实可定位不证明其所谓“遗漏”成立，且一次对照不足以证明泛化。原输出、[离线检查](inspection.json)和评分保持不变，本次揭示了需要单独处理的截断结论范围风险。
