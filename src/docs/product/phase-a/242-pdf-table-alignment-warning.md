# PDF 布局表格的列对齐提示

原有表格列对齐提示主要识别带竖线的 HTML 表格；PDF 的 `layout` 提取文本即使包含多列数值，也可能被视为普通段落，导致事实旁缺少列对齐风险提示。

现在对于原文中唯一定位的引文，若来源是按布局提取的 PDF，且引文所在行具有文字标签及两个以上由布局空格或制表符分开的数值单元，将其标为 `table_alignment_unverified`。多行引文逐行检查；用户编辑和保存时也重新计算提示。该检测只是有限的版式线索，不证明表格结构、财年、单位或事实正确，也可能漏报或误报；阅读顺序提取不使用该线索。它沿用现有表格的警示行为，并不声称已经自动验证计算输入。

对 238 号已保存模型输出及原始资料的离线重放，五条保留数值事实均显示对齐待核查；这不改变原运行记录或失败结论。研究计算、分析、真实资料和主题编辑测试通过；无新增模型调用。
