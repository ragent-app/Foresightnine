# 355 研究运行容量与资料分页（离线验证）

本记录区分用户主动设置的预算、供应商已证实的能力和应用内的处理上限；旧实验和已保存研究不因新策略被改写。研究调用数、搜索调用数、累计 token、时间和费用在请求中省略时目前为 `None`，显式数值或零仍应遵守；单次请求的超时、取消、权限、来源隔离和并发保护不等于用户运行预算。

实施前盘点：

- 供应方通用 policy 默认输入 3,000，研究环境变量 `FORESIGHTNINE_RESEARCH_MAX_INPUT_TOKENS` 若设置限定 1–12,000；请求 `max_input_tokens_per_call` 亦上限 12,000。输入预算函数还将提示限制为至多 48,000 UTF-8 字节。字节预算是保守估计，不是该供应商上下文的测量值。历史实验所用 6,000 是实验设置，不是已证实的模型容量。
- 一次资料准备最多 20 个来源，每源最多 8,000 字符、总共 10,000 字符；候选最多 512、选择组最多 32、替换候选前 64 和最多 4 轮。这些局部资源边界不能被误称为全部资料已经研究，应为多页处理及未处理状态提供明确路径。
- 单次请求的来源 ID 列表当前各有 100 项上限；成果容器还存在来源、事实和主张等有界容量。改变处理方式时须处理持久化、增量合并、来源权限、引用原文范围、恢复和超出容器容量时的明确状态，不能只提高数字。
- 当前新运行采用无固定步骤次数的 `round_strategy`，旧版 schema 2 续接保留 7 个动作的兼容限制。不得把旧恢复策略误称所有新运行的默认。
- `FORESIGHTNINE_MODEL_CALL_QUOTA` 的默认 20 是按账户/IP 等 subject 的 24 小时累计调用配额；它不是用户设置的研究预算，也不同于真正的并发或瞬时滥用保护。账户计费配额、速率/滥用保护及未知价格的费用限制需要分别如实处理，不能靠取消安全保护宣称无限。
- provider 能力配置目前描述端点、模型、版本和结构输出方言，没有已证实上下文窗口；不能把某个历史运行的 6,000 或 12,000 当作供应商真实容量。未确认容量、分词估算误差、外部服务拒绝和未知结算须如实保留，不能扩大权限或重放未知调用。

本轮不涉及生产部署、现有账本修改或历史实验重跑。

## 实施与离线检查

研究默认不再设置人为输入或输出 token 数；未知提供方容量保持未知，已配置且适用的容量与用户显式输入、调用和总量预算仍单独处理。请求体完整 UTF-8 字节用于保守预留估算，不能称为供应商实际分词。托管账户继续在调用前检查可用额度；发送后用量未知应保留预留，不伪造实际消费。个人供应方与托管账户权限、真实账本、超时取消和来源隔离保持。

来源与候选按工作页处理，保留已读范围、剩余范围和来源绑定；后续研究可以在未读完全部资料时继续按任务选择，同时展示未读缺口。分页合并按调用作用域映射证据、事实、计算和问题引用；恢复时核验来源与权限，未知外部调用不自动重放。资源保护页大小不表示用户运行预算，也不代表全部材料已处理。

离线组有重叠，不合计为全套通过：runtime 初组有 16 项失败和 1 项跳过，随后受影响 23 项中 20 项通过、3 项旧预期失败；后者按新语义修正后 3 项定向通过。分页与托管初组 19 项中 17 通过、2 失败；两项分别为测试桩误将取证决策当分析和来源绑定失效的剩余范围表示，修正后定向两项通过。真实 API 两个不同来源连续授权 read 的离线测试 1 项通过。HTTP 503 发送后未报告用量时，初始检查发现终态观察器错误释放预留；修正后该项定向复验通过，预留保留且不自动重发。

实际 staging.env 白名单只读检查：总单次请求超时配置 120 秒，研究输入、每日模型调用配额及能力 profile 未设置；文件内容不证明正在运行的进程采用该配置。本轮没有修改部署、重启服务或发真实模型请求。

供应商 `/models` 未提供已核实的上下文容量时保持未知，不填入猜测数值。旧 CLI 适配器无托管账户额度约束时可执行；若托管账户额度存在而适配器无法约束输出，则明确拒绝，不能据此宣称所有供应商兼容。本轮未部署或进行真实模型验收。
