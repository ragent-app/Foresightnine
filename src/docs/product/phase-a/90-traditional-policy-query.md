# 繁体中文政策查询与基点提示

第 89 号政策任务使用繁体中文提问；既有部分查询映射及“目标利率区间”意图只覆盖简体或较窄的表述，选中了准备金与贴现率段落而非所问的联邦基金决议。现在仅在检索意图中对有限繁简字符作归一，原始问题、资料和引文位置不改写；同时识别中英文目标区间与未来政策措辞。片段方法标识更新为 v24。该有限映射不能覆盖所有繁简字形或理解所有指标。

第 89 号输出中的 `75個基點` 此前也未被基点提示识别。现支持简繁体“个／個”“点／點”和对应百分点写法；缺失引文时仍只是待核查提示，不判断事实或方向。离线检查第 89 号固定政策输入，在原输入预算中选中了目标区间及持续加息措辞；对已保存输出识别了未获引文覆盖的 `75個基點`。本次没有新模型调用或修改原 0/2 成绩，离线片段可见性不证明模型质量。

研究分析、运行、原始文档和证据测试 155 项通过，覆盖繁体问题、基点提示、原文偏移和输入预算。
