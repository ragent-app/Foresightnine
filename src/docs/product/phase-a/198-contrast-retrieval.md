# 对照句检索修正

197 号真实资料实验中，原始 BEA 文件同时包含服务业增加 491 亿美元和商品减少 100 亿美元的句子，但 v39 选段没有将其送入模型。该次预先登记的实验仍为未通过，本次修正不改变原结果。

v40 在问题明确请求反方、风险或相反证据时，有限扫描原文中同时出现至少两个与问题相关的指标、两个数字及相反变化词的句子，优先考虑完整保留这些句子的原文窗口。此规则只是检索线索，不判断句子是否构成反证；实体、时间、口径和语义仍须复核。所有引用继续使用原始文本偏移。扫描范围、候选数和取消检查均受限。

离线检查确认 197 保存的 PDF 对应目标段落进入新选段，原文偏移可定位；此前银行压力测试开发样本的 12.4%、9.9%、抵押贷款、信用卡和商业地产风险仍在模型输入中。相关分析、原始文档、运行及核验测试通过。没有因此次离线检查调用模型。197 已用于定位和开发，不能当作独立测试集，也不能据此认定 B02、B04 或 B09 已通过。
