# 有界证据缺口补充

研究运行新增默认关闭的 `gap_followup` 选项。用户选择后，系统依据已记录的缺引文、证据警示或复查不支持等通用状态，最多选择三条条目，结合原问题重新检索本次已授权资料，并最多进行一次额外模型调用。原结论文本仅作为未可信的上下文，不能当作系统指令或已确认事实；不会将其发送给外部搜索服务，也不会添加新的资料权限。没有可用缺口或预算时，不发起补充调用。

补充前保存原研究检查点；模型调用在既有调用、Token、时间和费用边界内预留并结算。结果独立检查来源与引文，保留原研究，补充的事实分配唯一标识并重映射计算输入，无法安全重映射的事实和计算明确省略；反方到新增结论的模型建议保持待核查。来源选段按两次调用分别记录，不能用两次选段的并集误认为任一次模型读过全文。无法完成时保留原成果与状态，费用可能未知。

补充目标、状态、调用用量和提示哈希保存在运行记录；工作区由用户明确启用并提示可能产生额外调用。结果仍需按通用规则审查，补充调用完成不证明缺口已解决。该能力暂时只检索已授权材料，未实现按缺口外部发现资料，也不能发现所有未记录缺口或替代研究规划。

根据用户要求，本次未运行测试、浏览器检查或模型实验。API 模式快照和 TypeScript 类型按实现生成，不属于功能测试；整个流程、兼容性、恢复和模型质量尚待后续授权后集中验证。阶段 B 尚未完成。
