# PDF 重新提取的幂等与响应丢失恢复

重新提取接口可接收 `Idempotency-Key`。同一账户和请求标识通过存储锁串行化创建；同一原文件及读取方式重试返回同一来源，不同原文件或读取方式复用该标识返回冲突。旧调用者不传标识时保留原有行为。权限、模拟标记、原文件校验和及账户隔离继续生效；未提供或已清除标识的独立请求仍可能创建另一份来源。

工作区在发起提取前生成标识并保存在当前浏览器标签页的会话存储，不存凭据；刷新后重试同一资料会复用该标识。提取已创建但添加主题响应丢失时，页面先查询最新版本，确认已附加后继续，不再创建额外版本。会话存储不可用时仅保留内存中的重试信息，关闭标签页或丢失标识后不能保证复用。

验证覆盖单进程并发、不同账户隔离、同键不同请求冲突、原文件哈希异常、旧无键调用及生成契约；临时 PostgreSQL 跨进程重启与两个独立进程并发均通过。临时数据库第一次准备时，`pg_isready` 在数据库创建前返回就绪，测试未启动；改用数据库查询确认后通过并清理容器。Web 类型、客户端测试和契约生成检查通过。本地 Playwright 使用测试账户和原始 PDF，分别模拟提取响应与添加响应在服务端提交后丢失：刷新重试复用同一来源，添加阶段通过读取最新版本恢复，均未创建重复来源或版本。Browser 插件不可用；测试中的网络失败控制台消息为预期，临时服务已停止。未调用真实模型，也不改变研究质量验收结果。
