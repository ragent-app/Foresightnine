# 新资料上的片段选择修正验证

在 M01 保留题失败并用于修改片段选择后，选用另一份未用于此前模型调用的 [BEA 2022 年 GDP 初值原始 PDF](https://www.bea.gov/sites/default/files/2023-01/gdp4q22_adv.pdf)，检验能否同时定位全年和第四季度数据。题目与资料在相关失败后选定，且参考值对开发者已知；该运行是修复验证，不是独立盲测或总体质量验收。2026 年取得的 PDF 不证明历史文件未被修订。

运行前固定代码提交、输入、来源哈希、参考答案及评分/运行脚本哈希；最多一次模型调用、10000 Token、120 秒，不搜索、不复查、不重试外部调用。固定要求包含两项有正确单位、期间与可定位引文的事实，支持性结论有可定位引文，至少两个不重叠片段，预算内完成。语义支持、完整性和历史可得性不由机械分数证明；单价与货币费用未知。

来源获取记录：先尝试错误的连字符路径 `gdp4q22-adv.pdf`，单次请求返回 `HTTPError`，当时未记录具体状态码；随后从 BEA 公开页面和检索结果确认下划线路径 `gdp4q22_adv.pdf`，对该正确路径单次请求成功。两次请求各未重试，成功文件及哈希记录在对应来源清单。

结果：一次调用报告 978 Token，两个片段均被选中，但未覆盖所需的全年数值，机械检查失败；模型如实报告片段缺口，研究为部分完成。该运行已用于排查，不再作为独立测试，也没有重跑。
