# 财务表格的多指标检索

年度财务表格检索由收入扩展到明确指定的经营活动现金流、营业利润、净利润及毛利润。仅在问题包含两个不同年份、单一可识别指标且不是明确的季度或利润率任务时使用该路径；多指标、季度、利润率或无法识别的任务回退通用检索。针对单位位于年份下方的表格，优先保留当前表格附近的单位；遇到明显的正文分隔或距离过远的单位则不按该路径配对。选择方法为 `v29`。

在固定 2055 字节预算下，对此前用于开发的 NVIDIA 2023 SEC HTML 正文提取做离线检查：经营现金流、净利润、毛利润和原收入问题均选中了对应行、两年列及百万单位。该文本来自原始 HTML 的提取，表格分隔符由系统生成；这只是选段检查，不证明列、币种、会计口径或模型结论正确，也不是新的独立测试或新模型调用。

合成测试覆盖多项指标、单位位于表头后、跨正文分隔、远处单位、季度及多指标回退；分析、运行和原文文档相关测试共 149 项通过，补充边界专项测试通过。不同文件可能使用不支持的表格结构或别名，仍须查看原始申报及来源上下文。
