# 固定输入的财报与宏观自动检查

调用前固定实现提交、四题输入与参考值、资料及提取文本哈希、运行程序、评分程序、模型参数、调用顺序与预算，见 `manifest.json` 和 `references.json`。四题分别运行：Visa 净收入、United Airlines 总营业收入、BEA PCE 公告、美联储利率声明。每题最多一次供应商调用、10000 Token、120 秒，总计最多四次；模型为 `glm-5.3-flash`，供应商调用超时 60 秒，不搜索、不做二次复查、不重试不确定的外部调用。美元费用未知；程序在状态不确定时停止后续题目。

前两题是按公开 SEC 10-K 整理的结构化事实，不是完整原始申报文件： [Visa](https://www.sec.gov/Archives/edgar/data/1403161/000140316124000058/v-20240930.htm)、[United Airlines](https://www.sec.gov/Archives/edgar/data/319687/000010051725000046/ual-20241231.htm)。后两题使用本次获取的原始 [BEA 公告](https://www.bea.gov/sites/default/files/2025-05/pi0425.pdf)和[美联储声明](https://www.federalreserve.gov/monetarypolicy/files/monetary20241218a1.pdf)。各来源的公开复用条件、例外与限制见[来源矩阵](../03-source-inventory.md)；当前 PDF 的哈希不证明历史字节完全一致。原始 PDF 与提取文本分别固定，不把衍生事实题与读原文题作为同一能力。

预登记要求四题均满足所需数值、期间、单位、可定位引文、相关上下文、指定确定性计算及预算；无法判断的项不当作通过。扫描中公式的“除法 × 100%”系数不当作模型宣称的结果，其他非预期百分比要求核查。对每题分别保留结果和机械评分；机械通过不能证明所有主张的语义、真实历史可得性、完整文档覆盖或投资效果。

这四份输入没有用于此前提示词或规则调整，评分程序固定后才调用模型；但开发者知道公开题目和参考值，没有独立人工复核、人工耗时基线，也不能声称盲测或 A4 正式总体验收。按用户要求不等待人工验收，缺失的人工证据仍如实记录。此次结果不用于对同一测试集调整提示词、实现或阈值后重新计分。

预登记结果：四题均未达到全部机械条件，原成绩 0/4。V24 两项事实和 10.02% 确定性计算正确，但模型将 JSON 内无空格省略号当作引文，原实现未定位该引文，结论未保存；U24 两项事实、6.23% 计算和支持引文可定位，但另一条引文无效，且事后发现模型正文将 57,063 百万美元错误表述为 57,070.63 亿美元，这是原评分脚本未覆盖的金额单位错误；P25 选中的原文片段未包含所需的 PCE 环比及同比正文；F24 主张引文可定位且降幅事实可用，但模型把目标区间放入一个不能解析的单值字段，两个区间端点未作为结构化事实保留。所有运行均为部分完成，语义支持未独立核验。四次分别报告 996、1145、1225、1060 Token，合计 4426 Token；金额费用未知。

后续如修复程序或做离线重放，只作为开发记录，绝不修改本次冻结评分或冒充新的独立测试。

后续修复仅使用已保存输出和原文做离线诊断，没有再次调用模型，也没有重新评分。无空格省略号只在同一片段中存在唯一、有序且跨度受限的连续原文时展开；F24 的显式利率区间拆为两个带原文位置的端点，引用仍需语义核验。U24 中错误的人民币式中文美元金额现在可作为待核查候选提示：仅覆盖有限的中文美元单位，且要求同一主张中另有能够匹配、未编辑的有来源结构化金额作为锚点，不构成通用金额或语义验证。

增加来源片段覆盖状态后，一次离线诊断发现 PCE 月度段落因预算缩小再次落选，记录保留在 `P25-post-fix-coverage-diagnostic.json`。随后 `ranked_nonoverlapping_windows_v7` 在固定输入预算下针对特定月度、年度比较语句增加有限锚点；`post-fix-v7-selection-diagnostic.json` 显示 PCE 的月度和年度段落以及原 GDP 样本的季度和年度段落均入选，来源覆盖仍明确为部分。这只检查定位，不证明模型能够正确解读。原四题机械成绩保持 0/4。
