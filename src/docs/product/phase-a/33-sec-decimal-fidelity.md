# SEC 结构化数值精度

SEC company-concept 的 JSON 小数现在使用十进制解析，并在生成的来源文本中输出等值 JSON 数字，避免经过二进制浮点后静默舍入。原响应哈希仍单独保存；生成文本是经过筛选的结构化资料，不是原始申报文件全文，旧来源与研究版本不改写。涉及超过 1000 位有效数字或指数绝对值超过 1000 的十进制观测会被省略，并在来源文本披露；这些上限用于限制异常输入。

77 项相关 SEC、分析和计算测试通过，包括精确小数及极端指数；测试通过模拟 SEC 响应进行，未发出真实 SEC 请求。精确传输不证明财务口径、期间归属、可得时间或公司识别正确，也不改变先前模型评估结果。
