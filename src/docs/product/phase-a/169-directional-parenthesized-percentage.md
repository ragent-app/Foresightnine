# 有明确方向的括号百分比

168 号研究的原文写作 `increased $23.7 billion (0.1 percent)`，现有数字解析因为单位位于括号内而遗漏 0.1，错误提示该百分比未被引用。现在仅在相邻的明确上升或下降动词及受支持格式下识别括号内的百分比，按动词区分方向；没有明确方向的括号百分比继续保持歧义，裸数会计括号仍按既有规则处理。数值匹配不能证明指标、时间或结论语义正确，其他表达仍可能漏检。

对 168 号保存的原结果离线重新准备复查输入，修改前索引 0 因未引用百分比提示被跳过；修改后六项均满足当前机械送审条件。未再次调用模型或改变历史结果、原始复查响应及原评分。模型此前返回了未提交的索引，复查拒绝结果仍然有效；只有未来实际调用才能评估是否改善，不可倒推本次语义正确。

复查方法标识更新为 v21，以区分新的送审条件；历史记录保留原方法。测试覆盖上升、下降、无方向括号、会计负数及未引用提示，并运行研究分析、证据、计算和复查相关 API 测试。初次测试中一个会计括号断言使用了既有解析不支持的句末标点形式，改成既有可解析形式后通过；没有借此扩大本次实现范围。阶段 B 仍未完成质量验收。
