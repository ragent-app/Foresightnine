# 331：多来源结构化数据的预算分配

结构化事实提取此前按来源顺序消耗总数上限：前两份资料较长时，后续资料可能完全没有事实进入研究，影响多公司和多指标比较。现在先对每个有授权、被本次运行选中的受支持来源分别提取有限观察值，再按来源顺序轮流分配总数预算；保留来源内部顺序、原文定位、期间、单位和身份。单来源或总预算存在有效观察值未纳入时，返回截断状态并在研究限制中说明。

此变更适用于结构化适配器接口，当前接入的仍是已有 SEC 公司指标快照；不会额外请求外部数据，也不把不同公司、指标或期间自动视为可比。已有数据连接器可能在提取前已限制返回记录，提取阶段的未截断状态不能证明来源数据完整。范围、使用许可、日期和财务含义仍需检查。

按用户要求未运行测试或模型实验。多来源分配、预算边界、数据和原文定位尚待集中验证，不改变阶段 B 状态。
