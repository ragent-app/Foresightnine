# 双来源修订关系研究：运行前登记

以 29 号已用于开发的任务和两份保存的 BEA 原始 PDF 检查同一指标初值与后续修订。两份资料发布于不同时间，数值变化可能是修订而非同一时间的互相矛盾；须分别保留来源、发布时点、指标期间、单位与修订关系。固定当前实现、资料及提取哈希、问题、选段、模型及支持参数、生成和复查提示。每项研究最多一次生成和一次批量复查、两次调用、20,000 Token；单次超时 60 秒、总计 120 秒，不搜索、不重新下载、不重试。终态或用量不明则停止。此前已知累计 313,227 Token，另有未知历史用量及未知美元费用。

沿用 29 号的事实与跨来源修订关系机械要求，预算条件适配本次两次调用；额外记录反方及复查状态。按来源原文检查值、期间、单位、发布日期和每条引用的语义；数字共现和模型复查都不能证明语义。资料和答案已被开发者查看，当前实现、预算和模型调用数也不同于 29 号；该运行是非盲开发回归，不能归因于某次修改或算作独立验收。原始输出、评分和失败均保留。

## 运行结果与离线修正

操作完成，生成和复查各一次，共 **3,342 Token**；已知累计 **316,569 Token**，另有未知历史用量及未知美元费用。研究为 `partial`，预登记机械检查未通过：两个数值均作为事实及可定位引文保留，但没有一条修订关系结论同时附上两份来源的有效引文。模型把部分表头和数据拼成原文中不存在的连续引文，相关结论被丢弃。它另给出带引用的反方，但引文只是后一份表头，不能据此证明其对两份来源或“没有反证”的概括；模型复查对该条给出不确定。

后续修复两处遗漏：跨来源数值候选可识别标签末尾格式明确且日期合法的发布日期及修订限定，仍保留原标签、期间和 `requires_entity_and_method_review`；对只分析部分来源却作无范围限定的“没有反对性证据”断言增加来源范围警示。使用原结果[离线重放](replay.json)得到一项待核查差异候选，并提示第 2 条主张；无新模型调用，历史结果和机械评分不变。候选数值不同并不自动证明冲突、修订关系或相同统计口径，均需核对原件；词法提示也不能覆盖全部说法。此开发回归不改变 B02、B04、B09 验收状态。
