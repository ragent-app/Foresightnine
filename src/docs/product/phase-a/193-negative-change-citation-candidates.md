# 下降金额的候选引文

真实研究中，反方可能提到来源中的下降金额，却漏引对应原文。对已定位且标记为方向待核对的负向金额或百分比事实，若主张也明确写出相同的下降方向和幅度，系统现在可以把同一已引用来源中的事实原文作为候选引文。候选仍标记 `requires_semantic_review`，不会自动加到结论，也不证明指标、期间、币种或因果解释；重复值、来源权限不足、位置歧义、否定或幅度不符时不推荐。

美元下降识别增加对“fell in nominal terms ($… billion)”等有限表达的支持；仍只作为方向待核对线索，不能单凭它确认负值或用于计算。用户可在工作区查看并主动添加候选原文，添加后生成用户版本且仍未独立核验。若还有其他缺口，不能将整条反方视为已充分支持。

对 182 号已保存的供应商输出离线重放，候选列表包含商品支出下降 96 亿美元的原文和另一项价格变化原文；这没有证明反方的经济解释，亦不改变原始实验结果或评分。自动测试覆盖候选与否定、不同数值、重复事实及权限，并通过研究 API 验证添加引文后的版本与未核验状态；本次没有真实模型调用，阶段 B 尚未完成。
