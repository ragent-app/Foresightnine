# 季度引用缺口的候选原文

292 号 GDP 研究有部分主张写出季度，但其所附引文没有对应期间；同一研究的其他引文中存在相关季度。现在可将同一来源、唯一定位且包含相同季度和年份的其他研究条目引文列为候选，不自动附加，也不清除原来的期间警示。同季度可能对应 GDP、GDI 或其他不同指标；候选仅按期间匹配，不证明数值、对象、指标口径或语义一致。

工作区改为逐条添加候选引文，避免一次把同季度但不同指标的全部原文附加到结论；用户保存后仍保留“用户编辑、来源支持未独立核验”标识。相关权限、唯一定位、保存及用户添加的 API 测试通过，Web 类型检查通过。Browser 插件及其 skill 未提供，使用本地 Playwright、一次性模拟 API 在桌面进行选择并保存，验证两个同季度候选中只添加所选一条；移动视口无横向溢出、无页面错误。测试未访问真实用户数据，临时服务已停止。
