## Runtime and authenticated API

The frozen direct native-runtime run used eight cases and a scripted writer with no functional semantic reviewer: all eight returned partial, with empty report and unresolved core parts. Thus all 4/4 unsupported candidates were withheld, and all 4/4 positive controls were also withheld. Eight runs consumed three local scripted writer calls each; total measured run time was 0.2891 s excluding startup. [Native results](frozen/candidate-native.json).

A separate authenticated local HTTP probe used the same four paired questions and sources, a scripted native writer and the blind development-model judgments replayed through the real review interface. All eight operations completed. Four unsupported candidates were partial and appeared in neither saved version nor export; three supported controls completed with the answer, and the ambiguous positive control was withheld by the reviewer. Each used two scripted writer calls and one scripted reviewer response (24 local calls total); operation timestamps sum to 0.5553 s. The tests do not establish real provider latency or cost. User-supplied source text remains available according to its permissions; rejected candidate claims were not promoted. [Sanitized API outcomes](frozen/candidate-api.json) retain statuses and checks without temporary local authentication tokens.

Twenty-five targeted offline tests passed on the same copied application: semantic-review binding and invalidation; restart, recovery and budget preservation; unknown external result and action replay prevention; stop/cancellation and revoked-source handling; FRED/source permission denial and unauthorized metadata; clarification, same-turn continuation and account privacy; and personal-scope tests. These are the assertions of those tests, not exhaustive lifecycle or privacy proof. A Starlette/httpx deprecation warning was emitted. Earlier in integration the authenticated probe exposed a `user_receipts` NameError; the subsequent fix is included in this snapshot and the final probe completed. No paid or external provider calls were made. Scripted writer and reviewer cost was zero; cost and latency for the separately invoked development-model judge were not recorded and must not be inferred as zero.

No conclusion is drawn here about natural autonomous research, live BYOK/provider review quality, external search privacy, real-source licensing or availability, independent human adjudication, population accuracy, browser/mobile usability, investment outcomes, or repeat paid calls under real service failures. Zero unacceptable severe errors in these cases alone does not establish the broader release criteria. Actual end-to-end evaluation and any provider or publication action require their own evidence and authorization.
