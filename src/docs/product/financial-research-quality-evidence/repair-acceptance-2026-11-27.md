## 审核不可用时的交付

可逐字定位的数值和能独立复算的结果可以自动交付。混合问题只交付已核实内容，涉及前提、政策或个人建议的判断仍须有相应依据。合并重复句子时保留依据、条件和例外。受控案例包含加密资产、个人投资条款和宏观主题。

债券样本复用了 11 月 23 日报告的原句。原运行没有持久化逐条裁决，回放中使用显式构造的裁决检验呈现和去重。另在独立 PostgreSQL 16 实例上验证取消后重开，以及提交检查点后强制终止进程再恢复，两条路径均未重复外呼。

## 工具重传、耗时与未决项

在相同的三轮工具调用里，旧工具结果重复携带的内容从 24,035 字节降至 671 字节。最新工具结果、调用 ID 和协议要求的原生消息保留。每阶段记录模型和工具耗时、供应商返回的 token 用量、缺失用量的调用数、截断及重试。重复字节数单独计量。

24 个固定研究任务使用模拟模型和工具，每次调用分别注入 15 毫秒延迟。独立运行中，24 项均通过四项质量检查。每项并行平均耗时 266.218 毫秒，串行平均耗时 401.838 毫秒，速度比 1.51，关键路径上的平均模型轮数减少 41.67%。此前两次测量的速度比分别为 0.95 和 0.98，低于原有 1.2 门槛，耗时结果受运行环境影响。尚无六家银行真实模型对照的端到端耗时或费用结论。

银行取数、估值、同行比较、报告归档、导出及模型协议的组合回归共 68 项。研究运行时、证据呈现与多轮研究回归共 119 项通过。其中一个中断恢复用例暴露了子问题答案丢失的问题，修复后可从已核实的原文恢复已取得的数值，并保留尚待核验的判断。SEC 限流用例改为逐一核对当前所有收入标签各请求一次，并核验只重试一次。

Web 报告交互 9 项通过，V2 契约生成一致性检查通过。全量 Web 类型检查仍有 10 处错误，与干净基线的文件、行号与诊断一致。更广的 API 回归还有 3 个在修改前即可复现的模型请求参数或退避断言失败。本轮未修改这三项断言或性能验收阈值。
