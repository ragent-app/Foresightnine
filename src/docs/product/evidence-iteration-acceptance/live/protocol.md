# 真实模型配对预登记

基线 82900b4，候选为通过验收而实际启用的产品代码。使用既有授权的 Messages 研究实验配置，匹配同一注册的 endpoint、模型及能力，不切换账号。仅发送自编 J1/J4 财报题，财报首批完成后扩展 J2 合同、J3 行情。两题每臂两次，顺序 J1 ABBA、J4 BAAB，然后 J2 ABBA、J3 BAAB。单并发、固定开发时点、全工具定义、材料与权限；每臂 6 次模型、0 搜索、18 万总 token、160 秒、每请求至多 4096 输出 token 和 80 秒。禁止外部资料获取，供应商专属采样参数不发送。使用隔离的源码快照及只创建一次的启动凭证，遇到未知结果先对账，不能重发。上轮三次 429 后优先查用量回执、限流提示和已授权账户状态；无服务恢复证据时维持暂停。若有恢复依据，仅启动预登记的首个单臂。再次限流或发生未知外呼，立即停批。单方失败保留在完成率分母，不计算配对胜率。首批未形成可评分结果不扩展。

J1 两项分别为 5% 增长及价格 3/12=25%，其余驱动未知；J4 两项为下降 10% 及不能由处置前营收 8 推断下降贡献。J2 核对实际通知方、书面通知/补救期限及取消例外与订单履约状态，J3 核对两个标的同期价格及收益差。各项必须有足够的可定位依据。按版本中的最终分项和回答判定。预设改善条件为两臂均有可判回答、B 的有据分项数增加且错误归因和关键反证遗漏无新增；分别报告实际调用、输入/缓存/输出回执、时延及未知费用。只对已配对样本解释差异。
