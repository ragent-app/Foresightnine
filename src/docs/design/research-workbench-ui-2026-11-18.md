## 1. 设计原则

1. **对话是主工作面。** 任何宽度下，中间的问答流都是唯一的主区域。其余信息按需打开，不与问答争夺注意力。
2. **先说状态，再给细节。** 每个回答先说明完成、部分完成还是中断，再给内容；细节放进二级面板。
3. **一次只给一个明确的决定。** 部分完成时只有一个主按钮“继续研究”，其他操作收进“更多”。
4. **部分成果也是交付。** 报告为空时，仍然展示已取得的数字、计算和缺口。
5. **可信度分层可见。** 结论有角色标签，引文点开可查原文，候选线索与证据分开显示。系统只核对了引文位置和数字，没有核对语义，界面上要说明这一点。
6. **安静。** 底色为白色，配色低饱和，颜色只用于表达语义和主要操作。完成时不打扰用户，需要用户决定时才突出提示。

### 2.2 材质

**玻璃配方**（只有这一种，所有玻璃表面通用）：
- 底色：`glass` 或 `glass-strong`；
- 背景滤镜：`backdrop-filter: saturate(180%) blur(24px)`，另加 `-webkit-` 前缀版本；
- 内侧高光：`inset 0 0 0 1px glass-edge`；
- 外边线：`0 0 0 0.5px hairline`；
- 投影：
  - 小投影 `0 6px 20px rgba(20,24,33,.06), 0 1px 2px rgba(20,24,33,.04)`，用于输入框和状态条；
  - 大投影 `0 12px 40px rgba(20,24,33,.08), 0 2px 6px rgba(20,24,33,.04)`，用于面板、浮层和菜单。

**哪些表面用玻璃**：
- **用玻璃的**：只有浮在内容上方的表面，即顶栏、输入框、运行状态条、输入框上方的快捷标签、二级面板、引用浮层、菜单、登录卡片。
- **不用玻璃的**：问答正文、问题气泡和左栏都不用，玻璃上面也不再叠玻璃。面板内的分组列表用不透明度较高的 `group` 底色，保证文字对比度。

**降级**：
- 系统开启“减少透明度”（`prefers-reduced-transparency: reduce`），或浏览器不支持 `backdrop-filter` 时，所有玻璃表面改为不透明的 `surface`，并去掉模糊。
- 投影和分隔线保持不变。

### 2.3 字体

- **字体栈**：`Inter, "PingFang SC", "Hiragino Sans GB", "Noto Sans CJK SC", "Noto Sans SC", "Microsoft YaHei", ui-sans-serif, system-ui, sans-serif`，开启 `-webkit-font-smoothing: antialiased`。
- **Inter 加载方式**：使用本地文件，从 Ragent 的 `static/chat/fonts/InterVariable-latin.woff2` 复制，许可为 OFL，许可文件一并复制。

### 2.5 动效

- **时长与缓动**：普通状态变化 120 至 180 毫秒，曲线 `cubic-bezier(0.2, 0, 0, 1)`；面板、侧栏和浮层使用苹果式的弹性曲线 `cubic-bezier(0.32, 0.72, 0, 1)`，时长 320 毫秒，浮层为 180 毫秒。
- **面板进入**：宽屏从右侧移入 24px 并淡入；窄屏从底部上移 28px 并淡入。
- **浮层和菜单**：从 0.97 放大到 1，同时淡入。
- **侧栏收起**：网格列宽从 264 变为 0；内容区宽度、输入框和顶栏一起平滑过渡。
- **顶栏**：大标题滚出视口后，小标题淡入并上移 4px，顶栏的玻璃底色同时出现。
- **按钮按下**：缩放到 0.98。
- **分段控件**：选中项的底色和阴影过渡 180 毫秒。
- **减少动效**：系统设置减少动效时，关闭面板动画、状态圆点的呼吸动画和按钮缩放。

## 3. 布局

### 3.1 第一层（常驻）

```
宽屏（900 以上）
┌────────────┬──────────────────────────────────────────────┐
│[F9]  ✎  ▯  │ ▯ ✎（仅侧栏收起时）  ·小标题（滚动后出现）·   ▯ ⋯ │ ← 顶栏，滚动后变为玻璃
│ 搜索        │                                              │
│ 今天        │   大标题：研究问题                              │
│ · 研究 A    │   截止 … · v3 草稿 · 2 轮                       │
│ 本周        │            第 1 轮 · 今天 13:22                 │
│ · 研究 B    │                         [ 问题气泡 ]            │
│            │   回答 …                                      │
│ 设置        │   补充上一轮的缺口  寻找反方证据                  │
│ 退出登录    │   ( + │ 继续追问…            │ ⚙ │ ↑ )  ← 玻璃输入框 │
└────────────┴──────────────────────────────────────────────┘
```

- **左栏**：
  - 宽 264，`surface-low` 底色。
  - 顶部依次是：品牌标记、“新研究”图标按钮、“收起侧栏”图标按钮。
  - 下面是搜索框，然后是按“今天 / 本周 / 更早”分组的研究行，底部是设置和退出登录。
  - 收起后列宽变为 0，顶栏左侧出现“展开侧栏”和“新研究”两个图标按钮。收起状态按用户保存在本地存储里。
- **顶栏**：
  - 高 52，覆盖在内容区顶部。
  - 内容区顶部还在视口里时，顶栏是透明的，也不显示标题。大标题滚出视口（滚动距离超过 56）后，顶栏中间淡入单行小标题（13.5 / 600），同时出现玻璃底色和底部的 0.5px `hairline`。
  - 右侧是“研究记录”和“⋯”两个图标按钮。“研究记录”在面板打开时显示为选中状态，再点一次关闭面板。
- **大标题**：
  - 研究问题，28 / 600，字距 −0.02em。换行用 `text-wrap: pretty`，不用 `balance`，避免中文在词中间断开。
  - 下方是元信息（13 号字）：截止时间、版本和复核状态、轮次数。
- **输入框**：
  - 玻璃材质，固定在内容区底部，上方有 44 像素的渐变，从透明过渡到 96% 的 `surface`。
  - 输入框上方是建议操作，显示为一行文字链接（12.5 号字，`on-variant`），例如“补充上一轮的缺口”“寻找反方证据”，不再用标签形式。
- **900 以下**：
  - 左栏改为从左侧滑出的抽屉，宽 `min(300px, 86vw)`。
  - 顶栏左侧固定显示“展开侧栏”和“新研究”。
  - 大标题为 24 号字。

### 3.2 第二层（按需打开）

| 面板 | 打开入口 | 内容 |
| --- | --- | --- |
| 研究记录 | 顶栏按钮；回答下方的摘要标签；关键数字；运行状态条 | 页签：结论 / 资料 / 数字 / 过程 |
| 资料阅读器 | 引用浮层的“查看原文”；数字条目；资料条目 | 原文、引文高亮、元信息、权限、上一处 / 下一处 |
| 研究设置 | 输入框的设置按钮；“⋯”菜单 | 截止时间、范围、联网搜索、自动获取官方资料、本轮读取的资料、预算（折叠） |
| 添加资料 | 输入框的“＋”；拖入文件；“⋯”菜单；资料页签；候选线索的“获取原文”；部分完成提示块的“更多” | 文件 / 文本 / 网址 / SEC 数据，时间，使用权限，是否会被读取（见 4.10） |
| 复核与版本 | “⋯”菜单 | 复核状态、你的总结、复核备注、版本历史、保存为新版本 |
| 我的模型 | 设置页“模型”中的“编辑” | 协议、服务地址、模型名称、API Key、测试连接 |

**面板形态**：
- **1280 以上（检查器形式）**：浮动的玻璃面板（`glass-strong`），宽 420，与视口上、右、下边各留 12，四角均为 22 圆角。
  - 打开时，内容区、顶栏和输入框的右边界一起左移 432，内容重新居中。
  - 不加遮罩，问答流仍然可以滚动和操作。点击研究记录中的结论时，面板保持打开。
  - 无障碍角色为 `complementary`。
- **900 至 1279**：同样的浮动面板，但覆盖在内容上方，加很淡的遮罩，无障碍角色为 `dialog`。
- **900 以下**：从底部弹出的玻璃面板，高度上限 88%，上方两角 20 圆角，顶部有 36 × 5 的拖动条。

**面板结构**：
- 头部：标题（16 / 600）和关闭按钮（30 圆形，`fill-2` 底）；
- 页签：分段控件样式，底为 `fill-2`，选中项为白底，带细投影；
- 内容区：可以滚动；
- 底部：操作按钮，主按钮在右边。

**关闭方式**：Esc、点遮罩（有遮罩时）、点关闭按钮，或再次点顶栏的“研究记录”按钮，都可以关闭面板。关闭后焦点回到打开它的那个控件。同一时间只开一个面板，从一个面板跳到另一个时直接替换。

### 3.3 浮层与菜单

- **引用浮层**：
  - 打开方式：点击正文中的引用编号；
  - 位置：锚定在编号下方，下方空间不够时显示在上方；
  - 宽度：`min(340px, 视口宽 − 32px)`；
  - 样式：玻璃材质（`glass-strong`），16 圆角，大投影；
  - 内容：资料名称、引文、字符位置、核对说明，以及“查看原文”和“深挖这条引用”两个按钮。
- **菜单**：
  - 样式：玻璃材质，14 圆角，内边距 5；菜单项高 36、圆角 9，悬停时底色为 `fill-2`；
  - 顶栏“⋯”菜单：复核与版本、研究设置、研究记录；分隔线；导出完整记录（JSON）、仅导出元数据；
  - 部分完成提示块的“更多”菜单：交付已有成果、补充缺口、添加资料。
- 窗口大小改变时，关闭浮层和菜单。

### 3.4 设备适配

**适配断点**：

| 宽度 | 典型设备 | 布局 |
| --- | --- | --- |
| 1280 以上 | 桌面、大屏笔记本 | 左栏常驻，可以收起；二级面板为推开内容的检查器 |
| 900–1279 | 笔记本、iPad 横屏（1024、1180） | 左栏常驻，可以收起；二级面板覆盖在内容上方，加淡遮罩 |
| 600–899 | iPad 竖屏（768、820）、大屏手机横屏 | 左栏为抽屉；二级面板从底部弹出，有两档高度；引用和菜单仍为浮层 |

| 高度 500 以下且为横屏 | 手机横屏 | 顶部留白缩小，大标题 20，隐藏输入框上方的建议链接，二级面板高度上限 94% |

**通用规则**：
1. **安全区**：
   - 页面 viewport 声明 `viewport-fit=cover`。
   - 顶栏顶部、左栏抽屉、输入框底部、底部面板和底部操作菜单分别加上对应的 `env(safe-area-inset-*)`。
   - 横屏时左右两侧也要避开安全区。
2. **视口高度**：使用 `100dvh`；不支持的浏览器回退到 `100%`。
3. **软键盘**：
   - viewport 加 `interactive-widget=resizes-content`，键盘弹出时，固定在底部的输入框跟着上移。
   - 输入框获得焦点时，问答流保持在原来的滚动位置，不跳动。
4. **触屏设备**（`pointer: coarse`），参照 Apple HIG 的 44pt 点击区域：
   - 图标按钮 40，发送按钮 34，按钮高 40，左栏研究行和菜单项 44，分段控件选项 34，引用编号 20；
   - 所有输入框文字设为 16，防止 iOS 聚焦时自动放大页面。
5. **底部面板两档高度**：
   - 研究记录和资料阅读器先以 58% 的高度打开；点顶部的拖动条，在 58% 和 92% 之间切换。
   - 其他面板按内容自适应高度，上限 88%。
   - 后续实现可以加拖动手势，但必须保留点击切换的方式。
6. **底部操作菜单**（600 以下）：
   - “⋯”和“更多”菜单改为 iOS 式操作菜单：贴底部显示，左右各留 8；
   - 选项组和“取消”分成两个 14 圆角的玻璃组；
   - 每个选项高 56，文字 17 号。
7. **引用**（600 以下）：点击引用编号，打开一个按内容高度显示的底部小面板，内容为引文、位置和核对说明，底部是“深挖这条引用”和“查看原文”两个等宽按钮。
8. **首页**（600 以下）：
   - 标题距离顶部 12% 视口高度，示例问题在标题下方；
   - 输入框固定在屏幕底部，位置与追问时一致，方便单手操作。
9. **输入框上方的建议链接**（600 以下）：单行横向滚动，不换行，隐藏滚动条。
10. **左栏抽屉**：
    - 宽 `min(320px, 86vw)`，从左侧滑入，背后加淡遮罩，点遮罩关闭；
    - 打开新页面时自动关闭。
11. **设置页的行**（600 以下）：右侧按钮放不下时换到下一行。

**验收截图尺寸**：320×640、360×800、375×667、390×844、430×932、844×390（横屏）、768×1024、1024×768、1440×900。每个尺寸都检查浅色和深色模式，以及空状态、运行中、部分完成、面板打开四种状态。

### 4.2 研究首页 `/research`（同时作为新研究入口）

- 内容居中，宽度上限 680，距离顶部 16% 视口高度。
- 标题“你想研究什么？”，30 / 600，居中。
- 输入框与追问时用的同一个组件，最少 3 行：
  - 左边“＋”添加资料，右边研究设置和发送按钮；
  - 发送按钮在问题和资料都为空时不可用。
- 已设置的非默认选项（资料、截止时间、范围、预算）以标签显示在输入框内的第一行，每个标签都可以点 × 移除。

- 提交流程不变：创建主题 → 用同一个幂等键启动第一轮 → 跳转到主题页。

### 4.3 研究主题 `/research/:topicId`

**顶栏和大标题**：见 3.1。“⋯”菜单的内容为：复核与版本、研究设置；分隔线；导出完整记录（JSON）、仅导出元数据。

**轮次时间**：每轮开头居中显示一行小字（11.5 号字，`on-tertiary`），格式为 `第 N 轮 · 今天 13:22`，样式类似 iMessage 的时间戳。

**问题**：右对齐的气泡，底色 `fill-3`，20 圆角，最大宽度为正文宽度的 80%（窄屏 90%）。

**回答（完成）**：左对齐，不加卡片，自上而下为：
1. **状态行**：彩色文字“完成”，后面是元信息 `4 次模型调用 · 12,480 Token · 3 分 02 秒`。
2. **报告正文**：引用编号嵌在句子里，是 20 高的圆形标签，悬停或打开时变为主色。编号在主题内全局连续，同一段引文复用同一个编号。
3. **关键数字**：本轮的计算结果，最多 3 个，格式为数值（22 / 600）加说明（12）。点击后打开研究记录的“数字”页签。
4. **结论列表**：每条一行，左侧是 36 宽的角色文字（“支持”“反方”“待复核”），右侧是结论文字和引用编号。
5. **核对说明**：12 号字，“系统已核对引文位置和数字；结论是否被引文充分支持，需要你判断。”
6. **摘要**：一行文字链接，例如 `4 条结论 · 2 个数字 · 2 项计算 · 过程 5 步 ›`。每一段都可以点击，打开研究记录中对应的页签。

**回答（部分完成）**：
- 状态行用彩色文字“部分完成”。
- 下面一句由界面生成的摘要，例如：“已记录 2 个数字，完成 1 项计算，还没有形成可引用的结论。”
- 有关键数字时照常显示。
- 接着是“未完成的部分”提示块：16 圆角，`warning-tint` 底色，标题用 `warning` 色并带 7px 圆点，正文用 `on-surface`。块内依次是：
  - 最多 2 条缺口，其余缺口在研究记录里查看；
  - 停止原因；
  - 主按钮“继续研究”：恢复检查返回 `can_continue` 时显示；不能继续时改为“重新提问”；
  - 次要按钮“更多”。
- 最后是摘要链接。

**回答（中断或已取消，且没有保存新版本）**：状态行用 `error` 色的文字“运行中断”或“已取消”，下面是恢复原因（见 6.4），按钮规则同部分完成。

**运行中**：
- 输入框上方出现运行状态条：玻璃材质，40 高，20 圆角。
- 状态条内依次是：
  - 蓝色呼吸圆点；
  - “研究中 · {当前步骤}：{理由摘要}”，来自 progress 接口的 `current` 和最新事件；
  - 用量 `3 次调用 · 1 次搜索 · 2:14`（窄屏不显示）；
  - “取消”按钮。点击后按钮文字变为“正在取消…”，不弹出确认框。
- 点击状态条其他位置，打开研究记录的“过程”页签，并定位到当前轮次。
- 运行期间输入框不可用，占位文字为“本轮研究进行中，可以先取消再提问”。
- 屏幕阅读器只播报状态变化，例如开始、结束、中断，不播报每一步。

**输入框**：
- 样式：玻璃材质，24 圆角，小投影，内边距 6。
- 控件依次为：添加资料（36 圆形图标按钮）、文本框（15.5 号字，1 至 8 行，随内容增高）、研究设置（36 圆形图标按钮）、发送（32 实心圆形按钮）。
- 输入框上方一行建议链接：
  - “补充上一轮的缺口”：上一轮有缺口时显示；
  - “寻找反方证据”：存在支持性结论时显示。
- 在引用浮层里点“深挖”后，输入框内的第一行出现一个“深挖引用 N”标签，可以点 × 移除。
- 发送按钮在输入框为空时显示为浅灰色，有内容后变为实心黑色。
- 发送：Enter 换行，Ctrl/⌘ + Enter 发送。
- 存在未保存的复核修改时，发送前提示：“发送新问题前，先保存复核修改吗？”选项为“保存并发送”和“放弃修改并发送”。

### 4.5 资料阅读器

- 头部显示资料标题。
- 信息块是一个分组容器，内容为：类型、获取方式和时间；权限；当前引文的字符位置和核对说明；`sha256` 前缀（等宽字体）。
- 正文：16 号字，行高 1.8。当前引文用 `mark` 底色高亮（4 圆角），其他被引用的片段只加 1px 下划线。
- 底部：“上一处”“下一处”，以及“打开原始 PDF”。
- 资料不允许展示原文时，正文区域显示：“这份资料不允许展示原文。”
- 长文本先加载引文前后各 2,000 字符，提供“加载更多”。

### 4.6 研究设置面板

- 顶部说明：“默认设置适合大多数问题。这里的修改只对下一轮生效。”
- **截止时间**：日期时间输入框。只能在创建主题时设置；在已有主题里打开时只读，并说明“主题创建后不能修改”。
- **研究范围与期望成果**：多行文本。
- **联网搜索**：分段选择“开启 / 关闭”，**默认开启**（2026-11-19 用户决定），始终以布尔值提交 `discover_sources`。不提交 `null`：后端把显式 `null` 视为调用方输入并按关闭处理（`resolve_automatic_research_request` 只补全未提交的字段）。下方说明“搜索结果只作为线索，获取原文后才能作为证据。”
- **本轮读取的资料**（仅已有主题）：资料复选列表，默认全部（不提交 `selected_source_ids`）；取消勾选后提交所选列表，可以为空。不会被读取的资料不可勾选，并写明原因。显示“已选 X / N 份可读取的资料”，超过 20 份时提示超出部分不会处理。新添加的资料在已收窄的选择中自动加入。
- **自动获取官方资料**：分段选择“自动 / 关闭”，对应 `auto_fetch_official`。
- **预算（可选）**：默认折叠，展开后两列排列。各字段与后端参数的对应关系同 v1：模型调用、搜索次数、Token、运行时长（分钟，提交时乘以 60）、费用（美元，以字符串提交）、单次输入 Token。预算区底部说明：“留空表示不设上限；0 表示该项额度为零。单次请求超时和供应商限制仍然有效。”
- 底部按钮：“取消”和“应用”。

### 4.7 复核与版本面板

- **v3 的复核状态**：分段选择“草稿 / 已确认 / 保留意见”。选择“保留意见”时，复核备注为必填。
- **你的研究总结**：对应 `summary`，下方说明“研究 Agent 不会改写这段内容。”
- **复核备注**：对应 `note`。
- **版本历史**：每个版本一个条目，格式为 `v3 · 时间 · 研究 Agent · 完成`，并提供“对比”。对比在面板内展开，显示新增、删除、修改的结论，以及数字和计算的增删。
- 底部主按钮“保存为新版本”。运行进行中时不可用；遇到 409 冲突时提示：“研究在你保存前已经更新。请刷新后重新应用修改。”
- 编辑结论的入口在研究记录的“结论”页签：每个条目都有“编辑”，可以修改文字和角色；修改后的结论标注“你修改过”。
- **实施细节（M4）**：
  - 未保存的修改（复核状态、备注、总结、结论文字和角色）保存为“对最新版本的补丁”，关闭面板不丢失；新一轮研究、添加资料或新建计算产生新版本后，补丁仍按结论 ID 应用到最新版本，不必重做。
  - 保存时以最新版本内容为基础，只替换总结和改过的结论，轮次、资料、线索和缺口原样提交（后端拒绝修改这些服务端记录）。
  - 有未保存修改时，大标题元信息显示“有未保存的修改”，点击打开本面板；版本标签本身也可点击打开。
  - 结论页签顶部提示“N 条修改还没有保存。去保存”；改过的条目显示“未保存”和“撤销”。
  - 版本历史每行下方是与上一版相比的一行摘要（新增第 N 轮、结论新增 / 修改 / 删除、数字和计算变化、复核状态变化等），“对比”展开逐项明细：新增（+）、删除（−，删除线）、修改（~，旧值删除线后接新值）。
  - 研究 Agent 生成的新版本复核状态回到“草稿”，复核备注沿用上一版（与后端 `ResearchVersionChain` 一致）。
  - **新建计算**（研究记录“数字”页签底部，折叠）：公式分段选择“增长率 / 利润率 / 差额”，两个数字的标签随公式变化（本期 / 基期、分子 / 分母、被减数 / 减数），并说明期间要求。引文需要复核的数字不可选。后端计算并保存为新版本；422 时按原因提示。
  - 旧版本把百分比之差记成百分比的计算显示“需要重新计算”和“重新计算”按钮（`calculations/recalculate`）。百分比之差的单位 `percentage points` 显示为“个百分点”。
  - **确认框**：发送前和离开前的提示使用居中的玻璃确认框（窄屏贴底），主操作在上，“取消”在最后；关闭浏览器标签页时使用浏览器自带提示。
  - **未实现**：事实的方向和表格确认。后端对原生事实一律返回 422（没有可确认的表格元数据），因此界面不提供入口。

### 4.8 设置 `/settings`

参考苹果“系统设置”的写法：
- 大标题“设置”（28 / 700）。
- 下方是分段控件：账户 / 模型 / 数据源。
- 再往下是分组标题和分组容器。
- 内容放在 `surface-low` 底色的 16 圆角分组容器里，行与行之间用 0.5px 分隔线。每一行左边是名称（15 / 600）和说明（12），右边是操作按钮。

| 页签 | 行 |
| --- | --- |
| 账户 | 邮箱和登录方式，右侧“退出登录”；“删除账户”，输入“删除”后按钮才可用 |
| 模型 | 模型来源（分段选择“平台模型 / 我的模型”）；当前配置（协议 · 模型 · 地址 · 密钥状态），右侧显示“可用”或“不可用”和“编辑”按钮，点击“编辑”打开“我的模型”面板。页面底部说明密钥用途。 |

**实施细节（M5）**：

## 7. 交互规则

- **快捷键**：Ctrl/⌘ + Enter 发送；Esc 关闭面板、浮层和菜单；在资料阅读器中按 J/K 跳到下一处或上一处引用。
- **焦点**：打开面板时，焦点移到面板的关闭按钮；关闭后回到打开它的那个控件。弹出提醒不抢占用户当前的焦点。
- **运行进行中**：输入框、复核保存、添加资料、新建计算都不可用。研究列表、各个面板、资料阅读器和导出照常可用。
- **离开有未保存修改的页面**：先确认，选项为“保存为新版本”“放弃修改”“取消”。
- **点击结论**：在研究记录里点击一条结论，面板关闭，问答流滚动到对应位置并高亮。系统设置减少动效时，直接跳转，不做滚动动画。
- **操作入口不重复**：同一个操作只放一个主入口。“继续研究”只出现在提示块里，“取消”只出现在运行状态条上。

### 362 真实验收后的修复（2026-11-19）

依据 [362 验收记录](../product/phase-a/362-web-workbench-real-acceptance/evaluation.md) 的 7 项问题：

1. **模型请求的自动重试**（后端）：请求在写出之前失败（DNS、TCP 或 TLS 阶段，且记录为未发出）时自动重试，默认 4 次，等待 1、2、4、8 秒，受运行时长上限和取消约束；可通过 `FORESIGHTNINE_RESEARCH_PRESEND_RETRIES`、`FORESIGHTNINE_RESEARCH_PRESEND_RETRY_BASE_SECONDS` 配置。原来只覆盖 DNS、TCP，且两次重试间隔只有 0.05 和 0.1 秒；362 中最后一次失败是 TLS 握手超时（请求未发出）却没有重试。已经发出、结果未知的请求仍不自动重试，避免重复外呼和重复计费。过程页签中失败的调用显示为“模型调用失败 · 连接中断 / 请求超时”。
2. **事实记录参数**（后端）：`record_facts` 和结论的字段加了说明（`value` 必填、填纯数字、量级写在 `unit`；字符位置可省略，由系统定位）；参数校验失败时返回逐字段的简短说明，不再返回库的原始报错；引文位置不符时告诉模型引文实际所在位置并建议省略位置。
3. **停止原因文案**：增加 `provider_timeout`“模型服务请求超时”、`provider_transport_error`“与模型服务的连接中断”。
4. **搜索跳转链接**（后端）：搜索结果中的搜索引擎跳转链接（Google `/url?q=`、DuckDuckGo `/l/?uddg=` 等）解析为目标地址；无法解析目标的链接（如 Google `/goto?url=<令牌>`）不再作为线索，单独计为跳转链接，不算作搜索返回格式错误。
5. **部分完成后的主操作**：轮次已由模型提交（`reason` 为 `submitted`）时不再提供“交付已有成果”（后端的重新交付只会以相同内容替换本轮），主按钮为“重新提问”；没有保存轮次的中断运行仍可交付。
6. **平台模型名称**（后端 + 界面）：`/v1/account` 增加 `research_model`（平台研究实际使用的模型），设置页“平台模型”一行显示“研究使用 {模型}”；研究调用在用量账本中按实际调用的模型记录，不再统一记为通用模型。
7. **SEC 能力**（后端 + 界面）：新增 `GET /v2/research/capabilities`，返回各资料能力是否已配置（不含配置值）。未配置 SEC 联系信息时，资料页签的 SEC 线索只提供“打开网页”，添加资料的“网址”页签对 SEC 地址、“SEC 数据”页签给出说明并禁用查找和添加。能力未知时按可用处理，由后端给出最终结果。
