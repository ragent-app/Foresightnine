# ForesightNine 产品介绍与宣传文案

2026-11-27 修订。供官网、产品演示和闭测介绍使用。产品目标以[宏观方案](../product/fusion-finance-ai-macro-plan-2026-11-11.md)为准，具体功能按演示版本标注。

## 一句话定位

**ForesightNine 是为自主投资者设计的个人投资决策 Agent，目标是持续比较投资机会，结合个人持仓分析取舍，并复盘当初的预期与实际收益。**

## 当前研究入口文案

- **标题**：关注的公司，哪些变化值得重新判断？
- **副标题**：比较公司与同业，追踪影响投资价值的走势、新闻和披露，打开原文查看判断依据。
- **入口**：开始研究。
- **示例问题**：“这两家公司的利润率都提高了，哪一家的改善更可能持续？请列出支持和反对的依据。”

## 怎样讲清产品方向

| 投资者关心什么 | 介绍重点 |
| --- | --- |
| 哪家公司或投资产品更值得关注？ | 给投资推荐度一个参照：按什么价格、在多长期限内、相对哪些同行或跨行业机会，以及承担哪些风险。 |
| 对我来说，是否值得补仓或减仓？ | 目标体验会结合用户确认的资金用途、期限、风险承受能力、持仓和现金，对比持有、增减仓及保留现金的方案，说明建议比例与资金来源。 |
| 原来的建议为什么改变？ | 区分公司基本面、市场价格与用户组合的变化，保留原判断及后续证据。 |
| 当初预期的收益实现了吗？ | 目标体验分别展示事前情景、标的实际表现、建议组合的模拟表现，以及由用户记录的成交、费用与现金流支持的账户实绩。 |

## 面向不同用户的介绍

对有多项持仓的自主投资者，从“这次变化影响了我组合里的哪些标的”切入。对还在筛选候选公司的投资者，演示同行业经营对标和跨行业机会比较。独立研究者和小团队可以从证据、反方意见和可导出的研究底稿入手。

## 一分钟演示示例

1. 展示关注名单，提出一个有明确期限的资金取舍问题。
2. 打开一条与持仓相关的新披露，展示原文、反证和估值假设发生的变化。
3. 对照另一家候选公司；如使用规划原型，标明模拟画像、仓位和数据日期。
4. 回到当时的判断，说明哪个条件会触发下一次复核。已有实绩时展示其记录来源，模拟演示保留模拟标识。

## 演示与发布口径

从一个用户会反复遇到的选择开始，例如“新增资金是补现有持仓，还是留给另一行业的候选公司？”先演示当前版本可用的公司比较、证据和变化记录。讲到画像、目标仓位或实绩复盘时，按实际交付标注“规划中”“模拟示例”或已验证的功能范围。只在资料与授权覆盖时展示具体市场、时点和来源。

截图及收益图注明日期、币种、基准和数据性质；假设回报、模拟结果及用户实际收益应清楚区分。FM Raw 与约束后的结果可用于讲解组合模拟方法。用户自行作出投资决定，首版不下单、不托管资金。对外发布个性化建议前，需完成相应地区与数据使用审核。宣传材料不得承诺收益、把研究评级当成上涨概率，或把演示结果当作真实用户业绩。
