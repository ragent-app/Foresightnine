## 1. 核心定位

**ForesightNine 是把高价值信息、投资观点与量化约束组织成可审计世界线的研究工作台。**

它不是交易终端，也不替人下单；它把“我认为会发生什么”变成可被反驳、验证、修订和导出的研究链路：

> 高认知信息 → 反方审查 → 证据分级 → 弱/主/强世界线 → 条件概率 → 因子计算 → 受约束组合路径。

**宣传第一入口：** 面向高阶量化研究者、宏观/行业研究者和主动投资者——不是“找一个涨得最快的标的”，而是把复杂信息转译成可追溯的情景、条件与组合暴露。

**第二入口：** 面向认真做投资决策的个人——不需要先成为量化工程师，也可以用同一套流程，把模糊观点变成能讨论、能复盘、能管理风险的观点驱动组合研究。

## 3. 三段式产品叙事

### A. 先做高价值信息的“翻译器”
一条政策、一份财报、一次产业链变化，真正影响组合的不是信息本身，而是它如何穿过时间、供需、估值与资金行为。ForesightNine 将这些传导写成事件节点，区分事件发生时间与市场可见时间，并让每一个分支都有失效条件。

**可用表述：**
- 从信息噪声中抽取可讨论的传导链。
- 将“观点”拆成可证伪的前提与事件节点。
- 让隐含假设显性化，让关键变化可复盘。

### B. 再做高阶量化研究的“审计层”
系统先以反方审查挑战观点，再将证据保留为可核验来源、日期、摘录、支持/反对方向与等级。世界线以 P(H)、P(W｜H)、P(H∩W) 组织条件判断；模型估计明确标注为未校准，而不是伪装成确定性预测。

**可用表述：**
- 让每一个概率都能追溯到前提和证据。
- 不把模型输出包装成已验证事实。
- 用弱、主、强三种世界，代替单一路径的自信。

### C. 最后才进入观点驱动的组合研究
在市场数据通过校验后，系统进行本地 FM 因子计算，并同时展示 **FM Raw** 与 **Public Default**：前者保留原始研究权重、参数与假设；后者叠加集中度、流动性、冲击与可实施性约束。用户可查看压力情景、组合路径并导出完整研究 JSON 或分配 CSV。

**可用表述：**
- 先理解世界，再讨论权重。
- 原始研究与可实施约束并存，而不是互相覆盖。
- 让观点在组合层面经受弱情景、主情景与强情景的压力测试。

## 7. 产品事实卡（宣传 Agent 可复用）

- 研究流程：观点输入、反方审查、证据登记、世界线、条件概率、因子计算、组合路径与导出。
- 证据不是装饰：候选搜索结果必须由用户查看原始来源、发布时间与原文后才成为证据；不可用时可手动添加，系统不伪造搜索结果。
- 概率不是承诺：世界线以区间呈现，模型估计带有未校准标记，分支可修订。
- 数据不是黑箱：市场数据采用多来源优先级与失败降级；每行检查映射、日期、正价格、币种、新鲜度与形状，缺失保持缺失。
- 组合不是自动下单：FM Raw 保留研究输出；Public Default 添加集中度、流动性、冲击和可实施性约束。
- 模型不是锁定：登录后可使用平台模型，或配置个人 OpenAI-compatible 模型；个人模型调用不消耗平台额度，失败不静默回退。
- 凭据不在前端回显：个人金融数据 Key 与模型 Key 通过 TLS 传输、按账户加密存储，读取只返回掩码提示。
- 研究可留档：完整研究 JSON、分配 CSV、世界线 JSON 可导出。

## 8. 必须避免的宣传表述

不要说：
- “预测市场”“抓住必涨机会”“稳定收益”“跑赢市场”。
- “自动交易”“一键买卖”“智能荐股”“替你配置资金”。
- “概率已经验证”“模型证明了未来”。
- “实时全市场数据”或“生产可用多源行情”，除非生产数据许可、接入与页面状态已经实际验证。

应说：
- “研究、推演、情景模拟、压力测试、组合研究、可审计记录”。
- “模型估计”“待核验证据”“可修订判断”“历史/推断/模拟区间分开标注”。
- “不连接券商、不下单、不托管资金；结果不构成投资建议。”
