# Compliance gates

Public release requires documented market-data redistribution rights and target-region legal review. The initial release scope is research, education and simulation. The [product direction](../product/fusion-finance-ai-macro-plan-2026-11-11.md) includes personalized recommendations, position sizing and portfolio adjustments. Offering those services requires a target-region review covering that specific use. Brokerage execution and custody remain outside the initial scope.
